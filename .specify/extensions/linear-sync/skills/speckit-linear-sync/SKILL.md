---
name: speckit-linear-sync
description: Sync Spec Kit tasks and GitHub issues into Linear.
---

Run the project command `speckit.linear-sync`.

Use this after `$speckit-taskstoissues` and after task completion batches.
Keep `tasks.md` as the implementation source of truth. If Linear says Done but
`tasks.md` is still open, verify implementation evidence before changing the
task checkbox.

All Linear/GitHub issues, comments, project updates, and sync notes must be in
Russian and written in simple language.
