# Graf Logo Assets

Selected direction: larger, thin circular `Ф` symbol with purple equalizer bars.

Folders:

- `boards/` - saved logo exploration boards.
- `boards/raw/` - untouched generated PNGs from the session.
- `variants/` - cropped individual options from the latest board.
- `selected/` - selected `I-1` wordmark and source tile.
- `final-symbol/` - clean SVG and PNG exports for logo symbol, app icon, and favicon in light/dark versions.
- `favicon/` - canonical favicon source, light variant, exported sizes, and previous favicon backup.
- `data/` - selected-route handoff metadata.

Note: the `final-symbol/` SVG files are the current source of truth for the symbol.
