# Graf Final Symbol

Base direction: circular `Ф`-like mark with purple audio equalizer bars.

Use:

- `svg/graf-symbol-light.svg` on light surfaces.
- `svg/graf-symbol-dark.svg` on dark surfaces.
- `app-icon/graf-app-icon-light.svg` for light app icon treatment.
- `app-icon/graf-app-icon-dark.svg` for dark app icon treatment.
- `favicon/favicon-light.svg` and `favicon/favicon-dark.svg` for browser favicon variants.

The PNG and ICO exports are generated from these SVG sources.
