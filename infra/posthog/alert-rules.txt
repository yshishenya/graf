# GRAF analytics alert rules and their named owners (FR-055).
#
# One line per rule. The code is the exact value the guard, the backup task, the
# restore verification task, the retention task or the alert channel check
# emits. A rule without an owner role is a configuration error.
#
# The concrete named owner is never committed: this repository keeps roles and
# statuses only. The operator names the person in the out-of-git environment
# file, for example:
#
#   GRAF_ANALYTICS_ALERT_OWNER_INFRA_OPERATOR=<named owner>
#   GRAF_ANALYTICS_ALERT_OWNER_ANALYTICS_OPERATOR=<named owner>
#   GRAF_ANALYTICS_ALERT_OWNER_PRODUCT_OWNER=<named owner>
#
# When the environment does not name the owner, the alert still goes out and
# carries `alert_owner_unnamed` so the gap is visible in the channel and in
# journald.
#
# Format:
#   rule code=<code> scope=<analytics|host|backup|restore|retention|alerting> \
#        owner_role=<role> severity=<critical|warning> escalate_after_minutes=<n> \
#        requirement=<FR-030|FR-031|FR-032|FR-033|FR-035|FR-036|FR-051|FR-056>
