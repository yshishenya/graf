# UX Checklist: Единый ввод одноразового кода

- [x] Login, signup, invitation, browser-link, and desktop-link flows share one OTP structure.
- [x] Every digit has its own near-square cell with visible keyboard focus.
- [x] Paste, autofill, Backspace, Delete, arrows, Home, and End are defined.
- [x] Incomplete, invalid, expired, resend, and reduced-motion states keep the same slot geometry.
- [x] Desktop and 390px layouts have no horizontal overflow.
- [x] Each slot has a positional accessible label and the group has a clear purpose.
