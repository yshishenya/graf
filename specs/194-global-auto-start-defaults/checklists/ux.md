# UX Checklist: Глобальный автозапуск и defaults

**Feature**: [spec.md](../spec.md)

- [x] Fresh install starts with detection enabled.
- [x] Fresh install selects only verified native prompt-capable targets.
- [x] First detected meeting shows the normal prompt without a pre-detection gate.
- [x] Prompt copy is truthful when timeout auto-start is not authorized.
- [x] «Записать сейчас», «Пропустить» and «Всегда писать это приложение» remain visible.
- [x] Existing user-edited settings are not overwritten on refresh or update.
- [x] VoiceOver/accessibility text states whether automatic start is available.
