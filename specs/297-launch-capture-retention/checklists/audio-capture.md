# Audio Capture Checklist: F297

**Purpose**: Validate capture-continuity requirements before implementation
**Created**: 2026-11-17
**Feature**: [spec.md](../spec.md)

- [x] CHK001 Определён ли безопасный предел короткого разрыва системного звука и что происходит на границе?
- [x] CHK002 Указано ли, что микрофон не заполняется тишиной и реальная потеря микрофона остаётся fail-closed?
- [x] CHK003 Определено ли поведение при смене output device: одна запись, rebase нового потока, без потери кадров?
- [x] CHK004 Определён ли явный частичный результат, если продолжение невозможно, и чем он отличается от полной записи?
- [x] CHK005 Сохраняются ли AEC3, видимый индикатор, одна кнопка Stop и приватность паузы?
- [x] CHK006 Покрывает ли QA-матрица AirPods/наушники/док, короткий разрыв, сон/крышку и реальный звонок?
- [x] CHK007 Исключены ли аудио, расшифровка, приватные пути и идентификаторы встреч из логов и evidence?
- [x] CHK008 Сохраняются ли существующие форматы WAV/M4A, схема очереди, bundle ID и разрешения?
- [x] CHK009 Описано ли, как отличить реальную потерю источника от короткого timestamp-разрыва?
- [x] CHK010 Определён ли проверяемый сценарий, где запись продолжается после смены устройства и успешно загружается?
