## Правила, чтобы не мешать друг другу

1. Не переписывать историю `codex/297-launch-capture-retention` force-push'ем
   без согласования: в ней уже есть коммиты другого агента.
2. Не дублировать правки шести файлов из #8139 в этой ветке. Если нужна
   правка публичного текста — отдельный PR поверх master, а не здесь.
3. Не выпускать `0114` в production из чужого чата: миграция принадлежит этой
   ветке и приезжает только вместе с ней.
4. Общий Dev-стенд (`/Applications/GRAF Dev.app`, `graf-dev` Compose) занимает
   один оператор. Перед build/promote — `infra/scripts/dev-harness.sh status
   --json` и согласование. Сейчас стенд стоит на кандидате этой ветки.
5. Release/prune включение в production — отдельное действие после dry-run по
   workspace и проверенной свежей резервной копии (`docs/runbooks/backup-retention.md`).
