# Session renewal contract

- TTL по умолчанию 2592000 секунд; явная auth_session_ttl_seconds применяется при входе и продлении. Upload TTL остаётся 86400.
- Авторизованное обращение до expires_at после всех проверок сессии/пользователя/пространства/устройства сдвигает deadline до now+TTL с ограничением записи пять минут; меньший срок не перезаписывает больший.
- POST /logout и исторический POST /desktop/meetings не продлевают вход. 401/403, revoked/expired и отказ commit не публикуют продление.
- Только после окончательного ответа 2xx/304 middleware выполняет условное продление с проверенным tenant-контекстом и доставляет актуальный срок после commit. Redirect не продлевает: следующая успешная страница продлит вход. Отказ записи продления не превращает уже успешную операцию в ошибку и не публикует срок. Для Cookie: Set-Cookie с прежним токеном и стандартными флагами. Для X-Auth-Session/Bearer: X-GRAF-Auth-Expires-At (целые Unix seconds). Cookie, уже назначенное/удалённое маршрутом, имеет приоритет, включая смену пространства и callback.
- Native принимает только ответ 2xx или authenticated 304 с тем же scheme/host/port, положительным будущим сроком и исходным X-Auth-Session. Cookie уже существует, подходит origin и имеет тот же токен; срок только увеличивается. Нельзя создавать cookie по одному ответу. WebKit и native проверяются при применении, устаревшая генерация смены входа отклоняется.
- Обновление срока не публикует desktopAuthSessionDidChange; смена значения/области и явное исчезновение сохраняют нынешние уведомления.
- Браузерные конкурентные Set-Cookie не имеют атомарного сравнения: запоздалый ответ может перезаписать cookie и потребовать повторного входа; сервер никогда не оживляет отозванную сессию. Строгая защита значения cookie от позднего ответа относится к нативному bridge.
- Существующая действительная суточная запись может продлиться на следующем запросе; истёкшая не восстанавливается. Старый native клиент сохраняет старую границу cookie до перехода на обновлённую версию/обновления через кабинет. Отдельная установка не входит в локальную реализацию.
