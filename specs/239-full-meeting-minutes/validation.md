## Реальный путь

Отдельные локальные API/worker, PostgreSQL DB, MinIO bucket, Temporal
namespace/task queue. Реальные источники получены read-only, исполняющие
компоненты не подключены к production DB. Авторизованный HTTP POST создаёт
попытку, Temporal выполняет её, HTTP GET показывает итоговое состояние.
Модель/настройки приходят из явно указанной метки Langfuse `dev`.

Inventory: 164 записи; available 43, partial 14, deleted 76, inaccessible 20,
transcript_unavailable 10, source_unavailable 1. Выбраны три разные записи
длительностью 772, 988 и 4952 секунды. **Остальная база не проверена.**
Полные источники прочитаны хронологически. Приватные тексты/идентификаторы
и ответы хранятся вне репозитория; здесь только агрегаты.
