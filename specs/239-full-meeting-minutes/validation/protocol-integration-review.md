Реализовано:

- Общий исполнитель выполняет extraction → synthesis → verification.
  Каждая стадия имеет отдельную GenerationCall, неизменяемые ссылки на
  предыдущий вызов и его результат, хеш заголовка и полный допуск исполнения.
- Перед стадией, повторным использованием и публикацией проверяется допуск;

- Полный metadata-only отчёт предназначен операторскому журналу; обычный
  CLI выводит только агрегаты. Тексты, частные замечания и meeting identities
  в публичный вывод отчёта не попадают.
- Новый операторский writer напрямую вызывает этот финализатор. Он проверяет
  maintenance identity и проект Langfuse, удерживает PostgreSQL advisory lock,

  текущим допуском. Завершённый повтор возвращает историческое событие без
  нового перемещения. Неоднозначность требует reconciliation.
- Сетевое изменение использует публичный API Langfuse с `max_retries=0`:
  высокоуровневый SDK wrapper не позволяет явно отключить повтор. Отмена
  начатой операции ждёт завершения её защищённого участка.
- Старый boolean root promotion и MinIO LKG helpers удалены вместе с
  устаревшим тестом. Финализатор и evaluation runtime включены в runtime hash.

## D239-R01: точные номера фрагментов в модельном ответе, 2026-09-07
