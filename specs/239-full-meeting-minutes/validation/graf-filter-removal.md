# Удаление специального ограничителя ГРАФ в LiteLLM

Дата: 2026-09-06. Полоса: `high-risk-feature`, операционная часть T055.
Основание: дополнительное прямое разрешение владельца удалить ограничитель
ГРАФ на действующем шлюзе. Это не выпуск ГРАФ и не приёмка новых протоколов.

## Изменение

Из работающего обработчика удалены `async_pre_call_hook`, проверка hash,
запрет другой модели и импорт `HTTPException`. `GrafRouteBindingCallback`
заменён ответным `GrafResponseHeaders`; класс больше не фильтрует запросы.
Изменён один внешний Python-файл. Перезапущен только контейнер LiteLLM;
образ, окружение контейнера и YAML конфигурации побайтно не изменились.
Перед применением backlog показывал один запрос, включая саму проверку.

Хеш обработчика до изменения:
`dcaf3c8a408b2f2d4bc98a25a004038a0554cdc8dc19a735364f0988975c7058`.
После изменения:
`84187d2c0dbf1e6698665dc74bc0a53a4cda31f209654f39c125a3bbc26e16ad`.
Исходный файл сохранён в отдельной закрытой операционной резервной копии;
она не подключена к runtime. Секреты и частные встречи не копировались.

Старый production ГРАФ всё ещё требует ответные `X-GRAF-*` метаданные.
Только эта ответная часть временно сохранена на внешнем шлюзе: её AST
совпадает с прежней реализацией, она не ограничивает модели и не меняет
запрос/ответ LLM. Другая модель не получает ложные метаданные Luna.
Регистрация, mount и четыре переменные ответного обработчика удаляются
при общем выпуске совместимого ГРАФ. В новый код ГРАФ он не добавляется.

## Доказательства

- 27 исполняемых синтетических проверок: разные модели и ключевые aliases,
  отсутствующий/неверный/прежний заголовок, неизменность запроса, сохранение
  прежних ответных метаданных и отсутствие их при несовпадении модели.
- `/active/callbacks`: прежний блокирующий класс отсутствует, активен
  только `GrafResponseHeaders`. Файл runtime не содержит pre-call hook.
- `/health/readiness`: HTTP 200; Docker health: `healthy`.
- Реальные HTTP-запросы тем же ключом ГРАФ через штатный шлюз, без
  специального заголовка, без участия кода генерации:

| Модель | HTTP | Текстовый ответ | Время |
| --- | --- | --- | --- |
| `gpt-5.6-luna` | 200 | непустой | 3123 мс |
| `gpt-5.6-sol` | 200 | непустой | 2825 мс |
| `gemini/gemini-3.8-flash` | 200 | `OK` | 1224 мс |

Первый Gemini probe с `max_tokens=32` вернул HTTP 200 без текста. Отдельный
probe с `max_tokens=1024` вернул `OK`, `finish_reason=stop`; это не скрытый
повтор продуктового вызова и не подмена настроек Langfuse. Встречи не
отправлялись. Ни один вызов без заголовка не получил `X-GRAF-*` метаданные.
Отдельный запрос старого клиента к Luna вернул HTTP 200, `OK` и все три
ожидаемых ответных заголовка. Это проверка HTTP-контракта, не новая генерация
пользовательских итогов в production.

Права ключа проверены до/после по 15 полям; изменений нет. Полный ответ
`/v2/guardrails/list` имеет прежний SHA-256:
`fcfcbe7d1761050d7809ce4ab99af1b58a882e6d7148d0c76115945100f72629`.
Общие Jailbreak/SQL guardrails не изменялись. Остальные контейнеры не
перезапускались; production release ГРАФ остался прежним.

После перезапуска список моделей ключа вырос с 148 до 306. Полный ответ
`/model/info` поэтому не считается побайтно неизменным. Read-only проверка
через штатный Prisma-клиент подтвердила 51 запись конфигурации маршрутов,
последнее обновление `2026-09-04T02:28:04.557000+00:00`, ни одного обновления
во время этой операции. Мы не добавляли модели и не меняли маршруты.

## Проверка кода ГРАФ и оставшиеся условия

Поиск в `apps/server/src`, `apps/server/tests`, `infra`, `scripts` не
находит `route_binding`, `require_route_binding` или старых `X-GRAF-*`
заголовков. Файлов `infra/litellm/*` в текущем Git-дереве нет.
103 теста `test_litellm_gateway.py`, `test_outcome_prompts.py`,
`test_prompt_bundle.py` прошли повторно после операции; `git diff --check`
прошёл. Это focused validation, не полный CI.

Первоначальный `403 graf_route_binding_invalid` устранён. Сравнение качества
моделей и полнокорпусная приёмка ещё не завершены; этот отчёт не закрывает
T043–T048. Langfuse production labels, пользовательские итоги и accepted
pointers не менялись. Merge/release/deploy ГРАФ не выполнялись.
