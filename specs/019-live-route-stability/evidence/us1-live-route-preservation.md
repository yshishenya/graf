# US1 Live Route Preservation Evidence

US1 evidence must show that an active meeting route remains preserved while the meeting target still uses `2brain Rec Microphone` or `2brain Rec Speaker`.

Required metadata-only facts:

- route session id, meeting target, and route state transitions
- fresh per-side client activity snapshots with freshness window and natural-silence flag
- frame continuity counts for local microphone and incoming speaker paths
- release decision events showing preserved or denied release while client evidence remains active
- 30-minute development gate result for Chrome, Opera, Zoom, Telemost, built-in, wired, and USB coverage

Do not include raw audio, transcripts, meeting content, secrets, signed URLs, backend uploads, MediaScribe calls, or Langfuse traces.
