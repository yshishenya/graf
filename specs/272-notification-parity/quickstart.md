# Быстрая проверка: Паритет уведомлений GRAF с Krisp

**Ветка**: `272-notification-parity`
**Приложение для ручной проверки**: только `/Applications/GRAF Dev.app`
(единственная разрешённая копия; вторую создавать нельзя)

## Что проверяем

Собственная карточка уведомления GRAF и компактный индикатор записи вместо
системных баннеров: карточка не зависит от разрешения macOS и режима «Не
беспокоить», несёт действия, не повторяется после закрытия и не дублируется
системным баннером.

## Автоматические проверки

```sh
# Только новая поверхность: правила, содержимое, геометрия, индикатор
swift test --package-path apps/macos --filter DesktopNotificationCardTests

# Регрессия уведомлений
swift test --package-path apps/macos --filter DesktopNotification

# Полный набор macOS-тестов
bash apps/macos/Scripts/run-swift-tests.sh

# Быстрый репозиторный шлюз
infra/scripts/ci-local.sh --fast
```

## Ручная проверка в GRAF Dev

```sh
infra/scripts/dev-harness.sh status --json
infra/scripts/dev-harness.sh build
infra/scripts/dev-harness.sh promote
infra/scripts/dev-harness.sh status --json
infra/scripts/dev-harness.sh smoke
```

Перед сборкой и запуском прочитайте `docs/agent-guidance/local-development.md`.
Не запускайте приложение через `swift run`, не подписывайте вручную и не
создавайте вторую копию приложения.

## Сценарии

### 1. Карточка встречи

1. В календаре GRAF заведите встречу так, чтобы до начала оставалось около
   14 минут, и включите напоминания о встречах.
2. Дождитесь карточки: она должна появиться в правом верхнем углу, не
   перекрывая строку меню.
3. Проверьте содержимое: название встречи, «Начало в ЧЧ:ММ», кнопки
   «Подключиться и начать запись» и «Подключиться».
4. Нажмите «Подключиться» — открывается ссылка встречи, карточка исчезает.
5. Повторите и нажмите «Подключиться и начать запись» — открывается ссылка и
   начинается запись.
6. Закройте карточку крестиком и убедитесь, что для этой встречи она больше не
   появляется.

### 2. Независимость от системы

1. Отзовите разрешение на уведомления у GRAF Dev в системных настройках.
2. Повторите сценарий 1: карточка должна появиться.
3. Включите режим «Не беспокоить» и повторите: карточка появляется, звука нет.
4. Убедитесь, что системный баннер не появляется одновременно с карточкой для
   того же события.

### 3. Индикатор записи

1. Начните запись вручную.
2. Убедитесь, что индикатор виден поверх других окон, показывает «Идёт запись»
   и идущую длительность.
3. Остановите запись: состояние меняется на «Идёт расшифровка».
4. Дождитесь завершения обработки: индикатор исчезает.
5. Проверьте, что индикатор не забирает клавиатурный фокус: набирайте текст в
   другом приложении при видимом индикаторе.

### 4. Оформление и доступность

1. Переключите системное оформление между светлым и тёмным: карточка и
   индикатор остаются читаемыми.
2. Включите VoiceOver и пройдитесь по карточке: читается заголовок, время и
   назначение кнопок.
3. Увеличьте системный шрифт: текст не обрезается и не перекрывает кнопки.

## Что считается успехом

- Карточка появляется при отозванном разрешении и включённом «Не беспокоить».
- Ни одно уведомление не показывается дважды для одного события.
- Запись запускается и останавливается из карточки и индикатора одним нажатием.
- Внешний вид совпадает с [reference-card.html](reference-card.html) по ширине,
  полям, скруглениям, высоте кнопок и расположению на экране.

## Известные ограничения

- Собственная карточка звук не проигрывает: звук остаётся у системного баннера.
- Побайтовое совпадение шрифтов и значков с эталоном не заявляется.
