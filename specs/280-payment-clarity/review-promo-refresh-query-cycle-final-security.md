## Сохранность защиты и денежного пути

HMAC-SHA256/purpose/constant-time comparison, token ≤2048 / code ≤48, точные поля, целочисленный expiry / now < expiry и серверная user/workspace/session связь сохранены. Нет unsignedfallback при отсутствующих ключе/сессии и переноса legacy состояния. Cookie остаётся HttpOnly / SameSite=Lax / Secure HTTPS / path=/billing/checkout; ввод кодируется до заголовков, шаблон экранирует его, код не входит в URL / JS / logs. Состояние не хранит цену, quote, согласия и финансовое право.

GET по-прежнему проверяет текущую применимость/цену/quote; новая ветка не добавляет денежных действий. Неизменённый GET не продлеваетexpiry; explicitApply/замена имеют свой срок 300 с, emptyApply/remove очищают. Права личного владельца/членство, tenant/principal/CSRF, включённость оплаты, rateguards, блокировки/idempotency, verifiedreceipt, обязательные согласия, approvedcatalog/offer/quote, eligibility/лимиты/выбор одной скидки/providerfloor/серверная сумма сохранены. Подписанное presentation состояние не заменяет эти проверки.
