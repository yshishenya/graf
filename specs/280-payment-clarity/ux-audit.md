# F280 — независимый исходный аудит понятности оплаты

Дата: 2026-09-29. Рецензент: `ux_independent`. Исходная версия кода:
`04768db6d3bac13ea3121b1171f605aa32062c14`.

Это сохраненный исходный аудит до реализации F280. Он описывает наблюдения
по исходникам и проектным условиям, а не состояние будущего исправленного
интерфейса. Исправления должны получить отдельное повторное ревью.

## Метод и границы доказательств

Прочитаны 13 основных шаблонов страниц кабинета: 12 `billing_*_content.html`
и `referrals_content.html`. Дополнительно проверены два смежных шаблона:
`cabinet/auth/referral_landing.html` и `public/offer.html`. Число 13 не означает
13 файлов с префиксом `billing_`. Проверены связанные представления в
`cabinet/web_routes/billing.py`, каталог, предоставление оплаченного доступа,
выбор пакетов, общие сообщения о лимитах, подтверждение пробного периода,
код управления фокусом/копированием и существующие проверки доступности.

Применены навыки `copywriter` и `web-design-guidelines`; свежие Web Interface
Guidelines получены из опубликованного источника. Специальных правил голоса
бренда в проверенных путях не найдено. Тексты предлагаются в принятом проектом
простом русском стиле; английский регистр заголовков из общего навыка не
переносится механически в русскую локализацию.

Ограничения: это независимый анализ исходников, не прохождение платежа в
браузере, не проверка установленного GRAF Dev, не ручной тест с программой
экранного доступа, не исследование с реальными пользователями. Каталог в
репозитории не доказывает текущую конфигурацию рабочего сервиса. Финансовая
приемка F278, реальное зачисление, возврат и разрешение включить прием платежей
не проверялись. Из экспертного заключения нельзя вывести рост конверсии или
утверждение, что любой посетитель захочет платить.

`apps/server/src/twobrain_rec_server/cabinet/templates/cabinet/pages/`.

| `billing_discounts_content.html` | Промокод применен/недействителен/удален, история, приглашение | Сократить техническое объяснение резервирования; разделить ввод, примененную скидку и историю |
| `referrals_content.html` | Ссылка активна/неактивна, копирование, история/ожидание бонуса | Исправить «Поделиться», которое лишь копирует; выгода и срок начисления на виду, ограничения доступны |

Смежные поверхности:

- `cabinet/auth/referral_landing.html`: сохранить 10% на первую оплату, срок
  ссылки, обычную регистрацию без бонуса; объяснение выгоды пригласившему
  можно сделать вторичным. На этой странице нельзя обещать денежный бонус.
- `public/offer.html`: сохранить юридический договор и актуальные условия;
  сокращение интерфейса не отменяет обязательной информации до подтверждения.
- `cabinet/components/sections.html::trial_confirmation`: сохранить явный
  запуск, отсутствие карты/автосписания и последствия после семи дней;
  предварительные и окончательные даты не должны выглядеть противоречиво.
- `cabinet/components/primitives.html::billing_member_quota_notice`, overview
  и usage: не показывать оплату неуполномоченному участнику; действие зависит
  от реально доступных минут, места и прав. Другие входы/нативная навигация
  требуют отдельной полной карты в основном аудите F280.

## Минимальный путь и тексты

`Тариф → краткое подтверждение → ЮKassa → достоверный результат → встречи`.
Это два решения внутри GRAF: выбор условий и подтверждение покупки. Не нужно
добавлять промежуточные страницы только ради меньшего числа слов.

| Ситуация | Рекомендуемый основной текст / действие |
| --- | --- |
| Личный | «Без лимита по минутам и встречам. 5 ГБ для аудиозаписей». Полная цена за месяц/год. «Выбрать Личный» |
| Бесплатный | «300 минут в месяц. 250 МБ для аудиозаписей». «Ваш тариф» для текущего |
| Trial | «7 дней без оплаты. Карта не нужна». Реальные 500 МБ, отсутствие автосписания и последующий бесплатный тариф доступны до запуска |
| Подтверждение | «Личный · месяц», общий объем, «К оплате {сумма}», срок, «Далее {полная цена} за {период}», реальная дата/правило списания |
| Согласия | Отдельно «Принимаю условия оплаты» и «Разрешаю автосписания на указанных условиях. Отключить можно в подписке». Оба изначально пусты |
| Промокод | «Есть промокод?»; «Скидка {значение} на эту оплату». Ошибка: «Этот промокод не подходит. Проверьте код или удалите его» |
| Выбор места | «Общий объем», «{объем} всего · {полная цена} за {период}». «Проверить доплату» |
| Увеличение | «Увеличить до {объем}», «К оплате сейчас {доплата} за период {срок}», полная будущая цена. «Оплатить {доплата}» |
| Уменьшение | «{объем} со следующего неоплаченного периода», «Сейчас 0 ₽. Уже оплаченный объем сохранится до {дата}. Файлы не удаляются». «Сохранить без списания» |
| Досрочная оплата | «Оплатить следующий {период}», будущий срок, сумма и маска карты. «Оплатить {сумма} с карты» |
| Renewal off | «Автопродление останется выключенным». Будущая цена называется ценой, а не запланированным списанием |
| Ожидание | «Проверяем оплату. Подтверждение еще не получено. Повторно платить не нужно». Действие определяется существующей операцией |
| Оплата/услуга требуют разбора | «Оплата получена. Проверяем доступ». Поддержка и безопасный номер платежа; без выдуманной причины |
| Обычный успех | «Оплата прошла. Личный активен до {дата}» / «Доступно {объем}». «Открыть встречи» |
| Подтвержденная отмена/ошибка | «Оплата отменена» / «Оплата не прошла». Повтор только после достоверного завершения исходной операции |
| Неизвестный исход | «Проверяем результат оплаты. Пока не начинайте новый платеж». «Проверить статус» |
| Подписка | Оплаченная дата, полная сумма/дата следующего платежа, «Отключить автопродление» без навязанных препятствий |
| Отключено | «Личный доступен до {дата}. После этой даты — бесплатный тариф». Уже отправленный платеж описывается отдельно, только когда существует |
| История/счет | Дата, покупка, сумма, статус; «Платеж и чек». Отдельные состояния денег, доступа и чека |
| Возврат | «Для возврата напишите в поддержку». Открытие письма не означает отправку заявки/возврат |
| Приглашения | «Другу — 10% на первую оплату. Вам — 7 дней за месяц или 30 дней за год». Срок 14 дней после подтвержденной оплаты и ограничения не скрываются |
| Минуты заканчиваются | «Осталось {минут} до {дата обновления}». Действие по тарифу вторично, нет давления |
| Минуты закончились | «Лимит обработки закончился. Он обновится {дата}». Доступный путь продолжения; не предлагать обход обработкой без сохранения |
| Место закончилось | «Нет места для новых аудиозаписей». Увеличить либо освободить место; обработка без хранения только при доступном лимите обработки |

Все суммы/даты/объемы берутся из действительного расчета. Первая попытка
автопродления в исходной модели происходит за 72 часа до окончания периода,
поэтому «спишем в день окончания» неверно. При нескольких оплаченных
интервалах ближайший эффект и значимые переходы объема остаются на виду.

## Опасные сокращения

- Месячный эквивалент вместо полной цены годового платежа.
- Только доплата за место без полной будущей цены вместе с тарифом.
- Будущая цена, скрытая из-за выключенного автопродления или разовой скидки.
- Предвыбранное или объединенное согласие на оферту и регулярные списания.
- «Деньги не списаны» при неизвестном исходе или успех только по возврату из ЮKassa.
- «Больше ничего не спишется» после отмены при уже отправленном платеже.
- Обещание удаления файлов при простом уменьшении объема либо автоматического возврата после открытия письма.
- Препятствия отмене, ложная срочность/популярность, неподтвержденные отзывы и проценты роста.
- Удаление необходимых сведений из договора под предлогом сокращения текста.

## Приемка и вопросы новому пользователю

Основные проверки: одна главная точка действия; существенные финансовые
условия без раскрытия; цена/срок/согласия из актуального расчета; сохраненная
карта названа до прямого списания; повтор не создает операцию; success,
unknown, pending, failed, canceled, refused и service gap правдивы; отмена
не мешает пользоваться оплаченным сроком; помощь доступна прямо из ошибки.

Доступность: клавиатура и фокус, подписи/ошибки, однократное понятное
объявление смены состояния; узкие экраны, 200% и проверка reflow 400%, обе
темы, длинные суммы/даты, веб и разрешенный GRAF Dev. Синтетические
браузерные проверки и установленное приложение — разные доказательства.

Рекомендуемый исследовательский протокол: на короткое время показать экран,
убрать его, затем без подсказки спросить:

1. Что вы покупаете и сколько спишут сейчас?
2. За какой срок указана сумма? Какой общий объем вы получите?
3. Есть ли автоматическое продление? Сколько стоит следующий период без скидки?
4. Где отключить продление? Пропадет ли оплаченный доступ сегодня?
5. Платеж уже подтвержден или еще проверяется? Нужно ли платить повторно?
6. Удалятся ли существующие файлы после уменьшения объема?

Первоначальное независимое предложение — 10 новых участников и минимум
9 самостоятельных прохождений; ноль критических ошибок в сумме, годовом
периоде и автосписании. Это предложение для согласования требований, а не
выполненная приемка. Утвержденный протокол и размер группы определяет spec.
Небольшой тест на понятность не доказывает статистический рост конверсии.

## Независимый вывод

Исходный путь перегружен и содержит смысловые ловушки. Упрощение должно убрать
