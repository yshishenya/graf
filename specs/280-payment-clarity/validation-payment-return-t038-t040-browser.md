## Что проверяют новые сценарии

T038, `manual-cooldown`: быстрый pending-ответ явно делает ручную проверку недоступной; видимое объяснение ссылается через `aria-describedby` на существующий текст ожидания. Проверяется вычисленный браузером вид настоящего CSS: приглушённая непрозрачность и `cursor: not-allowed`; после интервала возвращаются обычный вид, доступность и реальный защищённый POST. Для доступной фокусу кнопки с `aria-disabled` принудительное указательное нажатие не отправляет ранний запрос и сохраняет понятное объяснение. Все шесть автоматических начал соблюдают интервал ≥10 секунд; после окончания окна следующая ручная проверка действительно работает.

T039, `focus-controls`, `focus-latest`, `focus-success`: сохраняются раскрытые сведения и фокус summary, чека, тарифа, помощи и продолжения оплаты; идентификаторы настоящих элементов непустые и уникальные. Исходно сфокусированная кнопка продолжения отключается нативно во время удержанного запроса; фактический путь фокуса через body либо отключённую кнопку наблюдается до перемещения пользователем на чек. Последний выбор пользователя сохраняется после замены. Перевод фокуса за пределы main использует настоящую ссылку оболочки «К содержимому», которая видна при фокусе на обеих ширинах; обновление не отбирает этот фокус. При успехе исчезнувшее продолжение переводит фокус к подтверждённому результату; оплаченный срок и единственное связанное право доступа проверяются серверной связкой. Старый `a11y`-сценарий с фокусом основной кнопки и последующим клавиатурным переходом сохранён.

T040: пять отдельных групп `current-context-in-flight-user/workspace/session/invoice/replacement` выполняются независимо. В четырёх полях меняется текущий контекст именно во время удержанного настоящего POST303→GET, после формирования серверного ответа и до его доставки; ручной `reinit()` не вызывается. Проверяются отклонённая замена, тот же main, немедленный alert, отключение форм, отсутствие новых POST и доступное чтение `?view=local` без финансового запроса. Проверка другого main заменяет его настоящим HTML из отдельного ASGI GET `?view=local`, без выдуманных элементов и без готового фиктивного ответа; поздний старый ответ должен оставить этот новый узел и его полный HTML неизменными.

Существующие 18 групп сохранены. Единственное исправление прежнего ожидания находится в `idle-five`: начала 0/14/28/42/52 с означают конец автоматического окна на 60 с и окончание ручного десятисекундного интервала на 62 с. Прежний assertion «кнопка доступна уже на 60 с» воспроизводил исходный дефект молча отклонённого нажатия и противоречил T038. Вместо него проверяется более сильное поведение: исходный точный текст окончания на 60 с сохранён; отдельно видна оставшаяся пауза; клавиатурный Enter не создаёт раннего POST; на 62 с без повторной инициализации кнопка доступна и реальный ручной POST соблюдает ≥10 с. Сохранены пять фактических автоматических начал, запрет шестого автоматического начала за границей окна, отсутствие навигации документа и отсутствие новых автоматических запросов после повторной инициализации.

Для всех групп Python-связка сохраняет проверку одного создания платежа, ровно одной операции и счета, ожидаемого количества прав доступа, точной связи права с покупкой и сохранённого отказа от автоматических списаний. Проверяется равенство количества настоящих POST и обращений к синтетическому поставщику; безопасные восстановительные GET не создают проверку поставщика. Старые ограничения одного запроса, 15 секунд, позднего ответа, всех четырёх incoming/current границ, ошибок и no-JS перехода не ослаблены.

## Воспроизведение

Команды запускаются из `.`, используют существующие зависимости и создают отдельную PostgreSQL базу. Не применять к production DB.

```sh
GRAF_PAYMENT_RETURN_BROWSER=1 GRAF_BROWSER=chromium \
GRAF_NODE_MODULES="$PWD/apps/server/tests/browser/node_modules" \
apps/server/scripts/run_local_postgres_tests.sh --focused \
  tests/contract/test_billing_payment_return_browser.py -q --tb=short --show-capture=no

GRAF_PAYMENT_RETURN_BROWSER=1 GRAF_BROWSER=webkit \
GRAF_NODE_MODULES="$PWD/apps/server/tests/browser/node_modules" \
apps/server/scripts/run_local_postgres_tests.sh --focused \
  tests/contract/test_billing_payment_return_browser.py -q --tb=short --show-capture=no
```

Для узкого воспроизведения T040 к той же команде добавляется `-k 'current-context-in-flight'`; для 14 групповых экземпляров причинного GREEN — `-k 'current-context-in-flight or manual-cooldown or focus-latest'`.

На окончательных проверочных файлах завершились `node --check`, Ruff для Python bridge и `git diff --check`. Отчёт готов к независимому прочтению авторами требований, контроллера и браузерного обзора. Этот результат не подтверждает exact-SHA GitHub CI, release-full, production deployment, настоящую частную страницу владельца, банковское зачисление, возврат, фактическое удержание клиента или пять человеческих проверок. Эти доказательства не подменены браузерной матрицей.
