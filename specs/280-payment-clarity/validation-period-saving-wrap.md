## Область

FR-012/030/064 и SC-019 требуют сохранять читаемость оплаты при 320 CSS px
и увеличении 200%. В двух кнопках оформления и двух ссылках выбора периода
используется общий `.billing-period-switch :is(a, button)`. Исправление
разрешает естественный перенос свойствами только внутри переключателя:
`white-space: normal; overflow-wrap: anywhere;`. Его существующая grid-сетка
использует `repeat(auto-fit, minmax(min(100%, 140px), 1fr))`: два периода
остаются рядом при достаточном месте и переходят в одну колонку при тесной
ширине. Высота может увеличиваться.
Текст, цены, шаблоны, обработчики и финансовые правила не меняются.

## Причинная проверка

Неизмененная прежняя матрица Chromium прошла: **20 passed, 56.71 s**.
Она не передавала `annual_saving_label` в оформление, поэтому не находила
переполнение настоящей подписи. Fixture теперь использует существующую
серверную `_annual_saving_label(100000, 1000000)`:
**«Экономия 2 000 ₽ (17%)»**. Годовое оформление также включено в полную
оболочку страницы. Существующий browser runner расширен проверкой
реальных строк каждого текстового узла через `Range.getClientRects()`
относительно родительской кнопки/ссылки и окна, с допуском 1 CSS px.

На исходном CSS новая проверка дала **RED**: 1 failed / 19 passed, 4.63 s.
При 320 px, светлой теме, 200%, JS выключен годовая кнопка занимала
`x160…254`, а настоящая подпись — `x68.78125…345.21875`.
Она выходила за кнопку и окно. Это самостоятельное воспроизведение с
точной серверной подписью; прежний пробный результат с синтетической
подписью не считается авторитетным доказательством.

После RED две декларации переноса устранили выход текста, но независимая
визуальная проверка выявила дробление слов при двух тесных колонках.
Применена собственная адаптивная grid-сетка с минимальной шириной 140 px
(ограниченной 100% родителя). При недостатке места две кнопки/ссылки
располагаются друг под другом. Шрифт, содержимое и допуск не менялись.
Только перенос без адаптации считается промежуточной версией, а не итогом.
