# План измерения результата

## Цель и статус

Цель — больше целевых небрендовых переходов и активаций, сохраняя главный лендинг. Рабочий ориентир за 90 дней после фактической публикации: +30 небрендовых переходов за последние 28 завершённых дней по сравнению с 28 днями до публикации; при положительной базе отслеживать +30% как дополнительный ориентир. В том же последнем 28-дневном окне — 3 органические активации (регистрация + первая успешно обработанная встреча). Это проверяемая гипотеза, не обещание и не утверждение текущего роста.

## База и источники

Дата публикации пока unknown. Числа Google/Яндекс/активаций unknown. До публикации выгрузить только агрегаты последних 28 завершённых дней из Search Console/Вебмастера: date range, URL, clicks, impressions, CTR, query category (бренд/небренд). Брендовые варианты: ГРАФ, GRAF и название/адрес rec.2brain.pro, 2brain — правила фильтра сохранить вместе с отчётом. Не складывать sessions Метрики и clicks поисковиков; Google и Яндекс — отдельные источники с итогом clicks.

Активации брать из существующей подтверждённой органической атрибуции в продуктовой аналитике; не считать download click установкой или встречей. Новый entrance path может не поддерживаться текущим аналитическим allowlist. Пока это не доказано, показатель активации по новым страницам — unknown, никаких выводов об источнике по косвенным совпадениям.

## Контрольные точки

- D0: фактическая публикация, exact source SHA, public 200/canonical/sitemap и исходные агрегаты.
- D14: URL inspection/статус индексации всех трёх страниц в обоих поисковиках; HTTP 200 отдельно от indexing.
- D30: первые показы и query relevance; при их отсутствии проверить indexation/полезность страниц, не создавать массовые копии.
- D60: запросы, переходы, продуктовые действия; менять только подтверждённые слабые места страниц.
- D90: последние 28 завершённых дней против prelaunch 28 дней; brand/nonbrand отдельно, clicks и activation отдельно. Малая выборка/сезонность/другие релизы ограничивают причинный вывод.

Расчёт delta = clicks_after - clicks_before; relative = delta / clicks_before только при baseline > 0. Missing не равно 0; при отсутствии данных оценка цели «не измерена», не PASS. Счётчики и consent в этой фиче не расширяются.

## Решение по итогам

Успех: цель clicks выполнена и подтверждены полезные действия. При росте только показов/кликов записать частичный результат, проверить соответствие запросов и путь к продукту. При незавершённой индексации или недоступной атрибуции назвать конкретный оставшийся шаг. Пересмотр числа 30/3 возможен после реальной базы, с явной записью основания.
