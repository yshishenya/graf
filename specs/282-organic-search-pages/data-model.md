# Data model

Новых сохраняемых сущностей нет. Фиксированный каталог трёх публичных путей содержит title и description; содержимое принадлежит соответствующему блоку шаблона. Пользовательские значения не выбирают произвольный шаблон или canonical. Существующая модель аналитики не меняется. Measurement record содержит дату публикации, окна сравнения и подтверждённые агрегаты либо unknown; в git не включаются частные данные, cookies, IDs пользователей или содержимое встреч.
