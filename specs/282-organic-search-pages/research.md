# Research — 2026-09-30

- Decision: три фиксированные страницы `/transcription`, `/meeting-minutes`, `/record-without-bot`. Rationale: текущий sitemap — 7 URL, из них 5 юридические; задачи требуют разных ответов. Alternatives: переделка главной/массовые копии под ОС отклонены по решению владельца.
- Decision: существующий public_page_response, _meta.html, собственные изображения и локальные шрифты. Rationale: уже обеспечены escaping, canonical и security headers. Alternatives: новая система CMS/шаблонный движок не нужны.
- Decision: самостоятельный scoped CSS новых страниц. Rationale: существующая landing.css не меняется; кнопки/шрифты/общее оформление переиспользуются, стили статьи изолированы.
- Decision: нет _analytics.html на новых страницах и изменений в allowlists. Rationale: публичная внешняя аналитика ограничена главной и скачиванием. Shared response сохраняется, однако unknown paths в аналитическом каталоге могут не считаться; измерение поисковых кликов — отчёты поисковиков. Полная атрибуция новых путей отдельно не доказана и не заявляется.
- Decision: браузерная загрузка и запись через desktop — разные пути. Rationale: кабинет позволяет загружать готовое аудио/видео; текущий публичный desktop installer — macOS, Windows разрабатывается по сообщению владельца. Страницы не обещают запись на неподдерживаемой ОС.
- Evidence: публичный HTML главной, /download, robots/sitemap и 404 проверены; Grow My Website 96/100, og:image absent. Это не измерение индексации, спроса или трафика.
- Unknowns resolved: отчёты поисковиков и конверсий недоступны в текущем проверенном контексте; статус unknown сохраняется. Новые integrations не вводятся ради чисел.
