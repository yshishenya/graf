# Повторный UX/UI/IA/CX review

**Дата:** 2026-08-03

## Решение

Боковое меню — единственный основной способ перехода между настройками. Оно
должно отвечать только на вопрос «куда перейти»:

- два уровня иерархии: короткий заголовок группы и ссылка;
- одна короткая подпись на ссылку;
- иконка помогает сканированию, но не заменяет текст;
- текущий раздел обозначен цветом, фоном и `aria-current="page"`;
- scope не показывается в меню: он остаётся рядом с конкретной настройкой,
  где объясняет область действия.

Overview остаётся прямым входом `/settings`, но не дублирует меню ссылками и
длинными описаниями. На нём остаётся только необходимая граница для
macOS-записи.

## Целевая структура

```text
Настройки
├── Встречи
│   ├── Запись
│   ├── Итоги
│   └── Календари
├── Рабочее пространство
│   └── Пространство
└── Аккаунт
    └── Аккаунт и безопасность
```

## UX/CX правила

- Не смешивать в одной навигации задачу, область действия и permission scope.
- Не повторять название раздела в eyebrow, sidebar и карточке без причины.
- Не использовать поясняющий текст там, где короткое название уже однозначно.
- Сохранять обычные ссылки, чтобы работали Cmd/Ctrl-click, back и deep-link.
- На узком экране меню становится обычным вертикальным блоком перед контентом;
  скрытого горизонтального скролла нет.
- Деструктивные действия, CSRF, account-safe copy и native recording boundary
  не упрощаются визуальной чисткой.

## Accessibility/UI gate

- `nav` имеет одну понятную accessible name.
- Заголовки групп — семантические `h2`, но не focusable.
- Все ссылки имеют видимый `:focus-visible` и минимум 44px hit area.
- Иконки декоративны и скрыты от screen reader через `aria-hidden`.
- Scope сохраняется как дополнительная информация только в содержимом
  конкретной настройки; overview не дублирует links из sidebar.
- Breakpoint `640px` сохраняет доступность всех разделов на ширине 320px.

Решение опирается на текущий GRAF UI kit, предоставленный структурный
референс и рекомендации [Apple Human Interface Guidelines для sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars) и [settings](https://developer.apple.com/design/human-interface-guidelines/settings).
