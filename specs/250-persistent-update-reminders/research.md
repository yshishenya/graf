# Исследование практик обновления — 2026-09-06

Проверены исходный код GRAF, документация и исходники закрепленного Sparkle 2.9.4. Исследование выполнялось отдельно от реализации.

| Решение | Причина | Рассмотренная альтернатива |
|---|---|---|
| Постоянный индикатор + штатное окно по нажатию | Gentle Reminders прямо предусматривает кнопку приложения; системное уведомление может не дойти | Системные push как единственный сигнал отвергнуты |
| Расписание Sparkle 4 часа + запуск | Время сна учитывается dispatch_walltime; resetUpdateCycle предназначен для изменения настроек | Собственный опрос/wake handler не нужен |
| Кэш только известной версии | Сохраняет напоминание после рестарта и ошибки, не доверяет кэшу при установке | Собственный разбор/выбор релизов дублирует совместимость и phased rollout |
| Skip оставляет пассивный индикатор | Штатный поиск исключает skipped versions, даже из latest-item в no-update | Скрыть Skip публичным API нельзя; объявлять каждый выпуск критическим неправильно |
| Сверка известной сборки через didFinishLoading | Полная подписанная лента доступна до фильтра skip; отсутствие в ней подтверждает отзыв | Любой no-update как отзыв дает ложное исчезновение |
| Ручная установка с existing relaunch gate | Защищает запись/финализацию | Принудительный restart нарушает продуктовые требования |

Ограничение: 4 часа — интервал штатного поиска при включенном приложении/сети; не обещание доставки офлайн. Публикация сервера/GitHub Release сама по себе не обновляет appcast. Старым клиентам для нового поведения нужен очередной подписанный выпуск.

Уточнение расписания: 4 часа — настроенный период, когда нет активной сессии Sparkle или уже загруженного отложенного обновления. В этих состояниях штатный планировщик может отложить следующую проверку. Старое продуктовое значение 86400 мигрирует в 14400 один раз; другие явно настроенные интервалы сохраняются. Флага включения автоматического поиска миграция не меняет. Интерфейса настройки периода в GRAF сейчас нет.
