# Контракт интерфейса

- Один AppUpdateController принадлежит жизненному циклу приложения.
- Главное окно: нативная строка над рабочей областью; «Доступна новая версия GRAF <версия>», пояснение состояния, кнопка «Обновить GRAF» / «Открыть обновление» / «Повторить». Никаких произвольных URL.
- Строка меню: существующий значок меняется на символ загрузки с доступным названием «GRAF — доступна версия …»; всплывающее окно содержит ту же строку уведомления и кнопку. Она доступна и без входа в календарь.
- Меню приложения: «Проверить обновления…» без версии, «Обновить GRAF до …» с версией.
- Existing native/sidebar + WebKit bridge сохраняют boolean-only отображение и единственное фиксированное действие checkForUpdates. Разрешены только main-frame сообщения с допустимого адреса.
- VoiceOver читает текст версии/состояния; кнопка >=40pt и keyboard focus; ⇧⌘U открывает обновление. Уведомление не перекрывает Stop, не требует цвета для понимания, не вызывает системные разрешения.
- canCheckForUpdates управляет доступностью; повторный вызов не создает независимый установщик.
