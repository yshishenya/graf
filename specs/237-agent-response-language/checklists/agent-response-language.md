# Reviewer checklist: язык ответов агента

**Фича**: [237-agent-response-language](../spec.md)

**Назначение**: независимая проверка постоянного правила в корневом
`AGENTS.md` перед завершением significant-feature slice.

Чеклист заполняет независимый reviewer. Агент, реализующий задачу, не меняет
состояние этих пунктов на `[x]`.

## Область и точность правила

- [x] Правило применяется к языку ответа пользователя и не требует отвечать
  по-русски, если пользователь попросил другой язык.
- [x] Требование избегать необязательных англицизмов ограничено
  русскоязычными ответами.
- [x] Разрешённые исключения сохраняют точные имена, команды, пути,
  программные обозначения и буквальные сообщения.
- [x] Непонятные обязательные технические термины требуют краткого пояснения.

## Согласованность и границы

- [x] `AGENTS.md`, `spec.md`, `plan.md` и
  `contracts/response-language.md` не противоречат друг другу.
- [x] Изменение не добавляет автоматический словарь, фильтр, зависимость или
  изменение продукта.
- [x] Legacy Impact классифицирован как `untouched` и подтверждён по diff.

## Evidence и closeout

- [x] Convergence выполнен после реализации, а результат записан отдельной
  задачей в `tasks.md`.
- [x] Все exact-SHA и GitHub governance evidence относятся к одному
  проверенному commit.
