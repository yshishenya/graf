# Договорённость о языке ответов

## Обязательное поведение

- Ответы пользователю написаны простым и понятным языком.
- В русскоязычных ответах при наличии точного и привычного русского слова оно
  используется вместо необязательного англицизма.
- В русскоязычных ответах неизбежный непонятный технический термин кратко
  объясняется при первом использовании.

## Разрешённые исключения

Названия продуктов, команды, пути, программные обозначения и буквальные
сообщения сохраняются в исходном виде, если перевод ухудшает точность.
