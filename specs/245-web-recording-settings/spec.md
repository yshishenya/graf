# Feature Specification: Автозапись в общих настройках

**Feature Branch**: `codex/245-web-recording-settings`
**Created**: 2026-09-06
**Status**: Implemented locally; release pending
**Input**: «давай перенесем настройки записи сначала. Остальное пока не делаем».

## User Scenarios & Testing

### US1 — Управлять автозаписью в общих настройках (P1)

Пользователь открывает «Настройки → Запись» внутри GRAF и меняет правила
автозаписи на этом Mac без отдельного окна.

Independent test: изменить правило, открыть настройки повторно, проверить
сохранённое значение и решение обнаружения встречи для того же приложения.

1. При существующих правилах страница показывает все проверенные приложения и
   их текущие значения «Всегда / Спрашивать / Никогда».
2. Изменение отдельного правила сохраняется на Mac; остальные правила сохранены.
3. «Для всех приложений» меняет только текущий проверенный список. Новое
   приложение получает «Спрашивать». Смешанный набор явно обозначен.
4. При ошибке сохранения страница показывает ошибку и подтверждённые значения.
5. «Запомнить выбор» в предложении записи обновляет уже открытые настройки.

### US2 — Сохранять доступность и совместимость (P1)

Independent test: открыть настройки через меню/шестерёнку; при недоступном
кабинете открыть существующую локальную форму; в браузере нет активных контролов Mac.

1. Меню GRAF, ⌘, и шестерёнки открывают общий раздел записи при готовом кабинете.
2. При недоступном кабинете они открывают существующую локальную форму.
3. Старый клиент на новой странице сохраняет ссылку открытия локальной формы.
4. Обычный браузер объясняет область действия, не сохраняет локальные правила.

### Edge Cases

- Пустой/обновлённый реестр, повреждённый файл настроек, ошибка записи на диск.
- Одновременное изменение через предложение записи или резервную форму:
  применяются изменения только выбранных целей к последнему сохранённому состоянию.
- Переход на другую страницу, перезагрузка, выход из аккаунта, смена WebView:
  сообщения старого документа и чужих страниц не меняют настройки.
- Неподдерживаемая версия клиента или отсутствующий ответ: локальная ссылка
  остаётся доступной; значения не выдаются за сохранённые.

## Requirements

### Functional Requirements

- **FR-001**: Общая страница записи внутри GRAF показывает правила проверенного
  нативного реестра; состояние загружается с этого Mac.
- **FR-002**: Сохраняются три состояния, default «Спрашивать», массовое применение
  текущим целям и восьмисекундное поведение предложения без изменений.
- **FR-003**: Сервер не хранит и не разрешает эти правила. Формат существующих
  настроек, установленные значения и разделение каналов GRAF/GRAF Dev сохранены.
- **FR-004**: Успех показывается только после сохранения. Ошибка загрузки/сохранения
  понятна, повторное чтение доступно; несохранённый выбор не остаётся как успешный.
- **FR-005**: Изменение действует в существующем обнаружении встреч и отражается
  во всех открытых формах. Частичное обновление не стирает другие правила.
- **FR-006**: Меню, сочетание клавиш и шестерёнки ведут на общую страницу при
  готовом кабинете; существующее локальное окно доступно при сбоях и по ссылке.
- **FR-007**: Только доверенная открытая страница записи внутри активного GRAF
  может читать/изменять правила. Неизвестные цели, действия, значения, версии,
  чужие страницы, подфреймы и устаревшие документы отклоняются.
- **FR-008**: Браузер и старые клиенты не показывают неподтверждённые локальные
  контролы как работающие. Ссылка локальной формы остаётся для старых клиентов.
- **FR-009**: Русские подписи, доступные имена, клавиатурное управление,
  объявление ошибки/сохранения и корректный список при узком окне обязательны.
- **FR-010**: Микрофон, разрешения, захват, Stop, правая панель, календарные
  подсказки, серверные политики и локальная очередь не меняются.

### Key Entities

- Проверенное приложение: стабильный идентификатор, отображаемое имя.
- Локальное правило: приложение и одно из трёх значений.
- Состояние страницы: загрузка, готовность, сохранение, ошибка, недоступность.

## Success Criteria

- **SC-001**: Все существующие явные правила сохраняются после переноса и перезапуска.
- **SC-002**: Все три значения и массовый выбор проходят проверку сохранения и
  использования существующей политикой; другие настройки не изменяются.
- **SC-003**: Нулевая запись настроек при недоверенном или некорректном запросе.
- **SC-004**: Все точки входа и сценарии недоступности имеют рабочий путь;
  управление текущей записью не зависит от общей страницы.

## Clarifications

### Session 2026-09-06

- Из обсуждения и уточнения пользователя: только первый этап — правила
  автозаписи и массовый выбор; остальные переносы исключены.
- Общая страница управляет текущим Mac внутри GRAF; удалённое управление
  компьютером из обычного браузера не входит.
- Локальное хранилище, текущий детектор и резервная нативная форма сохраняются.
- Формальная проверка clarify: функциональность, данные, UX, надёжность,
  безопасность, зависимости, ошибки и критерии завершения определены;
  дополнительных вопросов нет. Изменения во время записи действуют на будущие
  решения детектора, не останавливают и не запускают текущую запись сами по себе.
