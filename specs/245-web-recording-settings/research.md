# Research
## Decision
Повторно используем существующие WebKit, store, реестр и нативную резервную форму.
## Rationale
Настройки уже принадлежат клиенту. Их серверная копия создаёт расхождения и
нарушает локальную доступность. Пустого переключателя без native ack недостаточно.
Старый клиент продолжает открывать нативную форму через прежнюю ссылку.
Исследование через speckit-plan research agent подтвердило существующие writers
полного снимка и отдельные очереди store: общий atomic patch нужен для всех writers.
## Alternatives considered
- Новое серверное API и синхронизация устройств исключены пользовательским scope.
- Полная замена нативной формы исключена требованием offline.
- Универсальный RPC/новая зависимость избыточны; достаточно фиксированных команд.
