# UX Requirements Checklist: Понятная подсказка на таймлайне

**Created**: 2026-08-18

## Discoverability and accessibility

- [x] Подсказка объясняет видимый объект, действие и результат [Clarity]
- [x] Tooltip-only и icon-only alternatives explicitly excluded [Consistency]
- [x] Keyboard, screen reader, touch, narrow width and reduced motion covered [Coverage]
- [x] Secondary visual weight and no-overflow behavior defined [Completeness]
- [x] Truthful unavailable state prevents misleading instruction [Edge Case]
