## Причина и исправление

[Full 40613955028](https://github.com/yshishenya/graf/actions/runs/40613955028)
отказал до выпуска. Импортированная фикстура `migrated_postgres_urls` создавала
общую роль без наследования маркера `strict_rls`. Подготовка другой БД могла
сохранить зависимый grant и сорвать удаление роли. Существующий collection hook
теперь выводит strict по действительной зависимости фикстур до классификации
postgres и построения перечня фаз. Роли, RLS и очистка не меняются.

Temporal отказал при загрузке SDK test server с HTTP 429 до создания среды.
Один помощник в прежнем тестовом модуле разрешает максимум три попытки только
для точного download429 с `https://temporal.download/`; паузы — 5 и 15 секунд.
Иная ошибка, отмена или третий отказ выходят сразу. Шесть прежних сценариев
сохраняют настоящий environment, Worker, workflow, activities и shutdown.
Код продукта, SDK cache, версии и CI YAML не менялись.
