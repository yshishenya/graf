# Дизайн настроек GRAF

## Главное решение
Один путь: **GRAF → Настройки → нужный раздел**. Настройки меню, профиля и Cmd+, ведут в один экран основного окна. Контекстные команды открывают сразу «Запись» или «Уведомления». Отдельное локальное окно — резерв только при недоступном кабинете. У него нет другой логики и другого набора значений.

## Навигация

| Группа | Пункт | Содержание |
|---|---|---|
| Личное | Аккаунт | Профиль, оформление, язык/часовой пояс, способы входа, активные входы, закрытие аккаунта |
| Рабочее пространство | Пространства | Существующие пространства, приглашения и место новых встреч |
| Рабочее пространство | Тариф и оплата | Действующий тариф, использование, счета и оплачиваемые действия |
| Встречи | Запись | Автозапись и полный список поддерживаемых приложений |
| Встречи | Итоги | Действующие форматы итогов; никаких новых переключателей AI |
| Встречи | Календари | Существующие подключения и выбранные календари |
| Приложение | Уведомления | Локальные напоминания/звук/приватность и аккаунтные письма/подсказки |

Сверху «Назад», без логотипа-карточки и обзора плитками. «Аккаунт» — первый экран общей команды настроек. Внутри раздела один заголовок. Основная навигация встреч заменяется меню настроек и возвращается по «Назад»; отдельные верхние tabs не появляются. При уходе из сложной формы сохранить действующее предупреждение о несохранённых данных, если оно есть; не отправлять форму навигацией.

## Путь от начала до конца

1. Первый запуск/вход: существующий вход и проверка разрешений, видимые ручные Record/Stop. Этот экран не запускает запись сам.
2. Пользователь открывает настройки: в аккаунте доступны профиль и оформление; «Запись» находится в группе «Встречи».
3. В «Записи» коротко объяснено действие правил. Пользователь находит название, выбирает правило справа, получает тихое «Сохранено». Нет повторного окна/кнопки подтверждения.
4. При начале встречи действуют прежние правила. «Спрашивать»: видимое предложение с 8 секундами, «Записать», «Не записывать», «Запомнить выбор». Отсутствие действия запускает запись. Запоминание меняет только текущее приложение после явного действия.
5. При записи всегда видны состояние и Stop. Переход в настройки не скрывает этот контроль и не меняет текущую запись. Выбор «Никогда» относится к следующему автоматическому запуску.
6. Напоминание о следующей встрече управляется разделом уведомлений: включение, 0/1/5 минут, названия, звук. Система показывает своё фактическое разрешение.
7. После встречи результаты остаются в истории без звука; новые проблемы доступны в существующем центре уведомлений. Его «Настройки» возвращают в тот же раздел.
8. При недоступном кабинете локальная запись и резервный редактор доступны по текущим правилам. После восстановления — возврат в единый экран, повторное чтение подтверждённого состояния.

## Экран «Запись»

Заголовок «Запись», далее блок «Автозапись» и пояснение «Выберите, как начинать запись встреч в каждом приложении на этом Mac».

Одна общая строка «Для всех приложений» → select, под ней тонкий разделитель и полный перечень. Каждая строка: полное имя слева, текущая настройка справа. У каждого select доступное имя «Автозапись: Zoom» и т. п. При mixed общий select показывает «Разные правила», а не подсвечивает «Всегда». Никаких огромных кнопок, пустых иконок или пустых карточек.

Короткая постоянно видимая подсказка: «Всегда — без запроса. Спрашивать — запись начнётся через 8 секунд, если вы не откажетесь. Никогда — только ручной запуск». Вторая короткая строка ниже списка: «Ручная запись остаётся доступна». Пояснение не спрятано только во всплывающую подсказку.

Над списком поиск по имени, поскольку текущий допустимый реестр содержит 79 приложений. Очистка возвращает все строки; пустой поиск не меняет правила. Подпись массового выбора явно говорит, что он действует также на скрытые поиском строки. Полный список — из действующего реестра и в его сортировке. Не выдумывать Google Meet/браузерную поддержку; не маскировать неизвестное имя общим «Приложение». Регистрация установленности — отдельная будущая задача, здесь не добавляется. Для узнаваемости достаточно названия, сторонние логотипы не нужны.

## Экран «Уведомления»

| Блок | Строка | Управление / пояснение |
|---|---|---|
| На этом Mac | Уведомления macOS | Фактическое разрешение; action по состоянию |
| На этом Mac | Напоминать о встречах | Switch; «Перед началом встречи из подключённого календаря» |
| На этом Mac | Когда напоминать | Select: «В момент начала», «За минуту», «За 5 минут»; disabled только если reminders off |
| На этом Mac | Показывать названия встреч | Switch; «В системных уведомлениях. Выключите, чтобы скрыть названия» |
| На этом Mac | Звук уведомлений | Switch; «Во время записи звук всегда выключен» |
| На этом Mac | Проверить уведомление | Небольшая вторичная кнопка; только явное действие, сохранённые значения |
| Письма и подсказки | Письма с новостями и советами | Switch; область аккаунта |
| Письма и подсказки | Подсказки в GRAF | Switch; область аккаунта |

На этой странице не нужен второй пункт «Настроить на этом Mac». История уведомлений — содержимое отдельного существующего центра, не вторая страница настроек. Ссылка «Открыть историю» допустима один раз в конце. Нет выключателя видимости записи или обязательных сообщений. Статус теста: «Запрос передан macOS» с пояснением о системных правилах, не «Уведомление доставлено».

## Компоновка и оформление
Значения ниже — точные параметры проекта GRAF, выбранные по наблюдаемой композиции. Это не извлечённые CSS-токены Krisp.

| Token | Значение | Назначение |
|---|---|---|
| settings-rail-width | 208 px | Единственная боковая панель при широком окне |
| settings-content-max | 760 px | Читаемая область настроек, центрирована в правой части |
| settings-page-padding | 32–48 px | Воздух вокруг содержимого; 20 px в узком виде |
| settings-header-height | 52 px | Небольшая строка заголовка с нижней границей |
| settings-row-min-height | 58 px | Название + пояснение; увеличивается по содержимому |
| settings-section-gap | 28 px | Между смысловыми блоками |
| settings-control-width | 172 px | Select правила/времени, без сжатия текста |
| settings-control-height | 32 px | Native select/button; hit area switch минимум 32×32 |
| settings-font | system -apple-system / 13 px | Основной текст, line-height 1.5 |
| settings-heading | 15 px / 600 | Блок, а не огромный рекламный заголовок |
| settings-radius | 6 px | Контролы и активная строка меню |
| dark background / rail | #1e1f21 / #252628 | Спокойные плоскости без стекла/градиентов |
| dark text / secondary | #ececef / #aaabb2 | Контраст первичного/вторичного текста |
| dark border / selected | #35363a / #38393c | Нейтральные границы/выбор раздела |
| accent | #9581ff | Активный switch/фокус; не цвет каждого заголовка. Текст #202125; hover #a18cff для WCAG AA. |
| light background / rail | #ffffff / #f6f6f7 | Светлая системная тема |
| light text / secondary | #202125 / #62636b | Контраст в светлой теме |

У существующего SF Symbol/SVG GRAF stroke около 1.5 px и роль декоративного дополнения; название доступно без иконки. Нет сторонних активов. Контролы используют нативные select/input/button и эквивалентные SwiftUI Picker/Toggle.

## Состояния и обратная связь

| Состояние | Вид и поведение |
|---|---|
| Loading | «Загружаем настройки…», контролы не показывают выдуманные значения |
| Saving | «Сохраняем…», локальная группа блокируется до ответа, навигация не обещает отмену |
| Confirmed | Подтверждённое значение и тихое «Сохранено»; через короткое время текст можно убрать |
| Save error | Прежнее подтверждённое значение, красное сообщение рядом с группой, повтор |
| Timeout | «Не удалось подтвердить изменение»; предложить повторное чтение, без автоматического повторения записи |
| Empty registry | «Список приложений пока недоступен» и «Повторить»; bulk disabled |
| No auth | Локальные уведомления disabled с просьбой войти; правила записи сохраняют текущую независимость от сервера |
| Permission denied | Компактное сообщение «Уведомления выключены в macOS» + системные настройки; preferences не считаются доставкой |
| Permission notDetermined | «Разрешение ещё не запрашивалось» + «Разрешить уведомления» |
| Offline | Аккаунтные данные не подменяются локальными, доступен только резерв локальных настроек |
| Version conflict | «Настройки изменились. Загрузите актуальные значения»; не перезаписывать автоматически |
| Active recording | Прежний индикатор и Stop; звук подавлен независимо от preferences |

## Адаптивность и клавиатура
При ширине до 760 px rail заменяется компактным раскрываемым списком разделов с явным текущим пунктом; выбор закрывает навигацию и фокусирует заголовок. До 560 px строка «текст/контрол» переносится вертикально; select занимает доступную ширину. Полное имя переносится, никогда не скрывается и не сжимается до нуля. 320 px и 200% — без горизонтальной прокрутки. Высокие списки прокручиваются в области содержимого, заголовок/навигация доступны.

Tab: Назад → разделы → controls по порядку. Selected link имеет aria-current, select связан с названием, status — aria-live polite, error — alert. Escape закрывает открытое меню; native control следует платформенной семантике. Обновление snapshot сохраняет фокус по идентификатору. Focus 2 px accent с offset 2 px; forced-colors не скрывает его. Switch state передаётся не только цветом. Анимация только hover/switch около 120 ms, prefers-reduced-motion отключает переходы.

## Что убрать и что сохранить
Убрать обзор-карточки, NSTabViewController поверх sidebar, три кнопки на приложение, постоянную ссылку второго редактора, повторные объявления об автосохранении и дубль уведомлений в аккаунте. Сохранить все реальные операции профиля/безопасности/календаря/тарифа, полную информацию о приватности, локальный резерв и ошибках. Не удалять функции под видом визуальной чистки.

## Передача в реализацию
`prototype.html` показывает выбранную композицию и демонстрационные состояния, не подключён к реальным данным. Макет не доказывает работоспособность bridge, доставки, TCC, сохранения на диск или установленного GRAF Dev. Reviewer принимает требования по checklists; затем выполняются tasks.md и quickstart.md. Внешний вид «1 в 1» не объявляется принятым до сравнения реального GRAF Dev.
