## Проверенный долг

- cabinet.css: sidebar height:100vh + border-right var(--line), dark --line #7e8898. Декоративная граница должна отделиться от semantic control border.
- sections.html: десять disabled пунктов и два подменю без рабочих действий. Удаление не является удалением доступной возможности.
- cabinet.css: gap навигации и selected background дублируются; list-card рамка/радиус перекрываются. Проверять computed styles, не удалять классы по одному rg.
- DesktopMeetingShellView.rowsNeedingNativeVisibility всегда пуст; compact panel недостижим в режиме кабинета. allRowsForLocalMode жив.
- Фиксированные тёмные native цвета конфликтуют по принципу с системными primary/secondary. Проверить фактический цвет/контраст в реальном окне.
- Разный размер окна автозаписи уже исправляет F246; F255 не делает свою копию исправления.
- .card presentation — только кандидат: остаётся до проверки всех сборок/API/тестов.
- Старый OPEN #5804 F201 T002 не соответствует текущему X T002 specs/201; F255 не закрывает и не переименовывает его. Удаление второго входа «Настройки» исключено из этой фичи, пока владение не согласовано.

## Что не считать долгом

no-JS/mobile navigation, историческая совместимость данных, current route allowlist,
CSRF формы, локальный режим, состояния загрузки select и реальные команды update/support bridge.
Слово legacy, размер файла или отсутствие использования в одном шаблоне не доказывают мёртвый код.
