## T025: тема без ухода со страницы, 2026-09-07

В меню профиля выбор темы остаётся быстрым действием: JavaScript отправляет существующую CSRF-защищённую форму через `fetch`, поэтому текущий экран и положение пользователя не заменяются страницей аккаунта. Сервер принимает необязательный локальный `return_to` только для обычного HTML/no-JS пути и использует прежний `/settings/account` fallback. При сетевой или серверной ошибке локальный preview откатывается к последней сохранённой теме, элементы выбора снова доступны, а меню не закрывается. Новых API, хранения или зависимостей нет.
