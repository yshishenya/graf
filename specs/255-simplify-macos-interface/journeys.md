# F255: путь пользователя до и после

База `a389657e607ef8389fcf947b26b158cee6928884`; подсчёт по исходникам, затем обязательное повторение в runtime. Действие — нажатие, выбор или сочетание клавиш. Системный выбор файла учитывается отдельно. Завершение задачи измеряется достижением нужного экрана/результата, не одним открытием меню.

| Начальное состояние → результат | Сейчас | Цель |
|---|---:|---:|
| Список → общие встречи, раскрытая панель | 1 | 1 |
| Список → настройки | 1 | 1 |
| Настройки → мои встречи | 1 | 1 |
| Настройки → общие встречи | 2 | 1 |
| Видимые иконки свёрнутой панели → раздел | 1 | 1 |
| Полностью скрытая панель → раздел | до 2 | ≤2 |
| Список → открыть профиль | 1 | 1 |
| Список → аккаунт через закрытый профиль | 2 | 2 |
| Открытый профиль → аккаунт | 1 | 1 |
| Список → сменить тему, автосохранение | 3 | ≤3 |
| Список → настройки через профиль | 2 | 2 |
| Список → календари | 2 | ≤2 |
| Другая категория настроек → календари | 1 | 1 |
| Список → открыть загрузку | 1 | 1 |
| Загрузка через выбор файла | 3 + системный выбор | столько же |
| Открытый диалог → перетаскивание и загрузка | 2 | 2 |
| Готовые разрешения → начать запись | 1 | 1 |
| Активная запись → остановить | 1 | 1 |
| Доступная история → назад/вперёд | 1 | 1 |
| Домой/обновить | 1 | 1 |
| Выбор материала | 0 | 0 |

Десять постоянных заглушек → 0; два пустых подменю → 0. Проверки разрешений, сохранения и отправки не сокращаются ради количества нажатий. Сочетания ⌘[, ⌘], ⌘0, ⌘R сохраняются. Если системная sidebar скрывается полностью, такой режим не выдаётся за rail с видимыми иконками; однодейственные переходы в существующем web rail сохраняются.
