## Требования

- [ ] CHK001 Определены ли исходное состояние и предел действий для каждого затронутого пути, включая различие rail и скрытой панели? [Полнота, Spec FR-001/FR-002, journeys.md]
- [ ] CHK002 Измеримо ли упрощение: десять заглушек и два пустых подменю исчезают без удаления работающих входов? [Измеримость, Spec FR-007/SC-002, journeys.md]
- [ ] CHK003 Различаются ли обязательное системное стекло, матовое исполнение и совместимость со старым сервером без ложного обещания стекла? [Ясность, Spec FR-004, contracts/interface.md]
- [ ] CHK004 Достаточно ли определены геометрия, длинные названия, роли цветов и контраст вместо общего требования «красиво»? [Ясность, Spec FR-003/SC-004, contracts/interface.md]
- [ ] CHK005 Согласованы ли light/dark/system, предпросмотр/ошибка сохранения и системные параметры доступности без новой настройки? [Согласованность, Spec FR-005/FR-015, contracts/interface.md]
- [ ] CHK006 Полны ли требования к клавиатуре, VoiceOver, Escape, возврату фокуса и текущему пункту при смене владельца? [Покрытие, Spec FR-006/FR-008, contracts/interface.md]
- [ ] CHK007 Указаны ли пределы размеров/масштаба и приоритет видимого Stop при нехватке места? [Граничные случаи, Spec FR-006/FR-009, quickstart.md]
- [ ] CHK008 Полны ли требования к входу, сети, локальному режиму, загрузке/сохранению и восстановлению страницы? [Покрытие, Spec FR-008/FR-009, contracts/interface.md]
- [ ] CHK009 Определены ли общие роли оформления всех поверхностей и граница с чужими F245–F253, админкой, public/no-JS? [Полнота, Spec FR-010/FR-011/FR-013, inventory.md]
- [ ] CHK010 Явно ли обосновано изменение прежнего reference-направления, происхождение ресурсов и допустимые удаления? [Прослеживаемость, Spec FR-012/FR-014, research.md]
- [ ] CHK011 Разделены ли требования к нативному доказательству, синтетическому preview, review и окончательному релизу? [Измеримость, Spec FR-016/SC-006, quickstart.md]
