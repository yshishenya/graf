# F255 T021: подменю профиля

2026-09-07, active Spec Kit slice / high-risk UX. Основание — скриншот владельца после возврата прежней навигации.

Причина: независимые `details` открывались штатным кликом и не закрывали соседей. Исправление находится в общем `initCabinetProfileMenus`, используемом web и embedded документами: mouse pointerover открывает один пункт, обычная строка закрывает подпункты, уход закрывает их через 150 мс. Задержка позволяет пересечь зазор. Клавиатурный фокус защищён от закрытия при случайном уходе мыши; summary activation и Escape сохранены.

Внешний контур стал мягче, радиусы контейнеров — 8 px, строк — 4 px. У вариантов темы нет отдельных рамок; текущий выбор обозначен галочкой. Увеличенный контраст сохраняет видимый контур. Состав и порядок меню, формы темы/выхода, доступность команд не изменены.
