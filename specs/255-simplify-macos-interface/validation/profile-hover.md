# F255 T021: подменю профиля

2026-09-07, active Spec Kit slice / high-risk UX. Основание — скриншот владельца после возврата прежней навигации.

Причина: независимые `details` открывались штатным кликом и не закрывали соседей. Исправление находится в общем `initCabinetProfileMenus`, используемом web и embedded документами: mouse pointerover открывает один пункт, обычная строка закрывает подпункты, уход закрывает их через 150 мс. Задержка позволяет пересечь зазор. Клавиатурный фокус защищён от закрытия при случайном уходе мыши; summary activation и Escape сохранены.

Внешний контур стал мягче, радиусы контейнеров — 8 px, строк — 4 px. У вариантов темы нет отдельных рамок; текущий выбор обозначен галочкой. Увеличенный контраст сохраняет видимый контур. Состав и порядок меню, формы темы/выхода, доступность команд не изменены.

## Повторный дефект по видео владельца: T022

Видеозапись от 2026-09-07 11:02 выявила пробел T021: прежняя проверка зазора перескакивала сразу внутрь submenu и не проходила через padding родительского меню. Во время реального перехода этот отступ становится `event.target === menu`; pointerover ошибочно закрывал все details. Подсветка встречи появляется уже после исчезновения подменю, а не вызывает его.

Воспроизведение на production assets: summary заканчивается на x247, submenu начинается x255; `elementFromPoint` для x247–254 возвращает само меню. Перемещение реального указателя на x251 немедленно скрывало подпункты. Причина — переход через внешний зазор мог попасть в строку встречи, после чего таймер закрывал меню. Исправление остаётся локальным: прозрачная зона наведения у submenu, проверка `relatedTarget` и повторная проверка `:hover` перед закрытием. Задержку не увеличивали, оформление и строки встреч не меняли.

Существующий WKWebView тест теперь вычисляет точку между фактическими краями summary/submenu, проверяет её hit target, посылает событие туда и ждёт 220 мс; отдельный шаг проверяет `pointerleave` с дочерним `relatedTarget`. До исправления падал `paddingKeptOpen`, после — весь suite 7/7 PASS. Browser pass: остановка в отступе на несколько секунд, переход внутрь и обратно сохраняют подменю; переход на «Настройки» закрывает его. После изменения ресурса тестовая страница обновлена без кэша. Локальные логи `/tmp/graf-f255/hover-video/{before,after,server}.log`; видео/кадры владельца в git не добавлены.
