## Runtime UI pass 2026-09-07

После разблокировки Mac установленный `GRAF Dev` был проверен через CUA. Для
проверки server-rendered кабинета временно использован тестовый сервер с
производственными шаблонами на локальном Dev-порту; после прохода он остановлен,
штатный `graf-dev-api-1` запущен снова. GRAF Local и Krisp не использовались.

- Окно 1040×680: внешние углы, общий матовый фон, левая навигация и правая
  панель отрисованы без обрезания. Сворачивание и повторное раскрытие правой
  панели сохранили содержимое и независимую кнопку записи; запись не запускалась.
- Левая навигация в исходном варианте: свернутая панель с пиктограммами и
  расширенная панель с логотипом, названиями разделов и профилем снизу.
  Основной порядок «Мои встречи → Поделились со мной → Настройки» сохранён.
- Меню пользователя открывается нажатием снизу слева и содержит прежний
  состав, disabled-состояния и команды. `Escape` закрывает меню и возвращает
  фокус на кнопку профиля.
- «Вид», «Решение проблем» и «Документация» раскрываются наведением. В каждый
  момент открыт только один пункт; переход через внутренний зазор сохраняет
  подменю, переход на другой пункт закрывает прежнее, уход в основную область
  закрывает всё. Проверено также в расширенной панели.
- Экран автозаписи открывается из правой панели. В списке нет одинаковых
  пустых иконок; строки приложений имеют компактные кнопки «Всегда /
  Спрашивать / Никогда» с высотой 28 pt и радиусом 6 pt. Настройки и запись не
  изменялись.
