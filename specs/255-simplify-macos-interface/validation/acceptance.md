## T026: причина отказа воспроизведения

Метаданные разрешённой тестовой записи: media 4382,250 мс, playback 4437,333 мс; declared duration=5 с. Размеры и SHA-256 обоих объектов совпадают с реестром. Причина `source_mismatch` — сравнение целочисленной ceil-длительности с допуском 250 мс. Для `initial_mixed_recording` общий helper теперь явно принимает совпадающее округление вверх. По умолчанию строгая проверка сохраняется: существующий тест обрезанного MP3 остаётся отказом, manual upload не изменён.

- Новая проверка 4001/4382/4437/5000 мс → 5 сначала FAIL; после исправления PASS. 0/4000/5251 мс → 5 отклоняются; без явного флага 4382 → 5 также отклоняется.
- Media matrix + storage: 55 PASS, включая хеши/размеры и обрезанный MP3.
- PostgreSQL finalize/публикация/удаление/публичный контракт плеера: 29 PASS, 1 skip, изолированная БД удалена. Существующий настоящий FFmpeg → upload/finalize → normalization → stored test расширен длительностями 1,0 и 0,4 с при декларации 1 с.
- Ненастроенный MediaScribe в Dev подтверждён `infra/docker-compose.dev.yml`: адрес и ключ пусты по определению стенда. Это ожидаемый отказ внешней обработки, не ошибка новой оболочки. Внешние credentials не переносились; содержимое тестового аудио не сохраняется в отчёте.
- Сборка промежуточного кандидата `faaaf93a18b3f2ca2419bf2bd6ef8f2901047792` остановлена оператором до установки, чтобы включить исправление длительности в единый следующий Dev. Это не PASS сборки.

Живое подтверждение темы и плеера требуется на новом установленном SHA.
