## Проверенные шаги и ограничения

1. Krisp Settings → App: свежий снимок `/tmp/graf-f255/audit/krisp-app-settings.png` согласован с текущим AX на момент снятия. Общий тёмный внутренний контейнер объединяет левую панель и контент; тонкая вертикальная граница, компактные строки, сдержанное выделение, отступ контента, разделение смысловых групп без карточки вокруг каждой строки.

Однако снимок CUA после переходов продолжал возвращать Settings → App даже после повторного подключения. Эти снимки отвергнуты как evidence нового экрана.
3. Профиль внизу основной панели присутствует в AX; открыть меню подтверждённым текущим снимком не удалось из-за рассогласования захвата. Не заявлять полный визуальный аудит профиля, списка/деталей, правой панели Krisp, светлой темы или доступности.

## Выводы для GRAF

- Сначала вернуть прежние навигацию и полный профиль: структура владельца важнее предположения, что системный List автоматически улучшает продукт.
- Общую рамку, внутреннюю навигацию и вспомогательную правую панель следует рассматривать вместе. Отдельные радиус16/margin8 только слева отменены. Внешнюю рамку и системные кнопки macOS не перерисовывать.
- Предпочтительное направление: общий внутренний контейнер с согласованным фоном, внешним отступом и радиусами; соединённые внутренние границы тонкие, без белой полосы. Если правая панель отдельная, её внешние отступы и радиус должны соответствовать общей композиции. Точные метрики требуют живого сравнения всех трёх областей, а не подстановки ещё одного радиуса.
- Матовый вариант: непрозрачные семантические поверхности, чёткий текст/фокус, минимум декоративных рамок. Существующие размещение команд и пути сохранить.
- Liquid Glass: только системный материал для подходящего слоя управления, без стеклянных строк/транскрипта/карточек. Не требует замены HTML-навигации системным списком. Если публичный API не даёт сохранить структуру и стабильный WebView, не выдавать CSS blur за системное стекло; матовый вариант остаётся рабочим.
- Автозапись: убрать одинаковые заглушки, компактная высота28 pt; сохранить подписи, selected/focus и текущие три правила. Поиск иконок и новые настройки не нужны для этого исправления.

## Официальные рекомендации, прочитаны 2026-09-07

- [Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos): разумная плотность, меньше вложенности, полноценная клавиатура и изменение размера.
- [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars): ясные короткие группы, знакомые символы, возможность скрытия; критическое действие не прятать у нижней границы. Профиль остаётся внизу; Stop — в независимом видимом слое записи.
- [Windows](https://developer.apple.com/design/human-interface-guidelines/windows): адаптивное содержимое, системная рамка/кнопки; не имитировать собственное системное окно.
- [Materials](https://developer.apple.com/design/human-interface-guidelines/materials): разделять слой содержимого и управления; системные материалы с доступным непрозрачным исполнением.
- [Menus](https://developer.apple.com/design/human-interface-guidelines/menus): предсказуемые группы и порядок, ограниченная глубина подменю, видимое выбранное состояние. Общая рекомендация не даёт основания менять продуманное владельцем меню без проверки.

Контраст численно не измерен; скриншот не доказывает VoiceOver/клавиатуру/Reduce Transparency. Полный проход T020 остаётся открытым до устранения рассогласования снимков и проверки остальных экранов. Новое оформление по этим ограниченным данным не внедряется.
