# F255: существующие данные и производное состояние

Новых таблиц, миграций, настроек материала и серверного источника прав нет.

| Состояние | Владелец | Ограничение |
|---|---|---|
| Тема light/dark/system | Существующий профиль и механизм preferences | Native отображает подтверждённую тему; не создаёт второе постоянное хранилище |
| Текущий маршрут/история | EmbeddedCabinetNavigationController и существующий route policy | Материал/сворачивание не пересоздают WKWebView и историю |
| Разделы и доступность команд | Существующие cabinet_navigation/settings_category_navigation и реальный документ | Native не хранит альтернативный список прав/разделов |
| Ширина/видимость панели | Состояние UI | Никакого backend запроса ради геометрии |
| Материал | Возможности ОС и параметры доступности | Вычисляемое значение, не пользовательская настройка |
| Запись/ошибки/локальная сохранность | Действующие native модели | Оболочка не управляет их жизненным циклом |

Граница интеграции передаёт только allowlisted метаданные навигации/темы и фиксированные команды.
Не передавать transcript, audio, tokens, произвольный JavaScript/URL или данные других фреймов.
При смене документа/аккаунта прежний snapshot недействителен. Неуспешное подтверждение native-владения оставляет одну существующую веб-навигацию.
