# Модель данных функции

Новая серверная таблица не нужна. Модель описывает данные, которые проходят
через конфигурацию страницы, браузерное согласие и проверку провайдера; запись
сессии хранится только у внешнего провайдера в пределах его настройки и не
становится внутренним объектом GRAF.

## Выбор cookies и аналитики

| Поле | Тип | Ограничение |
|---|---|---|
| `state` | перечисление | `unknown`, `accepted_all`, `necessary_only`, `customized`, `revoked` |
| `categories` | множество перечислений | только `necessary`, `analytics`, `advertising_attribution`, `behavior_replay`; `necessary` всегда включена |
| `analytics_allowed` | логическое | вычисляется из `categories`, не задаётся произвольным значением |
| `advertising_attribution_allowed` | логическое | вычисляется из `categories` |
| `behavior_replay_allowed` | логическое | вычисляется из `categories` и не расширяет поверхность Webvisor |
| `copy_version` | короткая строка | обязательна; новая версия не даёт новых разрешений молча |
| `decided_at` | дата и время | обязательна для сохранённого решения |
| `surface` | стабильный класс | только безопасная публичная поверхность или категория выбора |

Переходы:

```text
unknown -> accepted_all | necessary_only | customized
accepted_all -> revoked | necessary_only | customized
necessary_only -> accepted_all | customized
customized -> accepted_all | necessary_only | revoked
revoked -> accepted_all | necessary_only | customized
```

Неизвестное, повреждённое или устаревшее значение трактуется как `unknown` и
выключает необязательный сбор до нового выбора.

## Политика страницы

| Поле | Тип | Ограничение |
|---|---|---|
| `page_class` | стабильная строка | только класс из инвентаря страниц |
| `sensitivity` | перечисление | минимум `public`, `product`, `meeting`, `auth`, `financial`, `admin`, `embedded`, `error`, `future` |
| `page_view_allowed` | логическое | false по умолчанию для неизвестного или чувствительного класса |
| `safe_event_allowed` | логическое | true только для утверждённых мета-сигналов |
| `yandex_webvisor_allowed` | логическое | true только для `public_landing` и `public_download` при полном согласии |
| `click_map_allowed` | логическое | не шире Webvisor-политики |
| `scroll_map_allowed` | логическое | не шире Webvisor-политики |
| `form_analytics_allowed` | логическое | false до отдельного утверждения полей и права |
| `masking_required` | логическое | true на всех внутренних и чувствительных поверхностях |
| `blocked_reason` | стабильная строка | объясняет запрет без раскрытия приватного URL |

Новый класс получает `future_browser_page`, `yandex_state=blocked` и
`masking_required=true`, пока владелец инвентаря явно не добавит его.

## Безопасное событие

| Поле | Тип | Ограничение |
|---|---|---|
| `event_name` | перечисление | только версионированный публичный или внутренний каталог |
| `page_class` | стабильная строка | должна существовать в инвентаре |
| `stable_fields` | перечислимые значения | неизвестные поля удаляются или отклоняются |
| `campaign_attribution` | ограниченный объект | только разрешённые UTM и категория реферера |
| `consent_state` | перечисление | текущее состояние выбора, не произвольный текст |
| `stable_pseudonymous_user_id` | обезличенная строка | только `graf_pseudo_*`, никогда исходный ID |
| `occurred_at` | дата и время | серверное или проверенное ISO-8601 значение |

Запрещены: email, телефон, имя, название рабочего пространства, исходные
идентификаторы, meeting ID, файл и путь, токены, секреты, пароль, cookies,
платёжные сведения, URL, query, hash, DOM-текст, аудио, расшифровка и произвольная
полезная нагрузка.

## Доказательство настройки провайдера

Это метаданные выпускного evidence, а не пользовательское событие.

| Поле | Тип | Ограничение |
|---|---|---|
| `provider` | перечисление | `yandex_metrica` или утверждённый внутренний провайдер |
| `counter_reference` | закрытая ссылка | не публикуется в обычных логах и клиентском ответе |
| `inventory_version` | короткая строка | совпадает с версией политики страницы |
| `checked_at` | дата и время | обязательна для ручной проверки |
| `capabilities` | набор статусов | Webvisor, clickmap, scrollmap, links, bounce, forms, filters, goals |
| `retention_status` | статус | фактический срок должен быть прочитан из рабочего кабинета |
| `legal_status` | статус | выпуск разрешён только при `approved` |
| `privacy_status` | статус | выпуск разрешён только при `approved` |
| `provider_smoke_status` | статус | должно быть проверено тестовым визитом |

## Жизненный цикл

1. Браузер получает только обезличенную и минимальную конфигурацию класса страницы.
2. До выбора пользователя создаётся только необходимое локальное состояние.
3. После opt-in формируются разрешённые события или публичная запись в пределах
   политики страницы.
4. При отзыве новые отправки прекращаются; локальный выбор обновляется.
5. Данные у внешнего провайдера живут по его фактической настройке хранения.
   GRAF не заявляет об автоматическом удалении того, что уже передано наружу.
