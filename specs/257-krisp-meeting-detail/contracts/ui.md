# UI Contract: страница итогов

## Иерархия

Все приватные контролы внутри #cabinet-main. Верхняя строка с возвратом и существующим action-row; центрированный title/metadata; строка tablist + format group + copy; detail-main с двумя панелями; действующий playback sibling.

## Контролы

- Сохранить id/detail-tab и data-detail-panel, aria-controls/selected/tabindex, hash/query navigation и source-return.
- data-summary-format-controls остаётся единственным владельцем picker/listbox/pending/refresh; формат не потомок role=tab. При переходе к расшифровке группа скрыта; открытое меню закрывается.
- Действия со страницей скрыты при processing replacement-active; недоступный экспорт не становится доступным из-за новой кнопки.
- data-detail-copy выбирает `summary` для вкладки `outcomes` и `transcript` для `recording`; доступность определяется существующим, не disabled option[value] внутри select[data-export-scope] и формой экспорта. Выбор в диалоге не меняется. Недоступный состав: disabled, понятная причина. Без JavaScript прямое копирование скрыто; обе разрешённые панели видны и имеют якоря. Доступны только существующие скачивания текущих артефактов с action=download (owner/shared); JSON-экспорт выбранного состава и выбор/генерация формата требуют JavaScript. Ограничение объясняется видимым текстом, ссылка на личные форматы остаётся.
- Копирование делает ровно один requestExport, фиксирует состав до await, сохраняет CSRF/revisions/endpoint/no-store. При ошибке видимый текст/role=status; при отключённом clipboard доступен существующий экспорт. После removal исходной формы не пишет приватное содержимое в clipboard и не крадёт фокус.
- Share/more/details/delete/reprocess сохраняют существующие роли, клавиатуру, подтверждения и возврат фокуса.
- Общий pending-gate блокирует повторное копирование и экспорт до завершения операции. Непосредственно перед clipboard проверяются подключённость исходных формы и trigger, отсутствие replacement-active и актуальная разрешённость захваченного option. При отмене/ошибке finally восстанавливает только разрешённые текущим состоянием действия. Смена вкладки сама по себе не отменяет разрешённый захваченный состав. Дополнительного запроса проверки прав не вводится.

## Геометрия

Подробные координаты верхней области при1800×915, состояния элементов, карта переходов и границы измерений: [design-handoff.md](../design-handoff.md), §§1–4/12–14. Метаданные12/16px, вес600, высота24px; вкладки14/20px, вес600, высота28px. После локализации ширину текстовых кнопок определяет надпись. Повторная проверка при высоте915 сохранила геометрию верхней области измерения1800×859 ниже.

Подтверждённое измерение веба при фактическом viewport 1800×859 CSS px, visualViewport.scale=1: колонка заголовка 674px, видимый текст документа 664px; заголовок 22px/32px, обычный текст 16px/28px, заголовок раздела 20px/24px. Прежние 600/20/14 и масштаб 82% были неподтверждёнными оценками и не используются как эталон. Для GRAF принять наружную колонку 674px и внутренний отступ текста 5px; окончательное совпадение проверяется T009.

Опорные точки SC-003: левый край/ширина названия, верх метаданных, верх/высота вкладок, левый край/ширина первого абзаца и расстояние вкладки→первый абзац. Координаты считаются в CSS px от верхнего левого угла viewport продукта; боковая панель отдельно исключается из доступной ширины. Измерять AI Notes/Итоги и Transcript/Расшифровку при scrollTop=0, закрытых поповерах и чате, одинаковой ширине колонки. Сравнивать типографические роли, а не вертикальное положение разделов после разного текста. Для нижних разделов использовать синтетический текст равного числа строк. При недоступном нормализованном измерении SC-003 остаётся непроверенным.

Уточнение метода, принятое независимым reviewer2026-09-09: для вертикальной опоры Transcript можно сравнивать расстояние от низа вкладок до верхней границы `AXStaticText` первой реплики через публичное дерево доступности macOS в обоих продуктах. Из экранных координат вычитается начало `AXWebArea`; масштаб проверяется по674×32 названия и28px вкладок. Это не DOM-координата текстового блока; DOM-ширина/левый край и типографика остаются отдельными измерениями. Допуск8px не меняется. Промежуточное сообщение Reformat закрывается перед сравнением готовой страницы.

Верхние действия находятся у правого края, back у левого. Компактные вкладки с мягким активным фоном вместо общей нижней линии. Длинные заголовки переносятся. Высота интерактивного элемента >=28px (coarse pointer >=44px), visible focus >=2px. Контраст WCAG 2.2 AA. На <=640px поля 16px и перенос группы действий; меню ограничены шириной viewport; min-width:0 у grid/flex потомков. При 200% горизонтальная прокрутка всей страницы отсутствует.

## Допустимые отклонения

Локализация, собственные шрифты/значки, реальные статусы GRAF, текущие форматы/протокол F239, защищённый доступ, границы удаления, сохранение панели плеера и no-JS. Нет чат/редактор/папки/теги/комментарии/публичная ссылка. Отличия перечислены в reference-audit.md.

R49/R50 подтверждают AI Notes на390/768/1024/1440: sidebar скрыт на390/768, виден на1024/1440; точный breakpoint не измерен. На390 RU выходит за правый край при scrollWidth=390. GRAF сохраняет собственную боковую навигацию и переносит действия по контракту выше; воспроизведение этого дефекта запрещено. Светлая тема и200% Krisp не подтверждены: собственные требования GRAF остаются обязательными. R52 подтверждает desktop-композицию AI Notes; повторная проверка остальных desktop-состояний не считается выполненной. Неизвестные конечные эффекты Share/export/download/delete/reprocess референса не меняют действующие операции GRAF.

## Граница с F256

F257 владеет шапкой, документом, вкладками, группой формата и прямым копированием. F256 владеет внутренними контролами воспроизведения, шкалой, обрезкой и комментариями. Для начала F257 завершение F256 не требуется: сохранить действующий mount плеера, source-navigation и возврат, существующие обработчики и вычисление запаса прокрутки. Не фиксировать предполагаемую высоту будущей панели F256, не менять общие CSS-селекторы так, чтобы затронуть её внутреннюю разметку. В T008/T009 проверить отсутствие перекрытия фокуса/источника/последней строки с действующей панелью; если к этому моменту F256 интегрирована, повторить эти сценарии с ней. Чужой worktree не изменять.
