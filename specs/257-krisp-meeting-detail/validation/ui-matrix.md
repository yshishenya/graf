# F257 — предварительная матрица интерфейса

Дата: 2026-09-08. Это автоматическая проверка общей страницы на синтетическом стенде Chromium. Проверка установленного GRAF Dev и окончательное принятие SC-001–SC-004 по T009 ещё не выполнены.

## Измерения

Во всех 16 сочетаниях web/embedded × dark/light × 390/768/1024/1440: `document.scrollWidth <= viewport`, `main.scrollWidth <= main.clientWidth`, обрезанных видимых новых действий — 0. Справка ограничена шириной окна. Темы дали одинаковую геометрию.

| Поверхность | Ширина | Колонка / текст | y названия / метаданных / вкладок / документа |
|---|---:|---:|---|
| web | 390 | 358 / 348 | 113 / 149 / 185 / 255 |
| web | 768 | 674 / 664 | 113 / 149 / 185 / 223 |
| web | 1024, 1440 | 674 / 664 | 56 / 92 / 128 / 166 |
| embedded | 390 | 294 / 284 | 56 / 92 / 128 / 198 |
| embedded | 768 | 656 / 646 | 56 / 92 / 128 / 166 |
| embedded | 1024, 1440 | 674 / 664 | 56 / 92 / 128 / 166 |

На широком окне измерены 22/32 px для названия, 12/16 px для метаданных, 14/20 px и высота28 px для вкладок, 16/28 px для текста. Широкие y-опоры и ширины совпали с нормализованными опорами R45/R52. Боковая панель была свёрнута штатным состоянием GRAF; её ширина исключается из сравнения центрирования.

Допустимые отличия: собственная мобильная навигация веба добавляет57 px сверху; узкое окно переносит Copy на следующую строку. Embedded сохраняет собственную узкую боковую панель. Метаданные протокола F239 оформлены компактно с сохранением полей и содержания; смысловые разделы, задачи, неизвестные сроки и ссылки не заменяются структурой выбранного шаблона Krisp. SC-003 остаётся предварительным до Computer Use на точном SHA.
