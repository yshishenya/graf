### Почему повторная обработка неприменима к текущей встрече

Текущий processing result связан с тем же синтетическим процессом. `cabinet/view_models.py::processing_state` публикует доступность повторной обработки только при совпадении ID с `processing_workflow_id(...)`, поэтому действие правильно отсутствует. Это N/A для данной fixture, а не PASS диалога. Запись в базу для обхода условия не выполнялась; существующие контракты повторной обработки сохранены.
