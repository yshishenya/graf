# UX Checklist: полный egress внешнего приглашения

- [X] A full invitation page exposes the existing playback and export surfaces
  only when readiness says they are available.
- [X] A genuinely unavailable artifact keeps truthful unavailable copy and does
  not imply a new recovery action.
- [X] Download actions use normal browser attachment behavior.
- [X] Existing report scope and format labels remain understandable to the
  recipient.
- [X] Revoked or expired access does not show meeting content or internal
  diagnostics.
