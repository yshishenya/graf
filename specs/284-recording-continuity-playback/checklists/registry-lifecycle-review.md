Проверены все вызывающие пути: секундный таймер, полный/неполный native

теперь принимает optional registry; прежнее удаление завершённого tracked

ровно один ended и отсутствие новых предложений/кандидатной телеметрии при

восстановление реестра использует действующие policy/prerequisites.

Композиция больше не выходит до advance. Ownership event без реестра проходит
reconcile; полный и неполный snapshot остаются на прежнем пути с признаком
полноты. Новые prompt/auto/candidate outputs дополнительно ограждены guard
registry до предложения/rollup. Асинхронный старт повторно проверяет текущий
реестр в currentMeetingDetectionStartDecision. Ended не зависит от реестра,
снимает ручное подавление только для завершённой цели и вызывает существующий
Stop с проверкой bundle/session; start-in-progress сохраняет pending Stop,
а finishMeetingDetectionStart выполняет его после успешного старта. Проверка
600s остаётся после обработки outputs и продлевается только текущим
подтверждением записываемой цели. Второй таймер или устаревший реестр не добавлен.
