# Quickstart
Автоматические проверки используют синтетические данные. Отдельный физический контроль Telemost с микрофоном и системным звуком разрешён пользователем 2026-10-03 только в единственном GRAF Dev.
1. Run `swift test --package-path apps/macos --filter MeetingDetection` and focused ownership/native/bridge/queue/deletion tests. New regression checks first fail on old code, then pass. Simulated clock covers45minutes, repeated snapshot failure/restarts, empty/inactive15s, unknown600s, manual suppression and permissions. Run actual shared evidence predicate and detector with advancing synthetic clock; source-string assertions alone do not qualify. Native empty + old log active must still end15–17s; native unavailable + cached log active must expire600s. Native-mode stream must never run a configured old-log-active script. Nested helper attribution and unapproved target suppression have negative cases.
2. From the repository root run `bash apps/server/scripts/run_local_postgres_tests.sh --focused -q tests/contract/test_playback_status_contract.py` plus quota-copy and cabinet playback focused checks. Use the helper’s isolated disposable database; a bare pytest invocation lacks the required test database setup.
3. Run new detail local-playback Playwright check and existing local-recording-focus/handoff, playback-refresh checks with existing Playwright NODE_PATH.
4. Run `python3 scripts/check_spec_kit_governance.py` and relevant changelog validator. Record commands/results in validation.md, including unavailable gates.
5. Live acceptance: first dev-harness status; clean authorized commit needed before build/promote. Only /Applications/GRAF Dev.app. Физический контроль выполняется только по явному разрешению пользователя; сохраняются обезличенные технические доказательства. Hardware acceptance and GitHub exact-SHA checks remain separate gates.

6. T010: simulate current process-list reads with one unreadable/exited/malformed process and an independently active registered meeting target. Retain positive target evidence across45min; no repeated prompt or stale600s stop. Partial empty never proves inactivity or renews the evidence clock; complete empty still ends after15s and entirely failed enumeration remains unavailable. No physical audio is captured.

7. T011: реальный LocalRecordingWriter, ограниченные синтетические источники с различными размерами пакетов и непрерывными PTS. Сначала red/source_overflow на прежнем порядке чтения, затем green без расширения буферов; обе финальные дорожки и длительность. Повторить отрицательные проверки настоящей потери/переполнения, часов, формата и бесконечного stop-source. Аппаратный45min Telemost разрешён пользователем 2026-10-03; предыдущий прогон failed через361s и не является PASS. Сохранять только обезличенные метаданные.

8. T012: пауза, несколько уже принятых микрофонных порций, resume до чтения. Заглушить всю паузную очередь при сохранении кадров/PTS, возобновить новые порции; проверить частичные reads, повторные паузы и настоящий writer. Источник без точной границы с непрерывным пополнением явно отклоняет resume, сохраняет паузу/открытый checkpoint и ограниченный Stop; это отдельная проверка от успешного возобновления производственного источника.
9. T013: задержать настоящий fetch playback poll, переиспользовать тот же main для другого meetingId, вернуть403/404/success либо отклонить сеть; новую встречу не менять. Задержанное чтение тела — отдельная проверка. Действующий403 своей встречи сохраняет отказ.
