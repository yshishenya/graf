# Contract: интерфейс `dev-harness` (изменения Feature 269)

**Version**: 1 | **Date**: 2026-09-16 | **Applies to**: `infra/scripts/dev-harness.sh` / `scripts/dev-harness.py`

Существующие команды и их JSON-поля сохраняются. Ниже — изменённые гарантии и
новая команда. Ошибки печатаются в stderr как `{"status":"blocked","error":…}`
с кодом возврата 2 (существующее поведение).

## `build --live`

- **Гарантии**:
  - каталог сборки `artifacts/<manifest_id>/build` удаляется при успешном завершении;
  - архив `runtime-images.tar` **не создаётся**;
  - приложение `artifacts/<manifest_id>/GRAF Dev.app` создаётся и остаётся;
  - артефакты манифестов вне политики хранения могут быть удалены в конце операции;
  - при незавершённом переходе схемы операция по-прежнему блокируется (существующее поведение).
- **Совместимость**: `manifest.components[].digest` заполняются как раньше; `rehydrate` для кандидата до promote недоступен (архива нет) — это ожидаемо.

## `promote --live`

- **Гарантии**:
  - при успешном продвижении архив `runtime-images.tar` существует для нового **целевого** манифеста (`parent_manifest_id` нового активного) и содержит все образы его набора;
  - приложение активного манифеста и приложение целевого манифеста остаются на диске;
  - архивы, приложения и теги всех прочих манифестов удаляются;
  - если образы прежнего активного манифеста недоступны в Docker, новый архив не создаётся, а операция завершается ошибкой до публикации active pointer (fail-closed);
  - при незавершённом переходе схемы используется существующий сценарий перехода; снапшоты удаляются после перехода в `complete`.

## `rollback --live`

- **Гарантии**:
  - требует, чтобы образы целевого манифеста были загружены; при их отсутствии ошибка содержит указание выполнить `rehydrate --manifest <path>` (существующее поведение);
  - после успеха применяется политика хранения: активный — приложение, целевой (родитель) — архив и приложение;
  - снапшоты и снимки приложения обновляются по общим правилам.

## `rehydrate --manifest <path>`

- **Гарантии**:
  - работает для манифеста, чей архив удержан политикой (целевой откат);
  - для манифеста вне политики возвращает `{"status":"blocked","error":"immutable Dev image archive is unavailable; rebuild a new candidate"}`;
  - проверяет каждый образ манифеста и label source SHA (существующее поведение).

## `prune [--dry-run] [--json]` (новое)

- **Назначение**: применить политику хранения и удалить накопленный мусор без сборки.
- **Ограничения**:
  - требует `GRAF_DEV_STATE_DIR` (как `live`-операции) и берёт общий state lock;
  - запрещена при незавершённом переходе схемы (`phase ∉ {complete, recovered}`) или при наличии `rollback-required.json` — код возврата 2, ничего не удаляется;
  - удаляет пути только внутри state root.
- **Гарантии**:
  - в `--dry-run` не изменяет состояние, печатает те же пути и объёмы;
  - удаляет: артефакты вне политики, теги `graf-dev-immutable:*` вне политики, каталоги завершённых переходов схемы, остаточные `transactions/previous-*.app`;
  - дописывает квитанцию в `<state>/prune-history.jsonl` (кроме `--dry-run`);
  - при ошибке Docker ставит `status: partial` и продолжает файловые удаления;
  - JSON-квитанция соответствует `contracts/prune-receipt.schema.json`.
- **Пример ответа**:

```json
{
  "operation": "prune",
  "status": "ok",
  "dry_run": false,
  "removed": [
    {"path": "/…/artifacts/dev-aaaa", "bytes": 2147483648, "kind": "artifact_set"}
  ],
  "kept": [
    {"manifest_id": "dev-751d52a9381f", "paths": ["/…/artifacts/dev-751d52a9381f/GRAF Dev.app"]}
  ],
  "bytes_freed": 2147483648,
  "partial_reasons": []
}
```

## `status --json`

- **Дополнение**: поле `retention`:
  - `active_manifest_id`, `rollback_target_id` (может быть `null`);
  - `artifacts_bytes`: суммарный размер каталогов `artifacts/*` (без вызовов Docker);
  - `archive_present`: bool для целевого манифеста;
  - `state_dir`: существующее поле.
- **Совместимость**: существующие потребители (`dev_state` в документации) продолжает работать.

## Ошибки и коды возврата

| Ситуация | Ответ |
|----------|-------|
| Незавершённый переход схемы | `blocked`, exit 2; состояние не меняется |
| `rollback-required.json` присутствует | `blocked`, exit 2; сначала `recover-schema`/`rollback` |
| Docker недоступен в `prune` | `status: partial`, exit 0; файлы удалены |
| Архив целевого отсутствует при `promote` | `blocked`, exit 2, active pointer не изменён |
| Целевой манифест отсутствует или нечитаем | `blocked`, exit 2; active pointer и артефакты не меняются |
| Попытка удалить путь вне state root | `blocked`, exit 2 |
