# UX Requirements Quality Checklist: Восстановление скачивания аудио

- [x] Цель пользователя сформулирована как наблюдаемое скачивание исходной записи.
- [x] Описаны browser и embedded macOS WebView сценарии.
- [x] Порядок событий меню и default navigation задан явно.
- [x] Отмена системного save panel не считается ошибкой и допускает повтор.
- [x] Недоступное аудио не превращается в неработающую видимую capability.
- [x] Ошибки не требуют нового модального состояния или redesign меню.
- [x] Требования не меняют clean-room UI, accessibility semantics или localization copy.
