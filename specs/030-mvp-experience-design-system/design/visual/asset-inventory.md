# Visual Asset Inventory

No external visual assets are required for feature `030`.

## Approved Asset Types

- Editable Figma frames created from original layout primitives.
- Original text, layout, and component specifications in this repo.
- Future product screenshots only after a separate implementation slice produces them.

## Forbidden Asset Types

- Krisp screenshots, icons, copy, UI captures, brand assets, or proprietary flows.
- Real private meeting content or raw audio.
- Secrets, signed URLs, tokens, passwords, or live local paths.

The design uses external kits and templates only as clean-room references or
published component sources. No Krisp screenshots, copied Krisp components, or
third-party product screenshots are embedded into the product screens.
