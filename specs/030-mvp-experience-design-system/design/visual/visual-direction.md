# Visual Direction

2brain Rec should feel quiet, precise, and trustworthy: a work tool for people who need meeting capture to be obvious, recoverable, and useful after recording.

## Principles

- Status first, decoration last.
- Native capture truth remains visually persistent.
- Web cabinet is denser and review-oriented, not a marketing dashboard.
- Use restrained contrast, compact cards, and clear typography.
- Avoid one-note palettes: pair graphite/white with green, cobalt, amber, and red semantic roles.
- Use spatial hierarchy instead of hero spectacle: top status strip, dense list,
  right detail/review panel.
- The product should feel like a modern 2026 desktop productivity tool: calm,
  sharp, native-aware, fast to scan, and not decorative.

## 2026 Minimalism

- Fewer surfaces, stronger state language.
- Soft panels with 8px radius maximum.
- No gradient blobs, bokeh, or decorative orbs.
- Icons clarify actions; copy explains risk.
- Thin dividers and grouped rows replace nested cards.
- Panels use subtle tonal contrast rather than large shadows.
- Empty states are compact and action-oriented.

## App Personality

- Desktop is the trust shell: the first impression is "I know exactly whether
  recording is happening and where my file is."
- Web is the workbench: the first impression is "I can find, process, review,
  share, and clean up meetings without guessing status."
- AI feels assistive and scoped, not magical. Scope controls and provenance sit
  near AI actions.

## Brand Distance From Krisp

- Do not copy Krisp navigation labels one-for-one when a 2brain term is clearer.
- Do not copy Krisp icon shapes, empty states, or exact row composition.
- Allowed lessons: dense meeting list, command search, filter chips, transcript
  plus playback review, AI drawer, and browser-only admin depth.
- Required difference: 2brain leads with capture/upload truth and owner-controlled
  storage; it does not present as a generic meeting-notes SaaS clone.

## Layout Feel

- Desktop:
  - Left rail: native sections and browser handoff entries.
  - Center: ready/recording/queue status and recent meetings.
  - Right rail: current source, minimal connection/session/policy badge, and
    recovery hints; full account/workspace summary comes from embedded web.
- Web:
  - Persistent sidebar for Meetings, Uploads, Action Items, Contacts, Settings.
  - Main list/review area uses table-like rows and sticky review controls.
  - Right drawer is reserved for AI, activity, or metadata, never generic promo.
