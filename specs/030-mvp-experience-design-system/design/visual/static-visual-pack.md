## Status

The existing v1 page is not final handoff evidence. It remains as historical
evidence only. The v2 page is also superseded because it was light/English. The
v3 Dark RU page is superseded after stakeholder review because it remained too
rough and not sufficiently kit-grounded. The v4.1 page is superseded because 14
frames were not enough for full MVP design coverage. The v5 page is superseded
after the 2026-06-13 Krisp/code/Figma re-audit. The v6 page is also superseded
for handoff after stakeholder review. The first v7 IA rebuild, v7.1, v7.2,
v7.3, and v7.4 are superseded by the active static pack candidate page
`030 MVP Experience v8 - Clean RU`.

The v8 clean Russian candidate has these layers:

- 17 visible top-level frames organized as workspaces, state variants, web
  cabinet surfaces, QA board, and separate light proof frame.
- Free UI kit grounding through Figma Simple Design System live samples.
- Apple macOS 26 native reference geometry, pending manual library attachment
  for real Apple instances.
- Dark theme as the primary MVP visual surface.
- Russian as the primary MVP UI language.
- QA evidence with frame-bound overflow `0`, bad button heights `0`, bad chip
  heights `0`, visible forbidden implementation copy `0`, and placeholder
  artifact nodes `0`.
- Speaker-lane evidence in `V8 08`: one separate lane per speaker, with
  talk-time percentages and assignment actions.

## Review Notes

  work, share/export/delete, degraded states, route/status matrices, and design
  system direction.
- V8 uses neutral synthetic Russian data and must not copy Krisp visual
  assets, icons, copy, exact navigation, or private meeting content.
