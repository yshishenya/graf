# Web Cabinet Handoff

## Implement In Browser Cabinet

- Meetings list and empty state.
- Manual upload for audio and common video/meeting files.
- Processing status.
- Meeting review complete and degraded states.
- Account/security basics.
- Deletion/access entry points.

## Browser-Only Or Deferred

- Broad admin.
- Billing.
- Team management.
- Public sharing.
- Advanced exports/downloads.
- Detailed audit.
- Help/legal.
- Full video review.

## Must Align With Desktop

- Same status meaning.
- Same deletion/access truth.
- Same source/track provenance.
