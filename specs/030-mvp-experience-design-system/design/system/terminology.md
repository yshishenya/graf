# Terminology

| Term | Meaning | Do not confuse with |
|---|---|---|
| Desktop trust shell | Native app surface that owns capture truth | Server web cabinet |
| Embedded cabinet subset | Allowlisted server content inside desktop app | Full browser product |
| Browser cabinet | Full web product surface | Desktop recorder shell |
| Recording | Native capture is actively running on this Mac | Server transcription or processing |
| Local package | Locally saved recording artifacts after `Остановить` | Uploaded server record |
| Local only | Exists only on this Mac | Uploaded or backed up |
| Uploaded | Server accepted artifacts | Transcript ready |
| Extracting audio | Server is pulling usable audio from an uploaded container | Full video processing |
| Transcribing | Server is generating transcript text | Notes/summary complete |
| Transcript ready | Transcript available | Notes ready |
| Notes ready | Summary/decisions/actions available | Human approval |
| Processing issue | Recoverable or explainable server/media state | Silent failure |
| Access denied | User/account cannot open this meeting | Meeting deleted |
| Deleted where controlled | Deleted in 2brain Rec controlled systems | Universal erasure |
| Browser handoff | Open route in browser | App failure |
| Source provenance | What 2brain Rec knows about capture/upload origin and track separation | Quality guarantee |
| AI answer scope | Meetings the assistant is allowed to query | Global workspace access by default |
| Platform desktop shell | Native host for macOS, Windows, or Linux capture-critical UI | Product web cabinet |
| Server-owned product UI | Backend/web-rendered product workflows embedded in desktop or opened in browser | Native capture controls |
| Спикер | Diarized voice label in transcript/speaker assignment | Meeting participant identity |
| Участник | Known person/contact in a meeting | Diarized voice label |
| Исполнитель | Person assigned to an action item | Speaker label |

## Product Copy Rules

- Say `Идёт запись` only for active native capture.
- Say `Загружено` only after the server accepts the media package.
- Say `Транскрипт готов` before saying `Заметки готовы`.
- Say `Удалено в пределах 2brain Rec` or equivalent bounded copy in confirmations and
  final deleted states.
- Do not say `video ready` for uploaded meeting containers unless the product
  intentionally supports video review.
- Do not say `speaker separation` when the source is uploaded mixed audio or
  unknown.
- Desktop copy uses `Открыть в браузере` for browser-only routes. It does not call
  those routes broken, unavailable, or unsupported.
- Desktop copy uses embedded server-owned routes for variable product UI such as
  speaker assignment. It must not describe those routes as native macOS logic.
- Use `спикер` for diarized voice, `участник` for a meeting person/contact,
  and `исполнитель` for an action assignee.
