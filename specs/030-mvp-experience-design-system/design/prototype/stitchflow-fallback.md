# StitchFlow Fallback

## Decision

Figma succeeded for feature `030`, so StitchFlow was not used as the primary prototype source.

## Fallback Readiness

If Figma access becomes blocked, regenerate the prototype in StitchFlow using:

- Screen inventory: `design/screen-inventory.md`
- User flows: `design/user-flows.md`
- Visual direction: `design/visual/visual-direction.md`
- Component inventory: `design/system/components.md`
- Route/status matrices: `design/route-visibility-matrix.md`, `design/status-state-matrix.md`

## Required Export Evidence If Used

- Stitch project id.
- Screen ids and names.
- `DESIGN.md` status.
- Exported screenshots.
- HTML/code checkpoint path.
- `download-project.json` warnings.
