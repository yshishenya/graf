## Исходные критерии и полнота объёма

Исходная #6330 требует read-only summary/evidence и одного owner/worktree для
исполнителя. T016 содержит оба результата, scoped путь реализации и путь отчёта.
Пять случаев US3 и оба дополнительных ограничения не потеряны: они явно назначены
в Independent Test и конкретизированы неизменённым agent-assignment contract.
Короткая task строка не должна повторять весь spec дословно, но обязана выполнить
эти связанные нормы; одного добавления произвольного абзаца для PASS недостаточно.

Исходные #6315/#6316/#6331/#6332/#6333/#6334 имеют по одной собственной задаче с
точными путями и подтверждением результата. Новое tasks не меняет исходный смысл
T019: local fast на финальном чистом exact SHA сохранён сверх трёх PR checks,
не заменён dirty диагностикой или предыдущим base. Проверка на этой стадии не
подтверждает возможность пройти fast и не освобождает от его исполнения.

Исходная #6314 сохраняет все пять критериев: collision-safe параллельные номера,
связь feature/umbrella/spec/branch/tasks/PR/receipt, отказ stale/partial evidence,
наблюдаемый безопасный enforcement и стабильный root. Для принятых общих механизмов
есть явные прежние владельцы и проверочные команды; их полный closeout здесь
не объявляется. T013 сохраняет реальный PR/manual/merge_group rehearsal и откат;
T020 обязан удерживать непроверенные operator gates и добавлять обнаруженный
обязательный остаток append-only. Implementation Strategy прямо сохраняет точное
операторское применение как требование всей фичи. Не назначается автоматический
cutover без разрешения, не отменяется требование при отсутствующем событии.

Это достаточная декомпозиция первого US3 среза с явным остатком, а не готовый
план немедленного применения защит. Перед будущим operator cutover требуется
отдельный конкретный diff/состояние/разрешение и, при необходимости, дополнительные
задачи по T020. Полная F230 не может быть закрыта по одному завершённому T016.
Семантика отменённых дублей для общего final closeout остаётся открытым известным
ограничением; обход completed-validator или фиктивные [X] не разрешены.
