## Проверенные границы

1. Константа PUBLIC_ANALYTICS_MAP_FRAME_ORIGINS содержит только официальные
   HTTPS origins metrika.yandex.ru, metrika.yandex.by, metrica.yandex.com,
   metrica.yandex.com.tr, webvisor.com и wildcard поддоменов webvisor.com.
   Список передаётся в браузер только при replay_allowed. Не добавлены HTTP,
   произвольные поддомены yandex или широкое разрешение любых предков.
2. public_template_response начинает с прежних общих защитных заголовков.
   Только сочетание automatic_enabled и replay_allowed заменяет
   frame-ancestors none ограниченным списком и удаляет X-Frame-Options.
   base-uri self и object-src none сохранены. Контекст вычисляет это
   сочетание только для двух разрешённых public surface при действующих
   global/environment/counter/withdrawal ограничениях. Приватные маршруты
   не получают исключение. Публичные маршруты проверены на использование
   своего analytics_path; пользователь не управляет готовым context.
3. trustedMapFrame использует URL parser, HTTPS и отсутствие нестандартного
   порта; затем сравнивает точный origin либо суффикс .webvisor.com только
   при наличии явного wildcard в конфигурации. evilwebvisor.com,
   webvisor.com.evil.invalid, metrika.yandex.ru.evil.invalid и лишний
   поддомен metrika.yandex.ru не проходят. Явный :443 нормализуется URL
   parser в стандартный origin и обоснованно допускается.
4. JS-проверка referrer не объявляется самостоятельной границей безопасности
   предков: реальный браузер дополнительно применяет CSP ко всем предкам.
   Отсутствующий или некорректный referrer не даёт trusted исключения.
   Сервер не ослабляет CSP на основании произвольно присланного Referer.
5. trustedMapFrame не обходит preference(). Общий старый или новый отказ
   предотвращает загрузку SDK; отказ во время загрузки не допускает init/hit;
   отказ после загрузки приводит к destruct. При старом отказе от replay
   с сохранённой analytics счётчик может работать, но init получает
   webvisor=false и clickmap=false. Новое исключение frame не превращает
   такой частичный отказ в разрешение записи поведения.
