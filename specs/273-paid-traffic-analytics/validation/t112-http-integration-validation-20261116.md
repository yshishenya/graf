## Поведение и область

Подключены два настоящих кабинетных POST alias к одному обработчику с прежними
Principal/Tenant/CSRF и внешней границей времени. Valid proof проверяется в
одной сессии сохранения пары событий; expired proof обновляется одной строго
читающей сессией без INSERT/COMMIT. Invalid/future/TTL race не открывают вторую
сессию и не получают новый бюджет. Источник периода в настоящем сервисе
`_result_period_context` остаётся `yield None` для обоих видов операции.

Два GET сохраняют исходный продуктовый review. Внутренний collector из уже
выбранных ORM-строк позволяет сопоставить исходную версию и точный блок со
свежей проверкой. Подпись новой версии не попадает на старый показанный текст.
Публичная схема ответа, тексты, шаблоны и расположение элементов в этом срезе
не менялись. Закреплённый итог сохраняет собственную версию при новой
расшифровке. Отказ дополнительной проверки сохраняет обычную страницу.

Общая auth/tenant/проверка текущего допуска переиспользована; новые сетевые
вызовы, таблицы, миграции, зависимости и секреты не добавлены. Рабочий сбор,
nginx/DNS/Compose, службы, Postal, очереди, письма, backups и настройки IP
не менялись. Stalwart не выбран почтой ГРАФ; миграции с Postal нет.

## Размер, время и границы доказательства

Обычный полный час 600+600 проверяет три положительные фазы без обрезания fixture
и повышения caps: issuance/renewal/admission. Наблюдались 89/87/94 SQL,
1222/1222/1228 строк, 1222908/1222972/1224805 исходных байт,
1870/1870/1909 JSON nodes; меньшие значения SQL допустимы при отсутствии
необходимости дополнительно уменьшать statement timeout.

Поле ровно 256 KiB проходит GET → renewal → admission. +1 байт безопасно
отвергается. Большой час с полями по 6700 символов имеет 8335873 исходных байта,
что укладывается в 8 MiB, но исходный срок может закончиться: в таком случае
тест принимает только удостоверенный первый отказ по времени, нулевые записи,
очищенные задачи/пул. Успешная тройка фаз для near-total не заявляется.
По 7000 символов дают 8691657 байт и отказ по размеру. Время и размер —
независимые условия; ни одно не повышено ради PASS.

Отсутствие общего CSRF secret сохраняет прежний продуктовый 503: renderer
использовал тот же secret до аналитики. Тест сравнивает с baseline при
выключенной аналитике, а не меняет продуктовый отказ на 200. GET pool timeout
проверяется отдельно для добавленной фазы; после этого тест освобождает только
собственный второй lease, чтобы обычное session renewal не ждало искусственно
занятый тестом пул ещё десять секунд. Продуктовый код для этого не менялся.

Ни эвристический external, ни accepted/HTTP200 не являются подтверждением
нового внешнего клиента, визита, прочтения результата или продажи.
