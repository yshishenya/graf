## Результат реализации

Существующий writer архивирует required/optional классы inventory и проверяет
полный фактический набор Docker volumes проекта. Неучтённый том закрывает успех.
Manifest, inventory, размеры и SHA-256 архивов проверяются до учёта набора;
маркер v2 и атомарное завершение не позволяют считать staging полной копией.
Ротация сохраняет последние семь пригодных наборов. Повреждённые и неполные
не учитываются и не вытесняют хорошие. Архивы остаются root-only 0700/0600;
API получает только состояние через read-only bind и существующую группу.

Прежняя готовность инвалидируется с fsync до проб и записи running state.
Единый путь отказа охватывает ранний выход; ошибка сохранения failed state
не прерывает оповещение. Неуспешная ротация не превращается в pass.
API и alerts требуют v2 complete-set, минимум две копии и возраст от окончания
0≤age<26 часов. Failed/unknown/future/26h закрывают готовность. Внешняя
выгрузка исключена решением владельца; копии на том же диске могут быть
потеряны вместе с историей. Новых служб/зависимостей не добавлено.
