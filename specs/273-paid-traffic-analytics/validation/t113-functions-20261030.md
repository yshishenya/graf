## Изменение

В прежний physical read-only source reader `local_retention_database_catalog`
добавлена сверка всего пользовательского routine descriptor с чистой PG17,
созданной штатными Alembic-миграциями этого дерева.31 функция, ожидаемый digest
`f587419462003e7aa9116c51191c23ad7a885867bf880885386a068a7f0f8550`
закреплён в исходниках; проверяемый сервер/CLI/Env/receipt его не задают.
Новых SQL-парсеров, библиотек, файлов пакета, services/roles/grants нет.

Отбираются все OID≥16384 в любой схеме и routines неслужебных схем. Включены
пользовательские функции в `pg_catalog`. Сначала проверяются PG17, точный
search_path, языки и отсутствие event triggers/FDW/foreign servers, затем
количество и kind. Неизвестные kind/procedure/aggregate не доходят до deparser.
Фактический `pg_get_functiondef`, namespace/name/arguments/owner/language,
невыводимые flags/support/probin/prosqlbody сверяются одним SHA256.
Сортировка явно C; source search_path не меняется ради совпадения.
Прежние семь точных trigger checks сохранены; общий hash их не заменяет.

Наружу уходит только digest внутри прежнего общего proof. Рабочие SQL/тела
функций не сохраняются. Учебный baseline содержит только стандартные
определения из собственных чистых миграций. Runtime повторяет тот же reader
в существующей конечной проверке, включая reduced source; RR сохраняется там,
где уже был, весь preflight общей RR-транзакцией не объявляется.
