## Что изменено

Dedicated receiver перенесён с конфликтующего10445 на10446. Один strip relay
на10447 снимает PROXY envelope и повторно выбирает upstream через прежний
`$kvn_443_backend`. Пять mail SNI и сами старые upstream не дублируются.
Новые PP-входы явно отключают сохранение error log: malformed envelope может
попасть в журнал парсера до HTTP guard. HTTP realip не добавлен.

Существующий helper использует исходные routing/rec конфигурации в отдельном
непривилегированном nginx и три учебных TLS backend. Расширены прежние
структурные тесты; новые общие сервисы и зависимости не добавлены.
