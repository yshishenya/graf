## Изменение

Четыре создателя временных PG-комплектов и общий SQL-validator согласованы
на `/var/lib/postgresql/data/twobrain-rec-backup.<alnum>`. Старый `/tmp`,
произвольные и неканонические пути отклоняются до запуска dump/inventory.
Логические dump/restore не копируют PGDATA целиком; очистка удаляет только
успешно присвоенный каталог текущей попытки.

Host metadata rehearsal создаются и удаляются через удержанный FD fixed
backup parent, существующего canonical0700 с владельцем оператора. Reference
должен быть его прямым canonical child. Коллизия не даёт права удалить чужую
цель. Рабочий вход root остаётся обязательным; нижний helper сохраняет прежний
owner==geteuid() для изолированных испытаний.

До и после runtime DB read новый context связывает host volume Source,
container PGDATA через проверенный proc-root и backup parent. Проверяются
процесс, единственный writable local mount, отсутствие submount, PGDATA env,
uid/gid/mode/noACL, dev/ino и фактическая FS. Linux64 amd64/arm64 fstatfs
допускает только ext/XFS/Btrfs, запрещает tmpfs/overlay и неизвестный ABI/magic.
`SHOW data_directory` сверяется до и после DB context. Нормальные изменения
mtime/ctime/size/nlink каталогов не дают ложной подмены.

Изолированная bootstrap PG fixture переведена с tmpfs на одноразовый anonymous
volume: реальный Docker cp не читает tmpfs. Причина подтверждена отдельным
контейнером без сети; контейнер и volume удалены штатным rm --volumes.
Это изменение тестового ресурса, не рабочей конфигурации. Первый общий native
профиль выявил эту причину и остановлен с cleanup. Следующая попытка обнаружила
ошибку нового assertion (fixture уже имела две учебные restore DB); проверка
теперь сравнивает исходное число. Вызов Linux-only ACL из нижнего Mac helper
убран: noACL остаётся обязательным в Linux runtime context. Неуспешные
попытки сохранены в закрытых ignored журналах, за PASS не выдаются.

Журналы и hashes находятся в ignored `.dev/growth/t113-staging-*20261031*`;
в Git сохраняются только безопасные метаданные этого отчёта и ревью.
Рабочий сервер, БД, GRAF Dev, внешние провайдеры и получатели не менялись.
