## Реализованная стадия

- [x] Один stdlib `infra/scripts/activation-operator.py`, только `--preflight`.
  Начальный Python обязан иметь `-I`. Linux/root и фиксированная установка;
  произвольные root/URL/SQL/commands/pass JSON и env-обходы не принимаются.
- [x] Проверка владельцев/прав корня и предков, основного `.git` и явного
  состава группы установки. Linked worktree отклоняется: его `git --git-path`
  даёт другой замок, чем у основной рабочей копии. Подтверждение существующего
  второго участника группы ещё не получено; рабочий запуск закрыт этой
  отдельной конечной причиной, состав доверия молча не расширяется.
- [x] Открывается ровно существующий shell deployment lock, без create,
  truncate или chmod. Проверяются regular/nlink/owner/group/mode/dev/ino,
  `flock EX|NB`, совпадение gitdir/common-dir/корня. После захвата и перед
  завершением повторяются исходные identity корня/предков/Git и состав группы.
  Замена корня ссылкой на прежний каталог запрещена, даже при прежнем lock inode.
- [x] `git archive` точного чистого HEAD; извлечение только обычных файлов и
  каталогов, без ссылок, дубликатов и выхода из своего назначения.
  Собственный launcher обязан совпасть с этим Git-коммитом.
- [x] Отдельная среда по frozen `uv.lock`, без dev/default groups, editable,
  загрузки нового Python и изменения project `.venv`. Используется имеющийся
  проверенный Python3.13. Пути инструментов фиксированы/проверяются, окружение
  не наследует пользовательские Python/Git/uv настройки.
- [x] Проверяются фактические Python3.13/import path, все файлы пакета,
  полный snapshot до/после установки и lock digest. Snapshot/пакет получают
  0400/0500; перед возвратом ещё раз сверяются package/source/lock.
  Это защита от случайной параллельной правки, не песочница от злонамеренного root.
- [x] Одна защёлка отмены действует через команды и очистку. TERM/KILL и
  reap собственной process group завершаются до удаления temp/освобождения
  замка. Linux subreaper позволяет самому дождаться осиротевших descendants;
  прежнее состояние subreaper и обработчики восстанавливаются независимыми
  `finally`, включая ошибки очистки. Отмена не становится успешной стадией.
- [x] После законченной подготовки собственный temp удаляется. Даже при
  успешной подготовке результат — **HOLD/full_preflight_not_implemented**,
  exit1; `bootstrap=verified` не означает полного preflight или admission.

Продуктовые модули, DB, Docker-службы, `.env`, права сервера, backup, cron,
GRAF Dev и production этим кодовым срезом не меняются. Нет provisioning,
stop/drain, revoke/ready, initial/T0, новых provider intents или внешних отправок.

потерю отмены в успешном finally/между командами, обход восстановления
обработчиков/subreaper при ошибке и отсутствие повторной identity корня Git.
Добавлены общий срок действия отмены, вложенные finally и повторная identity
с причинными сценариями. При проверке отмены обнаружено также перехватывание
`BootstrapHold` общим `except OSError` замка: конечная причина теперь сохраняется.
Повторное ревью приняло исправленные исходники: **SCOPED PASS**, три P2
закрыты, новых P1/P2 в этом объёме нет. SHA256 независимого отчёта:
`d631c02b7eb930beb977ab61dc60d844d390d87f39b75a63d9b6935b06e1bdb3`.
Это не приёмка полного preflight или рабочего запуска.

Config.User=twobrain, identity uid/gid maps, без user namespace. Серверный
