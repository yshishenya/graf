# T119 — подготовка независимого наблюдателя

Дата: 22.10.2026. Lane: active Spec Kit slice / high-risk-product.
Исходный HEAD: `0f2e0b4b7d4deba9902e18f416fb10f8d71c3a9d`.

Добавлены один исполняемый probe и systemd service/timer для существующего
astraglobal. Probe читает только публичный health/live: обычная проверка TLS,
HTTP 200 и JSON status=ok; timeout запроса 10 секунд. curl config отключён,
редиректы не принимаются. Без SSH, БД и Docker целевого сервера.

После первого отказа состояние degraded, после двух — target_unreachable.
Существующий Telegram/fallback transport переиспользован отдельными режимами
того же отправителя; общий channel probe извлечён без смены прежней логики.
Проверка канала выполняется и при здоровой цели, без guard целевого сервера.
Ошибка доставки не создаёт подтверждения и повторяется; неизменная доставленная
тревога подавляется 60 минут. Восстановление отдельно фиксируется/повторяется.

Состояние содержит только фиксированные коды, времена, число ошибок и
результаты. Права каталога 0700, файлов 0600, один lock, атомарная запись с
fsync. Повреждённое, неизвестное, будущее или устаревшее состояние не становится
ready; приватные пути и payload не выводятся при ошибке наблюдателя.

ответа, оба режима оптимизации Python и допустимый JSON с пробелами. В журнал
ошибки транспорта больше не копируется тело ответа; неиспользуемый redactor убран.
