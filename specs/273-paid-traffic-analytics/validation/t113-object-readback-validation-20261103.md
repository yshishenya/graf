## Проверяющий код и независимое ревью

`infra/scripts/rec-object-verify.py` снимает закрытый create-only эталон до
копирования, проверяет точное множество объектов/размеры, каждый байт с SHA256
и повторно проверяет источник и цель. Host-команда `source` сравнивает полное
исходное дерево, включая identity. В контейнере сравнивается содержимое:
bind mount может иметь другой device ID. Предел600с, HTTP connect5/read15с,
вывод фиксированный. Проверяются0700/0600/UID, обычные файлы с одной ссылкой;
ссылки, FIFO, source drift и ошибка доступа отклоняются.

Независимый reviewer обнаружил P1 автоматического HTTP-декодирования.
Исправлено `stream(..., decode_content=False)`; регрессия использует настоящий
`urllib3.HTTPResponse` с разными gzip-байтами одинаковой длины. Задан регион
локального MinIO `us-east-1`: SDK не наполняет кэш региона, который мог бы
запустить скрытый повтор HEAD после redirect. Несовместимая конфигурация
завершается отказом. [Независимое ревью](t113-object-readback-code-review-20261103.md)
приняло текущий checker: scoped PASS, P1/P2=0. После снимка reviewer добавлены
четыре теста сигналов и новый native профиль; их окончательное ревью входит
в приёмку всей будущей обвязки.
