## Реализация

- [x] `_read_coherent_backup` читает реальные закрытые файлы без ссылок,
  проверяет строгий manifest producer, полные byte hashes, размеры/числа,
  native schema/roles/ledger/inventory metadata и неизменность каталога.
  Полный manifest читается с пределом собственного размера; лимит receipt
  16К не обрезает список объектов. Повторно используются прежние функции.
- [x] `_verified_backup_set` требует завершённую последнюю попытку из журнала,
  текущий binding и возраст `0 ≤ age <26 часов`, а также вторую отдельную
  полную копию. Failed/in_progress/missing latest не заменяется старыми
  исправными копиями. Parent/fence/attempt/selected identities проверяются
  повторно; один общий deadline не продлевается.
- [x] Исторический companion может иметь прежний binding, но проходит
  физическую и native проверку. Он не доказывает пригодность текущей версии
  и не заменяет отдельную проверку восстановлением. Invalid/partial
  candidates не считаются, не исправляются и не удаляются.
- [x] По независимому ревью устранены три пограничных случая: канонический
  digest metadata различает int и float; выбранная копия сохраняет dev/ino
  до финальной сверки; слишком глубокий повреждённый JSON даёт конечный HOLD.
  Для каждого случая добавлена причинная проверка.
- [x] Native success создаёт первую копию, получает HOLD из-за отсутствия
  второй, создаёт вторую и читает обе без metadata mock. Выбранная последняя
  затем проходит прежнее восстановление, replay/COMMIT, новое reduced чтение
  и очистку собственных PostgreSQL/MinIO/staging ресурсов.

## Остаток и границы

Reader не создаёт ready/initial/T0, не удаляет копии и не выполняет ротацию.
Верхний trusted preflight/initial/verify/actual-restore/resume, ежедневный
контроль/ротация, CD/rollback, перевод shell на общий вход и T112 остаются
открытыми в той же T113/#7804. Это не завершение задачи или рабочего измерения.

Перед рабочим запуском нужен новый capacity preflight: последнее чтение
2brain.dev показало19,637% свободного места, ниже принятого20% guard.
Ничего на сервере не очищалось. Требуется достаточное место с учётом двух
копий и временного восстановления; возможный размер Docker cache сам
по себе не доказывает достаточность освобождения.

Production и GRAF Dev в этом срезе не менялись. Рабочие T0/ready, аналитика,
IP, внешние получатели и расписание не включены. Учебные пробы не считаются
трафиком, клиентами или оплатами; AC01–AC06 остаются открытыми.
