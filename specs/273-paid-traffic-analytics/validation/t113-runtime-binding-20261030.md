## Исправление

Общий ingest берёт source из встроенного GRAF_DEV_SOURCE_SHA, ID образа — из
операторского environment. Неверный/отсутствующий формат закрывает допуск до
sessionmaker. После общего SQL SH273,3 и identity-lock выполняется один запрос
к настоящей DB: cluster identifier, имя/OID, revision, дата создания текущего
аккаунта и текущее время DB. Требуются одна строка, настроенное имя БД и
единственный head миграций из пакета. Готовый файл не задаёт expected.

После последнего await заново проверяются основание/режим/флаги и read_ready;
в local_only требуется T0 < created_at <= DB now, возвращаются пустые providers.
NULL/будущее/старое время не открывают счёт. Sync и async callbacks поддержаны
общим примитивом. Прежний один владелец сессии, файловый SH и защита повторной
отмены сохранены. Безусловный activation_recovery_unverified не снят.

Compose получает отдельные pinned ID для API и maintenance. CD задаёт правильную
сторону перед candidate up и всеми тремя путями возврата, включая compatibility
после неудачного previous. Проверка image/env использует Docker inspect и
отклоняет неверное/дублированное значение без вывода полного environment.
Обязательность binding определяется environment конкретной версии Compose и
сохраняется в существующих метаданных image. Старые исторические записи без
новой capability остаются читаемыми; это не даёт analytics readiness и не
препятствует восстановлению продукта. Image-only override не расширяется.

Матрица DB охватывает: source/image missing/invalid до sessionmaker, шесть
