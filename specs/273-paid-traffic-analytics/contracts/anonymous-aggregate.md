# Контракт: обезличенный агрегат публичных страниц

Уровень 1 измерения. Покрывает FR-009 … FR-013 и SC-001 … SC-003.

## Назначение

Дать знаменатель для выводов по каналам, не создавая персональных данных. Это
единственная часть измерения, которая работает без согласия посетителя.

## Что обязательно

- Считается каждый визит на каждую публичную страницу, включая посетителей без
  согласия.
- Запись выполняется в момент обработки запроса, без сетевых вызовов и без
  зависимости от доступности стека аналитики.
- Сохраняются только измерения, перечисленные в `data-model.md`, и только в
  агрегированном виде.
- Метки кампании нормализуются: ограничение длины, разрешённый набор символов,
  отбрасывание значений, похожих на контактные данные.
- Класс устройства сохраняется только крупной категорией.

## Что запрещено

| Запрет | Проверка |
| --- | --- |
| Адрес устройства в любом виде | Разбор сохранённых записей |
| Идентификатор сессии или визита | Разбор сохранённых записей |
| Строка пользовательского агента | Разбор сохранённых записей |
| Отпечаток устройства | Разбор сохранённых записей |
| Постоянная cookie | Проверка заголовков ответа |
| Псевдоним из `product_analytics/identity.py` | Запрет импорта в модуле агрегата |
| Связь между визитами | Разбор сохранённых записей |

## Проверяемые утверждения

1. **SC-001**: доля публичных страниц без обезличенного измерения равна нулю.
2. **SC-002**: в сохранённых записях нет ни одного идентификатора. Проверка —
   разбор фактических записей, а не чтение кода.
3. **SC-003**: доля посетителей, давших необязательное согласие, измерена и
   доступна отчётам.

## Границы

- Агрегат не читает и не пишет состояние согласия посетителя.
- Агрегат не является основанием для уровней 2 и 3 и не подменяет согласие.
- Агрегат не используется для узнавания посетителя при повторном визите.
