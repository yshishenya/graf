# Данные и состояния

Новых таблиц, API или хранилищ нет. AccountProfile сохраняет имя, язык как существующее предпочтение, theme/timezone. Техническое значение языка не заменяется при сохранении других полей. Действующие drafts остаются ответственны за dirty/saving/saved/error/conflict.

Локальные правила автозаписи и уведомлений остаются за Mac. Все три правила и существующие version/trust guards сохраняются. Фильтр списка меняет только видимость; массовое изменение применяется ко всему поддерживаемому списку, как прежде.

Раздел настроек — производное от существующего маршрута состояние. При входе в настройки без записи правый inspector сворачивается; пользователь может раскрыть его. Активная запись, явное открытие локальной записи и критические проблемы сохраняют контроль. Сохранённый выбор левого меню обычного кабинета не переписывается.

Календари, аккаунт, пространство и тариф сохраняют серверные состояния. details — только состояние отображения. Ошибка внутри раскрытия делает её доступной без поиска. При закрытии details данные не отправляются, действия не выполняются.
