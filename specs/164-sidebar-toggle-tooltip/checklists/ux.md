# UX Requirements Checklist: Понятный toggle боковой панели

**Purpose**: Проверить качество UX/accessibility требований.
**Created**: 2026-08-18
**Feature**: [spec.md](../spec.md)

- [X] Следующее действие явно описано в icon, accessible name и tooltip.
- [X] Hover и keyboard focus имеют равнозначную подсказку.
- [X] Стабильная позиция и повторная активация без движения указателя описаны.
- [X] Focus retention, `aria-expanded` и `aria-controls` измеримы.
- [X] Узкий viewport, embedded, themes и reduced-motion включены.
- [X] Tooltip не перекрывает trigger, focus ring или навигацию.
- [X] Поведение после partial update и отсутствие duplicate controls описаны.
- [X] Clean-room граница с конкурентами зафиксирована.
