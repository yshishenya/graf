# Состояние интерфейса

Серверная модель не меняется. Тема определяется существующим выбором light/dark/system; явная тема имеет приоритет, system следует системе. Существующий ключ `graf-cabinet-rail` хранит expanded/collapsed; временное изменение ширины не должно переписывать предпочтение. Загрузка сохраняет текущие состояния и API. Новых сущностей, полей, миграций и хранилищ нет.

Сохранённое предпочтение панели отличается от временного видимого состояния: на узком экране защита фокуса может скрыть панель, не записывая новое предпочтение. `aria-expanded`, имя кнопки и класс `.is-rail-pinned` отражают видимое состояние. Явное действие toggle/Escape обновляет предпочтение по прежнему контракту; возвращение к широкому окну восстанавливает его. Это локальное состояние существующего обработчика, не новое хранилище.
