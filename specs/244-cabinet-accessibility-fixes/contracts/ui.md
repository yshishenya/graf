# Контракт интерфейса

- Общая темизация F240: `[data-theme=light]` и `[data-theme=dark]` имеют приоритет над media query; отсутствие атрибута означает system. Sidebar/menu/dialog используют общий набор tokens без возврата прежней тёмной sidebar-палитры. System и явная соответствующая тема имеют одинаковые цвета, включая открытые окна.
- `<dialog data-manual-upload-dialog>` получает `aria-labelledby`, ссылающийся на единственный видимый h2. `showModal`, Escape, возврат фокуса, form fields и upload endpoints не меняются.
- При переполнении прокручивается само окно загрузки; видимая нижняя граница остаётся в viewport. Существующий keyboard wrap не оставляет первый/последний контрол вне scrollport; повторное открытие показывает начальный контрол. Для скрытого file input проверяется связанная видимая dropzone. Не добавлять вложенный JS scroll controller или второй focus trap; сохранены остальные пользователи общего modal helper.
- `.app-shell[data-cabinet-shell]` на ширине ≤640 оставляет основной области минимум `viewport - 64px`. Раскрытая панель не закрывает сфокусированный основной контрол: временно скрывается при переходе фокуса в main или сужении с уже установленным фокусом, без перемещения фокуса и записи sessionStorage. Явные toggle/Escape сохраняют текущую запись предпочтения; aria-expanded/имя кнопки показывают фактическое раскрытие. При переходе к >640 применяется сохранённое предпочтение и прежние surface breakpoints981/1121. Нижние действия sidebar остаются достижимыми на короткой высоте; ни modal trap, ни подложка не добавляются.
- Проверки включают standalone и desktop-embedded. HTTP/JSON API и серверные права не меняются.
- Приёмка FR-001/FR-002 требует совместной ревизии с окончательными theme fixes F240. Старый SHA PR, WIP или объявленный PASS палитры без браузерного вычисления стилей не закрывает зависимость.
