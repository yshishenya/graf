# UX Checklist: Темы и доступность кабинета

**Purpose**: Одобрение полноты, однозначности и измеримости требований до реализации.

**Created**: 2026-09-06

**Feature**: [spec.md](../spec.md), [plan.md](../plan.md)

**Review Ownership**: Рецензент — владелец продукта либо явно назначенный им проверяющий. Исполнитель не отмечает этот список самостоятельно.

**Review assignment**: 2026-09-06 владелец явно поручил Codex: «перепроверь чеклист сам очень внимательно». Ниже — результат этого отдельного этапа проверки требований тем же агентом, не независимая приёмка реализации.

**Marker Semantics**: `[x]` означает одобрение качества требования, а не готовность кода.

## Темы и читаемость

- [x] CHK001 Явно ли охвачены текст поиска, placeholder, фильтры/сортировка, строки normal/hover/selected/focus, empty/loading/error и загрузка с контрастом текста ≥4.5:1 и значимых контролов/фокуса ≥3:1, корректными исключениями и учётом фактического цвета без округления до PASS? [Completeness, Measurability; FR-001, SC-001]
- [x] CHK002 Однозначно ли задан приоритет явной темы, поведение system с открытыми окнами и согласованные цвета sidebar/profile, диалогов и summary controls без конфликта с общей палитрой F240? [Consistency; FR-002, US1, Assumptions]

## Окно загрузки

- [x] CHK003 Полны ли требования к доступному имени «Загрузить файл», прокрутке при390×320/640×400, корректному/нечитаемому файлу, недоступной загрузке, видимому фокусу во всём цикле Tab/Shift+Tab, повторному открытию, подсказке и возврату фокуса после закрытия? [Coverage; FR-003, US2, SC-002]

## Узкая панель

[Clarity, Edge cases; FR-004, US3, SC-003, quickstart §4]

## Notes

Статус: 6/6 требований проверено и одобрено после устранения пробелов; отчёт по каждому пункту и отрицательные браузерные пробы — [evidence/checklist-review.md](../evidence/checklist-review.md). Исходный чеклист не был одобрен автоматически: исправлены конфликт темы F240, неполные требования видимости фокуса в upload/rail, методика контраста и граница совместной приёмки.

Блокировка именно по UX checklist снята. Это не PASS реализации: tasks, analyze, issue sync, продуктовые исправления, совместная проверка с финальным F240, commit approval и PR checks ещё предстоят. При реализации нельзя переотмечать этот список вместо выполнения этих этапов.
