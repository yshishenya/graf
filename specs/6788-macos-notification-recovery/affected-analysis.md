## Существенные границы переноса

- US5 не меняет захват, согласие или F214. Видимая индикация и Stop остаются
  в F255; раскрытие закрытого меню и Stop — два действия по явному решению
  владельца. Это прежнее документированное исключение Constitution §II.
- Новый GET `/api/v1/desktop/notification-context` сохраняет независимые
  principal/device/tenant проверки, возвращает только проверенный текущий
  контекст и no-store. Неизвестный owner старой локальной записи не угадывается.
  Смена auth epoch ограждает асинхронные ответы и действия.
- Сама активность GRAF, выбранный session ID или `onAppear` не доказывают
  видимость соответствующей ошибки. Минимальный допустимый путь — одна
  OS-попытка полезного инцидента и в foreground, без blanket подавления.
  Тихое поглощение допустимо только при доказанном соответствующем контексте;
  требования не обязывают вводить отдельный механизм определения видимости.
- `public.processing_workflows`: только `workflow_id`, `workspace_id`,
  `meeting_id`, `media_revision_id`, `purpose`, `status`, `attempt_ordinal`,
  `created_at`. Штатные права на другие таблицы нормализации сохраняются.
  Сигнал будит существующее продолжение, а GET и обновление UI не создают
  новые оплачиваемые генерации.
- F258 T002–T005 → T018/T019; T006–T010 → T018/T020; T011/T012 → T014/T015/T021.
  Старые #6818–#6823/PR #6824 остаются Refs до сверки итогового PR. Source
  checkout не изменяется; старые 1734 server и 820 Swift PASS/1 SKIP и CI
  34243003216 подтверждают только исходный SHA, не объединённый результат.

## Что этот gate не закрывает

Подтверждённые замечания к коду C1–C3 из [code-review.md](code-review.md)
остаются открытыми до повторной проверки объединённой реализации:
ошибочное подавление по `NSApp.isActive`, повтор перенесённой встречи после
due-time и неверная вкладка асинхронного сетевого fallback. План исправить
их или выбранное направление C1 не являются доказательством исправления.

Нужны объединённые Swift/server/Node проверки, actual restricted-role test,
первый embedded вход, показ готовых частей ≤15 секунд, сохранение player/draft,
проверка реальной записи и OS действий. F257 сообщил родителю об освобождении
Dev во время этого review; reviewer не проверял manifest/schema и не выполнял
promotion. Освобождение стенда не разрешает понижение 0090→0089 или отдельную
копию: перед запуском остаётся штатная проверка совместимости harness.

Исторический [analysis.md](analysis.md) описывает прежние 16 задач/16 FR+SC.
Для объединённого объёма актуален этот отдельный affected-анализ; исполнитель
связывает его с T017 и issue mapping. Ни один прошлый PASS не переносится
автоматически на новый commit, PR или установленную сборку.
