## #6819: исходные критерии и текущие доказательства

| Критерий | Код и исполняемая проверка |
|---|---|
| Пустой слот не скрывает пригодное аудио; queued/generating/blocked отражают текущую попытку | `cabinet/egress.py::_latest_accepted_media_revision`, `outcomes/progress.py::{latest_summary_attempt,summary_progress}`; `test_empty_summary_slot_keeps_audio_and_reports_current_attempt`, четыре варианта, включая failed. Проверяет аудио, состояние, отсутствие ложного summary и desktop sync. |
| Partial виден и согласован между поверхностями | `test_published_partial_is_visible_but_invalid_pointer_never_substitutes_audio`: processing, общая проекция, API списка и HTML обычного/встроенного кабинета. |
| Устаревший источник и неверный опубликованный pointer не выбирают произвольное аудио | Те же две регрессии: изменение source hash, отсутствие подмены media revision; другой формат не получает чужое состояние. |
| Сохраняются границы встречи/пространства/типа, источника, доступа и удаления | Остальные регрессии `tests/integration/test_meeting_summary_slots.py`: cross-workspace, same-meeting/type и CAS с source/access/deletion fences. |
| Старые пригодные части не исчезают из-за текущей попытки; контракт состояния безопасен | `tests/contract/test_processing_status_contract.py`, в частности `test_latest_replacement_status_keeps_previous_complete_artifacts_visible`, проверки видимости и разделения полномочий. |

Пути к тестам и модулям в таблице заданы относительно `apps/server/` и
`apps/server/src/twobrain_rec_server/` соответственно.

оба исходно требуемых файла тестов через штатный runner с изолированной

```sh

  tests/integration/test_meeting_summary_slots.py \
```

зависимости не устанавливались. Временный контейнер удалён штатным runner.

`adc0acba0a05b9353ccfe521a6a005904721c728`. Сравнение Git деревьев `apps/`
