# Контракт пользовательского пути

## Запись и отправка

Нативная истина захвата остаётся в существующей сессии. Значок меню F255 —
постоянная поверхность состояния. Stop первый в меню; Mute отключает только
микрофон. Команды проходят общий handler с существующими guards. Не поднимать
кабинет при обычных Stop/Mute/Unmute; для отказа старта показать необходимое
восстановление. Нельзя показывать «Идёт запись» до подтверждения старта.

Постоянный виджет и восьмисекундное послесловие результата удаляются.
Временный запрос F214 остаётся. Длительность/подробности доступны по запросу,
не создают отдельное окно или секундный таймер в строке меню. При закрытом
кабинете захват продолжает работать; OS Focus не скрывает управление записью.
При полном экране используется штатное раскрытие строки меню, без нового оверлея.

Локальная отправка — строка и карточка локальной записи на устройстве-владельце;
переход к ним не требует существующего серверного объекта. В браузере такой
неотправленный файл не выдумывается. Технические повторы не создают уведомлений.
Сохранность и доступный retry зависят от реальной custody-проекции. Общий
blocked_config описывается как недоступность обработки, а не вина пользователя.

## Настройки

Оба меню F255 → общий раздел уведомлений. Встроенный кабинет содержит:
«На этом Mac» + «Настроить на этом Mac»; «В кабинете» + историю; ниже
«Письма и подсказки». Нативный переход — отдельный доверенный локальный маршрут,
не внешний URL/произвольный script message. Повторное открытие выбирает нужную
вкладку и сохраняет черновик. Локальный вход доступен при неработающем сервере.
Браузер содержит объяснение границ без фиктивной настройки конкретного Mac.

Нативные значения: reminders, один offset0/1/5, showTitles=false, sound=false
для новой установки. Сохранённые значения не сбрасывать. Permission запрос
только по действию; при denied — настройки macOS. Тест передан ОС не значит
баннер виден. Автозапись на отдельной вкладке, без изменения трёх режимов.

## Системные действия

Календарь: название при разрешённом превью, иначе «Встреча в календаре»;
тело «Начало в HH:mm. Запись ещё не начата». Абсолютное время в текущем часовом
поясе. Основное нажатие открывает календарный контекст GRAF, отдельное
«Подключиться» открывает проверенный HTTPS URL. Без ссылки действие отсутствует.
«Настроить уведомления…» открывает нативную вкладку. Число/видимость действий
определяются ОС; кастомный split-button не обещается.

Любая команда требует текущего owner/context, существующего неизменённого
вхождения события и актуального времени. Неизвестная action — никаких действий.
Закрытие не подключает/не записывает/не открывает окно. При старой карточке
не выполнять прежний URL; при необходимости открыть безопасный текущий контекст.

## Подавление и восстановление

Один occurrence/инцидент — один сигнал. При переносе до доставки перепланировать;
после уже состоявшегося показа не повторять от технической синхронизации.
Отключение отменяет pending/delivered; включение восстанавливает только ещё не
показанные будущие события. Прошлые сообщения после входа/сна не воспроизводятся
залпом; свежее актуальное событие допускается в существующем окне максимум5мин
после начала и только до конца встречи. Смена фаз сама не вызывает уведомление.

Связанная активная запись подавляет своё напоминание. Другие события не меняют
захват; sound при любой записи отсутствует. Открытый соответствующий контекст
обновляется тихо. Focus и denied не обходятся собственной панелью.

Локальная ошибка с полезным действием — один системный сигнал при необходимости,
нажатие открывает конкретную запись. Текст не раскрывает её название по умолчанию.
Серверные ошибки/готовности идут только через существующую историю. Read снимает
новизну, актуальный успех снимает проблему; поздний callback не возвращает её.


## Проверяемые границы (независимый review R1–R4)

- Неготовый handler не сохраняет команду Start для будущего выполнения. Команда
  возвращает отказ, основной GRAF открывает существующее восстановление с текстом
  «Управление записью ещё не готово. Повторите попытку». Команды не повторяются
  автоматически. Целевой ответ управления p95 ≤200мс (F249 SC006); это ответ/
  состояние starting/stopping, а не ложное обещание завершённого захвата.
  В синтетической Dev-проверке от Stop до прекращения захвата/освобождения
  ресурсов ≤5с; при превышении записать FAIL, не обрывать сохранение таймаутом.
  Аудиопорог PRD: dropout <0.5% нормальной записи, непрерывная временная шкала,
  отсутствие новых alignment/discontinuity ошибок. Код аудио не меняется;
  аппаратный 60мин baseline PRD не выдаётся за результат короткой записи.
- Native settings разрешены только top-level navigation текущего embedded
  кабинета после готовой доверенной auth-сессии: точные scheme/host/port базового
  origin, точный путь `/desktop/settings/notifications/mac`, без query/fragment,
  userinfo, encoded-slash/dot/traversal. Обычная внешняя ссылка/subframe не
  вызывает native callback. Повторная проверка lifecycle выполняется на границе
  callback; смена account/разлогиненный кабинет не переносит старую команду.
- Dedup означает максимум одну попытку доставки в окно события, а не доказательство
  показа баннера. Durable claim хранит expiry и scheduledFor. Будущую reservation
  можно безопасно заменить после отмены/рестарта; после её due-time повтор
  запрещён, даже если Focus скрыл баннер. Старый claim без scheduledFor также
  запрещает повтор. Не обещать надёжно наблюдать показ/прочтение системного баннера.
  Отказ add не создаёт цикл мгновенных повторов; актуальное будущее напоминание
  можно восстановить только пока его исходный due ещё впереди. После выключения
  уже наступивший reminder не воспроизводится при включении. Новое ещё будущее
  событие с другим occurrence не подавляется старым claim.
- При showTitles=false удалить управляемые GRAF доставленные карточки с
  приватным превью; pending перепланировать с тем же ID и безопасным текстом.
  Уже наступившие карточки не пересылать. Успешное удаление запросов GRAF не
  означает удаления истории/снимков, которыми владеет сама macOS.

## Состояния и обновление результатов (перенос F258)

- Готовый звук не зависит от пустого summary slot. Invalid published pointer
  закрывает доступ, а не выбирает произвольный другой источник.
- Transcript ready + summary queued/generating: «Расшифровка готова. Готовим итоги».
  Blocked: временная задержка только при реальном автоматическом продолжении.
  Failed: ошибка только итогов, готовые звук/расшифровка сохраняются.
- Partial/available — результат с фактическими ограничениями. No speech и
  archive disabled объясняются отдельно; unavailable скрывает прежнее содержимое.
- Активный экран обновляет состояние <=15с; offline/visibility/pageshow
  восстанавливают опрос. Нет порога 5 минут/40 запросов, после которого
  ожидающая встреча перестаёт обновляться. Один запрос на поверхность за раз.
- Обновляется выбранный формат без полной перезагрузки, history mutation,
  потери player/focus/title draft. Запоздалый ответ не изменяет другой экран.
- Проверенный owner берётся из native GET независимо от календаря; auth epoch
  ограждает await/callback. Неизвестный owner старой записи не присваивается.
- Все актуальные локальные ошибки проверяются до ограничения числа видимых
  групп; новый инцидент после восстановления может создать новый сигнал.
  Активность окна настроек не означает видимость конкретной ошибки.
- Новый grant media worker ограничен SELECT public.processing_workflows:
  workflow_id, workspace_id, meeting_id, media_revision_id, purpose, status,
  attempt_ordinal, created_at. RLS, запрет остальных колонок и DML этой таблицы
  сохраняются. Прежние штатные INSERT/UPDATE playback normalization tables
  не отзываются. Готовый звук будит существующее продолжение без новой генерации.

GET /api/v1/desktop/notification-context сохраняет PrincipalDependency +
DeviceDependency + TenantDependency, возвращает только user_id/workspace_id
и Cache-Control: no-store. Не назначает владельца неизвестной старой записи.
