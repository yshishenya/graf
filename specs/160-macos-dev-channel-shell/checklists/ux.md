# UX and Accessibility Checklist: macOS Dev Channel and Native Home

- [x] GRAF Dev is visibly distinct from GRAF in name and app metadata.
- [x] Home, Back, Forward, and Reload have labels, tooltips, disabled states, and keyboard operation.
- [x] Permission denied/restricted/revoked states stay truthful and actionable without workaround promises.
- [x] Web/auth/session/settings/meeting routes remain understandable after native navigation.
- [x] Dev remains loopback-only and never silently falls back to production.
