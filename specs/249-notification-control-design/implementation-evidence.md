# Проверка реализации F249

Дата: 2026-09-06. Lane: high-risk UX / capture-adjacent / reference fidelity.
Это evidence разработки, не разрешение выпуска или утверждение идеального интерфейса.

## Реализовано и проверено

- Сервер: одна карточка на источник и получателя, revision/read_revision,
  транзакционные producers processing/summary/sharing, текущие попытки и форматы,
  RLS, CSRF, повторная проверка доступа/удаления, срок истории 30 дней,
  подписанные cursor, HTML fallback. Mandatory billing outbox сохранён.
- Веб: important/history, точка только для нового важного, одиночный просмотр,
  обновление 30 секунд с сохранением focus, очистка при ошибке/смене области,
  отсутствие системной доставки. Отдельная форма настроек с CAS-конфликтом.
- Mac: общая панель CalendarTray, отдельный виджет с существующими capture
  действиями, локальные проблемы, нативный presenter с владельцем сессии,
  настройками и дедупликацией. Запросы напоминаний сериализованы, чтобы старое
  завершение add не отменяло новую версию. Контракт автозаписи 214 сохранён.
- Legacy: удалён всегда пустой rowsNeedingNativeVisibility и недостижимая
  compact queue; автономный recovery renderer и decoder сохранены.

## Живой браузер

Настоящие маршруты, templates, JavaScript и PostgreSQL с искусственными карточками:
вход; сохранение настроек; конфликт двух вкладок и явное сохранение своего выбора;
отмена после сохранения; просмотр не решает проблему; тихая готовность; сохранение
focus после 30 секунд; Escape; 360 px без горизонтального overflow и с доступным
footer; offline очищает карточки; retry восстанавливает историю. Все 12 проверок PASS,
pageErrors пуст. Light и dark screenshots осмотрены, данные синтетические.
Это проверка UI на подготовленных карточках, не реальная MediaScribe-транскрибация.
Транзакционные producers отдельно проверены интеграционными тестами.

## Единый Dev-процесс

По указанию пользователя все последующие установленные macOS-проверки выполняются
только в GRAF Dev через harness. AGENTS.md и scoped guidance задают этот маршрут.
Два старых launchers и сборщик native-preview теперь отказывают до сборки/запуска;
10 старых инструкций обновлены, README упаковки отделён от Dev-проверок.
Удалены только две временные app-копии, созданные этой задачей. Данные приложений
и TCC не удалялись. Имя действующего сертификата, внутренний loopback-флаг,
старый decoder канала и исторические release facts сохранены ради совместимости.
