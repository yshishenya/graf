# Проверка дизайна и реализации

## Исторический нативный макет

[Сборка, реальные поверхности и evidence](native-preview/README.md). Проверены отдельные NSPanel, Stop после закрытия главного окна, нативные настройки и локальные проблемы. Разрешение на тестовую запись и баннер получено; дальнейшие проверки выполняются только в GRAF Dev. Это не тест capture рабочего приложения.

## Вспомогательный HTML-прототип

Из корня репозитория:

```sh
python3 specs/249-notification-control-design/validate_prototype.py
python3 -m http.server 8765 --bind 127.0.0.1 --directory specs/249-notification-control-design
```

Открыть `http://127.0.0.1:8765/prototype.html`. Макет автономный, без сетевых запросов к продукту, реальной записи, оплаты и сохранения настроек. Сценарии сверху переключают состояние. Кнопки внутри проверяют предлагаемый путь. Счётчик 12:34 условный, кроме настоящего 8-секундного таймера в синтетическом ask-сценарии.

Прототип демонстрирует основные поверхности, но не реализует системное окно, focus trap macOS, экранное разрешение или весь серверный lifecycle. Кнопки проверки источника/восстановления моделируют успех, не диагностируют компьютер. Раздел «Ещё» содержит кнопки и отдельный диалог выхода; настройки Mac/аккаунта разделены. Это ограничения макета, не готовый продукт.

## Design acceptance cases

1. Готовность: нажать «Начать запись» → состояние записи, виджет, Stop. Пауза микрофона → системная запись и общий таймер продолжаются; продолжить микрофон; Stop → отправка.
2. «Без сети»: запись и Stop сохраняются; восстановление связи не создаёт новую запись.
3. «Запрос · 8 с»: дождаться автоперехода; режим остаётся ask. Повторить с «Запомнить»+«Не записывать» → never; без флажка → ask.
4. Колокольчик: «Обычный день» и «12 готовых встреч» не дают точку. «Нужны действия» показывает одну проблему; открытие/«Просмотрено» убирает точку, сохраняя проблему. Повтор не возвращает точку. Восстановление автоматически убирает вопрос из «Важного». Массовой кнопки чтения в вебе нет.
5. «Нет уведомлений»: осмысленное пустое состояние. «Ошибка отправки»: копия и восстановление, никаких обещаний готовности.
6. Настройки: категория, scope, сохранение/отмена, «Запрет macOS»; Stop и история не отключаются.
7. Светлая/тёмная тема, viewport 360px, клавиатурный фокус, Escape из inbox. Проверить фактическое отсутствие обрезанных основных действий.

## Фактическая проверка 2026-09-06

- `validate_prototype.py`: 7 проверок правил прошли; JavaScript syntax, 66 уникальных HTML id и локальные ссылки корректны.
- Историческая проверка версии review=2 (дизайн заменён повторным аудитом): открытие inbox сохранило 2 непрочитанных; массовое чтение обнулило badge, но фильтр «Требуют действия» сохранил ошибку.
- Явный отказ + remember дал «Никогда». Таймер 8 секунд + remember завершился записью макета и сохранил «Спрашивать». Первый ограниченный wait автоматизации завершился раньше таймера; последующий осмотр подтвердил ожидаемый итог.
- Stop компактного виджета перевёл макет в отправку, убрав признаки активной записи.
- Сохранение выключенной готовности убрало всплывающий баннер, история осталась доступна.
- Escape закрыл inbox, вернул focus на bell и `aria-expanded=false`.
- 360px: осмотр light и dark, настройки и OS deny; измерение DOM не выявило горизонтального выхода текста/контролов. 736px: overflow false, 0 контролов вне ширины. 1024px: визуально проверена тёмная панель активной записи без сети. После проверки viewport override снят.
- Пустой inbox проверен. Browser error logs пусты.
- `git diff --check` прошёл; 18 уникальных FR и 22 последовательно пронумерованных задачи; custom checklist markers оставлены открытыми.

Не проверены в этом этапе: 200% масштаб, реальный VoiceOver/нативный focus trap, системная доставка уведомлений, actual recording, upgrade/rollback, производительность p95 и исследование с пятью пользователями. Их наличие в требованиях не означает прохождение.

## Runtime acceptance — частично выполнено; см. implementation-evidence.md

На отдельном тестовом аккаунте и синтетической записи после реализации:

| Сценарий | Ожидаемый результат |
|---|---|
| Hidden main window/menu, full screen, второй монитор | Постоянный индикатор и доступный одним действием Stop |
| Ask/always/never, timeout+remember, двойное действие | Точный 214, нет второго start, timeout не запоминает |
| Отзыв mic/system audio | Правдивый источник, восстановление/Stop, нет ложной готовности |
| Network/server outage, upload retry | Local capture продолжается; один incident; pipeline не дублирует данные |
| Disk full/partial file/no-speech | Правдивое состояние и доступное восстановление, без выдуманного успеха |
| Result while recording, repeated worker callback | Одна история, без прерывания текущей встречи |
| Просмотр показанной revision одновременно с новой версией | Новая версия остаётся непросмотренной; read-all отсутствует |
| Logout/scope/revoke/delete во время async request | Старый ответ и название не появляются |
| OS deny/Focus/restart/wake | Нет обхода OS; старые reminder отменены/истекли; локальный контроль доступен |
| Старые optional false, старая форма, конфликт версии | Отказы не включены повторно, новые поля не сброшены |
| Old settings/local queue + upgrade/rollback | Данные читаемы, миграционный decoder и local fallback живы |
| Web/WKWebView/VoiceOver/200%/360px | Фокус, текст и действия доступны, theme согласована |

## Дополнительная проверка HTML при продолжении

Историческая проверка до повторного веб-аудита: 17 чистых проверок, 87 уникальных ID, синтаксис JS и локальные ссылки прошли. Реальный браузер подтвердил новое unread после read-all; ошибка read-all сохранила счётчик; исправленная ошибка перехода сохранила 2 непрочитанных. Ошибка аккаунтного Save сохранила dirty draft, а Mac Save завершился отдельно. Уход с dirty draft открыл диалог с безопасным фокусом «Остаться». Выход при искусственной записи открыл подтверждение с фокусом «Продолжить запись». Отмена сохранила запись; виджет позволил Stop при закрытой панели. По итогам визуального осмотра HTML-виджет закреплён в viewport, чтобы его не уносила прокрутка. На ширине 360 px повторный осмотр подтвердил отсутствие горизонтального переполнения и Stop внутри viewport при записи; нативный макет проверен отдельно.

Актуальный дизайн и evidence: [web-attention-audit.md](web-attention-audit.md). Это прежнее предложение: после review=4 серверная read-all полностью исключена. Полный CI и продуктовые тесты не запускались: изменён только дизайн, высокорисковая реализация не начата.

## Актуальная проверка разделения · review=4

Источник решения и приёмки — [surface-separation.md](surface-separation.md). Результат: 25 чистых правил HTML, 95 уникальных ID, синтаксис и локальные ссылки; нативная сборка — 7 self-check. HTML review=4: сценарий Mac-only не создал точку, в history только 2 серверных результата; серверная processing-проблема показала точку/действие. Веб-форма не содержит переключателей macOS. Native и web события имитируются независимо; это не проверка интеграции настоящего сервера.

FR-020 добавлен в spec/tasks; вопросы разделения добавлены в reviewer-owned checklists без отметок выполнения. Полный CI, серверные интеграционные тесты, настоящий capture/OS delivery, VoiceOver и мультиустройство остаются приёмкой внедрения. Прежние результаты review=2/3 выше являются историей, не актуальным контрактом.
