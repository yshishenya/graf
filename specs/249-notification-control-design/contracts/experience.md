# Полный дизайн взаимодействия: панель GRAF и уведомления

Статус: предложение для проверки и внедрения. Числа и тексты ниже — решения GRAF. Проверенное поведение Krisp перечислено отдельно в [исследовании](../research.md).

## 0. Владельцы разных уведомлений

Актуальное разделение: [Mac — запись и устройство; веб — встречи и аккаунт](../surface-separation.md). Нативное приложение показывает локальные состояния, проблемы записи/отправки и календарные напоминания, независимо от открытого окна. Системные баннеры macOS — его канал. Веб-колокольчик показывает только серверные события; это правило одинаково для браузера и кабинета внутри GRAF. Отдельного нативного центра готовых итогов/оплаты нет.

Защищённый запрос 214 и постоянный Stop — нативные поверхности, не обычные уведомления. Разрешение ОС и Focus не управляют их доступностью. В [native-preview](../native-preview/README.md) теперь отдельный раздел «На этом Mac», без серверной ленты и счётчика непрочитанного.

## 1. Информационная архитектура

```text
GRAF в строке меню macOS
 ├ Текущее состояние → Запись / Пауза / Остановить
 ├ Источники → Микрофон / Системный звук / Исправить проблему
 ├ Ближайшая встреча → Подключиться / Другие встречи
 ├ Отправка → состояние очереди / Открыть записи
 └ Открыть GRAF · На этом Mac · Настройки · Ещё

Верхняя панель кабинета
 ├ Название текущего раздела
 ├ Контекстные инструменты: поиск, фильтр, сортировка, загрузка
 └ Уведомления → Важное / История

Настройки
 ├ Запись → Автозапись по приложениям (локально на этом Mac)
 ├ Календари → источник, фильтры, показ времени/названий в строке меню
 ├ Уведомления → локальные категории на Mac; серверные события/письма в вебе
 └ Приложение → виджет, запуск, тема, обновления (существующие возможности)
```

`⌘,`, шестерёнка панели и меню профиля ведут в единый обзор настроек; конкретное предупреждение ведёт сразу в нужный раздел. Страница автозаписи сохраняет нативное владение настройками. Единый обзор — существующая страница настроек GRAF с дополнительным локальным разделом, а не третье окно настроек. Из браузера видна подпись «Эти настройки доступны в GRAF на Mac» и переход в приложение, но нет фиктивных переключателей Mac.

В кабинете колокольчик закреплён в одном месте общей верхней панели на всех авторизованных страницах пространства. Он не участвует в форме поиска/фильтра, не исчезает при переходе к настройкам. На узком экране инструменты переносятся; колокольчик остаётся доступен. В административном/биллинговом контексте событие содержит явную область, чтобы не выглядеть ошибкой текущей встречи.

## 2. Кнопка строки меню macOS

- Один значок GRAF; нейтральный шаблонный символ в готовности, точка записи и длительность при захвате, символ паузы и подпись микрофона при паузе микрофона, отдельный знак проблемы рядом. Цвет дополняет форму и текст.
- Имя для диктора: «GRAF. Идёт запись, 12 минут 34 секунды. Микрофон и системный звук. Открыть управление». Диктор не получает новое объявление каждую секунду.
- Приоритет подписи: текущая запись → проблема, мешающая записи → ожидающая отправка → ближайшая встреча → готовность. Проблема отправки не заменяет таймер активной записи.
- Нажатие открывает панель, повторное закрывает; Escape/нажатие вне закрывает только панель, не останавливает запись и не означает отказ от автозаписи.
- Время ближайшей встречи опционально. Название выключено по умолчанию для новых установок; пользователь может включить его в «Календари». Если оно уже включено, не сбрасываем существующий выбор. Длинное название обрезается по ширине, полное доступно в панели.
- Панель 360 pt по умолчанию, отступы 16, интервал групп 16, строк 8; привязана к значку, не уходит за visibleFrame экрана. При нехватке места прокручивается содержимое календаря; состояние и Stop остаются доступны.
- При скрытой системной строке меню, полноэкранном приложении или закрытом основном окне обязательный компактный виджет предоставляет постоянный индикатор и Stop. Настройка «Скрыть виджет» не применяется, если это последний видимый путь остановки.

### Композиция панели

1. Шапка: GRAF, текущее пространство, шестерёнка «Настройки».
2. Текущее состояние: «Готово к записи» или «Идёт запись», длительность, «Автозапись» при автоматическом старте.
3. Две строки источников: «Микрофон: …» / «Системный звук: …» с фактическим состоянием. «Звук не обнаружен» не равен «Нет разрешения».
4. Основные действия: готовность — «Начать запись»; запись — «Пауза микрофона» и «Остановить»; пауза — «Продолжить» и «Остановить». Stop не прячется в «Ещё».
5. Не более одной главной проблемы с конкретным действием; вторичные проблемы раскрываются через «Ещё N».
6. Ближайшая встреча и «Подключиться». Нажатие открывает только проверенную ссылку, не начинает запись. Без ссылки: время и «Открыть календарь», если такой безопасный переход доступен; иначе понятная подпись без мёртвой кнопки.
7. Если есть очередь отправки: «2 записи ожидают отправки» → общий список с нужным фильтром. Каждая запись восстанавливается на своём экране.
8. Подвал: «Открыть GRAF», «На этом Mac», меню «Ещё».

«Ещё»: показать виджет, открыть настройки, проверить обновления, справка, завершить GRAF. Выход при записи показывает диалог «Остановить запись и выйти?» с безопасным первым действием «Продолжить запись». Выход при очереди: «Отправка продолжится после следующего запуска GRAF» только если очередь действительно сохранена. Обновление откладывается до завершения записи; никаких правок механизма Sparkle в этой фиче.

| Проверка старта | Подготавливаем запись, индикатор ожидания | Отмена, если поддерживается текущим стартом | Второй старт; утверждение, что звук уже пишется |
| Поиск встречи | Ожидаем встречу, нейтральный значок | Ручной старт; автозапись | Реакция на музыку/уведомления как на встречу |
| Запрос | Запись начнётся через 8 с | Записать; Не записывать; Запомнить выбор | Скрыть его через настройки обычных сообщений |
| Ручная запись | Идёт запись + длительность | Пауза; Stop | Убрать последний индикатор |
| Автозапись | Идёт запись · Автозапись + длительность | Пауза; Stop | Второй контроллер старта |
| Только расшифровка | Только расшифровка + длительность; звук захватывается | Пауза; Stop | Обещать отсутствие захвата звука |

| Локальная запись без сети | Идёт запись · Нет связи; «Сохраняем на этом Mac» при доказанной записи на диск | Stop; открыть очередь | Обещать отправку/сохранность без подтверждения |
| Отправка после Stop | Запись остановлена; Отправляем запись | Открыть запись; новая запись при готовности | Использовать таймер как будто запись продолжается |
| Ошибка отправки | Не удалось отправить; локальная копия подтверждена/не подтверждена отдельно | Повторить через существующий механизм; открыть | Повторять каждую секунду; терять локальную копию |
| Нет разрешения | Нет доступа к микрофону/системному звуку | Открыть настройки macOS; проверить снова | Запуск без нужных разрешений |
| Частичный захват | Не записывается микрофон / системный звук | Исправить; Stop | Подпись «всё готово» |
| Место заканчивается | Мало места на Mac, оценка только при достоверных данных | Открыть записи/хранилище; Stop | Удалять данные автоматически |
| Диск заполнен | Запись остановлена: нет места; сохранность фрагментов по факту | Открыть запись; освободить место | Бесконечно показывать «идёт запись» |
| Политика | Запись запрещена правилами пространства | Причина/настройки или обратиться к администратору | Недоступная кнопка без причины |
| Нет входа | Войдите для отправки записей; локальная доступность по действующей политике | Войти; Stop активной записи | Новый авторизационный gate поверх текущего capture |
| Ошибка календаря | Календарь временно недоступен / Данные обновлены … | Обновить; настройки | Блокировать ручную запись |

## 3. Полный пользовательский путь

### Первый запуск

1. Пользователь настраивает текущие разрешения GRAF и завершает существующий путь готовности записи.
2. Короткое пояснение: «В строке меню виден статус GRAF. Во время записи всегда доступна остановка»; пример с искусственной встречей.
3. Разрешение macOS на уведомления запрашивается только после понятного действия «Включить уведомления на этом Mac». Отказ не повторяет системный запрос при каждом запуске; появляется ссылка в настройки macOS.
4. Пользователь видит разницу «Напоминания о встречах» и «Автозапись». Для новых приложений действующее значение «Спрашивать» сопровождается явным текстом про 8 секунд.
5. Дополнительные письма/советы не включаются новой миграцией поверх прежнего отказа.

### До встречи

Напоминание за 1 минуту по умолчанию; возможные значения 1/5 минут/в момент начала, только одно на событие. Оно появляется лишь для будущего/текущего доступного события с актуальной версией календаря. Нажатие «Подключиться» открывает ссылку. Скрытие не отменяет событие и не меняет автозапись. Если пользователь уже участвует в соответствующей встрече, напоминание подавляется. При нескольких одновременных событиях панель предлагает выбрать встречу; запись не связывается с произвольным первым событием.

### Начало встречи

Текущий детектор 214 решает, есть ли допустимая встреча. «Всегда» — старт без запроса, затем обязательный индикатор. «Спрашивать» — отдельная панель с названием приложения, «Запись начнётся автоматически через 8 секунд», «Записать», «Не записывать», «Запомнить выбор». Таймер завершается существующим механизмом; обновление UI не создаёт второй таймер. При явном отказе подавляется текущая встреча; при сохранении выбора настройка меняется на «Никогда». На истечении таймера настройка остаётся «Спрашивать» даже при установленном флажке. «Никогда» — нет автоматического предложения, ручной старт сохраняется при разрешении политики.

### Во время встречи

Постоянный компактный виджет: состояние, время, пауза/продолжение, Stop; источники раскрываются. Не перекрывает основные кнопки приложения встречи, переносится между мониторами. Ошибка источника появляется рядом с действием исправления. Потеря сети не выносит пользователя из встречи и не прекращает локальную запись. Готовности предыдущих встреч обновляют список встреч и тихую историю, без точки на колокольчике; советы не показываются.

### Остановка и ожидание

После подтверждённого Stop таймер прекращается, появляется строка «Запись остановлена» и фактический статус отправки. Состояния «на этом Mac», «отправляется», «обрабатывается» и «готово» различаются. Новая встреча разрешена независимо от обработки предыдущей, если текущие capture gates позволяют. Кабинет не открывается сам по умолчанию.

### Получение результата

При фактической готовности итогов: «Итоги встречи готовы» → «Открыть итоги». Если настроена только расшифровка — «Расшифровка готова». Если расшифровка готова, а итоги упали, пользователь получает «Расшифровка готова. Итоги не удалось подготовить» с доступной расшифровкой и восстановлением итогов. Повторная генерация не стирает прошлый результат и не создаёт десятки готовностей.

### Возврат после отсутствия

После сна или повторного входа показывается актуальный список, а не серия накопленных всплывающих карточек. Старые календарные напоминания истекают. Неустранённые ошибки выделяются. Доступ к удалённой встрече или отозванным правам заменяется спокойной страницей «Встреча недоступна» без раскрытия прежнего названия.

## 4. Разделение содержания и доставка

| Поверхность | Содержание | Прерывание |
|---|---|---|
| Нативная панель / виджет | Запись, источники, Stop, очередь отправки | Постоянное актуальное состояние |
| Нативная панель решения | Режим «Спрашивать» 214 | Защищённый 8-секундный запрос |
| «На этом Mac» | Активные локальные проблемы и восстановление | Без unread-счётчика, без истории результатов |
| Системное уведомление macOS | Актуальное напоминание или локальная проблема с действием | Одна попытка для события, с учётом разрешения/Focus и видимости контекста |
| Веб-колокольчик, включая embedded | Серверные результаты, доступ, действия аккаунта | Без баннеров; точка только у нового важного |
| Email | Существующая обязательная доставка и отдельно выбранные сообщения | Прежний контракт, без новых писем о каждом успехе |

Нативный клиент не показывает системный баннер серверного результата/обработки/биллинга. Browser Notifications, звуки и мигание вкладки в вебе не используются. Существующий веб-кабинет внутри Mac не создаёт вторую нативную копию своих событий.

Локальный инцидент стабилен; retry не создаёт повтор. После подтверждённого устранения и нового возникновения возможно новое уведомление. Пока соответствующий статус уже виден, отдельный баннер подавляется. Capture-проблема остаётся в постоянной панели независимо от разрешений ОС; Focus не обходится. Напоминание не воспроизводится после истечения и подавляется при уже начавшейся соответствующей встрече. Нет выдуманного глобального лидера устройств.

Полная матрица причин, текстов, владельцев, повторов и переходов — [surface-separation.md](../surface-separation.md).

## 5. Каталог уведомлений и точные тексты

В системных уведомлениях локальных/календарных событий `{встреча}` заменяется на «Встреча», пока пользователь явно не включил названия. У каждого действия повторно проверяются права/актуальность. Относительное время сопровождается полной датой в доступном описании.

| ID / событие | Условие, канал и приоритет | Текст и действие | Повтор, истечение, разрешение |
|---|---|---|---|
| N01 Напоминание | Mac: Актуальное событие, выбранный момент; P2, macOS при разрешении | За 5/1 минуту: «Встреча начнётся через 5 минут» / «Встреча начнётся через минуту»; в момент/после начала: «Встреча уже началась». «Подключиться» | Ключ occurrence+start_revision; expires min(start+5 мин, end); при переносе отмена старого; не в постоянной истории |
| N02 Предложение записи | Mac: Только разрешённый детектором режим ask; P1, нативная панель | «Началась встреча в {приложение}. Запись начнётся автоматически через 8 секунд». «Записать» / «Не записывать» | Ключ текущего кандидата 214; один исход; не в истории |
| N03 Запись началась | Mac: Подтверждённый capture; постоянный статус | «Идёт запись» / «Идёт запись · Автозапись» | Не обычный баннер, не непрочитанное |
| N04 Пауза / продолжение | Mac: Подтверждение действия; постоянный статус | «Микрофон на паузе» / «Идёт запись» | Обновление одного статуса |
| N05 Stop | Mac: Подтверждённая остановка; текущая панель | «Запись остановлена». Статус отправки по факту. «Открыть запись» | Без постоянного нового уведомления |
| N06 Нет сети во время записи | Mac: Локальная запись продолжается; P1, статус | «Нет связи с сервером. Запись продолжается на этом Mac». Сохранность только при подтверждении | Один инцидент; разрешается после восстановления связи, без нового баннера успеха |
| N07 Отправка требует действия | Mac: Авторитетный terminal/action-required, а не очередной retry; P1, локальное состояние + macOS при допустимом показе | «Не удалось отправить запись». «Копия сохранена на этом Mac» только при проверенном файле. «Открыть запись» | Ключ local_recording+incident; при успехе resolved; повторная попытка использует текущий upload pipeline |
| N08 Нет микрофона | Mac: Подтверждённая потеря обязательного источника; P0 | «Микрофон не записывается. Проверьте устройство и доступ». «Проверить микрофон» | Пока не восстановлен; состояние остального звука описывается фактически |
| N09 Нет системного звука | Mac: Подтверждённая ошибка источника; P0 | «Системный звук не записывается». «Проверить разрешения» | Не возникает от обычной тишины; resolved по capture health |
| N10 Мало места / диск полон | Mac: Реальный порог storage health; P0 | «Мало места на Mac» или «Запись остановлена: нет места». «Открыть записи» | Порог берётся из текущего storage gate; этот дизайн не вводит новый расчёт времени до заполнения |
| N11 Только расшифровка готова | Веб: Готов canonical transcript, итог не ожидается; P2 | «Расшифровка готова». «Открыть расшифровку» | Ключ meeting+result_revision; история 30 дней |
| N12 Итоги готовы | Веб: Готов опубликованный итог; P2 | «Итоги встречи готовы». «Открыть итоги» | Обновляет карточку результата этой ревизии; не дублирует transcript-ready |
| N13 Частичный результат | Веб: Расшифровка есть, итог terminal-failed; P1 | «Расшифровка готова. Итоги не удалось подготовить». «Открыть встречу» | Встреча доступна; повтор итогов в существующем экране, не повтор захвата |
| N14 Речь не распознана | Веб: Терминальный no-speech; P1 | «Речь не распознана». «Проверьте звук записи или загрузите другой файл». «Открыть запись» | Не «готово» и не бесконечный retry; восстановление в экране записи |
| N15 Обработка не завершена | Веб: Терминальная ошибка обработки; P1 | «Не удалось обработать запись». «Открыть запись» | Обычная очередь/длительное ожидание не являются terminal; нет выдуманного срока готовности |
| N16 Нужен вход | Контекст входа каждой поверхности: Текущая сессия недействительна; P1, status | «Войдите, чтобы отправить записи и открыть результаты». «Войти» | Один инцидент на auth epoch; Stop доступен; старые серверные сообщения очищены |
| N17 Календарь отключён | Веб: Подключение отозвано/истекло; P1 status | «Календарь нужно подключить снова». «Открыть календари» | Не блокирует запись, нет повторных баннеров при каждом poll |
| N18 Новая общая встреча | Веб: Подтверждённо выдан доступ конкретному пользователю; P2, история | «С вами поделились встречей». «Открыть встречу» | Только если действующий sharing pipeline даёт достоверный event; иначе не выпускается |
| N19 Платёж/безопасность | Веб: Только достоверное событие, требующее действия именно этого получателя | Существующий проверенный шаблон и действие | Успешный платёж/чек не зажигает колокольчик. Обязательные письма и прежний outbox остаются без изменений |
| N20 Уведомления запрещены ОС | Mac: Проверенное permission state; только настройки | «Уведомления macOS выключены. Управление записью и локальные проблемы остаются доступны». «Открыть настройки macOS» | Не повторяется при каждом запуске; не влияет на capture |

Для N11→N12, когда итог ожидается, промежуточная расшифровка доступна на встрече без отдельного баннера; N12 — одна тихая серверная карточка результата, без точки и без системного баннера. Если итог ожидается слишком долго, интерфейс встречи показывает фактическое ожидание; уведомление не придумывает ошибку по таймеру. Для результата после пользовательского reprocess используется его ревизия, группировка сохраняет один последний видимый результат на встречу, история действий остаётся на экране встречи.

## 6. Центр уведомлений

Подробные решения и повторный аудит: [веб-колокольчик без лишнего шума](../web-attention-audit.md).

Панель под колокольчиком: ширина 400 px, не шире viewport−24; высота ограничена доступным экраном, список прокручивается. Шапка «Уведомления», настройки и закрытие. Два переключателя: «Важное» по умолчанию и «История». Числового badge, фильтра «Непрочитанные» и массового «Прочитать всё» в веб-интерфейсе нет.

- Маленькая точка означает новое **требующее действия** событие. Формула: актуально, доступно, `requires_action`, `resolved_at == null`, `revision > read_revision`. Обычная готовность и адресное предоставление доступа — тихая история, без точки.
- «Важное» содержит все актуальные проблемы, включая просмотренные. История содержит полезные результаты и события; одна карточка на встречу/инцидент, без технических повторов.
- Открытие панели ничего не читает. Успешный переход в относящийся к проблеме экран либо «Просмотрено» подтверждает только показанную revision. Ошибка перехода/сохранения не снимает точку. «Просмотрено» доступно только для нового важного; обычные результаты не требуют разбирать очередь.
- Просмотр не исправляет проблему. После подтверждённого восстановления карточка автоматически уходит из «Важного», её статус в истории меняется на «Решено», без новой точки и баннера. Повторный poll/retry не повышает revision и не переоткрывает инцидент. Новое подтверждённое возникновение после восстановления может снова привлечь внимание.
- Строка: смысловой символ, короткий заголовок, объект/область, что доступно и следующий шаг, время, одна основная кнопка. Новый важный заголовок отмечен небольшой точкой; нет фиолетового фона на каждой готовности. Просмотренная ошибка сохраняет подпись «Просмотрено · Требует действия».
- Пустое важное: «Сейчас ничего не требует вашего действия. Готовые результаты — в списке встреч и истории». Это не обещание исправности всей инфраструктуры или готовности всех работ.
- Срок тихой истории — 30 дней после результата/разрешения, активные проблемы не истекают автоматически; срок не меняет хранение встреч/аудита/финансовых документов.
- Локальные инциденты видны только в нативной панели/разделе «На этом Mac». Ни standalone, ни embedded web inbox их не получают; веб не подтверждает сохранность локальной копии.
- Загрузка/503: состояние неизвестно, содержательные старые карточки скрыты до повторной проверки прав, доступно «Повторить». Ошибка не превращается в подтверждённое пустое состояние. 401/logout/смена области очищают прежнее содержимое. При получении сигнала удаления/отзыва данные скрываются сразу; при каждом запросе права проверяются заново. Возврат во вкладку/pageshow скрывает карточки до проверки; активная открытая панель перепроверяет доступ каждые 30 секунд. Мгновенное удалённое стирание без сигнала не обещается.
- Escape, повторное нажатие колокольчика и нажатие вне закрывают панель; закрытие через Escape возвращает фокус инициатору. Переход в карточку переносит фокус в её экран. Новые обычные результаты не попадают в live region; `role=status` используется для результата явного действия пользователя.

## 7. Настройки и область действия

В нативных настройках вверху статус macOS и «Проверить уведомление» с синтетическим сообщением. Проверка никогда не запускает запись. Если разрешения нет, кнопка объясняет путь включения вместо ложного «отправлено».

| Контроль | Новая установка | Область / смысл |
|---|---|---|
| Напоминания о встречах | Включено в приложении; macOS только после разрешения | На этом Mac; 1 минута, выбор 1/5/0; доступен при подключённом календаре |
| Готовность результатов | Без отдельного переключателя доставки | Только веб-список и тихая история; системного канала нет |
| С вами поделились | Без нового переключателя подписки | Веб, тихая история; только поддержанное достоверное событие |
| Показывать названия в уведомлениях macOS | Выключено | На этом Mac; ограничено более строгими настройками ОС/пространства |
| Звук уведомлений | Выключено | На этом Mac; не озвучивать во время записи |

| Новости и советы по почте | Существующее значение, включая действующий default true; миграция не меняет согласие | Пользователь; хранить прежний optional_email_enabled |

Две самостоятельные формы: «В аккаунте» (существующие дополнительные письма и советы; результаты и доступ объясняются текстом без новых переключателей) и «На этом Mac» (напоминания, названия, звук). У каждой собственные «Сохранить / Отменить» и подтверждение. Нет общего атомарного Save для двух хранилищ. Каждая форма следует текущему явному сохранению: до Save изменения не действуют; Save недоступна при отсутствии изменений; на ошибке draft не теряется; status «Не удалось сохранить. Попробуйте ещё раз». Успех «Настройки сохранены». Смена страницы при несохранённых изменениях: «Остаться» (вернуться к отдельным формам и сохранить нужную) / «Не сохранять». Локальная форма не ждёт сервера, серверная не делает вид, что сохранилась без подтверждения.

Старые значения не трактуются как согласие на новые каналы: сохранённое false дополнительных уведомлений остаётся false. Массовое «отключить все» не добавляется: оно создаёт ложное ожидание скрытой записи. Отдельный режим Focus не изобретается, используется решение ОС и правила активной записи.

## 8. Визуальная система и доступность

Наследовать типографику, фиолетовый акцент и токены существующего GRAF, без добавления сторонних шрифтов и картинок. Нативные символы macOS и собственные существующие web-иконки. Фон панелей адаптируется к теме; существующее несовпадение светлой web-страницы и тёмной нативной панели следует устранить через общий выбор темы, не жёсткие цвета.

Основной текст 14 px/pt, вторичный 12–13, заголовок 16; масштабирование до 200%. Текстовый контраст ≥4.5:1, границы фокуса/контролов ≥3:1; цели не меньше 32×32 для мыши, 44×44 для touch. Радиус панели 12, контролов 8; движение 120–180 мс с уважением Reduce Motion. Красный зарезервирован записи/опасности и сопровождается символом/словами.

Popover не крадёт фокус при приходе нового события. При явном открытии фокус на заголовок/первый фильтр, Escape возвращает на кнопку. Клавиатура проходит фильтры, карточки, действия, настройки; при modal-варианте узкого экрана фокус удерживается внутри. Никаких hover-only действий. Веб fallback без JS: ссылка на отдельную страницу истории и обычные формы POST с CSRF.

Отсчёт 214 остаётся доступным для диктора; не озвучивать каждую секунду поверх разговора: объявить полный текст при появлении и финальное состояние. При keyboard focus не менять существующий срок автоматически — изменение восьмисекундного контракта требует отдельного продуктового решения. До внедрения нужна проверка достаточности доступности этого защищённого поведения, зафиксированная рецензентом.

## 9. Приватность и истинность

- Никаких фрагментов расшифровки, AI-итогов, имён участников, email, локальных путей, signed URLs в системных уведомлениях, аналитике и диагностике.
- Внешнее сообщение содержит только категорию, нейтральный текст и внутренний идентификатор перехода. Название разрешено лишь по явному предпочтению и актуальным правам.
- Локальные проблемы не отправляют содержимое файла на сервер. Сетевое отсутствие не означает «файл потерян».
- Уведомления не могут менять доступ к встрече, создавать платёж, удалять запись или запускать произвольный URL без существующей проверки.
- Политика записи/согласия выполняется до старта; подсказка «предупредите участников» не является подтверждением их согласия.
- GRAF не обещает удаление вне своего контроля; просмотр уведомления не удаляет финансовую историю, аудит, Langfuse и Temporal.

## 10. Границы совместимости и запуска

Новая общая панель заменяет только ограничение calendar-only из контракта 168; безопасная проекция календаря, очистка при смене сессии, защита старого ответа и проверка ссылок остаются. Механизм 214 и текущие команды capture не переписываются.

Перед удалением legacy: точный список символов → все callers/тесты/встроенные и автономные пути → работающий преемник → scoped regression → сравнительный сценарий обновления/отката → удаление. Пока преемника нет, существующая поверхность восстановления не удаляется. Известные кандидаты и условия находятся в research.md.

Внедрять последовательными проверяемыми частями: 1) общая нативная панель и единые точки входа; 2) категории настроек и доставка; 3) история и прочитанность; 4) удаление доказанно недостижимых дублей. Существующие обязательные финансовые уведомления остаются работоспособны на каждом этапе.

## 11. Уточнения после проверки проекта

- Время отсчёта спрашивания принадлежит текущему контроллеру 214. Escape/закрытие обычной панели не означает «Не записывать». Полный текст объявляется один раз, порядок Tab: «Записать», «Не записывать», «Запомнить выбор». Native VoiceOver/полный экран остаются приёмкой, которую HTML не доказывает.
- Stop принимает один запрос; сразу показывает «Останавливаем запись…», сохраняет видимый индикатор до подтверждения capture. Повторное нажатие не отправляет вторую команду. Пауза/старт аналогично не подтверждаются только по клику. При ошибке Stop: «Не удалось остановить запись. Повторите попытку», индикатор остаётся правдивым. Выход не убивает процесс до сохранения текущей очереди штатным путём.
- Перенос или изменение времени встречи отменяет ранее запланированное напоминание. После сна показывается только ещё актуальная встреча в своём окне; перенос только названия не даёт второго показа. Встреча без ссылки не получает кнопку «Подключиться».
- «Ещё» — доступный popover со списком обычных кнопок (без роли ARIA menu, пока нет полного меню с управлением стрелками). Escape закрывает его с возвратом фокуса. Выход при записи — отдельный диалог, первая безопасная кнопка «Продолжить запись», второе действие «Остановить и выйти». Отмена не меняет запись.
- Нативные уведомления не перехватывают фокус; локальные проблемы не имеют прочитанности. В веб-панели фокус при открытии переходит в шапку, при закрытии возвращается на колокольчик. После просмотра карточка в «Важном» остаётся на месте до разрешения, фокус сохраняется на действии. При удалении карточки фокус получает следующая, затем предыдущая, при пустом списке — выбранный фильтр.
- Сообщение не становится прочитанным при ошибке перехода. При ошибке сохранения просмотра сохраняются непрочитанность и действия. При 503 содержательные старые карточки скрываются до проверки прав, вместо них нейтральная ошибка; при 401 очищается и индикатор. Не показывать «нет уведомлений», пока нет успешного пустого ответа.
- В standalone web первой версии результаты обновляют историю без всплывающего баннера: вкладка не может достоверно знать, идёт ли нативная запись на Mac. Embedded использует ту же серверную ленту, без передачи события нативному presenter. Глобальное устранение повторов между независимыми браузерами и устройствами не обещается.
- Не гарантируем доставку macOS или удаление ранее увиденного внешнего превью. GRAF гарантирует безопасный выбор payload, одну попытку показа локального события на владельца/версию/устройство и доступное текущее локальное состояние. Отдельная серверная история видна только после актуальной проверки прав.
- Просмотр относится к одной показанной серверной revision; новая версия не поглощается. Массовая read-all и локальный read-state не нужны разделённым поверхностям и убраны из проектируемого контракта.
- Если нет достоверного сигнала для категории (например, нет producer адресного sharing), переключатель не показывается. Возможность включается только вместе с работающим источником и проверкой отказов; никаких контролов «на будущее».

## 12. Уточнения перед реализацией

Локальные предпочтения напоминаний, названий и звука хранятся для owner+device. Разрешение macOS относится к приложению на устройстве, но не переносит согласие показывать названия между владельцами. При выходе/смене владельца или пространства отменяются известные pending/delivered уведомления, очищается календарная проекция и поколение загрузки. Новый владелец получает безопасные defaults; чужое show_titles не наследуется. Отключение напоминаний/календаря и перенос события отменяют запланированные requests. Старая попытка не повторяется при повторном входе.

Для пользователя, которому недостаточно восьми секунд, до записи доступен раздел «Автозапись»: выбрать «Никогда» и пользоваться ручным стартом. Защищённый countdown 214 не меняется. Соответствие требованиям времени WCAG не объявляется до отдельной нативной проверки с VoiceOver.

N17 остаётся контекстным состоянием существующих настроек календаря, без новой карточки/точки. N19 использует только реально существующие финансовые инциденты, получателя и текущий статус; новые события безопасности не изобретаются.
