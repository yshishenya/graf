# F200 — внутренний MSIX 0.1.0.23 x64

На Windows 11 в Parallels собран свежий Release x64. База:
`972af4762e7afc1a5a1c8d9025aec1eb6ce7127e`. Из 224 входов восемь файлов
приложения взяты из проверенных изменений текущего рабочего дерева:

| Задача | Что вошло в пакет |
| --- | --- |
| [T105](validation-2026-11-06-t105-short-notice.md) | Обновление нативных карточек после закрытия предыдущей: `AppMain.cpp` и два файла `RecordingNoticePresenter` |
| [T117](validation-2026-11-06-t117-gate-publication.md) | Три файла защиты при публикации новой очереди; это не ремонт существующего хранилища рабочего профиля |
| [T119](validation-2026-11-06-t119-telemost-path.md) | Исправление обработки ссылки календарной встречи в `CalendarMeetingOpener.cpp` |
| [T120](validation-2026-11-06-t120-stale-clock.md) | Ожидание свежего показания часов WASAPI при выходе из паузы; старое показание не включает микрофон |

Версия `0.1.0.23` задана только в копии манифеста сборки. Независимое
ревью сверило все входы и процедуру сборки. MSBuild восстановил
зависимости из изолированного локального набора и выполнил полный
Rebuild. Свежие объекты и строки компиляции подтверждают включение
`WasapiCaptureWorker.cpp` и `RecordingNoticePresenter.cpp`. В пакете
нет тестовых EXE или принудительно подключённых тестовых заголовков.

В Windows подпись пакета действительна с существующим сертификатом
разработки `CN=GRAF`, отпечаток
`816CC8B4EB216A0755BFB118992BB594AF51BF6C`. Проверка структуры MSIX,
точки входа и комплектности прошла. На Mac независимо сверены SHA-256
всех 26 файлов в архиве, идентификатор `com.graf.desktop` и совпадение
EXE внутри MSIX со свежим EXE сборки. Временное дерево Windows и копия
исходников на Mac удалены; журналы и пакет сохранены.

Пакет 0.1.0.23 не устанавливался и не запускался. Установленная 0.1.0.18
осталась открыта и отвечала после сборки, её EXE и хранилища доверия
сохранили контрольные суммы. Не было захвата звука, миграции рабочего
профиля или публикации. Подпись разработчика не предназначена для
распространения клиентам.

Актуальный установленный `/Applications/GRAF Dev.app` указывает
`GRAFSourceSHA=bd088c8fdea6007a12df3eee13da62b20e3c5828`. Этот исходник
содержит изменения F292, которых нет в истории Windows-кандидата.
В частности, Mac возвращает фокус после закрытия системного диалога
сохранения; проверка установленных оболочек после Save и Cancel
добавлена в [quickstart §11](quickstart.md#11-итоговая-приёмка-двух-платформ-2026-09-27).
Сборка пакета не доказывает, что обе оболочки загружают одинаковую
версию общего кабинета, или что на Windows воспроизводится сбой фокуса.
Для приёмки 0.1.0.23 остаются точная установка и запуск в отдельном
профиле, совместная проверка с Mac, обновление и откат, запись на
физическом Windows x64 и остальные условия F200.

## Проверка, что приёмка относится к нужному MSIX

В [quickstart §8](quickstart.md#8-msix-package-smoke) добавлена команда
проверки по заранее известному SHA-256. Она сверяет доверенную на этом
хосте подпись, регистрацию пакета у текущего пользователя и байты
установленного EXE. Отдельный параметр проверяет открытое окно того же
пакета в текущем сеансе Windows. Регистрация из распакованной папки
не принимается как установка MSIX.

На рабочей Windows 11 в Parallels совпали MSIX, установленный EXE и
отвечающее окно **0.1.0.18**. Пакет **0.1.0.23** прошёл статическую
проверку с закреплённым хешем и действительной подписью на этом
хосте, но как установленный экземпляр был отклонён. Проверка
отклонила также неверный SHA-256, отсутствие подходящего процесса
и смоделированный процесс без окна. Проверки архива, подписи и
регистрации на искусственных данных: 17/17, включая изменённый
установленный EXE и регистрацию из папки.

| Артефакт | SHA-256 |
| --- | --- |
| Валидатор | `82b9f878b3ff8c028ad91015a2708e5d08c18d27f102bfa2bd1b3368c441c266` |
| Регрессионные проверки валидатора | `0e55ccb1035a023f314a9d937d5e21ea0eaa6b162b15ce222a3bcd6889b70995` |
| Журнал Windows | `d0d1aa1a9575db657cae2c816defd8558ed30327e652ed703a22b8064d4c011d` |

Рабочий процесс не закрывали, пакеты не устанавливали и доверие к
сертификатам не меняли. Временные копии MSIX удалены. Отдельная
`GRAF F200 QA ARM` на момент проверки была на экране лицензии
Windows Setup. Чистая установка, первое открытие и пользовательские
сценарии 0.1.0.23 ещё не проверены.
