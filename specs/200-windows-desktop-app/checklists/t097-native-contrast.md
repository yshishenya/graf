# T097 — требования к контрасту нативных окон Windows

FR-002 и SC-009. Чеклист требований заполняет независимый рецензент.

- [X] Определены холодный запуск с контрастом, смена A → B без выхода из контраста и возврат к обычной теме.
- [X] Для основной кнопки и «Остановить запись» заданы читаемость, видимый фокус и сохранение состояния; проверяются обычное состояние, наведение и нажатие.
- [X] Режим оформления кабинета, интерфейс macOS, состояние захвата и жизненный цикл окон остаются независимы от смены системных цветов.
- [X] Искусственные цвета, настоящий WinUI и точный установленный пакет с Narrator и 200% дают отдельные доказательства.
