# T104/B2b — допуск записи с выбором встречи

- [x] CRA001 Решение и текущий аккаунт привязаны к фактическому
  резервированию, а не к UUID, полученному из интерфейса. Положительное
  подтверждение журнала необходимо до writer и запуска звуковых устройств.
- [x] CRA002 Обычная запись сохраняет прежний маршрут; отказ журнала и
  отзыв действия не превращаются в обычную запись. Определены точки
  проверки Stop, смены/сброса аккаунта и протухания календарного снимка.
- [x] CRA003 План отличает проверки рабочего потока, финального допуска
  пакетов и настоящего действия панели. Внешний сценарий остаётся
  недоступен до согласованного поведения при отправке.
