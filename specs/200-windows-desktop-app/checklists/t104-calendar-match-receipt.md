# T104/B2c.1 — требования к подтверждению календарного выбора

- [x] CMR001 Потеря ответа и истечение срока до или после принятия различимы; квитанция берётся из принятой попытки, а не из текущей карточки.
- [x] CMR002 Определены границы аккаунта, устройства, записи, встречи, ревизии и удаления; ответ по запросу минимален и не кэшируется.
- [x] CMR003 Старый запрос и поведение macOS сохраняются; отдельная проверка настоящего API не подменяет сквозную приёмку установленной панели.
