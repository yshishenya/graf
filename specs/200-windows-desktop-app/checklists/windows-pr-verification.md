# F200: требования к опытной проверке Windows в PR

- [x] CHK001 Определены ли проверяемый PR, точная пара head/base, SHA задания, номер запуска и попытки, а также условия, при которых прежний результат перестаёт подтверждать текущий PR? [План, п. 1, 4–5]
- [x] CHK002 Различимы ли полная область, ошибочный расчёт и обоснованный пропуск? Описаны ли переименование, неизвестный путь и отсутствие предварительного ограничения списка файлов? [План, п. 1, 5]
- [x] CHK003 Явно ли заданы тип события, место запуска кода PR, права токена, зависимости, обращение с форками и запрет переноса доверия на их журналы? [План, п. 3–4]
- [x] CHK004 Однозначно ли определены хост и цель, пять ожидаемых тестов, условия прохождения каждого, смысл отсутствующего JUnit и отличимые причины неуспеха? [План, п. 2, 4–5]
- [x] CHK005 Разделены ли локальная проверка, опытный запуск в GitHub, включение в защиту ветки, приёмка установленного приложения и физического Windows x64? [План, п. 4–5; T063, T071]

План: [Проверка Windows в запросах на слияние](../windows-pr-verification.md).
Отметки о требованиях принадлежат независимому проверяющему.
