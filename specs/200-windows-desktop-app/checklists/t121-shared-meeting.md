# Чеклист требований: открытие общей встречи (T121)

**Цель:** проверить, что требования однозначно описывают открытие общей встречи в Windows с тем же результатом, что в GRAF Dev macOS, без расширения доступа.

**Дата:** 2026-11-07

**Требования:** [уточнение T121](../spec.md), [контракт §11](../contracts/windows-native-web-bridge.md#11-t121-открытие-общей-встречи-f292--2026-11-04), [сценарии приёмки](../quickstart.md#t121-scoped-acceptance-shared-meeting--2026-11-04), [задача #7933](https://github.com/yshishenya/graf/issues/7933).

Составлено по `$speckit-checklist`. Отметка принадлежит рецензенту и подтверждает качество требования, а не готовность реализации.

## Ссылка и полномочия

- [X] CHK001 Определены ли обе формы ссылки, схема для установленного пакета, допустимые поля и поведение при неверной ссылке, в том числе при дубликатах и превышении предела? [Clarity, §11.1]
- [X] CHK002 Можно ли однозначно отличить синтаксически допустимый идентификатор от подтверждённого доступа и допустимый маршрут от произвольного адреса или вложенного запроса? [Security, §11.1–11.2]
- [X] CHK003 Раздельно ли заданы правила навигации, чтения аудио, экспорта и нативных команд для гостя, вошедшего пользователя и своего кабинета? [Consistency, §11.2]

## Вход, воспроизведение и отказ

- [X] CHK004 Задано ли, когда запрос на открытие потребляется или отменяется при холодном запуске, повторной активации, смене аккаунта и закрытии; описана ли независимость записи и Stop? [Completeness, §11.2–11.3]
- [X] CHK005 Определено ли, как оба сценария входа возвращают к той же вкладке, версии и позиции, без переноса браузерной сессии и без секретов в адресе входа, настройках или диагностике? [Security, §11.1, §11.3]
- [X] CHK006 Достаточно ли чётко определены сверка сессии после входа без нативного моста, отзыв старого ответа и результат при временной ошибке чтения сессии? [Recovery, §11.3]
- [X] CHK007 Определён ли результат при отсутствии сети, отозванном доступе и для отсутствующей, актуальной или сменившейся версии записи, включая позицию 0, явный повтор и отсутствие неожиданного нативного эффекта? [Exceptions, §11.1, §11.3, Quickstart T121]
- [X] CHK008 Названы ли отдельные доказательства общей веб-части, настоящей активации установленных GRAF Dev и MSIX, а также сохранения прежних путей входа, оплаты, экспорта и T106? [Measurability, Quickstart T121, T097/T063]

## Независимая проверка требований

**Итог: 8 подтверждено, 0 открыто.** Проверены общие требования §11.1–11.3. Отдельный проект §11.4 проходит по своему чеклисту; эти отметки его не закрывают.

| Пункт | Основание |
| --- | --- |
| CHK001 | Контракт §11.1 и quickstart Strict intent: ровно один из `meeting_id` и `share_token`, схема регистрации пакета, допустимые поля, предел 16 KiB, один decoding, отказ на дубликате и неверной форме без замены pending. |
| CHK002 | Контракт §11.1–11.2: UUID только синтаксис; права подтверждают собственная сессия и серверный грант. Разрешены точные маршруты на настроенном origin; произвольные, вложенные и неканонические адреса отвергаются. |
| CHK003 | Матрица §11.2 и quickstart Shared capability разделяют публичный просмотр гостя и вошедшего, адресного получателя summary/full и владельца. Аудио и экспорт проверяются сервером отдельно; общий reader не получает мост даже после входа. Свой кабинет сохраняет прежние проверки. |
| CHK004 | §11.3 и quickstart Cold/repeat, Tray/quit: один pending до готовности, однократное потребление, замена только допустимой ссылкой, отмена при выходе, смене аккаунта или уничтожении окна. Скрытие в трей сохраняет ожидание; запись и Stop не меняются. |
| CHK005 | Spec T121, §11.1/§11.3 и quickstart Auth continuation: публичный вход и регистрация используют запечатанное продолжение без токена в login next; адресный вход сохраняет локальный next, пространство, вкладку и допустимую пару версия/позиция. Браузерная сессия не копируется; секреты исключены из настроек и диагностики. |
| CHK006 | §11.3 и quickstart Public login cookie reconciliation: cookie собственного профиля читается нативно без моста; результат связан с текущими хостом, документом и ответом; поздний результат отбрасывается, временная ошибка остаётся unknown/retry, без ложного выхода. |
| CHK007 | §11.1/§11.3 и quickstart Auth continuation, Shared player: offline даёт явный повтор, отзыв/403/404 не оживляют intent. Без версии вкладка открывается без позиции, совпавшая версия переносит и 0, устаревшая не перематывает; явное обновление начинает сначала. Нативных полномочий у reader нет. |
| CHK008 | Quickstart Route/media, Shared capability и Regressions задаёт проверки браузерного reader, экспорта и сохранения прежних auth/payment/T106. Отдельно названы настоящий WebView2, установленная холодная и повторная активация MSIX и тот же путь Mac Dev в T097/T063; хеши исходников, PE и пакета фиксируются раздельно. |
