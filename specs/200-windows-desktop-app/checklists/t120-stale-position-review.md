# T120 — требования к ожиданию свежей границы Resume

Область: FR-002/FR-009, SC-002/SC-004, T120/#7590. Это проверка
формулировок до изменения worker; отметки принадлежат независимому
проверяющему.

- [x] CHK001 — Spec, desktop contract §3, plan и quickstart однозначно различают старое наблюдение q<L и свежую границу q≥L при B<releasedEnd.
- [x] CHK002 — Описано, какие проверки действуют до ожидания: точный S_OK, текущий поток/формат, монотонность, достоверное время, checked B, deadline и обычные faults.
- [x] CHK003 — Неопределённая граница не меняет epoch, звук и OPEN; ожидание сохраняет seq/T0/L/deadline, Stop доступен, READY возможен только со свежим B без подгонки.
- [x] CHK004 — Критерии задают два различимых исхода: старая пара B<releasedEnd → свежая допустимая пара и свежая пара B<releasedEnd → отказ без CLOSE, с рабочими Stop/retry.
- [x] CHK005 — Условия сохранения system/PTS/count/AEC, подавления непрочитанного префикса, границы проверки на устройстве и действующий владелец T120/#7590 указаны.
