# Чеклист требований T123 — сохранение экспорта

Тип: независимое ревью требований перед реализацией. Отметка
подтверждает проверяемость требования, а не готовность приложения.

- [x] CHK001 Описан полный путь выбора папки, имени, сохранения,
  отмены и исправления ошибок без тупика; определены допустимые действия.
- [x] CHK002 Определены клавиатура, диктор, видимость и возврат фокуса,
  включая отзыв в фоне, уничтожение окна и отсутствие запуска файлов.
- [x] CHK003 Установлена граница между отзывом и фиксацией; описаны
  смена фактического URL, потеря готовности, A→B и поздние ответы.
- [x] CHK004 Выбраны явные условия для новой записи и замены; конфликт
  или подмена имени/каталога не повреждают исходные данные.
- [x] CHK005 Копирование на другой том, прерывание замены и повторный
  запуск имеют проверяемые условия безопасного завершения и восстановления.
- [x] CHK006 Описаны доступ к временным данным, уборка, границы
  телеметрии, отсутствие новых прав и ограничение файловых операций
  рабочим потоком.
- [x] CHK007 Нативные тесты, реальный WebView2 и установленная приёмка
  разделены; поведение GRAF Dev при подтверждении замены не объявлено
  проверенным по документации, видимой кнопке или стенду.
