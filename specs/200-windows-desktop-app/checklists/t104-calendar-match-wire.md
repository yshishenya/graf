# T104/B1 — допуск контракта календарного решения

- [X] CRW001 Действующие сервер и Mac подтверждают маршрут, ключ, UTC, три решения и условия наличия UUID. Некорректный вход не образует запрос.
- [X] CRW002 Идентификатор и срок ответа ограничены, неоднозначный ответ не даёт результата; ответ должен соответствовать решению. Разбор не становится разрешением начать запись или связать другую запись.
- [X] CRW003 Необязательное поле создания встречи сохраняет прежние байты без попытки. Обычный/защищённый путь и точные позитивные и отрицательные проверки определены. HTTP, повторы и хранение не принимаются в B1.

## Примечания независимой проверки

- **CRW001:** `DesktopUploadClient.calendarContextResolveRequest`, модель
  `DesktopCalendarContextResolveRequest`, тест `CalendarAutoContextMatchTests`
  и серверный `ResolveRecordingCalendarContextRequest` подтверждают маршрут,
  ключ, UTC ISO-8601, версию контракта и наличие UUID события только при
  `user_selected`. Канонические ненулевые UUID — сознательно более строгий
  допуск Windows B1. Quickstart задаёт отрицательные проверки входа.
- **CRW002:** план B1 фиксирует предел 8192 байта до JSON-разбора,
  ненулевой UUID, положительный UTC instant по правилам `calendarInstant`
  (зона обязательна, дробные секунды допустимы), точные состояния для
  каждого решения и отказ при дублях. Список совпадает с действующим
  серверным контрактом; `ambiguous` допустим для `automatic`. Quickstart
  проверяет реальную форму ответа с дробной датой, дату без зоны, дубли,
  неподходящее состояние и границу 8192/8193 байта. Проверка истечения
  относительно текущего времени и привязка к запросу, владельцу и записи
  остаются за границей B1.
- **CRW003:** `DesktopApiClient::createMeetingBody` и обе инстанциации
  (обычная и защищённая строка) дают исходную точку для побайтного теста;
  Mac `createMeetingPayload` и серверный `CreateMeetingRequest`
  подтверждают необязательное поле. План и quickstart требуют сохранять
  старое тело без попытки, добавлять только UUID при наличии и проверять
  неверные UUID. HTTP, повторы и сохранение решения не принимаются.
