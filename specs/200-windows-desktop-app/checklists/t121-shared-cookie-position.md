# T121 / CHK022 — позиция в общем продолжении входа

Область: выдача публичного продолжения и возврат по подписанному cookie.
Основания: [§11.1–11.3](../contracts/windows-native-web-bridge.md),
[план T121](../plan.md), [#7933](https://github.com/yshishenya/graf/issues/7933).
Отметки принадлежат независимому рецензенту.

- [X] CHK001 Новый и ранее выпущенный допустимый cookie приводят к той же вкладке. Позиция без версии убирается, позиция с версией сохраняется, включая 0; соответствие текущей записи по-прежнему проверяет проигрыватель.
- [X] CHK002 Правила доступа, HTTPS, срок, проверка целостности, закрытый cookie и маршрут входа не ослабляются. Не добавляются схема, поля или новая серверная авторизация.
- [X] CHK003 Проверка на отдельных базе и HTTP-приложении покрывает вход и регистрацию, старый cookie и прежние отказы; старый код воспроизводит дефект. Выкладка, установленный пакет, OAuth и привязка к поколению не входят в этот допуск.
