# T123 — независимое ревью требований

**Чеклист требований пройден: 7 из 7 подтверждены, открытых пунктов нет.**
Первичное ревью: 4 из 7. Повторно проверены и подтверждены CHK004, CHK005 и CHK007.
Проверен высокорисковый срез Spec Kit по [AGENTS](../../../AGENTS.md),
[конституции §VI](../../../.specify/memory/constitution.md) и
[порядку Spec Kit](../../../docs/agent-guidance/spec-kit-flow.md).
Отметки относятся к требованиям. Анализ Spec Kit, привязка задачи и
приёмка точного пакета не входят в это ревью.

| Пункт | Результат и основание |
| --- | --- |
| CHK001 | Подтверждён. FR-002, контракт «Выбор папки и имени» и § «Граница разрешения и результат», Quickstart §11: переход, создание папки только по команде, допустимое имя, Save/Cancel и понятные следующие действия при конфликте или ошибке. |
| CHK002 | Подтверждён как требование. Контракт, строки 9–23 и 27–32, план T097/T123, строки 4114–4122: клавиатура, диктор, масштаб и контраст, уничтожение окна, отказ от запуска файлов, отдельные правила для обычного возврата и фонового отзыва. Стенд не заменяет проверку диктором. |
| CHK003 | Подтверждён. Контракт, строки 27–47, и план, строки 4093–4103 и 4145–4153: URL и готовность, исключение для отклонённой навигации, необратимый отзыв, два порядка отзыва и допуска к фиксации, отдельная проверка позднего A после запуска B. |
| CHK004 | Подтверждён при повторной проверке. Контракт, строки 54–76, и план, строки 4124–4136: для нового имени публикация без замещения; для замены каталог и исходник связываются до показа подтверждения. Тот же дескриптор исключает конкурирующее изменение и удаление до переноса; утрата привязки или отсутствие нужной гарантии аннулируют согласие. Quickstart §11, строки 404–411, требует подмены папки и имени и попытки записи при том же File ID. |
| CHK005 | Подтверждён при повторной проверке. Контракт, строки 54–65 и 77–97: копирование и сброс буферов на томе назначения, состав защищённого намерения и его фиксация до переноса, четыре состояния повторного запуска. Восстановление идёт без замещения, а при неопределённости известный резерв сохраняется. Quickstart §11, строки 397–411, задаёт два локальных тома, три точки прерывания процесса, перезапуск Windows и независимую сверку байтов и свойств. Возможность надёжно фиксировать намерение и переходы предстоит доказать для каждого поддерживаемого места; иначе замену не начинать. |
| CHK006 | Подтверждён. Контракт, строки 3–5, 39–41, 51–53 и 93–97, и план, строки 4124–4143: временная папка одного запроса с ограниченным доступом, уборка только своего, приватность путей и содержимого, файловая работа вне UI-потока, без новых веб-команд и полномочий. Границы хранения данных для восстановления определены в CHK005. |
| CHK007 | Подтверждён при повторной проверке. Quickstart §11, строки 388–418, различает лист Mac и панель Windows, конечный файл и приватные временные данные при отзыве. План, строки 4139–4157, контракт, строки 99–102, и T123/T097 оставляют отдельные нативные проверки, реальный WebView2 и установленную приёмку. Фактический исход замены в GRAF Dev записывается отдельно; research не выдаёт показ подтверждения AppKit за результат WKDownload. |
