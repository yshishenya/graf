# T121 — разбор позиции во входящей ссылке Windows

Чеклист относится только к `WebViewRoutePolicy::sharedMeetingRoute` и
проверкам этого метода. Основания: [§11.1 контракта](../contracts/windows-native-web-bridge.md),
[план T121](../plan.md), [приёмка T121](../quickstart.md), [#7933](https://github.com/yshishenya/graf/issues/7933).
Отметки принадлежат независимому рецензенту.

- [X] CHK001 Для обеих форм ссылки явно задано, когда оставить вкладку без позиции и когда передать позицию на дальнейшую сверку версии. Покрыта позиция 0.
- [X] CHK002 Ошибочный формат, дубликаты и превышение границ по-прежнему отклоняются. Маршрут остаётся одним из двух фиксированных; разбор не выдаёт полномочий.
- [X] CHK003 Проверка среза воспроизводит дефект и подтверждает обе формы ссылки после изменения. Допуск не распространяется на готовые HTTPS-адреса, вход, восстановление, выдачу нативного моста, Mac или установленный пакет.
