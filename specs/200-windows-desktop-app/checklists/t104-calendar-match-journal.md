# T104/B2a — допуск локального хранения календарного выбора

- [X] CRJ001 План связывает решение с проверенными сервером, пользователем,
  рабочим пространством и каноническим UUID записи; формат различает три
  решения и не содержит названий, ссылок, токенов или звука.
- [X] CRJ002 Определены граница частного локального каталога, версия и размер
  записи, защита DPAPI пользователя, правила публикации без перезаписи и
  различие отсутствия, конфликта, повреждения и недоступности. Старый формат
  очереди и пакета записи сохраняются.
- [X] CRJ003 Проверки доказывают чтение после открытия новым процессом,
  идемпотентное повторение, отказ при чужом контексте, повреждении или
  подмене пути и сохранение первого выбора при конфликте. Пределы этого
  среза оставляют допуск записи, загрузку, очистку и откат открытыми.

## Независимая проверка требований

- **CRJ001:** `plan.md`, §T104/B2a, задаёт точную привязку к origin, actor,
  workspace и ненулевому каноническому UUID записи. Полезная нагрузка
  ограничена кодом решения и UUID события только при явном выборе;
  три решения и канонический UUID события определены в §T104/B1.
- **CRJ002:** §T104/B2/B2a согласован с родителем
  `AppMain.cpp::localCustodyRoot()`: частный соседний каталог `calendar-match`,
  версия 1, предел 4 КиБ, отдельная область пользовательского DPAPI.
  Отсутствие определяется только открытием фиксированного имени относительно
  проверенного удерживаемого родителя; ошибка самого корня не означает
  пустой журнал. Нарушение формата, общая ошибка аутентификации DPAPI,
  конфликт и ошибка ввода-вывода не превращаются в отсутствие. Публикация
  без замены считается подтверждённой после сброса каталога. При сбое файл
  остаётся, повтор с тем же значением и чтение подтверждают сброс заново.
  `quickstart.md` задаёт проверки первого чтения и отказа сброса, включая
  восстановление без изменения конверта. Прежние форматы очереди и пакета
  вне среза. Отметка подтверждает требования; долговечность первой записи
  в новом подкаталоге и обработку ошибок ещё предстоит проверить по коду
  и на Windows.
- **CRJ003:** §T104/B2a определяет сценарии для нового процесса, повтора,
  конфликта, подмены каждого компонента контекста, обрезанного конверта и
  ссылок Windows; также требует сохранить первый выбор при отказе. Отметка
  подтверждает перечень проверок, а не факт их выполнения. Начало записи,
  отправка, очистка и откат остаются за границей среза.
