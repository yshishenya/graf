главного окна. Основание — spec T125, plan T125, data-model T125,
quickstart T125, открытая T125 и Constitution II. Независимая проверка
требований: [7/7](t125-main-window-placement.md).

| FR-015 / Constitution II | Расчёт ограничен рабочей областью, исходный путь индикатора и Stop сохраняется; активная запись и выход проверяются отдельно по T108. |
| SC-009 | Окно и управление доступны с клавиатуры, при масштабе 200% и на уменьшенной рабочей области. |

**CRITICAL 0 · HIGH 0 · MEDIUM 0 · LOW 2.** Требования согласованы; открытая
T125 означает известный разрыв реализации, а не разрыв спецификации.
LOW: отрицательное начало рабочей области отдельно фиксируется при
установленной приёмке; повреждённое значение и отказ хранилища разделены
в Quickstart. Обязательных вопросов к пользователю для T125 нет.
Решение касается только главного окна, не сохраняет приватных данных,
не меняет захват и не ослабляет выпускные условия.

Далее: синхронизация T125 с GitHub, реализация и нативная проверка, затем
приёмка на точном установленном MSIX. Данный анализ не принимает приложение.
