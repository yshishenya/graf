# T121 — позиция в адресах восстановления Windows

Построение адресов из допустимого GET-адреса просмотра и выбор адреса
программного перехода и повтора в Windows.
Основания: [§11.1–11.3](../contracts/windows-native-web-bridge.md),
[план](../plan.md), [приёмка](../quickstart.md),
[#7933](https://github.com/yshishenya/graf/issues/7933).
Отметки принадлежат независимому рецензенту.

- [X] CHK001 Для обоих видов просмотра программный переход, ранний повтор до `NavigationStarting` и вход сохраняют вкладку без позиции при отсутствии версии. С версией сохраняется допустимая позиция, включая 0.
- [X] CHK002 Сохраняются действующие ограничения на доверенный адрес, метод, ключи и их декодирование; позиция не выдаёт полномочий. Публичное продолжение и адресный вход сохраняют свои маршруты.
- [X] CHK003 Проверки воспроизводят дефект на старом коде, покрывают два выхода входа и фактический вызов `reload()` после раннего сбоя. Отдельными остаются переходы, начатые самим WebView, ответы сервера, фактический вход и запуск установленного пакета.
