# Чеклист требований T125: размещение главного окна Windows

**Цель:** проверить полноту и согласованность требований до реализации.
**Дата:** 2026-11-10.
**Фича:** [спецификация F200](../spec.md#session-2026-11-10--t125-расположение-главного-окна-windows).
**Владелец отметок:** независимый проверяющий. `[x]` означает достаточное качество требований, а не приёмку приложения.

## Паритет и восстановление

- [x] CHK001 Указаны точная сборка Mac, обычное состояние окна и измеримый допуск при перезапуске в прежней конфигурации? [Clarity, Spec T125, Quickstart T125 §2]
- [x] CHK002 Различены неизменная рабочая область, смена масштаба, изменение рабочей области и исчезновение сохранённого монитора, с ожидаемым видимым результатом каждого? [Coverage, Spec T125, Quickstart T125 §2–4]
- [x] CHK003 Определено, какое размещение сохраняется при сворачивании, разворачивании, скрытии в трей и штатном завершении, и отделено открытие того же окна от нового процесса? [Consistency, Spec T125, T108, Quickstart T125 §5]
- [x] CHK004 Определено начальное размещение при отсутствии значения, повреждении и ошибке чтения, а также поведение при ошибке записи и без WebView2? [Recovery, Spec T125, Quickstart T125 §1/6]

## Границы и доказательства

- [x] CHK005 Ограничены владелец и содержимое локального значения; исключены запись, настройки устройств, облачная синхронизация, общий кабинет и дочерние окна? [Scope, Spec T125, FR-002/015]
- [x] CHK006 Определена доступность заголовка и нативного управления, включая 200% масштаба; сохранены видимый индикатор и Stop и отдельная приёмка T108? [Accessibility, Constitution II, FR-015, SC-009, Quickstart T125 §3–5]
- [x] CHK007 Отделены переносимые проверки расчёта, тесты Windows и приёмка точного установленного MSIX, включая отсутствие второго монитора на стенде? [Measurability, Quickstart T125, T097]

## Независимое ревью требований — 2026-11-10

**Результат: 7 checked / 0 unchecked.** CRITICAL 0 · HIGH 0 · MEDIUM 0 · LOW 2.
Чеклист достаточен для реализации среза после остальных обязательных
проверок Spec Kit (analyze и связь задачи с GitHub). Риск среза
остаётся `high-risk-product`; T125 остаётся открытой.

- **CHK001.** [Spec T125](../spec.md#session-2026-11-10--t125-расположение-главного-окна-windows),
  [матрица паритета](../parity-matrix.md#сверка-установленного-graf-dev-и-общего-кабинета-2026-11-10)
  и [Quickstart T125, шаг 2](../quickstart.md#t125-восстановление-главного-окна-между-запусками):
  эталон GRAF Dev `73fdf67f9bec371468093a6bc55410b06c1f4eab`, F293 FR-008.
  Для полностью помещавшегося обычного окна при неизменных экране, рабочей
  области и DPI допуск — один физический пиксель по каждой из четырёх границ.
- **CHK002.** [Spec T125](../spec.md#session-2026-11-10--t125-расположение-главного-окна-windows),
  [Plan T125](../plan.md#t125-восстановление-размещения-главного-окна),
  [Research T125](../research.md#t125-выбор-нативных-средств-размещения)
  и Quickstart, шаги 2–4: при прежних условиях прямоугольник тот же; при
  смене DPI сохраняется логический размер, при смене рабочей области
  прямоугольник ограничивается её границами; при исчезновении монитора
  окно центрируется на основном. Per-Monitor V2, DPI выбранного экрана и
  экранные координаты `rcWork` для штатного [`AppWindow.MoveAndResize`](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.windowing.appwindow.moveandresize)
  учитывают отрицательное начало. Локальные координаты `DisplayArea.WorkArea`
  напрямую не передаются.
- **CHK003.** Plan T125, [задача T125](../tasks.md#phase-26-convergence)
  и Quickstart, шаг 5: `AppWindow.Changed` принимает геометрию только видимого
  обычного окна. Сворачивание, разворачивание и скрытие её не заменяют;
  скрытие и Quit могут сохранить уже принятую геометрию. Загрузка из
  хранилища происходит один раз в новом процессе; возврат из трея открывает
  то же окно и не доказывает восстановление после выхода.
- **CHK004.** Spec и Plan T125, Quickstart, шаги 1 и 6: отсутствие, порча или
  ошибка чтения ведут к начальному обычному размещению 1080×620 логических
  точек с ограничением рабочей областью. Ошибка записи не мешает запуску
  и управлению записью. Размещение работает независимо от WebView2.
- **CHK005.** [Data Model T125](../data-model.md#t125-размещение-главного-окна),
  Plan и Research T125: `AppMain` хранит в `LocalSettings` одно составное
  значение `main-window-placement.v1` для профиля Windows и семейства пакета:
  идентичность дисплея, знаковые отступы, размер и DPI. Невалидное значение
  отклоняется целиком; облачная синхронизация, записи, настройки устройств,
  общий кабинет и дочерние окна вне среза.
- **CHK006.** [Constitution II](../../../.specify/memory/constitution.md#ii-visible-capture-and-user-control),
  [Product Gates](../../../docs/agent-guidance/product-gates.md#capture-and-platform),
  [FR-015](../spec.md#functional-requirements), [SC-009](../spec.md#success-criteria)
  и Quickstart, шаги 3–5: заголовок и нативное управление доступны с
  клавиатуры при 200%. Во время захвата видимый индикатор и Stop в одно
  действие обязательны при отказе WebView, сворачивании и смене фокуса.
  [Quickstart §7 / T108](../quickstart.md#7-automatic-recording-and-accessibility-gate)
  отдельно требует проверить тот же сеанс, Stop и Quit, включая случай
  недоступного управления через трей.
- **CHK007.** Plan и Quickstart T125 разделяют переносимые расчёты, тесты
  событий окна и хранилища в Windows и ручную приёмку точного установленного
  MSIX. [Quickstart §8](../quickstart.md#8-msix-package-smoke) связывает пакет,
  установленный EXE и запущенное окно. Одноэкранный прогон оставляет шаги 3–4
  открытыми; сравнение с GRAF Dev и общая визуальная приёмка T097 отдельно.

**Неблокирующие замечания к будущим проверкам:**

- **LOW · CHK002/007.** Отрицательные координаты обязательны в переносимом
  расчёте, а расположение второго монитора слева или сверху в установленном
  сценарии указано «по возможности». Зафиксировать фактический знак начала
  рабочей области; при отсутствии такой конфигурации не считать нативный
  случай с отрицательными координатами проверенным.
- **LOW · CHK004.** Quickstart отдельно воспроизводит повреждённое значение,
  но не отказ чтения или записи. При проверке хранилища в Windows
  воспроизвести эти отказы отдельно и проверить доступность управления.

Это проверка требований. Установленный MSIX, GRAF Dev и доступность Stop
в работающем приложении здесь не проверялись; T108 и T097 не закрываются.
