# F200/T097/T123 — внутренний кандидат 0.1.0.35 x64

Проверка существующей задачи Spec Kit высокого риска. База
`3dfeaff5a6774ab12be781547e4a300f9ce2a46c` и незакоммиченный
срез 231 файла Windows. В сравнении с 0.1.0.34 изменились только
`ExportSavePanel.cpp` и `NativeExportSaveCommitTests.cpp`:
исправлены подмена длинного адреса и запоздалый ответ Проводника;
нативный файловый тест теперь учитывает длинные пути при проверке
прав и восстановления. Оба файла совпали с
[проверенными исходниками T123](validation-2026-11-06-t097-export-focus.md#2026-11-08--ввод-длинного-адреса-и-запоздалый-переход).
Версия 0.1.0.35 подставлена только в манифест сборочной копии.
Серверный кабинет не входит в MSIX и не выкладывался. Эталон
установленного GRAF Dev на Mac: `bd088c8fdea6007a12df3eee13da62b20e3c5828`.

## Сборка и подпись

Windows 11 ARM64 в Parallels, MSBuild Release x64. Свежая сборка
AEC3 и её 10 проверок прошли. Прошли 17 проверок упаковки, включая
имитацию ответов ОС, и 48/48 переносимых тестов на Mac.
Windows подтвердила действительность тестовой подписи `CN=GRAF`.
Независимая проверка сверила все 26 файлов внутри MSIX, PE x64,
неизменный манифест пакета за исключением версии и
`PerMonitorV2` внутри EXE. Журнал компилятора подтверждает
свежую компиляцию `ExportSavePanel.cpp`. Проверка точного
пакета на рабочем пользователе ожидаемо отклонила зачёт запуска
0.1.0.18 как запуска 0.1.0.35. Тестовые сборочные деревья удалены.

## Обновление и откат в отдельном профиле

Обычный временный пользователь на подготовленной Windows:
0.1.0.18 → точный 0.1.0.35 → диагностика установленного AEC3
(код 73) → откат к 0.1.0.18. Проверены хеши установленных EXE.
Контрольный файл в `LocalState` сохранился при обновлении и откате.
Тестовые пользователь, профиль, регистрации и копии входов удалены.
У рабочего 0.1.0.18 не изменились EXE, PID и время запуска; доверие
к сертификатам не менялось. Квитанция:
`bd7ed30a07c15f4928b284b4724fde1dfae59fd609ab5e16c3e22bb61b4427be`.

Обычное окно 0.1.0.35 не открывалось. Диагностика не читала
микрофон, не проверяла защищённую очередь или экспорт из кабинета.

## Чистый стенд и следующий сценарий

На `GRAF F200 Offline QA 117` Windows Setup ожидает принятия условий.
Вторая машина `GRAF F200 QA ARM` находится на этапе подключения к
сети, сетевого адаптера в текущей конфигурации нет. В обеих машинах
нет обычного пользовательского сеанса. Сеть, доверие и лицензия
не менялись. Обычную активацию второго пользователя в рабочем
сеансе не использовали: перенос активации и пригодность
неинтерактивного профиля не проверены для этой пары версий.

ISO `GRAF-F200-QA-035-WebView2.iso`, метка `GRAF_F200_QA_035`,
SHA-256 `95f13c4ee6004f7a2a3f769db5eb292d3486effb1d50f30bb39fa830f6aff775`.
На Mac и Windows сверено 9/9 файлов носителя. Временный образ
проверки размонтирован и удалён. Изменён только путь к
`cdrom2` машины Offline QA; Parallels указывает, что изменение
вступит в силу после перезапуска. Образ ещё не проверен из этого
гостевого сеанса. В [Quickstart](quickstart.md#8-msix-package-smoke)
обновлены точные версия и метка, пять блоков PowerShell разобраны
Windows без выполнения. Добавлен сценарий T123 для установленного
окна с проверкой адреса, клавиатуры, диктора и хеша результата.
