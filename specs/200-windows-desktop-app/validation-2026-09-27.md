не записана как доказательство неработающей кнопки приложения.

## Исправление

Microsoft различает фатальный отказ браузера/страницы и автоматически
восстанавливаемые GPU/utility-процессы:
[Handling process-related events](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/process-related-events).

Обработчик теперь сохраняет состояние документа при автоматически
восстанавливаемом вспомогательном процессе. При отказе браузера/страницы
инвалидирует поколение и мост, показывает конкретный тип отказа и числовой
exit code; только BrowserProcessExited требует пересоздания контрола.
Диагностика сохраняет только числовые kind/exit, без descriptions, URL,
frame information, cookies и содержимого страниц.

Добавлены проверки сохранения состояния и незавершённой навигации при
вспомогательном сбое, отказа поздних ответов после фатального сбоя,
пересоздания только для браузера и отсутствия оживления закрытого host.
Номер тестового MSIX увеличен до 0.1.0.5 для обновления без удаления профиля.

## Раунд 58 — боковое подменю и низкое окно

Пользователь вручную открыл меню установленного MSIX 0.1.0.5 и показал
раскрытие «Вид» вниз. Частный снимок не добавлен в репозиторий.
Проверка адресов в исходниках подтвердила общий маршрут Mac/Windows
`/desktop/meetings` и общие cabinet.css/cabinet.js, а не отдельный Windows UI.
Публичный CSS рабочего сервера ещё содержит условие высоты `max-height: 620px`,
которое отсутствует в ветке. SHA-256 прочитанного публичного CSS:
`95b4cc5c4bc3e2c5dd8708f44d324112bcedb19bf7969a213f0eded5eb824120`.
Пересборка MSIX не доставляет серверное оформление. Размер и версия ресурсов
конкретного открытого Mac-окна не измерены; причина различия этих двух окон
не выдаётся за независимо доказанный факт.

На синтетическом стенде с настоящими шаблонами CUA подтвердил боковое меню
при 1080×620 и 744×530, но обнаружил дополнительный дефект 744×400:
нижние пункты выходили за фон из-за сочетания max-height и overflow:visible.
Основное меню теперь прокручивается, вложенные панели используют уже применяемый
HTML Popover API и не обрезаются прокручиваемым родителем. Они помещаются
по высоте, открываются справа или слева по доступному месту. Раскрытие внутри
сохраняется только при недостаточной ширине и в мобильной навигации.
Удалены больше не используемые is-flipped и псевдоэлементы промежутка.
Изменение высоты панели, например при ошибке сохранения темы, пересчитывает
положение. Закрытие основного меню закрывает вложенные панели.

Независимый gate требований: PASS, 112/112; новые требования не понадобились.
Независимое ревью выявило P2: прокрутка встроенного раздела могла его закрыть.
Исправлено: обработчик прокрутки перемещает только отдельные всплывающие панели,
не трогая встроенные разделы и их scrollTop. Регрессии проверяют обе ветви.
Во время проверки WebKit исправлен порядок измерения: координаты заголовка
снимаются после перевода панели в верхний слой, без временного изменения
высоты основного меню. Базовый position:absolute сохраняет расположение
