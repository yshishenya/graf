# T108: удаление неиспользуемого пути выхода из политики крестика

Существующая полоса `high-risk-product`, F200/T108, [#7342](https://github.com/yshishenya/graf/issues/7342).
Требования и контрольный список не менялись. Единственный вызов в приложении —
обработчик `AppWindow.Closing`. Явный выход продолжает использовать
`requestExit()` → `beginExit()` и ожидание завершения текущей работы.
Из политики и тестов удалён вариант явного выхода, которого приложение
не вызывало.

- Сравнение прежней ветки `window` с новой политикой при компиляции:
  **112/112** сочетаний состояний сеанса, наличия трея, наличия индикатора
  и уже начатого выхода дали одинаковое решение. Временная проверка удалена.
- `RecordingIndicatorTests`, свежая переносимая Debug-сборка:
  **1/1** (включая повторное скрытие, сохранение того же сеанса, ожидание
  на stopping/finalizing и возможность закрыть после сохранения).
- Проверка замороженной версии Spec Kit, правила GRAF и `git diff --check`
  прошли.

Рабочий GRAF 0.1.0.18 отвечает; приложение не перезапускалось и не обновлялось.
Эта правка сделана после сборки 0.1.0.37. Нативный запуск и проверка крестика,
возврата из трея и выхода во время сохранения на точном установленном пакете
ещё нужны. T108 и задача GitHub остаются открытыми.

### T097: подготовка интерактивной QA ARM

Продолжение в отдельной `GRAF F200 QA ARM`, UUID
`93aac645-2aad-4bd5-bd5a-f20254fe8065`. Рабочая `Windows 11`

Отказ `prlctl exec` согласуется с включённым `IsolatedVm=1`;
установка Tools сама по себе эту границу не снимает.

набора Parallels установлен ARM64 MSI Tools 27.0.0-58625,
SHA-256 `c7c4ccacc1d40f92abf474e617c6d79184883ba1f91e0712005cfbf51b3cf1cc`.

его SID и отсутствие членства в Administrators; смена имени QA требует
повторной проверки после загрузки. Секреты профиля в отчёт не включены.

Подключён объединённый автономный носитель
`GRAF-F200-QA-038-OFFLINE.iso`, SHA-256
`6a4a32f335c533eb9c355015bb6f6897b05e36519758f6d829c45205a1944e2a`.
Его девять файлов извлечены и сверены; MSIX и открытый сертификат

После перезапуска показана первоначальная настройка Windows с выбором

взял завершение настройки QA на себя; лицензионные условия агент
не принимал. GRAF и его сертификат в этой QA не устанавливались,
доверие сертификатам не менялось. Следующий шаг — обычный рабочий
стол, проверка области QA и только затем отдельное согласование
доверия точному development-сертификату по Quickstart.
Подготовка VM не закрывает T097/T108 и не является приёмкой чистой
установки или физического Windows x64.
