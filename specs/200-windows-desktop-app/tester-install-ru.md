# Тестовая сборка Windows для пользователей — 2026-11-22

Документ описывает, как получить сборку Windows без отдельного Windows-компьютера
у команды и как передать её тестировщикам. Публичный выпуск требует сертификата
подписи от удостоверяющего центра и здесь не выполняется.

## Что это

Ручная полоса `.github/workflows/windows-tester-build.yml` собирает установщик
на hosted Windows x64, подписывает его **самоподписанным** сертификатом
`CN=GRAF` и выкладывает комплект:

- `GRAF-Windows.msix` — приложение;
- `GRAF-Windows.cer` — сертификат, которому нужно доверять перед установкой;
- `GRAF-Windows.msix.sha256` — контрольная сумма;
- `build-info.txt` — версия, SHA-256, исходный коммит, `public_release_ready=false`;
- `GRAF-Windows.appinstaller` — только если при запуске указан `feed_base_url`;
- системные зависимости, которые объявляет сам пакет: `Microsoft.VCLibs` из
  Windows SDK и `Microsoft.WindowsAppRuntime` из NuGet, если они нашлись при
  сборке. В `build-info.txt` строка `framework_dependencies` перечисляет каждую
  зависимость как `имя=included|missing`.

Перед выкладкой полоса сама проверяет пакет: манифест, точку входа, подпись,
архитектуру x64 и обязательные файлы запуска (`GrafWindowsApp.exe`, среда C++,
`WebView2Loader.dll`, библиотеки FFmpeg). Если чего-то нет, сборка падает и
артефакт не публикуется. Список файлов пакета и объявленные зависимости
попадают в summary прогона.

## Как запустить

1. Actions → `windows-tester-build` → Run workflow.
2. `version` — четыре числа, например `2026.11.22.1`.
3. `feed_base_url` — необязательно: папка по HTTPS, если нужны автообновления
   через `.appinstaller`.
4. Забрать артефакт `graf-windows-tester-<version>`.

Полоса не является выпускной: она не проверяет установку на физическом
устройстве, не использует сертификат удостоверяющего центра и не публикует
пакет.

## Что делает тестировщик

1. Скачать `GRAF-Windows.cer` и `GRAF-Windows.msix` из артефакта, сохранить в
   одну папку.
2. Проверить SHA-256 файла `GRAF-Windows.msix` и сравнить с
   `GRAF-Windows.msix.sha256`.
3. Установить сертификат: двойной щелчок по `GRAF-Windows.cer` →
   «Установить сертификат» → «Локальный компьютер» → «Поместить все сертификаты
   в следующее хранилище» → «Доверенные лица».
   Сертификат не ставится в корневые доверенные: он подтверждает только этот
   тестовый издатель.
4. Если в комплекте есть файлы `Microsoft.VCLibs...appx` или
   `Microsoft.WindowsAppRuntime...msix`, установить их первыми, затем открыть
   `GRAF-Windows.msix` → «Установить». Если в `build-info.txt` для зависимости
   стоит `missing`, сообщите об этом: пакет может не установиться на чистой
   машине.
5. Запустить GRAF, войти в аккаунт, разрешить микрофон и проверить запись.

Если при установке Windows пишет, что издатель не доверенный, — сертификат не
установлен или установлен в другое хранилище. Повторить шаг 3.

## Что сообщать

- Версию из `build-info.txt` и SHA-256 пакета.
- Версию Windows и разрядность.
- Что именно делали и что произошло: запись, пауза, остановка, вход, кабинет,
  уведомления, обновление.
- Текст ошибки или скриншот без личных данных: не присылать записи встреч,
  транскрипции, cookies, токены и адреса с параметрами.

## Чего этот канал не даёт

- Доверие без установки сертификата: у обычного пользователя будет
  предупреждение издателя.
- Публикацию и автообновление без HTTPS-папки.
- Замену финальной приёмки: подпись удостоверяющего центра, чистая установка,
  физическая аппаратная матрица и выпускные проверки остаются отдельными
  воротами F200 (T124, T063, T071).
