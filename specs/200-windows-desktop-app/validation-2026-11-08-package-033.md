# F200/T097 — внутренний MSIX 0.1.0.33 x64

Срез F200 высокого риска, база `3dfeaff5a6774ab12be781547e4a300f9ce2a46c`
и зафиксированные изменения рабочей копии. Сверены все 231 файла Windows.
Единственное отличие исходников от 0.1.0.32 — системная роль цвета текста
акцентной кнопки в [AppMain.cpp](validation-2026-11-08-t097-native-contrast.md).
Версия изменена только в копии манифеста сборки.

На Windows 11 ARM64 / Parallels заново собран AEC3 Release x64: 10/10.
Сборка приложения и подпись MSIX завершились с кодом 0. Проверки
средства упаковки — 17/17, включая имитации ответов ОС. Отдельная
проверка Windows подтвердила подпись разработки `CN=GRAF`, целостность
пакета и корректно отклонила его как не установленный. Побайтно сверены
26/26 файлов MSIX, архитектура PE x64 и встроенный `PerMonitorV2`.
Манифест MSIX совпал с 0.1.0.32 за исключением номера версии. Объект
`AppMain.obj` получен свежей сборкой; тестовых подмен во входах
компилятора и тестовых файлов в MSIX не обнаружено.

Рабочий GRAF 0.1.0.18 сохранил EXE и процесс. После запуска из «Пуска»
его окно отвечало; Win32 сообщил 1080×620 при масштабе монитора 100%,
а режим окна — без учёта DPI. Эти измерения относятся только к 0.1.0.18.
Временные деревья сборки и проверочные копии удалены. Сертификаты,
пользовательские данные и настройки рабочей машины не менялись.

и сценарии проверки. Mac и Windows сверили все девять файлов; Windows
проверила разбор PowerShell, затем временный ISO отключён и удалён.
Изменён только путь к ISO в сохранённой конфигурации `cdrom2` отдельной
машины `GRAF F200 Offline QA 117`. Parallels применит путь после
штатного выключения и включения. Установка чистой Windows остаётся
на шаге лицензионных условий; машину не перезапускали.

На этапе сборки 0.1.0.33 не устанавливали. Обычный запуск из «Пуска» и
запись на нём ещё не выполнялись. Для T097 остаются живые проверки из
[Quickstart](quickstart.md):
боковые подменю, две контрастные темы, масштаб 200%, Narrator,
фокус и остановка записи с клавиатуры. Проверка артефакта не подтверждает
аппаратную запись или готовность публичного выпуска.

## Установка, обновление и откат в отдельном профиле

В Windows 11 / Parallels создан временный обычный профиль без GRAF.
Пройдены четыре фазы: 0.1.0.18 → точный MSIX 0.1.0.33 → самопроверка
AEC3 из установленного EXE → откат на 0.1.0.18. На каждой фазе
проверены регистрация и SHA-256 EXE. Самопроверка вернула ожидаемый
код 73. Контрольный искусственный файл в `LocalState` побайтно
сохранился при обновлении и откате. Реальная запись не запускалась.

Тестовый профиль, учётная запись, регистрация и временные файлы в
Windows удалены. Независимая проверка после выхода увидела ноль
тестовых учётных записей и одно отвечающее окно рабочего GRAF 0.1.0.18.
Его EXE, PID и время запуска совпали до и после. Использовано
существующее доверие к сертификату, хранилище сертификатов не меняли.

Это проверка перехода версий и самопроверки звука в подготовленной
Windows. Обычный запуск окна, чистый образ ОС, ремонт WebView2 и
сохранность настоящей очереди этим результатом не подтверждены.
Отдельная виртуальная машина всё ещё показывает условия Windows Setup.

## Нативные тесты Windows и сверка базы

Из свежей копии 231 файла до подстановки номера версии MSIX собраны
девять целей CMake/Ninja Release x64 на Windows 11 ARM64 / Parallels.
В CTest прошли 9/9: системные цвета, обновления, маршруты, жизненный
цикл WebView2, календарный переход, мост настроек, общий кабинет,
индикатор записи и нативное сохранение экспорта. В экспорте проверены
отзыв, конфликт, прерывание процесса, восстановление и повтор выбора
папки. Тестовые EXE не входят в MSIX; обычный запуск из «Пуска» и
фактическое взаимодействие с установленным окном эти проверки не заменяют.

Первый прогон дал 8/9: в тесте экспорта проверка прав по имени файла
`published-acl-read` завершилась ошибкой на вложенном временном пути
длиной более 260 символов. С тем же EXE повтор на длинном пути дал
тот же отказ, а на коротком прошли и отдельный тест, и полный набор
9/9. Код не менялся. Тестовый отказ сам по себе не устанавливает
поведение установленного GRAF при сохранении по длинному пути.
Временные исходники и сборка удалены; сохранены журналы обоих прогонов.

## Проверка окна для установки и отката

Из проверенного ISO извлечены оба MSIX, `Get-GrafQaState-033.ps1`
и `validate-package-smoke.ps1`. Хеши совпали с квитанцией носителя.
Вложенный валидатор побайтно совпал с файлом из рабочей копии
F200. В режиме `-RequireWindow` помощник на ISO проверяет хеш
валидатора, передаёт точный SHA-256 пакета для выбранной фазы и
требует наблюдаемое окно. Отдельный вызов валидатора для той же
фазы исключён из [инструкции](quickstart.md#8-msix-package-smoke).

На рабочей Windows без установки и без ввода в приложение
тот же валидатор подтвердил отвечающее окно GRAF 0.1.0.18 из
точного пакета. Проверены версия, пакетная идентичность процесса,
пользователь текущего интерактивного сеанса и хеш установленного
EXE. 0.1.0.33 прошёл статическую проверку подписи, а попытка
выдать работающую 0.1.0.18 за окно 0.1.0.33 отклонена на проверке
регистрации. Процесс, время запуска и HWND 0.1.0.18 остались прежними.
Временные копии входов в гостевой Windows удалены.
