## Результат

На Windows 11 ARM64 в Parallels, .NET x64, WebView2
156.0.4314.58, из начального фокуса на кнопке профиля во всех четырёх
прогонах прошли Enter → Tab к аккаунту → Tab к «Вид» → Enter →
Tab к выбранной теме → Escape. Escape закрыл меню и вернул фокус
на кнопку профиля. Прогоны: исходный CSS и вариант с пустыми
альтернативами у двух декоративных символов; обычный масштаб и
200% масштаба страницы с эмуляцией forced colors. Системный DPI и
системная тема Windows не менялись.

При открытом подменю в каждом прогоне проверены дерево движка и
дерево Windows UI Automation: три варианта темы, единственный
выбранный вариант «Системная», состояние кнопки профиля и раскрытия
«Вид». У исходной страницы доступные имена были `Вид ›` и
`Системная ✓`; в сравнительной — `Вид` и `Системная`. Раскладка
строки, выбранной темы и подменю совпала по всем измеренным
координатам, оба символа остались в вычисленном CSS. Из 16 измерений
UI Automation одно, на первом закрытом меню до первого ввода, не
вернуло кнопку. Остальные 15, в том числе все четыре измерения
открытого подменю и возврата после Escape, совпали с ожиданием.
Дерево движка подтвердило все 16 состояний. Ввод подан в отдельное
окно WebView2, через браузерный интерфейс автоматизации.

WebKit 26.6 в Playwright подтвердил те же доступные имена и отметку
выбранного варианта при ширинах 1080 и 540 px. Снимки двух
затронутых элементов совпали побайтно между вариантами на каждой
ширине. В обоих вариантах обычный Tab после «Вид» переходил на
следующий пункт раскрытия, а Option+Tab — к выбранной теме;
Escape возвращал фокус на профиль. Это наблюдение отдельного
WebKit, с его настройками навигации, а не результат на GRAF Dev.

Предложенный вариант добавляет пустой альтернативный текст
(`content: "›" / ""`, `content: "✓" / ""`); состояния раскрытия
и выбора уже передаются отдельными свойствами. Такой способ
предусмотрен [CSS Generated Content §1.2](https://www.w3.org/TR/css-content-3/#alt)
и [WebKit](https://webkit.org/blog/15063/webkit-features-in-safari-17-4/#alt-text-for-generated-content).
Подготовленный двухстрочный патч оставляет прежние объявления
как запасные для движков без поддержки синтаксиса. `git apply --check`
прошёл; код общего кабинета в этой проверке не изменялся.
