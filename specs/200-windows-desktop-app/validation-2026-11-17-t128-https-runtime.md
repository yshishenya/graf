## Что именно проверяли

Цель одного разрешённого цикла — три read-only запроса настоящего Windows
HTTP-транспорта к локальному HTTPS-серверу: принятие свежего подтверждения
сервера и безопасный отказ при неподходящих заголовках кэширования.
Согласие пользователя: `call_4a88826dcabd42fab9c4ec972bc51ad9`, один тест
с последующим удалением временного сертификата.

Проверялся ранее собранный диагностический `DesktopUploadRecoveryTests.exe`
из R4, SHA-256
`f85fb79cc8d98c0a2a581ceee332e1864a6dd4078e5c73c100c0a78ad71aaeec`.
Это не сборка всего текущего дерева с несохранёнными в Git изменениями и не
приёмка установленного приложения.

Окончательные входы и состав процедуры прошли независимое рассмотрение:

`22e198cbe47aa79381040b278217b448665fdcf7d19f1b44d743ffe78b2b4946`,
ready-seal SHA-256
`a9b94f1c7cea2b571cbfdaa41f75d4297dc95c8736e1f6fede2c5f84bd813674`.
Разрешение на исполнение дал Main после этих проверок.

Отдельная проверка PowerShell в Windows воспроизвела механизм совместного
доступа без TLS и дочерних процессов: при открытом writer старый ReadAllText

прочитал точный ожидаемый текст. Все handles закрыты, собственный временный
файл удалён. Материалы:
`.dev/t128-live-proof-runtime-r1-20261117/main-log-sharing-isolated-regression-r1.stdout`.
Это подтверждает исправляемый способ чтения; точную строку первоначального
исключения утраченное внутреннее исключение восстановить не позволяет.

## Очистка

Удалён только собственный сертификат localhost с SHA-1
`655D687ACE75BBDAF342CC546F69340CCC7658D4`.
Перед подтверждением системного запроса проверены действие DELETE, имя,
срок и полный отпечаток. Транспорт завершился раньше системного запроса;
исходный UNKNOWN сохранён. Повторное удаление не выполнялось: прочитан
фактический успешный результат Windows и отдельно сверено исходное состояние.

Последующий FilesRemove прошёл штатно. Независимое read-only чтение в
13:25:15 UTC подтвердило точное исходное содержимое CurrentUser Root (24),
TrustedPublisher (0) и My (0), отсутствие собственных cert.pem, key.pem и
временной квитанции в Windows. Собственный закрытый временный каталог на Mac
также отсутствует. Диагностические журналы и результаты сохранены.
