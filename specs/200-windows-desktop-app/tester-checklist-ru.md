## 6. Обновление

Установка обновлений в этой сборке не разрешена: канал установки ещё не
утверждён, поэтому кнопка «Установить обновление» скрыта. Проверяется только
поиск обновлений.

При обычной установке из `GRAF-Windows.msix` источник обновлений не настроен:
приложение должно сообщить об этом понятным текстом, а не показывать ошибку.
Поиск новой версии проверяется отдельно, только если выдана привязка к
`.appinstaller`.

| Шаг | Ожидаемо | Результат |
| --- | --- | --- |
| «Проверить обновления» после установки из MSIX | сообщение «Для этой установки не настроен источник обновлений» | OK / FAIL |
| «Проверить обновления» при настроенном `.appinstaller` | обновлений нет или найдена версия | OK / FAIL / не проверялось |
| Кнопка установки | скрыта; если она видна и работает — сообщите об этом | OK / FAIL |

## 7. Что сообщить

- Что именно делали и что произошло.
- Текст ошибки целиком или скриншот без личных данных.
- Версию и SHA-256 из `build-info.txt`.
- Версию Windows и разрядность.
- Время события, если ошибка плавающая.

## Границы

Этот чек-лист проверяет установку и основные сценарии на вашей машине.
Публичный выпуск, доверие без установки сертификата, чистая установка на
эталонном образе и аппаратная матрица микрофонов остаются отдельными
ворогами F200.
