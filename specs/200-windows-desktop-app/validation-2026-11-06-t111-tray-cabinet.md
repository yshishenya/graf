# T111: меню Windows и возврат из настроек к встречам — 2026-11-06

Активный срез F200 на базе `d1340645da9cb9f401861cc42406b514e8e16fad`.
Mac открывает раздел `account` в главном окне. Windows уже передаёт в то же
пользовательское действие маршрут `/desktop/settings/account` от доверенного
адреса текущего кабинета. Обратная кнопка «Встречи» в оболочке Windows брала
отдельно прописанный адрес. При другом доверенном адресе тестового кабинета
политика WebView2 считала этот адрес внешним и не открывала список внутри окна.

Исправление: `CabinetWindow::openCabinet()` получает адрес из той же политики
и открывает фиксированный путь `/desktop/meetings`. Рабочий адрес по умолчанию
и правила доступа не менялись. Тестовый генератор задаёт только адрес в
конструкторе копии; `CabinetWindow.cpp` больше не переписывается. Генератор
также исключает файлы, которые Git уже видит удалёнными из рабочего дерева:
старый `AppInstaller.xml` вызывал `ENOENT` до сборки стенда. Проверка
обычных файлов сохранена.

- С исходным `openCabinet()` новый переносимый тест упал на переходе к
  встречам с локальным адресом. После исправления проверены точные пути
  по умолчанию и на loopback HTTPS, путь возврата и запрет внутреннего
  перехода на другой адрес. Три выбранных теста прошли на Mac и Windows.
- Стенды настроек и закрытия оболочки сгенерированы из тех же 224 файлов,
  что и Windows-тесты. Удалённый файл не попал в манифесты, маршрут
  `CabinetWindow.cpp` совпал с рабочим деревом, контрольные хеши 11 и 17
  соответственно неизменённых обработчиков записаны.
- В Windows 11 / Parallels (x64 под эмуляцией ARM64) прошли 14 циклов
  настоящего меню Windows. Новые проверки прочитали названия и доступность
  команд, выбрали «Начать запись» и «Настройки» клавиатурой в собственном
  меню теста и проверили по одному вызову при скрытом окне-владельце.
  «Начать запись» повторно проверяется при доставке: если готовность снята
  после выбора, вызовов 0. При завершении обе команды недоступны.
  Обработчики тестовые: звуковые устройства и профиль GRAF не использовались.
- SHA-256 манифеста входов:
  `e489add76fe65d7c3c8174f44c6083093cbe59aff95adbd0fad4f6362b9fbee4`;
  результата Windows:
  `58e6ba8ca14edf7399332a60fcc365afbe7279c1c67310f2fdf968fc93069f1f`.
  Настройка сборки, сборка, тесты: 0/0/0; временная папка VM удалена.

Эти прогоны проверяют маршрут и доставку команд отдельно. T111/T097 остаются
открытыми: на точном установленном MSIX из скрытого главного окна нужно
открыть настройки через значок, вернуться к встречам и проверить фактическую
запись и её единственность в условиях приёмки. Установленная 0.1.0.18 в
этом прогоне не обновлялась.
