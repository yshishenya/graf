# F200 / T103 — проверка входа в настоящем WebView2

Существующая задача [T103 / #7280](https://github.com/yshishenya/graf/issues/7280)
и набор `default23` из [quickstart](quickstart.md#t103-default23-после-all-entries-integration).
Исходная база: `972af4762e7afc1a5a1c8d9025aec1eb6ce7127e`. Из 225 входов
только запускатель теста и новый общий сборщик тестов входа и оплаты
отличаются от базы. Набор проверок и код приложения не изменены.
Независимое ревью подтвердило состав входов, прежние параметры компиляции,
подключение настоящего `WebView2Host::attach` и изоляцию профиля.

Windows 11 ARM64 в Parallels, MSVC x64: **23/23 PASS**. Каждый сценарий
запустил настоящий WebView2 в своём профиле с локальным HTTPS и
искусственной сессией. Проверены, в частности:

- HTML для неверного кода и ограничения попыток (400/429), формы после
  ошибок отправки и отсутствие нативного доступа у страницы входа.
- Возврат к оплате или конкретной встрече после истечения сессии;
  отдельные отказы 5xx кабинета, обрыв транспорта и ошибка TLS.
- Переходы назад, отмена и повторяющийся адрес в истории. В сценариях
  с оплатой число POST проверено по итоговому отчёту локального сервера:
  один исходный запрос, без повторной отправки из истории.

23 браузерных процесса штатно завершились; 23 тестовых сервера вернули
код 0. Временные профили, копия исходников и искусственный ключ TLS
удалены. Сверка до и после: 225 входов, 1662 сгенерированных файла
SDK и три DLL. Это проверка неизменности использованных зависимостей.
Установленный GRAF 0.1.0.18 сохранил хеш EXE
`20a7544617b3008cc6706f94b769d0ad3e66b3e3ec146e30768b3a795bb1f17b`.
Рабочая учётная запись, сервер, данные встреч и системное доверие
к сертификатам в тесте не использовались.
