origin/route/nonce/requestId/document generation/размера. Внешний bridge envelope
остаётся version1; внутренний notification request — version2. Read/test без

sound=false, quiet=false. Миграция отсутствующего quiet сохраняет старые значения

## Один канал и сроки

Одна собственная карточка: meeting/prompt/problem/short/preview с приоритетами
1/4/3/2/0. Prompt защищён; равный приоритет не вытесняет другое событие; preview
только на свободной поверхности, без очереди. Повтор identity сохраняет срок
и фокус. Вытесненное уже показанное событие не всплывает снова. После prompt
пересчитать актуальных кандидатов (приоритет, время, стабильный ID), не старую
неограниченную очередь. Непоказанный short допускается один, самый новый,
до20 секунд от возникновения; все существенные результаты входят в историю.

Meeting due=startsAt−offsetMinutes*60; deadline=min(due+120s,endsAt).
Показ только в этом окне при свежем контексте, reminders и !quiet. Нет −15min
карточки, toast или резервной службы. Запись/пауза/остановка/финализация не
допускают предложения второй записи. Перед Join/Record — актуальные owner/event/
link и текущие capture gates; перенос/отмена/изменение ссылки инвалидируют старые
действия. Dismissal различает контекст/eventID/start и не сбрасывается refresh.
Sleep/lock/context switch отменяют callbacks; wake не возвращает просроченное.
Скрытие главного окна не равно Quit; завершённый процесс ничего не показывает.

Quiet подавляет только необязательные сообщения/звук, не prompt/indicator/Stop
и не решение политики. Звук — один раз при первом реальном optional показе с
sound=true/quiet=false, не tick/refresh и не во время захвата. Автоматическое
следование всем Focus/демонстрациям не обещается. Preview — настоящий компонент
6 секунд без capture/history/server writes. Short/problem — 20 секунд,
hover/keyboard focus удерживает информационную карточку. Meeting hard deadline
не продлевается. Prompt — 8 секунд без удержания; close/focused Escape отменяет
предложение без сохранения правила. Только explicit start/skip+remember меняют
Always/Never. Timeout и close никогда не сохраняют правило. Невидимый prompt
не начинает отсчёт/запись; старый callback и двойное действие ничего не запускают.

## Вид, доступность и экран

Windows DIP повторяют F277: ширина380, radius12, padding12, optional title/detail/
actions без пустых строк; close слева сверху hit28; действия под текстом,
secondary перед primary, checkbox отдельно. Short: только «Запись не сохранена —
короче 30 секунд», 44–52 DIP при стандартном шрифте, без обрезания при увеличении.
Текст≥14, команды≥13; контраст текста≥4.5:1, controls/focus≥3:1.

На узком экране ширина уменьшается до доступной (минимум220), кнопки переносятся;
при нехватке высоты текст прокручивается с клавиатурой/диктором, close/checkbox/
actions достижимы без уменьшения шрифта. Невозможность разместить или избежать
перекрытия Stop даёт явный отказ; prompt отменяется без старта, результат остаётся
в истории/основном интерфейсе. Экран выбирается при первом показе по указателю,
иначе основной; сохраняется до terminal. Изменение рабочей области/отключение
монитора пересчитывает положение без сброса срока. Высокая контрастность,
уменьшение движения и непрозрачный фон при соответствующей настройке сохраняются.

Фоновый показ не активирует GRAF. Явный пункт «Перейти к уведомлению» даёт фокус;
Tab/ShiftTab/Space/Return и Escape внутри карточки работают, глобального Escape
нет. Первый щелчок действует сразу. Tick не пересоздаёт controls и не озвучивает
весь текст повторно. По закрытии явно активированной карточки контекст возвращается
насколько допускает ОС. Stop остаётся видимым и доступным независимо от карточки.

## Состояние, история и удаление старого

Envelope: context generation, identity, kind/content, absolute deadline, terminal.
Pending→visible→acted/dismissed/expired/invalidated; terminal однократен.
Контекст account/workspace/server origin. Meeting identity включает eventID/start;
incident — запись/тип без названия. Старые callbacks не разрешают эффект.

История в существующем меню: ≤50 нейтральных enum-событий с временем в памяти
текущего запуска/контекста. Без названий, ссылок, участников, аудио, расшифровки,
путей и повторного исполнения старых решений. Short/problem входят и в quiet;
preview/tick — нет. Один incident не дублируется; новое возникновение после
разрешения допускается. Context reset очищает историю/карточку. Нерешённая
проблема остаётся у записи независимо от истории.

Отдельно от истории сохраняются хешированные отметки использованного события:
origin/account/workspace + eventID + startsAt, без названия/ссылки. Отметка
проверяемо записывается до показа, действует до startsAt+120 секунд; ошибка
записи запрещает показ. Перезапуск, изменение offset/end, возврат контекста
или перенос встречи обратно не разрешают повторный показ/звук. Новое startsAt
создаёт другую идентичность. Просроченные отметки удаляются при сверке.
Отметки проблем записи сохраняются до подтверждённого разрешения проблемы;
неполный снимок не означает разрешение. Новое возникновение после разрешения
может уведомить снова. Это защита от повторов собственной карточки, не журнал
ОС, не сохраняемая история и не механизм повторного исполнения действий.

Не создаются ScheduledToastAdapter и постоянный журнал системных попыток.
Неподключённые черновики этого проекта хранятся вне product source, не входят
в сборку. Удалить активные старые ранние окна/представления/тесты/мёртвые пути.
Windows не имел выпущенного системного канала: не создавать фиктивную миграцию.
Если обнаружено реальное прежнее собственное OS состояние — допустима только
идемпотентная очистка без нового планирования/обработчиков резервного показа.
