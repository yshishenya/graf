# T123 — сохранение экспорта на Windows

Связь: FR-002/005/006, SC-002/009, [T123 и T097](../tasks.md).
Работает только для уже разрешённого экспорта общего кабинета.
Сервер, права экспорта, macOS и хранилище записей не меняются.

## Выбор папки и имени

- Панель находится внутри окна, открывшего экспорт. Показывает текущую
  папку, позволяет перейти в другую, создать папку по явной команде,
  изменить имя, сохранить или отменить. В списке папка открывается,
  а выбор файла предлагает его имя; экспорт не запускает файлы и не
  предоставляет не относящиеся к сохранению команды оболочки.
- Путь недоступен для сохранения, пока переход к папке не завершён.
  Имя — один допустимый компонент Windows, без путей, имён устройств
  и альтернативных потоков; допустимое имя пользователя не исправляется
  молча. Если имя или место не подходит, панель объясняет, что изменить.
- Поддерживаются Tab/Shift+Tab, Enter, Escape и системный диктор.
  Объявляются папка, имя, ошибка и подтверждение замены; порядок фокуса
  предсказуем. Проверяются поддерживаемые масштабы, узкое окно и
  системная контрастность. При Save/Cancel фокус возвращается только
  в активное актуальное окно. При программном отзыве другое активное
  окно сохраняет фокус; GRAF не активируется.

## Граница разрешения и результат

- Разрешение связано с текущим готовым документом верхнего уровня,
  фактическим URL, поколением, аккаунтом, окном и запросом. Смена
  любого из них либо потеря готовности отзывает запрос необратимо;
  отклонённая навигация при неизменном URL и готовности не отзывает.
  Устаревший запрос не изменяет новый и не получает обратной связи
  в другом документе. Уничтожение окна отзывает его запросы.
- До Save пользовательский каталог не трогается самим экспортом:
  исключение — явная команда создания папки. Завершение скачивания
  ещё не означает сохранения. Рабочий поток и отзыв согласуют
  единственную границу: если первым принят отзыв, окончательного
  имени не будет; если первым разрешено начать фиксацию, поток может
  завершить именно её или восстановить исходник, но без устаревшего
  сообщения и переключения фокуса. Прерывание после отзыва удаляет
  только собственные временные данные либо оставляет защищённые
  данные, нужные для безопасного восстановления.
- Результаты различимы: сохранено, отменено, конфликт имени, ошибка
  места, требуется восстановление. В актуальной панели конфликт
  предлагает другое имя или новое явное подтверждение, ошибка места —
  другую папку, а восстановление — действие для возврата исходника.
  У запроса один конечный результат; при отзыве он не показывается
  другой странице.

## Запись и восстановление

1. WebView2 скачивает в уникальную папку запроса с ограниченным доступом
   текущего пользователя и системы. Веб-страница не задаёт путь. При
   отмене и ошибке очищаются только принадлежащие запросу объекты.
2. Сохранение привязывает выбранный каталог к проверенному дескриптору.
   На томе назначения создаётся новый закрытый временный файл с
   эксклюзивным именем. Рабочий поток копирует все байты ограниченными
   блоками, сверяет длину и успешную запись, сбрасывает буферы. Источник
   и назначение могут быть на разных локальных томах. При подмене
   объекта пути или невозможности доказать требуемое поведение файловой
   системы место отклоняется; это касается и сетевых, съёмных и
   синхронизируемых мест, для которых гарантии не подтверждены.
3. Для нового файла завершающая операция по открытому дескриптору
   не заменяет занятое имя. Если другой файл появился поздно, его
   содержимое и свойства не меняются. Успех только после подтверждения
   записи полного нового файла под выбранным именем.
4. До показа подтверждения замены связать каталог и открытый исходный
   файл с их идентичностью на томе. Удерживать тот же дескриптор с
   правом на перемещение, исключающий запись и удаление другими
   открытыми дескрипторами, от показа до переноса. Если файловая система
   не гарантирует неизменность версии под этой защитой, либо привязка
   утеряна, согласие не используется. Повторное открытие по имени, даже
   с тем же File ID, не заменяет согласие на текущую версию. Отмена
   освобождает дескрипторы без изменений. После подтверждения целый
   исходный объект, включая свойства, перемещается связанным
   дескриптором в уникальное резервное имя, затем публикуется новый
   объект без замещения. Операции не обещают атомарной условной замены.
5. Перед перемещением исходника записать и надёжно зафиксировать
   закрытое намерение одного запроса: версию формата, идентичности тома
   и каталога, исходного и нового объектов, конечное, резервное и
   временное имена и минимальный закрытый способ повторно открыть тот
   же каталог. Если невозможно подтвердить сохранность намерения и
   файловых переходов при перезапуске на этом томе, замену не начинать.
   Восстановление после прекращения процесса или перезапуска Windows
   заново сверяет каталог и объекты, затем выбирает один исход:

   | Что находится на конечном месте | Что делать с исходником |
   | --- | --- |
   | Точный исходный объект, резервное имя свободно | Исходник на месте. Убрать только проверенный временный новый объект. |
   | Место свободно, в резерве точный исходник | Восстановить без замещения; при новом конфликте оставить резерв. |
   | Точный опубликованный новый объект | Исходник можно убрать только из подтверждённого резерва; неизвестный резерв не трогать. |
   | Посторонний объект, несовпадение идентичности или неопределённость | Не менять эти объекты. Сохранить известный резерв и возможность восстановления. |

   Намерение удаляется после подтверждённого разрешения случая. При
   неопределённости следующий запуск не повторяет замену. Не хранить
   историю путей после завершения. Пути, имена, содержимое и ключи не
   выходят в телеметрию и не возвращаются странице. UI-поток не
   выполняет файловое копирование, сброс буферов и восстановление.

Приёмка: нативные проверки на искусственных данных, реальный WebView2
с двумя последовательными запросами, затем [установленный MSIX и
GRAF Dev](../quickstart.md). Поведение macOS при согласии на замену
сверяется отдельно: наличие подтверждения не доказывает замену файла.
