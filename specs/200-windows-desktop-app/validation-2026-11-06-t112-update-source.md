# T112: источник обновлений Windows — 2026-11-06

Активный срез F200. Удалён старый `apps/windows/Installer/AppInstaller.xml`:
файл не входил в проект пакета, и исходники, сборка и публикация на него не
ссылались. В нём были неподтверждённые адреса и проверка при запуске
(`OnLaunch`); он не годился как заготовка для выпуска с явным действием
пользователя. В собранном 0.1.0.19 этого файла уже не было. Механизм обновления,
проект MSIX и подпись не менялись.

## Проверка

- В Windows 11 в Parallels открыт и отвечает установленный GRAF **0.1.0.18**.
  SHA-256 установленного EXE:
  `20a7544617b3008cc6706f94b769d0ad3e66b3e3ec146e30768b3a795bb1f17b`.
  Системный `PackageManager.FindPackageForUser` вернул тот же полный identity,
  что `Get-AppxPackage`. `GetAppInstallerInfo()` вернул null: источника у этой
  установки нет. Запрос доступности обновления и установка не выполнялись.
- Из точных исходников контроллера и теста
  `d1340645da9cb9f401861cc42406b514e8e16fad` собран отдельный тест x64 Release
  в той же VM. Оба прогона успешны: контролируемые ответы/повтор/закрытие,
  запреты установки и нативный отказ `noPackage` при запуске теста без MSIX.
  Это проверка контроллера; тест без пакета и наблюдение регистрации пакета —
  два разных случая. Временный каталог сборки удалён.
- SHA-256 списка входов теста
  `39c3b514809007e4039c38cacc438f5bb063b1d5435db013fd8803fd23bd5fa0`,
  результат с кодами завершения и очисткой
  `d506a9e0a30f1364a0e0109fa828036b839f5a71042500d5f4d2482dceb2e8ae`.

## Граница приёмки

Ожидаемое сообщение в открытом из трея окне: для установки не настроен
источник обновлений. Факт отсутствия источника подтверждён системным API;
ручное открытие окна этим не подтверждено. T112 остаётся открытой: требуются
проверка окна установленного MSIX и сквозная проверка на одобренном подписанном
канале с зарегистрированной привязкой, доступной новой версией, явной
установкой после завершения записи и сохранением данных. Доступ к записям,
изменение сертификатов и публикация канала для этой проверки не потребовались.
