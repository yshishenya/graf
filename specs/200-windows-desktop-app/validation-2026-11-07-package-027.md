# F200/T097 — внутренний MSIX 0.1.0.27 x64 с PerMonitorV2

В проект приложения добавлен частичный Win32-манифест с настройкой
`PerMonitorV2`. MSBuild объединяет его со штатным встроенным
манифестом EXE. Отдельный манифест MSIX не изменён в рабочем дереве.
Сборка CMake здесь создаёт тесты, а не второй EXE GRAF.

MSIX собран с нуля в Release x64 на Windows 11 ARM64 в Parallels.
Из 231 входа Windows на базе `3dfeaff5a6774ab12be781547e4a300f9ce2a46c`
по сравнению с [0.1.0.26](validation-2026-11-07-package-026.md) изменились
только проект MSBuild и добавленный Win32-манифест. В копии сборки
номер MSIX поднят до 0.1.0.27. Сборка, подпись разработки и статическая
проверка прошли. Независимо сверены все 26 файлов пакета, EXE и его
архитектура. `mt.exe` прочитал точные ресурсы `RT_MANIFEST #1` обоих
EXE: кроме объявления `PerMonitorV2` структура встроенного манифеста
не изменилась. Это результат независимой проверки сборки, а не
результат запуска установленного приложения.

Старый запускатель на последнем шаге ещё сравнивал число входов с 230:
вернул код 1 и сохранил временную сборку. Исходный журнал не исправлялся.
Отдельный проход заново сверил 231 вход, подпись и совпадение двух копий
MSIX, подтвердил отсутствие процессов сборки и удалил только временную
копию этой сборки. Проверка локальной копии на NTFS подтвердила подпись
и отвергла утверждение об установленном 0.1.0.27. Рабочая 0.1.0.18,
её процесс и хранилища доверия не менялись.
