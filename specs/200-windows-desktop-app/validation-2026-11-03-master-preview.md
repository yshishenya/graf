## Найденная и исправленная ошибка теста

`settings-autosave.test.cjs` искал кнопку «Загрузить сохранённое», тогда как
общий `settings-autosave.js` создаёт «Загрузить сохраненное». Исходный запуск
закончился настоящим locator timeout. В checkout и preview изменён только этот
точный locator; утверждения о конфликте, принятии серверного значения и отсутствии
лишнего POST сохранены. Исправленный сценарий прошёл отдельно на текущих assets
checkout и на preview. SHA-256 исправленного теста:
`a87b91ceb6b2a8d7a20e35421b413d0d130b55047c99f227163917eeb5b1c9f6`.

Другие неуспешные попытки сохранены и не объявлены PASS: первый Python запуск
использовал старый master unit test без F200 overlay и получил прежнее CSS
утверждение; DB-dependent notifications contract не смог подготовить disposable
Postgres. Следующий launcher после ошибки cwd не нашёл тестовый файл. После
исправления состава preview 102 теста прошли, четыре browser setup отказали
из-за отсутствующего параметра runtime. Только окончательный отдельный запуск
с настоящими установленными браузерами дал 106 PASS. Postgres contract остаётся
непроверенным; его ошибка не замаскирована отбором или пропуском.
