# F200/T101 — внутренний MSIX 0.1.0.30 x64

Проверка в рамках действующей F200: T101, с ограниченной проверкой
упаковки для T097. База `3dfeaff5a6774ab12be781547e4a300f9ce2a46c`
и точный снимок локальных изменений Windows, без коммита и выпуска.
Хеши всех 231 входных файлов сверены по SHA-256 до и после сборки; отдельная сверка
с рабочей копией после сборки также дала 231/231. От 0.1.0.29
отличаются четыре входа: инструкция сборки, проверка окон MSIX,
сценарий сборки AEC3 и его проверка. В отдельной копии исходников
поменяно только поле версии манифеста с 0.1.0.17 на 0.1.0.30.

В Windows 11 ARM64 / Parallels собран настоящий AEC3 Release x64
из закреплённого коммита `846fe90a289f58b7c9303a635142aa2c7caa93e5`.
Meson/MSVC выполнили 440/440 шагов, затем 10/10 проверок прошли,
включая отказ MSBuild при неучтённой скрытой библиотеке. Свежий
Release x64 MSIX собран с этой квитанцией и локальными пакетами
NuGet. Проверки сценария упаковки прошли 17/17; проверки подписи
и регистрации в этих 17 случаях используют имитацию результатов ОС.

Сам пакет подписан существующим сертификатом разработки `CN=GRAF`.
Windows подтвердила действительную подпись (отпечаток
`816CC8B4EB216A0755BFB118992BB594AF51BF6C`). Отдельная проверка
сверила все 26 файлов архива, x64 PE и хеш EXE из свежей сборки.
В манифесте приложения сохранился `PerMonitorV2`. Манифест
упаковки совпал с 0.1.0.29 за вычетом версии. В Windows пакет
прошёл повторную статическую проверку с заданным SHA-256;
`-VerifyInstalled -RequireRunning` корректно отказал, поскольку
в рабочем профиле был открыт GRAF 0.1.0.18. Временные копии
исходников, зависимостей и сборки удалены. Рабочая регистрация,
EXE и состояние процесса совпали до и после проверки упаковки.
Доверие к сертификатам не менялось.

## Установка, проверка AEC3 и откат под обычным пользователем

В той же VM создан отдельный временный обычный пользователь без
GRAF. Использованы уже установленные зависимости и действующее
доверие к сертификату разработки. Выполнен порядок:

1. Установлена 0.1.0.18, в её `LocalState` создан искусственный
   контрольный файл.
2. Поверх установлена точная 0.1.0.30; файл сохранился побайтно.
3. EXE из регистрации 0.1.0.30 выполнил `--verify-audio-backend`
   в контексте пакета и вернул ожидаемый код 73: самопроверка AEC3
   с искусственными потоками прошла. Микрофон и системный захват
   не использовались, обычное окно не запускалось.
4. Через `-ForceUpdateFromAnyVersion` выполнен откат до 0.1.0.18
   без предварительного удаления; тот же файл сохранился побайтно.

Отдельный процесс подтвердил регистрацию и точный хеш EXE в каждой
из четырёх фаз. После теста временная регистрация, профиль,
учётная запись и входные копии удалены. Независимая проверка
показала единственную рабочую 0.1.0.18, прежние в рамках прогона
PID, время запуска и EXE. Окно отвечает.
