# F200 — внутренний MSIX 0.1.0.25 x64

Полная чистая сборка Release x64 на Windows 11 ARM64 в Parallels.
Зафиксированы 230 файлов текущего дерева Windows на
`3dfeaff5a6774ab12be781547e4a300f9ce2a46c`, включая незакоммиченные
изменения. Файлы сервера и macOS в сборку не передавались. Единственная
правка в сборочной копии — версия `0.1.0.25` в манифесте. Последняя
[проверка T117](validation-2026-11-07-t117-product-baseline.md#разделение-восстановления-очереди-и-записи)
привязана отдельно; она подтверждает узкий сценарий на NTFS, а не
весь объединённый пакет.

MSBuild использовал закреплённые локальные NuGet-архивы и проверенный
AEC3. Подтверждена свежая компиляция `ProtectedCustodyMetadata.cpp`,
`ExportSaveCommit.cpp`, `ExportSavePanel.cpp` и остальных проверяемых
компонентов. Тестовый инструмент миграции в пакет не вошёл. Статическая
проверка прошла, подпись разработки `CN=GRAF` действительна на сборочном
стенде. На Mac независимо сверены все 26 файлов архива и идентичность EXE.
На Windows проверен хеш локальной копии; проверка установленной версии
корректно отвергла её, поскольку там по-прежнему открыт GRAF 0.1.0.18.
Его окно, процесс, EXE и хранилища доверия остались прежними.
Временные сборочные деревья и гостевая копия MSIX удалены.

Чистая установка, обновление, откат, физическая Windows x64 и
подпись для внешнего выпуска остаются отдельными условиями.

## Носитель для проверки без общих папок

Собран ISO `GRAF-F200-QA-025.iso`: исходная версия 0.1.0.18 для
обновления и отката, кандидат 0.1.0.25, две проверенные зависимости
MSIX, открытый сертификат разработки, проверка состояния обычного
пользователя и инструменты сверки. Закрытых ключей и данных профиля
нет. Независимое монтирование образа только для чтения подтвердило
точный состав и хеши восьми файлов. Отдельная проверка на Windows
прошла для семи входов; намеренное изменение сценария было
обнаружено, а проверка QA-профиля отказала на рабочей Windows.
Процесс рабочего GRAF остался прежним.

Образ подключён только ко второму виртуальному приводу отдельной
`GRAF F200 QA ARM`. После подключения сверены путь и хеш ISO,
порядок загрузки, установочный диск Windows, отсутствие сетевого и
звукового устройств, состояние общих папок и буфера обмена.
Проверенные параметры рабочей VM не изменились. Образ ещё не
читали внутри QA Windows: гостевой сеанс остаётся недоступен.
Сертификат не добавляли в доверенные; MSIX не устанавливали.

инструмента записи тестового профиля: его подготовка требует
привязки к SID уже созданного обычного пользователя.
