# F200 — внутренний MSIX 0.1.0.26 x64

Чистая сборка MSBuild Release x64 на Windows 11 ARM64 в Parallels.
Зафиксированы 230 входов `apps/windows` на базе
`3dfeaff5a6774ab12be781547e4a300f9ce2a46c`, включая изменения рабочего
дерева. По сравнению с [0.1.0.25](validation-2026-11-07-package-025.md)
отличаются семь Windows-файлов с изменениями экспорта и его проверок.
Компилятор заново собрал `ExportSavePanel.cpp` и `ExportSaveCommit.cpp`;
проверенный нативный код панели вошёл в EXE. Единственная накладка в
копии сборки — номер версии MSIX. Кабинет загружается отдельно;
серверные и macOS-файлы не являются входами пакета.

Сборка, подпись разработки `CN=GRAF` и статическая проверка прошли.
Тесты средства проверки пакетов: 6/6 для подписи, 3/3 для
сопоставления с установленной версией, 2/2 для WebView2 и 6/6 для
ресурсов языка. Независимый разбор на Mac сверил все 26 файлов
архива, архитектуру и EXE. Windows проверила ту же копию на локальном
NTFS, включая подпись, и правильно отказала в проверке установленного
0.1.0.26: рабочим остаётся 0.1.0.18. Пакет, процесс, главное окно и
хранилища доверия рабочего приложения не менялись. Временные
сборочные каталоги и проверочная копия в Windows удалены.
