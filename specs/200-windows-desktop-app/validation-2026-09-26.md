## Реализация и перекрёстная проверка, продолжение

Независимая проверка требований завершена: 112/112 PASS, без открытых
high/critical findings. Это gate качества требований, не приёмка приложения.
Для T101 независимое ревью потребовало подтвердить происхождение всех библиотек,
исключить подмену выбранного файла и отличать настоящий self-check от обычного
выхода старого EXE. Рецепт теперь записывает provenance только после успешной
компиляции с неизменными входами; повторное использование сверяет исходники,
заголовки и библиотеки. Abseil сверяется с закреплёнными архивом и patch, включая
содержимое распакованного дерева. Git LF в wrap-файле нормализуется из CRLF;
остальные хеши двоичные. Self-check возвращает отдельный код73 и требует
заранее записанного SHA256 EXE; обычный код0 не считается доказательством.

прошлые AEC_BUILD_EXIT=0 не подменяют её результат.
