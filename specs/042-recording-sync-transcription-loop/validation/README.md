# Synthetic Fixtures And Evidence

This directory records implementation evidence for feature `042`.

## Allowed Fixture Material

- Synthetic recording ids such as `offline-fixture-001`.
- Synthetic media revision ids such as `offline-fixture-001--initial`.
- Deterministic byte payloads generated by tests.
- Metadata-safe checksums, byte counts, status codes, and reason codes.
- Synthetic transcript text explicitly created for tests.

## Forbidden Material

- Real meeting audio, transcript text, participant names, account ids, or email
  addresses.
- Private Krisp screenshots or copied private reference-app transcript text.
- Credentials, tokens, cookies, signed URLs, secret paths, or object-storage
  keys.
- Live local absolute paths. Use redacted fixture names instead.

## Fixture Families

- `offline-local-package`: completed local package with no network and no server
  ids.
- `partial-upload`: server accepted one or more track ranges before disconnect.
- `accepted-initial-revision`: one logical meeting with one accepted initial
  media revision.
- `processing-ready`: accepted revision with synthetic transcript import.
- `sync-conflict`: local/server metadata mismatch with a safe reason and next
  action.

All fixture families must keep editing, trimming, video runtime behavior,
transcript editing, and speaker assignment editing out of `042` MVP scope.
