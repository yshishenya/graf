# Safety Checklist: Порог сохранения

**Purpose**: Проверка полноты требований capture/storage/UX до реализации.
**Created**: 2026-09-12
**Feature**: [spec.md](../spec.md)
**Review Ownership**: Маркеры принадлежат reviewer. [x] означает качество требований, не выполнение кода. Implement маркеры не меняет.

## Completeness and clarity

- [x] CHK001 Определены ли единый порог, точная граница и отсутствие диалога? [Clarity, Spec FR-001/003]
- [x] CHK002 Явно ли сохранены немедленный захват, начало записи, системный звук и Stop? [Consistency, Spec FR-002/003]
- [x] CHK003 Полны ли исключения для аварии, выхода, восстановления и неопределённых данных? [Coverage, Spec FR-004]
- [x] CHK004 Определены ли запрет upload и поведение между решением, очисткой и перезапуском? [Coverage, Spec FR-005/006]
- [x] CHK005 Ограничено ли удаление новыми принадлежащими записи локальными файлами с защитой путей? [Safety, Spec FR-006/008]
- [x] CHK006 Указаны ли историческая совместимость и ограничения отката? [Coverage, Spec FR-008, Assumptions]
- [x] CHK007 Определены ли текст, длительность, отсутствие фокуса/ошибки и VoiceOver для сообщения? [Accessibility, Spec FR-007, Contract]
- [x] CHK008 Измеримы ли требования производительности, диагностики и приёмки? [Measurability, Spec FR-009, SC-001–004]

## Notes

Проверять требования отдельно от реализации; при замечаниях оставить соответствующий пункт открытым.
