# Данные и совместимость
Новых сущностей/миграций нет. Профиль, устройства, сеансы, membership, calendar preferences и локальные AutomaticRecordingRule сохраняют существующие контракты. Меняется представление результатов и передача уже существующих query markers. Неизвестные маркеры не создают успех. При ошибке локальной записи настроек остаётся сохранённое значение.
