# Компактные списки настроек — спецификация внешнего вида

Дата решения: 2026-09-12. Размеры ниже — решение для GRAF, не измерения чужих приложений. Единицы: AppKit points, CSS pixels в кабинете. Сохранение/отмена из ui.md остаются обязательными.

| Элемент | Размер и поведение |
|---|---|
| Поле приложений | Максимум 380, ширина уменьшается вместе с контейнером; слева общий край содержимого. Высота native32; web сохраняет существующий доступный размер полей |
| Правило / напоминание | Native172 /190, высота32; общий край правой колонки. Web использует существующую сетку без горизонтального выхода |
| Раскрытая оболочка | Ширина поля; radius6, border1, отступ от поля4. Без указателя, толстого обрамления и отдельных карточек опций. Небольшая системная тень NSPanel; web 0 4px 12px rgba(0,0,0,.14) |
| Строка варианта | Минимум32, горизонтальные поля10, вертикальные6; font13 native/существующий web. Длинный текст переносится, высота растёт. Место для галочки24 |
| Высота меню | Три правила видны целиком; длинный каталог — до8 целых строк перед прокруткой. Высота включает border/viewport inset; экран ограничивает максимум, оставшееся содержимое прокручивается |
| Положение | Под левым краем поля. Если снизу места меньше необходимого, раскрыть вверх при большем доступном месте. Горизонтально ограничить visibleFrame с8pt запасом; на очень малом экране ограничить высоту и включить прокрутку |
| Строка приложения | Прежние40–44 minimum, разделитель1; длинное имя переносится. Новых внешних карточек нет |

Цвета: native controlBackgroundColor/labelColor/secondaryLabelColor/separatorColor/keyboardFocusIndicatorColor и системный selection; web существующие --panel, --text, --muted, --line, --focus-ring, --surface-2. Светлая/тёмная тема меняет цвета, сохраняя геометрию. Цвет сам по себе не обозначает выбор: выбранный вариант имеет галочку; стрелочная навигация показывает отдельное активное выделение. Галочка декоративная для AX; aria-selected/AXSelected отражают подтверждённое selectedValue, aria-activedescendant/AX active — activeIndex. Поле приложений является фильтром коллекции: сохранённого правила/галочки в его каталоге нет.

Фокус обозначается один раз вокруг всего поля; внутренний NSTextField не рисует отдельное кольцо. Tab/Shift-Tab сохраняют порядок формы, arrow button не забирает фокус из редактора; Enter/щелчок/AXPress подтверждают, Escape/blur/Tab отменяют незавершённый выбор. Настройки автоматически не раскрывают меню при первоначальном программном назначении фокуса; пользовательский щелчок, стрелка и ввод раскрывают. IME и ввод-фильтр остаются прежними. Перемещение/resize родительского окна, переключение вкладки, прокрутка внешнего контейнера и деактивация закрывают меню без сохранения. Никаких анимаций раскрытия.

Пустой результат: «Ничего не найдено», минимум одна строка, не выбирается; пустой каталог: «Список пока недоступен». Disabled поле не раскрывается. Ошибки загрузки/сохранения используют существующее объяснение/повтор формы, без отдельного popup ошибки. Фильтрация локальная; задержка сети не создаёт новую loading-анимацию. Ограничения длины не вводятся, подписи в меню доступны полностью с переносом; в закрытом поле длинное выбранное имя доступно через AX и редактирование.

Проверка: synthetic prototype — только согласованное направление; установленный GRAF Dev с открытыми меню обеих вкладок доказывает фактическую форму, клавиатуру, доступность и геометрию. Прежние screenshots закрытых полей этого не доказывают. Полный VoiceOver speech остаётся отдельной ручной проверкой, AX snapshot не равен озвучиванию.
