# UI contract
Combobox имеет одно видимое текстовое поле и стрелку внутри его границы. Пользовательский click, ввод или ArrowDown/ArrowUp открывает список; первоначальное программное назначение фокуса не раскрывает его, ArrowDown/ArrowUp перемещают активный вариант, Enter подтверждает доступный вариант, Escape закрывает с отменой запроса настройки, Tab закрывает и передаёт фокус. IME composition не подтверждает Enter. Роль combobox + listbox/options, aria-controls/expanded/activedescendant/selected и доступное имя. Пустая выдача озвучивается; disabled варианты пропускаются. Список ограничен высотой/шириной и прокручивается. Скрытый original select сохраняет имя/значения/валидацию и работает без JS; временный ввод не входит в FormData. Обновление value/options/disabled отражается в поле без потери активного ввода. Поля-фильтры приложений сохраняют частичный query при blur и очищаются пользователем. Дубли названий в settings сохраняют стабильные value; выбор app-фильтра может показать несколько одноимённых строк.
