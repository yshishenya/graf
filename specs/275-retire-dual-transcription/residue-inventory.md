# Проверка остатков F275

Область: исполняемый код сервера и macOS, проверочные сценарии, тесты и текущие
инструкции. Сохранённые данные, применённые миграции и исторические материалы
не удаляются. Это перечень допустимых причин сохранения, а не разрешение на
старую отправку.

## Результат поиска по рабочему дереву (2026-09-24)

- `submit_dual_track`, `dual_track_supported`, `/dual-track`: отсутствуют в
  production source/scripts. Имя удалённого метода есть в отрицательном тесте,
  который проверяет отсутствие вызываемого метода.
- `mic_file`/`incoming_file`: только исторический Codable enum AudioStates и
  фильтры observability/redaction. Отправителя multipart с этими полями нет.
- В processing/mediascribe/workflows старые имена остаются в читателе результата
  `import_results.py`, определении provenance ответа в `client.py` и двух
  пустых ключах отпечатка в `processing/store.py`.
- Исторические ORM FK в `db/models/processing.py` сохранены; в положительных
  проверках новых заданий явно проверяется их пустота. В миграциях 0098/0099
  меняются только defaults; downgrade сохраняет обратимость схемы.
- В служебных server/infra сценариях нет парных filenames/fields/endpoint.
- Ссылка на прежний активный документ удалена из текущих docs/apps/infra.
  Старые specs/evidence остаются историей; текущий OpenAPI совпадает с runtime.
- Само совпадение слов microphone/system в захвате, AEC, защите данных или
  историческом purge не считается работающим путём отправки. Проверены
  перечисленные выше основания сохранения.

Поиск повторяется при окончательной проверке; сетевое поведение подтверждается
тестами, а не только отсутствием строк.

## Недопустимые остатки

- Отправитель пары файлов, парный multipart или адрес создания такого задания.
- Положительный сценарий, который создаёт старый пакет через действующий API.
- Доступное продолжение старой загрузки, её автоматический или ручной повтор.
- Реклама поддержки старой отправки в текущем контракте или проверке готовности.
- Служебный генератор произвольных байтов под именем аудиофайла.

## Допустимые исторические обозначения

| Область | Причина сохранения | Запрещённое использование |
| --- | --- | --- |
| Применённые миграции и исторические столбцы MediaScribeJob | Чтение существующих строк, их происхождение и безопасное удаление; default меняется новой миграцией | Создание новой пары источников |
| Сериализация отпечатка single-source запроса | Старые пустые ключи должны сохранять точный SHA существующих повторов | Подстановка в эти ключи пары файлов |
| Enum исходников и ролей, исторические manifest/queue decoders | Открытие старых записей, согласование известного задания, tombstones | Пометка старого пакета как доступного для отправки |
| Retention/deletion, права на старые ключи объектов | Иначе ранее сохранённые исходники останутся неудаляемыми | Приём и запись новых старых пакетов |
| Историческая нормализация воспроизведения и роли результатов | Воспроизведение и чтение сохранённых данных | Новый запрос расшифровки пары источников |
| Фильтры закрытых данных в observability | Исторические имена чувствительных полей также должны скрываться | Запись содержимого таких полей в журнал |
| Отрицательные и исторические тесты | Доказывают отказ без сети, сохранность чтения и удаления | Положительная отправка через старый endpoint |
| Физические microphone/system в захвате и WebRTC AEC3 | Это реальные источники канонического микса, а не протокол отправки | Восстановление двухфайлового пакета |
| `specs/` завершённых features, `docs/evidence/`, ADR, changelog | Неизменяемая история решений и фактических прошлых проверок | Использование как действующего контракта |

Активный OpenAPI в `specs/012-server-ingest-foundation/contracts/openapi.yaml`
является исключением среди старых каталогов: он сверяется с текущим API и
обновляется. Исторические ссылки на прежнее имя документа остаются частью
истории; действующий контракт — `docs/integrations/mediascribe-api.md`.

## Команды проверки

```sh
rg -n 'submit_dual_track|dual_track_supported|/dual-track|mic_file|incoming_file' apps/server/src apps/server/scripts apps/macos/RecApp apps/macos/Shared/Sources infra/scripts
rg -n 'dual.track|initial_recording|mic_track_artifact_id|incoming_track_artifact_id' apps/server/src apps/server/tests apps/macos/RecApp apps/macos/Shared docs/integrations
rg -n 'mediascribe-dual-track-api' docs apps infra --glob '!docs/evidence/**'
git diff --check
```

Отсутствие строки само по себе не доказывает запрет. Его подтверждают проверки
загрузки/повтора после перезапуска, записанных HTTP-запросов, старых известных и
неизвестных внешних заданий, чтения и удаления. Результаты — в quickstart.md.
