# Research: Минимальная высота таймлайна спикеров

## Decision: использовать фиксированный минимум 120px

Текущая дорожка состоит из подписи и полосы воспроизведения в двух строках.
При текущих gap, line-height и padding три таких ряда требуют больше
`96px`; `120px` даёт небольшой безопасный запас и не зависит от длины имени.

## Decision: сохранить существующий bounded resize

`cabinet.js` уже ограничивает высоту минимумом полной высоты содержимого и
доступной высоты viewport, а keyboard/pointer paths используют одну функцию
`applyHeight`. Меняется только нижняя граница и синхронные значения в markup,
CSS и JS.

## Alternatives considered

- Вычислять минимум на сервере для каждого количества спикеров — отклонено:
  CSS-размер дорожки может измениться из-за текста и viewport, поэтому это
  создаёт дублирование layout-логики.
- Хранить размер в `localStorage` — отклонено: пользователь просил базовый
  размер, а постоянное состояние не нужно для исправления видимости.
- Увеличивать высоту только для ровно трёх спикеров — отклонено: получается
  скачок layout и четыре дорожки по-прежнему начинают с частично скрытого
  содержимого.
