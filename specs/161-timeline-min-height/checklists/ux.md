# UX Requirements Checklist: Адаптивная высота таймлайна

**Purpose**: Проверить UX, доступность и адаптивность формулировок
**Created**: 2026-08-19
**Feature**: [spec.md](../spec.md)

## Interaction and accessibility

- [x] Для 1–3 дорожек нет бесполезного resize affordance [Clarity]
- [x] Для 4+ дорожек есть понятный pointer/keyboard resize contract [Completeness]
- [x] Focus, cursor, ARIA values и Home/End semantics заданы [Accessibility]
- [x] Верхний предел не перекрывает playback bar и доступный viewport [Edge Case]
- [x] Узкий viewport и длинные speaker labels учтены [Responsive coverage]
- [x] Visual matrix использует synthetic-only evidence [Privacy]

## Notes

Все пункты пройдены; brand-distance и capture gates не затрагиваются.
