# Clarifications: Адаптивная высота таймлайна

### Session 2026-08-19

- Критических неоднозначностей не обнаружено: пользователь явно требует
  естественную высоту для 1–3 спикеров и расширение до полной высоты для
  больших встреч.
- Существующий `120px` сохранён как baseline для трёх дорожек и lower bound для
  4+; постоянное хранение размера остаётся вне scope.
- Keyboard/pointer resize и сохранение playback state остаются обязательными
  существующими контрактами.
