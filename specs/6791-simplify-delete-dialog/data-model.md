# Data model

Изменений сущностей, данных, схемы, retention и состояний нет. MeetingReviewResponse.governance.delete.state по-прежнему определяет доступность. Форма передаёт csrf_token (каноническое имя защитного поля) и confirmation_boundary; MeetingDeletionReport создаётся существующим запросом удаления.
