# UI contract
Веб: /settings/account. Встроенный: /desktop/settings/account. Раздел #account-sessions-title.
«Где вы вошли» + общее число действующих входов → единый список → массовое действие → свёрнутая помощь. Область — текущее рабочее пространство. Истории нет.
Строка: небольшой общий значок клиента, название, «Вы здесь» у текущего, краткая активность; native details раскрывается основной частью строки. Справа отдельная кнопка «Завершить» с полным доступным названием. Текущий без отзыва. 64–72 px на широком экране при обычном тексте, min-height действий 44 px; переносы разрешены.
Другие: POST sessions/{id}/revoke. Bulk: POST sessions/revoke-others. Первый POST перерисовывает аккаунт с подтверждением под целью; второй POST с csrf_token и confirm=1 выполняет операцию. Подтверждение называет цель/дату и последствия. Для отсутствующей в списке цели подтверждение под списком. Без JS отмена возвращает к якорю; JS скрывает подтверждение, возвращает фокус к кнопке и поддерживает Escape. Начальный фокус на отмене.
Результат в существующем account_outcome. После успеха список и общее число формирует сервер; только текущий → «Других входов нет». Ошибки и повторный вход сохраняют существующий путь. Подтверждение не обещает удаления файлов или остановки записи. Все пояснения внутри одной справки.

При отсутствии исходной кнопки отмена (JS и no-JS) возвращает к #account-sessions-title с tabindex=-1. Это относится и к массовому действию, если других действующих входов больше нет.
