## Текст для заметок о выпуске
Раздел «Где вы вошли» стал компактнее. В нём показываются только действующие входы в текущее рабочее пространство. Текущий вход отмечен «Вы здесь», сведения об остальных раскрываются нажатием на строку.

Совместимость: обновление не меняет сроки действия входов, правила доступа или хранение данных. Переносить данные не требуется. Список показывает известные приложение/браузер и систему; местоположение не определяется.

## Откат
Использовать штатный guarded rollback на предыдущий одобренный серверный SHA. Обратной миграции БД для F6794 нет. Возврат интерфейса не восстанавливает уже завершённые пользователем входы: для них нужен новый вход. Критерии остановки — потеря текущего доступа, неверная цель отзыва, ошибка CSRF/повторного входа или недоступный список.
