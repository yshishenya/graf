## Границы новой исходной роли

`invite_only + link.state=absent` означает отсутствие сохранённой общей ссылки. Полная встреча в таком состоянии может быть лишь выбранным в форме предложением; доступ появится после прежнего подтверждаемого действия с явным `content_scope`. Это не повод писать в существующие grants, менять общий серверный default или снимать проверку прав. Адресные grants, включая summary_only, сохраняются; новое приглашение с viewer не должно менять прежних получателей. Для существующей active/expired/replacement_required ссылки UI обязан показать сохранённый scope. Эти ветви названы в FR-034, plan и quickstart, поэтому противоречия с F286 и FR-004 не выявлено.

Новый UI не меняет выдачу записи, сессию адресата, приём приглашения, membership, native intent или публичную проекцию. Файловые права off не должны отключать обычное прослушивание. Скрытый при invite_only общий scope остаётся в форме как предложение; его подпись не должна выдавать этот выбор за права адресного получателя.
