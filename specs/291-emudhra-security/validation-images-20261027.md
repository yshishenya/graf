## Проверка TLS

Каждый образ запущен одноразово, без томов, с read-only filesystem,
`--cap-drop=ALL` и пределом 64 процессов. Код не создаёт приложение сервера.
Лимит каждого соединения — 15 секунд; redirects и использование proxy из
окружения для HTTP-клиентов отключены, проверка сертификатов сохранена.

В каждом образе три клиента — HTTPX, Requests и системный SSL — прошли:

- обычный контроль `pypi.org`: TLS принят; HTTP-клиенты получили HTTP 200;
- `dv-g3b-emudhra.we-have-a-problem.com`: отказ проверки сертификата;
- `dv-g3b-aaa-emudhra.we-have-a-problem.com`: отказ проверки сертификата.

Итого **18 PASS / 0 inconclusive**. Отдельно уточнён системный отказ обоих
тестовых доменов в `runtime`: `verify_code=20`,
`unable to get local issuer certificate`; это не истечение срока, DNS или
таймаут. Private endpoints, секреты и данные встреч не использовались.

Технические build/TLS журналы, исполняемый сценарий, inspect и сводка сохранены
отдельно. SHA-256 `summary.json`:
