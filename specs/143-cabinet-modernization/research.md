# Research: Modernize Web Cabinet UI

- The goal is to bring the cabinet UI up to the standard of the recently modernized public landing page.
- We will use `bento-grid` inspired card layouts, improved typography, and "glassmorphism" or subtle tonal layering.
- The `cabinet.css` file defines all the variables at the `:root`. We can update these to provide better depth and contrast.
- Elements like `.cabinet-meeting-row` can be improved with better hover states, transitions, and subtle borders.
