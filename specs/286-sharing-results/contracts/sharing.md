# Interfaces — F286

Owner APIs use existing cabinet verified context/CSRF, workspace scope and metadata-only audit. Requests validate before mutation; no email-content or tokens in errors. Public responses use existing no-store/no-referrer/noindex headers and ingress limiter.

- GET/POST `/api/v1/cabinet/meetings/{id}/summary-sharing/link`: current or first publication. POST `{template_key,expires_in_days:7|30|90}`. Return grant ID, exact expires_at, share_url (owner only), saved projection and version. Existing active publication returns same address/body/date; ciphertext-less old grant reports explicit replacement requirement.
- POST link `/update`, `/rotate`, `/expiry`; DELETE link: explicit operation with expected publication version/grant ID; mutations never occur on GET. Conflict 409 refetches without applying stale update. Copy never changes lifetime/document.
- POST `/api/v1/cabinet/meetings/{id}/summary-sharing/batches`: `{template_key,recipients:[email],idempotency_key}` <=50 unique normalized addresses. Atomically persists snapshot/list/intent, returns batch status. GET `/.../batches/{batch_id}` returns immutable recipient results; POST `/.../{batch_id}/recipients/{recipient_id}/retry` only known failure; POST `/.../{batch_id}/cancel` for pending work.
- GET/PATCH `/api/v1/cabinet/summary-sharing/preferences`: ask_enabled/paused, expected_version on PATCH, version and rules/queue. No-op retains version; pause/resume advance auto_epoch only. Disabling ASK does not cancel rules. Resume starts no historic batches; сохраняется last_resumed_at, готовность должна наступить позже этой границы, для прежних правил также starts_at позже неё. Исключение — новое явно включённое после возобновления правило конкретной встречи до готовности; серия сохраняет только будущие экземпляры.
- GET/POST `/api/v1/cabinet/meetings/{id}/summary-sharing/auto-send`: current setting/state plus exact owner-only roster and scope rule versions (absent=0); POST `{scope:meeting|series,enabled,template_key,recipient_user_ids,expected_version}`. Permission, calendar identity and audience validated; rule SAVE never immediately sends already-ready historical series instances. Meeting override cancellation remains independent.
- Public summary-only URL uses existing `/api/v1/cabinet/public-shares/{token}?workspace_id=...` with saved projection. Invalid/deleted/expired response shows no document or metadata. Private routes always enforce normal ACL.
- Addressed published summary requires existing independently verified email and invitation consent; a forwarded invitation cannot authenticate another account. Legacy full-meeting ACL scope stays unchanged, but every unaccepted invitation requires independent login; no invitation token, old or new, bootstraps a session.
- Scoped opt-out URL GET shows confirmation; POST changes only automatic email preference. Signed random token not analytics/access token; document retains separate access policy.
- Workflow/activity payload includes only UUID batch identity; exact document/email remain in server DB, not arguments/logs. Recovery uses durable DispatchIntent. Postal acceptance, known failure and unknown remain distinct.
