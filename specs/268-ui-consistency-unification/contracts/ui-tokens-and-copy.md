# UI Contract: токены, состояния и тексты (фича 268)

Нормативный документ для кабинета, публичного сайта и macOS-приложения.

## 1. Палитра (единственный источник)

Кабинет: `apps/server/src/twobrain_rec_server/cabinet/static/cabinet/cabinet.css`
(`:root` — тёмная, `html[data-theme="light"]` и
`@media (prefers-color-scheme: light) html:not([data-theme])` — светлая).

Правило: ни одно правило вне этих блоков не задаёт цвет литералом. Допустимы
только `var(--token)` и `color-mix(in srgb, var(--token) …, transparent|var(--…))`.

Дополняемые токены: `--pink`, `--overlay-backdrop`, `--shadow-dialog`,
`--speaker-contrast-text`, светлые варианты `--speaker-color-*`.

`rgba(255,255,255,…)` подложки заменяются на `--line-soft`/`--surface-2`;
прозрачности чёрного для теней — на `--overlay-backdrop`/`--shadow-dialog`.

## 2. Шкала радиусов

| Токен | Значение | Применение |
|---|---|---|
| `--radius-xs` | 6px | мелкие плашки, пункты меню |
| `--radius-sm` | 8px | иконки-кнопки, строки состояния |
| `--radius-control` | 9px | поля, кнопки |
| `--radius-compact` | 10px | компактные панели |
| `--radius-card` | 12px | карточки, списки |
| `--radius-panel` | 14px | большие панели, статусы |
| `--radius-dialog` | 16px | диалоги |
| `--radius-pill` | 999px | пилюли, аватары, круглые кнопки |

Литеральные радиусы в правилах отсутствуют.

## 3. Типографика

- `--font-size-body: 14px` (фактический базовый размер), `body` не переопределяет.
- `--font-size-body-compact: 13px` — только внутри страниц настроек.
- Заголовок страницы: `--font-size-page-title` (20px) для списка, карточки
  встречи, настроек, удалений и истории уведомлений; клампы заголовков
  удалены.
- Заголовок диалога: `--font-size-dialog-title` (19px) во всех диалогах.

## 4. Состояния

| Состояние | Тон | Токены |
|---|---|---|
| Обычная обработка | нейтральный | `--muted`, `--surface-2` |
| Приостановка, «требует внимания» | предупреждение | `--amber`, `--warning-border`, `--warning-surface` |
| Терминальный отказ | ошибка | `--danger-text`, `--danger-border`, `--danger-surface` |
| Загрузка (скелетон) | нейтральный | `--line-soft`, `--surface-2`, высота `--meeting-row-height` |
| Успех (автосохранение, сообщение) | успех | `--green`, `--success-border`, `--success-surface` |
| Ошибка/конфликт (автосохранение, сообщение) | ошибка | `--danger-text`, `--danger-border`, `--danger-surface` |

Смысл состояния передаётся текстом и/или иконкой, цвет — дополняет.

## 5. Словарь текстов

| Смысл | Единственный текст |
|---|---|
| Остановка записи | «Остановить запись» (везде) |
| Раздел настроек | «Запись встреч» → блок «Автозапись» |
| Результат распознавания | «Расшифровка» |
| Результат модели | «Итоги» |
| Провайдер оплаты | «ЮKassa» |
| Отчёт об очистке | «Отчет удаления» |
| Обновление, версия неизвестна | «Проверить обновления…» |
| Обновление, версия известна | «Обновить GRAF до <версия>…» |
| Обновление, кнопка действия | «Обновить GRAF» / фазы: «Открыть обновление», «Повторить» |

Конвенция: в пользовательских строках нет буквы «ё» (замена на «е»),
исключение — «Mute микрофона» и имена файлов.

## 6. Индикатор обновления

- Постоянный индикатор ровно один: элемент оболочки (сайдбар кабинета в
  embedded, локальная плашка в локальном режиме).
- Верхняя полоса появляется только для фаз `downloading`, `installing`,
  `readyToInstall`, `failed`; для `available`, `deferredForCapture`, `checking`,
  `current`, `idle` — не показывается.
- Меню приложения и трей содержат одну команду с подписями из раздела 5.

## 7. Кнопки-иконки и диалоги

- Один компонент `.icon-button` (32×32, `--radius-sm`, hover из `--surface-3`),
  вариант `--ghost` без рамки и фона. Класс `.icon-control` удаляется.
- `.icon-button.danger-button` сохраняет опасный тон (исправление каскада).
- Все диалоги: `--radius-dialog`, тень `--shadow-dialog`, backdrop
  `--overlay-backdrop`, заголовок `--font-size-dialog-title`, паддинг `24px`.

## 8. Страницы вне системы

- История уведомлений рендерится через `base.html` и `cabinet_shell`: тема,
  навигация, профиль, стандартные карточки.
- Страницы удаления используют `cabinet-workspace`, карточки `--radius-card`,
  ссылки `.cabinet-link`, заголовки из общей шкалы.

## 9. macOS

- Фирменные цвета, радиусы и размеры шрифта берутся из `DesktopDesignTokens`;
  динамические цвета совпадают с кабинетом в светлой и тёмной теме.
- Фирменные элементы не используют системный акцент; системные материалы
  допустимы только в системных контролах.
- Цели нажатия интерактивных элементов ≥ 40pt; исключения — системные
  комбобоксы и меню.
