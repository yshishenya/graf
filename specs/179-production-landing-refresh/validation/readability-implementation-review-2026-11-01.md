## Независимая проверка кода без изменения состояния

Из нового тестового файла выделена через `ast` только функция
`test_public_product_panels_have_valid_roles_and_reciprocal_tab_links`.
Она исполнена в памяти со стандартным `HTMLParser` и чтением шаблона, без
загрузки приложения, pytest, PostgreSQL, установки зависимостей и записи
кэшей (`python3 -B`). Затем та же функция получила исходный шаблон из
`git show` через объект в памяти:

| Проверка | Результат |
|---|---|
| Новый статический контракт на текущем HTML | PASS |
| Тот же контракт на исходном HTML основы | Ожидаемый отказ: `tabpanel needs a generic container, not article semantics` |
| Сравнение HTML с основой после ровно трёх замен пар `article`→`div` у панелей | Полное совпадение |
| JavaScript `landing.js` против основы | Побайтовое совпадение |
| Пять хешей входов записи analyze | Совпадают с текущими файлами |

Полное совпадение после трёх замен означает сохранность текстов, атрибутов,
ссылок, изображений, шаблонных условий и остальных контейнеров HTML.
Новый тест ловит исходную ошибку семантики и проверяет взаимность связей,
соответствие `data-tab`/`data-panel` и отсутствие исходного `hidden` у панелей.
Он не выдаёт отсутствие атрибута `hidden` за доказательство фактической
видимости без JavaScript; для этого сохранена браузерная проверка T057.
Существующие селекторы вкладок по ролям и `data-*` не зависят от `article`.

CSS-правка ограничена наследуемым `overflow-wrap:anywhere` на `main`,
квадратной областью значка FAQ с запретом сжатия, локальным фоном
`.button-primary`/`.primary-cta` и двумя подписями подвала. Глобальная `--purple`,
размеры шрифта и действующее управление не изменены. Переносы могут
влиять на другие страницы общего CSS, поэтому их проверка остаётся
обязательной частью T057. Существующий `overflow-x:hidden` не добавлен
в качестве исправления; его наличие не доказывает отсутствие обрезки.
