# UX Requirements Checklist: подключение email

- [x] Основной результат определён: после submit виден экран ввода кода.
- [x] Время до доступного ввода измеримо и не зависит от доставки письма.
- [x] Resend, invalid/expired code и back описаны как embedded recovery states.
- [x] Общая ошибка встречи запрещена для доступного auth/settings-контекста.
- [x] Поведение web-пути и соседних форм явно сохранено.
- [x] Экран остаётся доступным при SwiftUI update и безопасном app rebuild.
- [x] Acceptance criteria не требуют нового текста, компонента или navigation chrome.
