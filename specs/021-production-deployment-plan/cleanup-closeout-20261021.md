## Сопоставление исходных критериев

| Критерий #7438 | Доказательство принятой реализации |
| --- | --- |
| Воспроизведение прежнего deadlock настоящим PostgreSQL | `cleanup-safety-review.md`: прежний helper получил DeadlockDetectedError при управляемой FK-гонке DELETE workflow / INSERT result; это модель гонки, не весь производственный граф блокировок. |
| Повтор всей транзакции, максимум 3 попытки, паузы 100/300 мс после rollback | Независимое ревью private retry signal, границы `engine.begin()` и `finally dispose`; transient и exhausted проверки. |
| Те же synthetic identity, фильтры, RLS, счётчики только принятой транзакции | Неизменные SQL/tenant/filter/CLI; 23 профильные проверки в принятом PR, соседние обычные строки сохранены. |
| Объектное хранилище только после commit | В окончательном тесте отдельный backend выполняет SELECT из синхронного storage callback; один вызов после commit. Само хранилище заменено тестовой реализацией. |
| Non-40P01, exhausted и postcommit остаются отказами | Отдельные отрицательные проверки; postcommit 40P01 не повторяет удаление. |
| Независимые требования и review, точные обязательные CI | `cleanup-safety-review.md`, `cleanup-analysis.md`, PR #7440; свежая live-проверка CI ниже. |
