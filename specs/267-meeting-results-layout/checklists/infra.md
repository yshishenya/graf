### Проверка требований — 2026-09-15

Рецензент: Codex (Cicero), F267; отдельная проверка по поручению основного агента. Прочитаны spec.md, plan.md, research.md, data-model.md, contracts/presentation.md и quickstart.md; переход конфигурации дополнительно сопоставлен с исходным кодом на HEAD 5d0abfcd0e43f8e0640d665e0ac4ed913ebb411f. Результат первичной проверки: 4/5, CHK013 оставлен открытым; это проверка требований, не выполнения будущих тестов.

- CHK012/014: [спецификация](../spec.md), FR-013–015; [план](../plan.md), Technical Context, Constitution Check и Design 1–3; [модель данных](../data-model.md) сохраняют поля/схему, один этап модели, точные снимки, слова и проверки доступа/источников/удаления без новых запросов при чтении.
- CHK015: [исследование](../research.md#shared-surfaces-and-export), [модель данных](../data-model.md) и Design 3 явно ограничивают общую страницу вычисленным аргументом из уже загруженного результата; narrow_summary_projection, внутренние снимки и запрещённые источники не расширяются.
- CHK016: FR-016; [quickstart](../quickstart.md#local-app-and-live-prompt) и [исследование](../research.md#provenance-without-a-new-stored-field) разделяют исходный текст, синтетическую живую оценку, отдельное разрешение на production и порядок установки классификации до активации промпта.

**F267-REQ-01 — HIGH, CHK013: план не проводит новый descriptor через синхронизацию промпта.** Design 1 сохраняет старое значение по умолчанию в meeting_protocol_config и назначает новое только в desired_prompts. Однако [sync_prompts](../../../apps/server/src/twobrain_rec_server/cli/langfuse_prompts.py), строки 240–243, отбрасывает конфигурацию desired_prompts и пересобирает её через прежнее значение по умолчанию. При выполнении только описанного изменения в Langfuse попадёт новый текст со старым descriptor, а результат получит «Тип встречи». Правило сохранения/replay само по себе этот разрыв не устраняет.

Для закрытия: уточнить plan/research, что sync_prompts переносит новый desired response_format вместе с текстом, сохраняя выбранную модель и разрешённые параметры; в quickstart предусмотреть синтетическую проверку конфигурации, передаваемой create_prompt для встроенного и пользовательского форматов. Реальная публикация для этой проверки не нужна. После уточнения документов требуется повторная оценка CHK013 рецензентом; до неё проверка требований перед реализацией не пройдена.
