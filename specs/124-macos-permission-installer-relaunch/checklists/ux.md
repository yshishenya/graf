# Relaunch and user-experience requirements checklist

- [x] The first-run flow has a clear next action for each ungranted permission.
- [x] The UI does not label a denied microphone state as if retrying the system
  prompt were guaranteed.
- [x] After opening Screen & System Audio settings, the user can explicitly
  restart GRAF from the preparation surface.
- [x] Returning from System Settings refreshes status and never displays false
  readiness.
- [x] System Quit & Reopen and the explicit restart close onboarding and active
  modal state before bounded cleanup.
- [x] Existing manual start/stop and capture safety gates remain intact.
