# Проверка переименования

## Подготовка

Только синтетические данные и отдельная тестовая PostgreSQL; никаких изменений
реальных встреч для GRAF QA. Использовать существующие `tests.fixtures.cabinet`
и настройки `apps/server/tests/conftest.py`. Нельзя подставлять production URL
в тесты, которые очищают таблицы. Для браузера переиспользовать локальный
подход `tests/fixtures/calendar_visual_ui_harness.py`; визуальная имитация
не заменяет проверку сохранения через реальную тестовую базу.

## Автоматические проверки после реализации

Из `apps/server`:

```sh
uv run pytest tests/integration/test_cabinet_meeting_rename.py tests/integration/test_cabinet_csrf.py tests/integration/test_cabinet_meeting_list.py tests/integration/test_cabinet_meeting_detail.py
uv run ruff check src/twobrain_rec_server/cabinet tests/integration/test_cabinet_meeting_rename.py
```

Файл теста добавлен в T002. Дополнительно запустить
тесты календаря/повторов ingest, затронутые T003. До принятия результата нужны
реальные PostgreSQL-проверки гонки в двух соединениях, не последовательная
имитация и не SQLite с отсутствующей блокировкой строки.

Из корня после сфокусированных проверок:

```sh
git diff --check
infra/scripts/ci-local.sh --fast
```

Полный CI и выпуск — отдельный этап по `release-and-validation.md`; fast
не является подтверждением release readiness.

## Путь пользователя

1. Открыть синтетическую готовую встречу; включить воспроизведение, перейти
   в расшифровку, переименовать Enter. Проверить плеер и вкладку; при успехе нет визуальных подписей.
2. Полностью обновить страницу; вернуться в список; найти по новому имени;
   скачать новый экспорт. Старое имя не возвращается после фонового запроса.
3. Повторить в `/desktop/meetings` и через обычное открытие из списка.
4. Ввести пустоту, 500/501 символ, emoji, кавычки, HTML-подобный текст,
   многострочный текст и запрещённые метаданные. Проверить буквальное
   отображение допустимого текста и объяснение отказа.
5. Esc/Enter/уход фокуса; переход с изменением и без; повторные Enter;
   IME-композиция; Tab/Shift+Tab; возврат фокуса; экранный диктор.
6. Отключить сеть, задержать ответ >15 с, вернуть 500; убедиться, что черновик
   остаётся и повтор не создаёт двойной записи. Перейти к другой встрече,
   вернуть поздний ответ: чужое название не меняется.
7. Две вкладки: сохранить разные имена. Конфликт не перезаписывает первое;
   явный повтор со второй версии работает.
8. Сохранение параллельно календарю/удалению; повтор начального ingest;
   private/team/shared/другая организация/отозванный доступ/CSRF.
9. Готовая, обрабатываемая, загружаемая, ошибочная и удаляемая запись.
10. 320/390/768/1440 px, 200% масштаб, светлая/тёмная тема, браузер и
    действительный WKWebView dev-клиента. Проверка `/desktop` в Chromium
    сама по себе не доказывает установленное приложение.
11. JavaScript выключен: Enter отправляет форму, ошибки остаются доступными; отсутствующие
    blur/Esc не обещаются.

В `validation.md` записывать только синтетические результаты, команды,
количество проверок, поверхность/версию, SHA и ограничения. Не хранить
названия реальных встреч, аудио, расшифровки, cookies или токены.

12. Esc при pending не отменяет отправленный запрос; Esc после timeout
    отбрасывает только локальный ввод и перечитывает имя/версию без перезагрузки карточки и ложного отката.
    При 404/revoke/delete переход к списку доступен, повтор rename запрещён;
    HTML-ошибка не возвращает недоступную карточку/её draft.
13. Пользовательское имя из 500 символов сохраняется полностью в новом
    экспорте; ограничение длины файлового имени отдельно от заголовка документа.

## Синтетический стенд редактора

```sh
cd apps/server
uv run uvicorn tests.fixtures.meeting_rename_ui_harness:app --host 127.0.0.1 --port 8873
```

Открыть `/meetings` или `/desktop/meetings`. Стенд использует настоящие
шаблоны, стили и JavaScript, генерирует тишину для плеера и хранит тестовое
имя только в памяти процесса. `/test/normal`, `/test/error`, `/test/lost`,
`/test/delayed`, `/test/forbidden`, `/test/deleted` переключают ответы.
`lost` сохраняет имя, но задерживает ответ на 17 секунд; после тайм-аута Esc
должен перечитать подтверждённое имя, не менять плеер. Для конфликта открыть
две вкладки до первого сохранения. Контроль реальной базы — отдельный
`run_local_postgres_tests.sh`, этот стенд его не заменяет.
