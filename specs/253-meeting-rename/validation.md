## Интерфейс на синтетических данных

Использован [meeting_rename_ui_harness.py](../../apps/server/tests/fixtures/meeting_rename_ui_harness.py):
настоящие шаблоны, CSS и JS; имя хранится в памяти процесса, плеер получает
сгенерированную тишину. Этот стенд не заменяет серверные тесты выше.

- Клик по заголовку → ввод → Enter; Tab/уход фокуса; Esc до отправки.
- Неизменённое поле: **0 POST**; Enter с последующим Tab: **1 POST**,
  проверено по событиям сети браузера.
- При успехе ошибка скрыта, подписи/кнопки сохранения визуально отсутствуют;
  объявление результата доступно через `aria-live` только экранному диктору.
- Перезагрузка, возврат к списку, новое название в карточке списка;
  сохранение перед переходом по внутренней ссылке.
- Две вкладки: конфликт сохраняет черновик; blur не перезаписывает;
  Esc принимает актуальное имя.
- Потерянный ответ после записи: поле немедленно readonly, Esc при pending
  игнорируется; после тайм-аута видна ошибка. Esc перечитывает новое имя,
  карточка и плеер не заменяются.
- Отзыв доступа: редактор и приватная карточка убраны, остаётся безопасный
  переход к списку, повторная запись не предлагается.
- Устаревший ответ htmx, начатый до переименования, не возвращает старое имя.
- Синтетический `KeyboardEvent(isComposing=true)` не вызывает POST.
  Полноценная системная IME-сессия не проверялась: браузерный инструмент
  не поддерживает `Input.imeSetComposition`.
- JavaScript выключен через средства разработчика: поле доступно, Enter
  отправляет обычную форму и показывает новое имя; JS затем включён обратно.
- Проверены светлая/тёмная тема, ширины **320/390/768/1440 px**, увеличение
  страницы **200%**. Горизонтального выхода за экран нет. Название из
  500 символов не обрезается; высокая шапка прокручивается, обычная закреплена.
- Клавиатура и доступные имена проверены через DOM/AX. Полный ручной проход
  VoiceOver и физическое мобильное устройство не проверялись. Эмуляция
  `Input.dispatchTouchEvent` недоступна в текущем браузерном инструменте;
  редактор использует обычную HTML-кнопку, без действий только по наведению.
- В консоли тестовой страницы ошибок JavaScript не обнаружено.
