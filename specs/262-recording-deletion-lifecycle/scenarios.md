## Что должно быть видно в приёмке

По каждому сценарию: начальное состояние, событие, конечная строка/фокус, native operation state, серверный receipt/epoch, локальный результат файлов и отсутствие нового server identity. Для гонок нужен управляемый порядок двух операций, а не только повторение по таймеру.

Обычный успех удаления не требует от пользователя следить за служебными состояниями. Они раскрываются в существующем отчёте и при проблеме. Рекомендуемый текст основного сценария: одно подтверждение → запись исчезла → краткое сообщение; ожидание сети/подтверждения остаётся явно отличимым от успеха.
