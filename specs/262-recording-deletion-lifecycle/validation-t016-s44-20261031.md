# F262/T016: постоянная автоматическая проверка S44

Дата: 2026-10-31. Issue: #6891. Исходная основа:
`914dc291bf4e3b832c1575b657280f9e1ebbd1b8`.
Порядок: active Spec Kit slice, high-risk-feature; изменение только тестов.
Точный коммит и обязательные проверки GitHub фиксируются в PR.

## Результат

В существующий `mixed-meeting-list.test.cjs` перенесён недостающий постоянный
сценарий S44. Две выбранные серверные записи получают разные индивидуальные
результаты до позднего общего ответа одной native-команды. Принятая запись
и её локальный alias отсутствуют после ответа, устаревшего HTML,
`htmx:afterSwap`, повторной проекции и повторного callback. Отклонённая запись
получает актуальные права через настоящий запрос обновления формы и
синтетический ответ списка: проверены разрешённый и запрещённый варианты.
Проверяются count=1, selection=0, скрытая панель и ровно одна команда удаления.

Существующая pytest-обёртка параметризована: исполняет как прежний recovery,
так и mixed-набор, проверяя код завершения и маркер S44. Новый механизм CI,
зависимости, продуктовый код и контракты не добавлены.

Отрицательные изменения применялись только во временных копиях JS; временные
копии удалены, исходник продукта в worktree не изменён. Первая проба включения
контролов только в обработчике общего ответа не вызвала отказ: актуальное
обновление списка восстановило права. Эта проба не считается отрицательным
доказательством; итоговая мутация ошибочно включала контролы в rejected-проекции
после каждого обновления и была обнаружена тестом.

Локально использован существующий Playwright 1.62.1 из среды Codex;
проектный lock для GitHub содержит 1.63.0. Полное совпадение сред не заявляется.
Два прежних предупреждения pytest относятся к rewrite уже загруженного модуля
и устаревшему использованию httpx в Starlette; ошибок и пропусков нет.

Повторяемые команды из корня, с путём существующих модулей в переменной:

```sh
NODE_PATH="$GRAF_NODE_MODULES" node apps/server/tests/browser/mixed-meeting-list.test.cjs
GRAF_BROWSER=webkit NODE_PATH="$GRAF_NODE_MODULES" node apps/server/tests/browser/mixed-meeting-list.test.cjs
cd apps/server
.venv/bin/python -m pytest -q -o addopts= tests/contract/test_cabinet_static_assets_contract.py
GRAF_BROWSER=webkit .venv/bin/python -m pytest -q -o addopts= tests/contract/test_cabinet_static_assets_contract.py -k recording_deletion_recovery_in_browser
```

## Сходимость и ограничения

Для S44 сопоставлены FR-003/009/011, US4.2, два варианта актуальных прав,
поздний и повторный общий ответ, устаревший HTML, alias, count и selection.
План сохраняет один исполнитель native-команд и существующий JS-контракт.
Применимые принципы II/IV/VI/VII конституции не ослаблены. Новых обязательных
пробелов этого среза не найдено; `tasks.md` побайтово не менялся.

Это дополнение к исторической строке S44 в `scenario-evidence.md`, где поздний
общий native callback ещё указан как непроверенный. Успех относится к
автоматической проверке настоящего cabinet.js с синтетическими ответами.
Реальный native bridge, файловая очистка, backend/RLS и установленный клиент
этими браузерными запусками не принимаются.

S46 — native server-only удаление без локального queue item, долговечная
metadata-only операция и перезапуск установленного клиента — остаётся открытым
в #6891. Остатки T013/T019/T021/T022/T023 и полная F262 не закрываются.
Выпуск, Full CI, развёртывание и замена GRAF Dev не выполнялись.
