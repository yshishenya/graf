## Минимальная дельта

- В существующем mixed-meeting-list после перехода local→server проверяется
  ровно одна команда bridge: localIds пуст, meetingIds содержит server-a.
- Два принятых удаления дают одну оставшуюся local-b, счётчик 1, выбор 0
  и скрытую панель. Это проверяется сразу после старого HTMX-фрагмента,
  затем отдельно после повторной native projection со старыми aliases.
  Неполная серверная выдача сохраняет текст «Найдено: больше 1».
- В recovery исправлено только ожидание «ещё» → «еще» по действующему
  тексту ошибки. Исходное падение воспроизведено до исправления; остальные
  положительные и отрицательные проверки сохранены.
