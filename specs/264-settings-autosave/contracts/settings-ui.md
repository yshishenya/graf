# Единая структура настроек GRAF

Это проект решения, не отчёт о внедрении. Источник композиции: живое наблюдение KRISP 2026-09-13; точные CSS-размеры KRISP не извлекались.

## Общий вид

Постоянное меню слева; один заголовок страницы; колонка до 760 px. Группы разделяет тонкая линия. Между группами 24 px, между строками 12 px; обычная строка не ниже 48 px. Подпись 13–14 px, заголовок группы 15 px, пояснение 12–13 px. Элементы управления от 32 px; зона нажатия переключателя вместе с подписью не меньше 44 px. В продукте переиспользовать текущие цветовые/типографические переменные и общий settings-класс. Цвета: существующие --text, --muted, --line-soft, --accent; светлая тема использует свои значения.

Один switch для включения, один select для одного значения, checkbox для нескольких элементов. Поле поиска — часть выбора: запрос не значение. Кнопки только для действий. Никаких рамок вокруг каждой строки. Подсказка не прячет обязательное предупреждение, но длинное общее объяснение не показывается постоянно.

## Состояния и взаимодействия

- hover: тихая подложка только интерактивного элемента; focus-visible: существующая контрастная обводка.
- dirty/pending: текущий выбор виден, короткий статус «Сохраняем…» у изменённой строки; без глобального баннера.
- saved: «Сохранено», исчезает через 2 секунды. Не появляется без подтверждения.
- error: «Не удалось сохранить» + «Повторить»; при тайм-ауте/потере ответа — «Не удалось подтвердить сохранение», повтор начинается с перечитывания; сообщение связано с полем, озвучивается. Значение не теряется.
- conflict: «Изменено на другом устройстве» + «Обновить» / «Применить мой выбор». Второе действие явно подтверждает применение к свежей версии.
- permission/session: конкретная причина и «Войти снова» либо существующее системное действие. Поля не выглядят успешно применёнными.
- loading: только краткий статус затронутого блока, без ложных доступных значений. empty: одно предложение и доступное действие, если оно есть.
- disabled: подпись/значение остаются видимыми, причина рядом только когда нужна.
- тема применяется сразу как предпросмотр. После ошибки не объявлять её сохранённой; текущий черновик и подтверждённая тема различимы, повтор использует общий путь.

## Клавиатура и размеры

Tab идёт по меню, затем по содержимому. Switch переключается Space, select поддерживает штатные стрелки/Escape/Enter; переключение раздела ставит фокус на его заголовок. Поиск не вызывает сохранения. IME заканчивает ввод до отправки. Ошибка не крадёт фокус при наборе.

На 768 px колонка занимает доступную ширину, меню остаётся штатным. Ниже 640 px поля переносятся под подпись; компактная навигация использует существующее мобильное поведение. На 360 px и при 200% масштабе нет горизонтального скролла. Длинные имена/приложения переносятся, критические действия не обрезаются. Никакой обязательной анимации; prefers-reduced-motion соблюдается.

## Автосохранение и границы

Контракт — US2/FR-003–007 spec.md и data-model.md. Явные действия FR-004 не регистрируются в общей очереди. No-JS FR-011 показывает обычные значения без редактирования и одну короткую причину. Макет демонстрирует композицию и переключение страниц; подтверждение сохранения в нём только иллюстрация, не доказательство серверной записи.

## Вложенные и локальные страницы

Формы способов входа/кодов подтверждения, активные сеансы, закрытие аккаунта, приглашения, подключение календарного поставщика, отключение календаря и вложенные страницы оплаты используют те же заголовки, строки, подписи и статусы. Их явные действия и необходимые последствия остаются на месте; глобальная очередь не перехватывает их submit. Отсутствующая функция KRISP не создаёт новый раздел GRAF.

Редактор формата: имя → назначение → разделы → язык → подробность. Для существующего формата нет Save/Reset; для нового и копии есть «Создать», которое после успеха не повторяет создание при последующем вводе. Escape, крестик и фон используют один путь закрытия: завершить запись или кратко предложить «Остаться» / «Уйти без сохранения». Фокус заперт внутри открытого диалога и возвращается к инициатору после закрытия. Enter в многострочном назначении вводит новую строку; в одиночном поле завершает ввод без случайного создания/закрытия. Составной ввод IME не подтверждается Enter преждевременно.

Резервное окно Mac: «Запись» → массовое правило, поиск, полный реестр; «Уведомления» → разрешение по необходимости, напоминания, время, названия, звук. Используются те же смысловые группы, переключатели/списки и сообщения. В это окно не дублируются Аккаунт, Пространства, оплата и серверные календари. При невозможности локальной записи статус и повтор расположены у изменённой настройки; текущее введённое значение не объявляется действующим правилом до подтверждения store.

Контраст обычного текста не ниже 4.5:1, крупного текста и значимых графических элементов/обводки фокуса — 3:1 в обеих темах. Статус связан с полем через доступное описание; ошибки объявляются один раз без принудительного фокуса при наборе. Ожидание не блокирует ввод в соседних независимых настройках. На ошибке перехода подтверждение ухода показывается только при попытке уйти, без постоянной панели управления сохранением.

## Уточнение при просмотре

По указанию пользователя от 2026-09-13 справочные блоки календаря и сессий удаляются целиком, без скрытого дубля. Настройки календарных фильтров используют те же переключатели, что остальные булевы настройки. Права, сопоставление событий и реальные сообщения об ошибках сохраняются.


## Уточнение после повторного сравнения с KRISP

Все семь страниц используют общий компактный заголовок без вводного подзаголовка. Не дублировать название страницы второй вводной группой. Необходимые пояснения (правило восьми секунд, область личного формата, отключение звука при записи) показываются через существующий `ui.tooltip`, доступный мышью, касанием и клавиатурой. Реальные ошибки и последствия подтверждаемого действия остаются видимыми.

Тариф: сведения и стоимость слева, доступные действия справа; ниже использование, способ оплаты, история. Нет повторного сравнения тарифов и справочного блока «Условия тарифа». Лимиты и запрет повторного платежа сохраняются. Итоги: выбор по умолчанию, личные форматы, встроенные; без повторного заголовка «Форматы итогов». Библиотека использует компактные карточки как в KRISP; существующий каталог и операции сохраняются.

При наличии подключённого календаря список поставщиков раскрывается действием «Добавить календарь»; без подключений он открыт сразу. Диалоги подключения размещены вне сворачиваемой области, чтобы повторное подключение работало и при закрытом списке. Одинаковые имя поставщика и подпись не дублируются.
