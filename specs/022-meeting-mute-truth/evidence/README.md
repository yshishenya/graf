# Meeting-App Mute Truth Evidence

This directory stores metadata-only evidence for feature 022.

Expected files:

- `target-matrix.md`: QA matrix for supported, unsupported, and deferred targets.
- `manual-validation.md`: manual run template for product Pause, Resume, and Stop.
- `test-results.md`: command output summary from the final validation pass.

Evidence rules:

- Do not include raw audio, transcripts, meeting notes, participant speech, signed URLs, credentials, or personal meeting content.
- Store only target ids, status values, timestamps, decision reasons, segment ids, durations, and validation command results.
- Meeting-app mute support must remain unproven unless a future target adapter provides fresh accepted evidence.
