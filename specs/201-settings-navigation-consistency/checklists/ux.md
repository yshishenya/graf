# UX Checklist: Единая информационная архитектура меню GRAF

- [x] Menu order matches FR-001 in browser and embedded surfaces.
- [x] Account and Settings routes are surface-aware and distinct.
- [x] Appearance exposes Light, Dark and System and preserves current selection.
- [x] Troubleshooting has exactly 3 disabled items.
- [x] Documentation has exactly 4 disabled items.
- [x] Support, feedback and Telegram are disabled buttons with no navigation.
- [x] Logout retains POST, CSRF, redirect, Escape and click-outside behavior.
- [x] Quit is enabled only behind the validated embedded bridge; browser does not render the action.
- [x] Disabled items are visibly muted and not mistaken for active actions.
- [x] Wide, narrow and compact rail layouts wrap long profile data without overflow.
- [x] No exact Krisp code, assets or styling is copied.
