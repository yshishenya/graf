## Изменение и границы

Текущий `scripts/dev-harness.py` использует существующий `promote --live`
и одну квитанцию `rollback-required.json`. Дополнительный
`operation.controller_source_sha` закрепляет исходники текущего инструмента
отдельно от неизменной активной версии. Допускается только остановленная
та же active identity с проверенной парой файлов из
`698ebfa5202986f1a681fd46eb4f12e505352ded` по договору
[promotion-recovery.md](contracts/promotion-recovery.md).

Старые исходники, guard запуска и migration preflight не изменяются.
Все мутации выполняет текущий класс; прежний код проверяет исходники и
закреплённый запуск. Перед разрешающим байтом pipe повторяются проверки
квитанции, исходников, lock inode и фактической записи gate-процесса.
Новые команды, зависимости и общий механизм восстановления не добавлены.

Дополнительно общий читатель квитанции сравнивает сохранённую контрольную
сумму прежнего runtime с закреплённой контрольной суммой его checkout.
Новый Git read ограничен той же active identity; обычное переключение
разных версий сохраняет прежнюю проверку исходников.

заменены маркерами; выполняются настоящие исходные проверки, guard и migration

обязательной службы, совместимого отката и разрешений. Только фактические
