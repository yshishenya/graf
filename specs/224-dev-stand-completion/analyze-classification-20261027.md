  app согласованы в contract/data-model/quickstart. Каждый префикс разрешения
  ссылки остаётся внутри своего архива; внешние/битые/циклические пути запрещены.
- Registration → лексикографически упорядоченные existing operational locks;
  соседям O_CREAT запрещён, T010 yield fd сохраняется. Root set/план/полный
  снимок повторяются после каждого ожидания и перед binding.
- Объявленная граница исключения самостоятельных старых писателей не выдаёт
  ps/lsof/Docker snapshot за абсолютную гарантию. При недоказанности — отказ.
