# F224/T009: сохранение неисполняемого описания

Полоса: `high-risk-product`, существующая T009/#7640. Исходная основа:
`c4a742eb9fb3f9c9d62d8c4f6e5b9bd12c0a62c4`. Реальное состояние стенда,
приложение, Docker и production этой проверкой не менялись.

## Результат

Невыбранный metadata-only архив с историческими четырьмя компонентами можно
сохранить без исполнения, переписывания и присвоения. Допуск выбирается по
явным предусловиям, а не после ошибки строгого валидатора. Любой runtime,
журнал схемы или признак восстановления исключает эту архивную область.
Все записанные компоненты проверяются; общие выбранные и живые потребители
продолжают требовать современный полный состав.

До кода уточнены FR-007 и договор state-ownership.md, принят независимый
проектный gate requirements16/0 и infra36/0, выполнен анализ без
CRITICAL/HIGH/MEDIUM и синхронизирована существующая #7640 без новых задач.
Доказательства этапов сохранены в операторском каталоге за27.10.2026:
`f224-preserved-metadata-{design-review,analyze}.md`, `f224-metadata-sync-*.json`.

## Исполняемая проверка

Использованы существующие Python/pytest, временные Git/HOME/state и подмена
внешних воздействий. Новые пакеты не устанавливались.

- RED на исходном коде: настоящий operation_adopt_state отказывает именно
  `manifest component missing: processing_worker`. Временная копия удалена.
- Независимое ревью обнаружило переполнение JSON-числа `1e999`. Восемь
  корректных описаний воспроизвели отсутствие обязательного отказа; короткий
  `parse_float` со штатным `math.isfinite` устранил ошибку.
- Двадцать четыре случая на иначе корректных pointer/manifest проверяют
  переполнение, NaN/Infinity, повторные ключи и вложенные варианты. С отключёнными
  только ограничениями JSON все24 дают ожидаемый RED `DID NOT RAISE`;
  рабочий разбор их отклоняет. Конечные числа ±1.25 принимаются.
- Завершённый journal содержит действительные современные previous/target
  и обе volumes. Его собственная проверка проходит, но исторический active
  затем отклоняется строгим валидатором по processing_worker. Современные
  selected/preserved с завершённым journal проходят и сохраняют оба снимка.
- Итоговая ownership-матрица: **326 PASS**,0FAIL/ERROR/SKIP.
- Ещё **325 PASS** в13 неизменных файлах: harness, adapter, promotion,
  rollback, schema, launch, runtime, isolation, smoke, safety и retention.
  Они выполнены на том же конечном коде; последнее дополнение меняло только
  ownership-тесты. Итог — **651 различная проверка**, без суммирования повторов.

Сохранены журналы/XML `f224-metadata-{red,overflow-red,permissive-red,
final-regressions,reviewed-ownership,journal}` и машинный
`f224-metadata-final-matrix.json`. Из общего XML взяты только325проверок
вне ownership, затем добавлены326из окончательного ownership XML.
Полные идентификаторы уникальны; пропусков и ошибок нет.

Проверяются неизменность полных исходных снимков и inode, отсутствие binding
при отказе, ошибки JSON/полей/компонентов/путей, запрет selected/live исключения,
реальное ожидание lock с изменением metadata/runtime/marker, повтор перед
публикацией, ошибка записи binding и безопасный повтор. Старые guards сохранены.

## Ограниченная сходимость и границы

`speckit-converge` применён к уточнению T009: FR-007/SC-001–003, явные
архивные границы, общие потребители и предусмотренные отрицательные сценарии
сопоставлены с кодом и проверками. Новых неохваченных обязательств в этом
уточнении не обнаружено. Остальные18FR/6SC/13задач сохраняют своих владельцев;
реальные runtime/rollback/TCC/release критерии уже принадлежат
T009/T011/T012/T013 и F249 T038, поэтому задачи не дублировались.
Prerequisite подтвердил F224; before/after-converge hooks отсутствуют.

Process/context/governance, changelog, diff и frozen bootstrap прошли.
Независимый итоговый отчёт `f224-preserved-metadata-code-review.md` хранится
в том же операторском каталоге. Проверки GitHub точного SHA и основы
подтверждаются отдельно в PR; локальные результаты их не заменяют.

Исправление и его слияние не закрывают #7640 или #6180. Обязательны отдельные
доказательства принадлежности выбранного root и исключения писателей,
реальное принятие состояния, единственный GRAF Dev, все службы, отрицательная
остановка, совместимый откат и сохранение разрешений macOS. Архив не получает
права использования. Выпуск и развёртывание в этот срез не входят.
