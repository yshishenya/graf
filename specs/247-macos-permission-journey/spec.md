# F247: Понятная подготовка записи в macOS

Дата: 2026-09-06. Ветка: `codex/247-macos-permission-journey`. Статус: реализовано локально; итоговая проверка T005 ожидает commit/CI.
Источник: пользователь поручил выбрать и реализовать понятный красивый путь без тупиков.
Risk lane: high-risk-product (permissions, capture, onboarding). Umbrella: #6598.

## User Scenarios & Testing

### US1 — Подготовить запись (P1)
Пользователь нажимает «Подготовить запись» и видит одно окно: «Ваш голос» и «Голоса собеседников». Следующий отсутствующий доступ выделен. Уже выданные права пропускаются.
Acceptance: unknown/unknown → явный запрос микрофона → явный запрос системного звука → обе строки готовы → «Готово». Нет автоматической записи из обработчиков настройки.

### US2 — Вернуться после отказа или перерыва (P1)
«Позже» закрывает окно; смена фокуса и перезапуск не открывают его заново. Кнопка подготовки всегда позволяет вернуться. После отказа доступно открытие настроек с подсказкой; возвращение обновляет статус без закрытия окна.
Acceptance: denied → Settings → grant → ready; unknown после запроса → Settings; закрытые Settings → помощь/повторная проверка/Позже.

### US3 — Восстановиться без потери записи (P1)
Недоступный в текущем процессе доступ блокирует новую запись. Проверка и повторный вход доступны. Перезапуск предлагается как способ восстановления, а не как обязательное следствие открытия Settings.
Acceptance: stale → retry → ready; ошибка проверки → помощь; активная запись/завершение → перезапуск недоступен.

## Functional Requirements

- FR-001: Одно нативное окно, две строки, один основной следующий шаг; запросы разрешений только после отдельного нажатия, без цепочки запросов. Настройка открывается по действию пользователя, без автоматических модальных окон при запуске/фокусе.
- FR-002: Статусы granted/unknown/denied/restricted/stale отражают ОС. Локальная история попыток выбирает действие «Настройки», но не подменяет разрешение. История хранится отдельно для текущего bundle.
- FR-003: После Settings статус обновляется автоматически; успех остается видимым до «Готово». Есть ручная повторная проверка и «Позже», включая незавершенный системный запрос.
- FR-004: Подсказка содержит текущее имя/иконку приложения, иллюстрацию переключателя, путь «Конфиденциальность и безопасность → Микрофон» или «Запись экрана и системного звука» с оговоркой о названии в версии macOS. Неуспешное открытие Settings дает ручной путь. Restricted объясняет обращение к администратору. Нет команды сброса TCC.
- FR-005: До согласия допустим только пассивный preflight. Проверка ScreenCaptureKit запускается только при preflight granted и завершается не позднее 8 секунд с возможностью повторить. Параллельные запросы/проверки исключены, поздний результат не восстанавливает отозванное право.
- FR-006: Открытие Settings и unknown→granted сами не требуют перезапуска. Stale дает повторную проверку и необязательный перезапуск; успешная проверка убирает восстановление. Общая ошибка runtime не объявляется отказом в правах без проверки. Перезапуск запрещен при protected work и незавершенном запросе.
- FR-007: Общий путь запуска записи до подготовки сессии проверяет права. При нехватке ручной старт открывает настройку и завершается без записи; detector не показывает модальное окно. Никакой возобновляемой команды записи после grant нет.
- FR-008: Пока настройка открыта, detector start блокируется как временно недоступный. После закрытия действуют прежние правила Всегда/Спрашивать/Никогда и 8-секундный таймер; настройки их не меняют. Интерфейс явно объясняет это поведение.
- FR-009: Клавиатура, VoiceOver, системные цвета светлой/темной темы, текстовые статусы помимо цвета, прокрутка при нехватке высоты. Иллюстрация не притворяется рабочим переключателем ОС. Текст: GRAF не сохраняет видео экрана; не обещает получать звук исключительно выбранного приложения.
- FR-010: Без новых зависимостей, прав Accessibility/Full Disk Access, аудиодрайверов, тестового захвата, изменения протоколов/сервера. Не сохранять аудио или содержимое встреч в доказательствах.

## Success Criteria

- SC-001: Все ветки US1–US3 имеют доступное следующее действие или выход; успешная настройка требует только двух отдельных действий запроса и подтверждения «Готово», за исключением действий macOS.
- SC-002: Автотесты подтверждают отсутствие автоматического запроса, ложного restart и потери ручного входа; проверка статуса ограничена 8 секундами.
- SC-003: Нативные макеты initial/settings/ready/recovery проверены визуально; доступность и реальные TCC-сценарии перечислены отдельно с честным статусом, без выдачи синтетического теста за проверку реальной ОС.

## Edge Cases

Нет микрофона; все права уже выданы; отказ; управляемый Mac; нет окна системного запроса; закрытые Settings; другое имя GRAF Dev; отозванное право; ошибка/таймаут ScreenCaptureKit; повторный клик; закрытие окна во время запроса; активная запись; старая копия приложения; малый экран.

## Assumptions / Scope

macOS 14+ согласно Package.swift. Системные названия зависят от версии ОС. Состояние разрешений локально. Правила автозаписи сохраняются согласно конституции. Clean-install TCC и реальные OS dialogs требуют отдельного ручного acceptance на тестовом Mac; не менять текущие пользовательские разрешения.
