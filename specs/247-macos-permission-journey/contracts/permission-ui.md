# UI contract F247

- Presentation: немодальная страница главного NSWindow; незавершённая настройка продолжается после Quit/Reopen. Позже/Готово очищают намерение.
- Progress: два компактных шага «Ваш голос» и «Собеседники»; готовность показана галочкой и доступным текстом. Только следующий отсутствующий доступ раскрыт.
- Initial microphone: цель «Чтобы вас было слышно», причина — сохранить вашу часть разговора; CTA «Продолжить», рядом пояснение о следующем системном запросе.
- System audio: цель «Теперь — собеседников»; звук с Mac, без сохранения видео экрана; отдельный CTA «Продолжить». Уже полученное разрешение не спрашивается заново.
- Settings: одно основное «Открыть настройки»; короткие действия найти текущую копию GRAF, включить переключатель, вернуться. Название системного раздела видно там, где нужно его искать. Иллюстрация помечена как пример, не интерактивна. Перед передачей в System Settings объяснён системный перезапуск и продолжение настройки.
- Busy request: «Ответьте на запрос macOS»; busy probe: «Проверяем, всё ли готово…». Повторные действия заблокированы, выход доступен.
- Recovery: «Проверить ещё раз» — основной путь. Дополнительные способы восстановления, перезапуск и ручной повтор запроса под «Не получается?». Protected work и busy сохраняют запрет перезапуска.
- Restricted: объяснение ограничения этого Mac, помощь администратора и основной выход «Вернуться в GRAF»; повторная проверка доступна в помощи.
- Ready: «Всё готово к записи»; что делать на встрече; отдельное упоминание сохранённых правил автозаписи; CTA «Готово» без запуска записи.
- Footer: «Пока настраиваем звук, запись не идёт. После выхода действуют ваши правила автозаписи».
- Accessibility: системные цвета, текстовые статусы, клавиатура, Escape=Позже (включая ready), основные действия не ниже 44 pt, прокрутка содержимого и постоянно доступный выход. Не выдавать дерево доступности/снимки за полную VoiceOver приёмку.
- Автозапись: текущий ask закрывается без skip и получает retryable; setup/request/probe временно блокируют старт. После выхода прежние правила и новый полный 8-секундный отсчёт.
