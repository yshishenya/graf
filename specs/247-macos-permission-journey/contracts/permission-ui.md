# UI contract F247

- Initial: Подготовим GRAF к записи; 0 из 2; две строки. Активна первая missing, единственная CTA «Продолжить» с пояснением о системном запросе.
- Help: «Включите [actual app]»; системный раздел, app icon/name, схематическая иллюстрация включенного тумблера с подписью «Пример в настройках macOS». Нажатие иллюстрации ничего не меняет.
- Denied: «Открыть настройки macOS», «Проверить снова», раскрываемая помощь и «Позже».
- Restricted: понятное ограничение администратора; можно проверить снова или выйти.
- Busy: индикатор проверки/ожидания macOS; повторный запрос запрещен, выход доступен.
- Ready: «Всё готово к записи», обе отметки, «Готово»; не запускает запись.
- Recovery: «Не удалось проверить доступ»; retry, помощь, необязательный restart только без protected work. Открытие Settings не требует restart.
- Footer: «Настройка сама не запускает запись. После завершения настройки автозапись работает по вашим правилам».
- Entry: «Подготовить запись» вместо неактивного Record при missing; доступен и при закрытом страница; действующие запись/переходы защищены.
- Автозапись: закрыть имеющийся prompt без skip, отметить retryable; пока страница/request/probe — route not ready, queued decisions блокируются. При закрытии нормальный повторный prompt имеет 8 секунд.
- Accessibility: осмысленные labels и IDs, keyboard default на активном действии, escape=Позже, статус словами; иллюстрация не интерактивный Switch; системные цвета/прокрутка.

- System restart: обычная страница без модального сеанса; разрешён внешний Quit. После запуска незавершённая настройка остаётся открытой, права проверяются заново; никаких автоматических запросов или возобновляемых команд записи. Позже/Готово завершают настройку.
