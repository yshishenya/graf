# Data Model: Safe macOS App Updates

This feature adds no meeting-data persistence or database schema. The model is an in-process presentation and safety state layered over Sparkle-owned updater state.

## AppUpdatePresentation

| Field | Type | Required | Rules |
|---|---|---:|---|
| `phase` | enum | yes | One of `unavailable`, `idle`, `checking`, `current`, `available`, `deferredForCapture`, `downloading`, `readyToInstall`, `installing`, `failed`. |
| `availableVersion` | string | no | Present only for `available`, `deferredForCapture`, `downloading`, `readyToInstall`, or `installing`; copied from a validated appcast item; never used as executable input. |
| `isUserInitiated` | boolean | yes | Distinguishes manual/menu/sidebar checks from scheduled checks for presentation only. |
| `message` | string | no | Short local user-facing status; never contains raw server bodies, URLs with credentials, or private content. |
| `showsSidebarBadge` | boolean (derived) | yes | True only for `available` or `deferredForCapture` when the version is trustworthy and not skipped. |

## ProtectedUpdateWork

| Field | Type | Required | Rules |
|---|---|---:|---|
| `captureActive` | boolean | yes | True for active or paused capture that still owns recording resources. |
| `captureTransitioning` | boolean | yes | True during recording start/stop transitions. |
| `recordingFinalizing` | boolean | yes | True until local recording finalization and required persistence finish. |
| `terminationCleanupPending` | boolean | yes | True while bounded application termination cleanup is pending. |
| `isProtected` | boolean (derived) | yes | Logical OR of all fields. Application replacement/relaunch is prohibited while true. |

## TrustedUpdateRelease

| Field | Type | Required | Rules |
|---|---|---:|---|
| `bundleVersion` | string | yes | Strictly greater than the installed `CFBundleVersion`. |
| `displayVersion` | string | yes | Human-readable CalVer release string. |
| `minimumSystemVersion` | string | yes | Three-part macOS version; initial value `14.5.0`. |
| `hardwareRequirement` | string | yes | Initial value `arm64`. |
| `publicationDate` | RFC 2822 date | yes | Stable release publication time. |
| `releaseNotes` | signed markdown/plain text | yes | Russian user-facing change summary; no private content. |
| `archiveURL` | HTTPS URL | yes | Public, credential-free, versioned, same approved host family. |
| `archiveLength` | integer | yes | Exact byte length used during validation. |
| `archiveSignature` | EdDSA signature | yes | Generated by the approved Sparkle signing tool. |
| `feedSignature` | EdDSA signature | yes | Covers appcast and release notes when signed-feed mode is enabled. |

## ReleaseTrustIdentity

| Field | Type | Required | Rules |
|---|---|---:|---|
| `bundleIdentifier` | string | yes | Must remain `pro.2brain.graf`. |
| `bundleName` | string | yes | Must remain `GRAF`. |
| `installPath` | string | yes | Public/owner-machine validation path remains `/Applications/GRAF.app`. |
| `teamIdentifier` | string | conditional | Required for Developer ID public release; must match the prior public release. |
| `designatedRequirement` | string | yes | New app must satisfy the previous trusted release’s designated requirement. |
| `hardenedRuntime` | boolean | yes | Required for public release. |
| `notarized` | boolean | yes for public release | Must be proven before public catalog publication. |

## State Transitions

```text
unavailable -> idle                 trusted bundle configuration becomes available
idle -> checking                    scheduled or user-initiated check starts
checking -> current                 no newer compatible release
checking -> available               validated newer release and no protected work
checking -> deferredForCapture      validated newer release while protected work is active
checking -> failed                  retryable or configuration/trust failure
available -> deferredForCapture     protected work begins before installation/relaunch
deferredForCapture -> available     protected work ends; cached offer can be shown
available -> downloading            user chooses install and the archive download starts
downloading -> readyToInstall       authenticated archive download completes while protected work is idle
downloading -> deferredForCapture   authenticated archive download completes while protected work is active
readyToInstall -> installing        Sparkle reaches the installation/relaunch boundary while protected work is idle
installing -> deferredForCapture    relaunch boundary arrives while protected work exists
deferredForCapture -> installing    protected work ends and retained install continuation runs
available -> idle                   user skips this version
available -> available              user dismisses; badge remains as gentle reminder
any configured phase -> unavailable trusted configuration becomes invalid
```

## Invariants

- `showsSidebarBadge` is never true for an untrusted, malformed, skipped, current, or unavailable release.
- At most one retained install continuation exists.
- The continuation is invoked at most once and only after `isProtected == false`.
- Update state never owns or mutates capture state.
- No field contains raw audio, transcripts, meeting titles, account identifiers, credentials, private keys, or signed private URLs.
