# Contract: Clean-Room Reference Comparison

Feature: `035-mvp-loop-live-evidence`

## Allowed Content

- Generic IA/product lessons such as discoverability of meeting list, transcript
  timeline, recording controls, upload/review states, and share/governance
  affordances.
- Intentional 2brain differences: original naming, copy, color, spacing,
  layout, icons, and native/web boundaries.
- Notes about future UX polish required for launch confidence.

## Forbidden Content

- Copied Krisp copy, brand colors, icons, layout, or visual assets.
- Private Krisp screenshots unless separately scrubbed and approved as
  commit-safe.
- Private account names, emails, meeting titles, transcript text, or recordings.
- Claims that the interface is accepted solely because it resembles Krisp.

## Result Values

- `pass`: reference lessons are documented and brand-distance checks pass.
- `needs_polish`: no forbidden similarity, but product quality gaps remain.
- `blocked`: forbidden similarity or unsafe reference content is present.
