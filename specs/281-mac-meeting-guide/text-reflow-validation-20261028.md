## Причина и исправление

Прежняя проверка увеличивала на `/guides` только текст шапки, поэтому
не замечала длинных слов заголовка и карточек. Настоящие шаблоны теперь
берутся из всего `PUBLISHED_CONTENT_PATHS`; существующий браузерный тест
сохраняет прежние клавиатурные проверки и отсутствие JavaScript.
Все исходные computed font sizes снимаются до изменения, затем удваиваются
без накопления наследуемого масштаба. Настоящий локальный Onest обязателен;
внешняя сеть заблокирована.

Новый тест на прежнем CSS воспроизвёл отказ:
`/guides width=320 text=2 overflow=471`, pytest1 FAIL. После этого добавлена
одна строка `overflow-wrap:break-word` для `.guides-intro,.guide-card`.
Переносится только не помещающееся слово; размеры шрифта не уменьшаются.
Это исходный срез до следующего отказа CI; дополнение ниже описывает
последующее исправление строки карточки.
