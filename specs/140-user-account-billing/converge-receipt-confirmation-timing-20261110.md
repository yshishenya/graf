# T075/T077 — время подтверждения чека

Под блокировкой счёта GET платежа и отдельный GET чека оплаты записывают
одну историю времени в `receipt_registration_timing`. Появление ID не
создаёт вторую запись. Для чека возврата время сохраняется в его карте
после проверки связи с подтверждённым возвратом. Запись отдельного чека
происходит после закрепления ID. Время берётся из PostgreSQL после проверки
ответа; состояние, ключ и время используют одну транзакцию.

Для нового `pending` сохраняется время первого принятого подтверждения.
Для старого `pending` оно задаёт нижнюю границу наблюдения, а исторический
возраст остаётся неизвестным. Терминальное состояние не синтезирует дату
начала. Новый подтверждённый `canceled` сохраняет основание с тем же сроком,
даже если старый статус уже был `canceled`. Повтор не меняет основание;
без проверенной связи нового факта нет.

Покрытие: первичная покупка при отмене регистрации, поздний GET без повторной
оплаты, оба порядка GET чека и платежа, повтор, старый `pending` и старый
`canceled`, отдельные возвратные чеки и транзакционный откат. Хранящееся
основание не ставит новое клиентское письмо. Проверка порога 72 часов,
ограниченный опрос, передача в O16 и проверка в тестовом магазине остаются
в T074/T075/T077; #4928, #4930 и #4932 остаются открыты.
