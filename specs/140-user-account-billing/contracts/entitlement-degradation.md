# Contract: entitlement and degradation

## Commercial enforcement boundary

Paid `Личный` enables unlimited commercial meeting/minute/transcription/AI use but not unlimited storage. It cannot disable local Record/Stop, visible capture, local custody, meeting deletion or allowed export. Technical size/concurrency/rate/safety/fair-use ceilings remain independent and cannot be raised by purchase.

## State-to-experience mapping

| State | New paid server actions | Existing data | User recovery |
|---|---|---|---|
| Free | 18 000 exact accepted seconds per Moscow calendar month; 250 MB normalized playback | normal under published retention | start eligible trial / choose plan / wait reset / delete data / process without archive within seconds quota |
| Trial Личного | unlimited core dimensions for 7 days after explicit once-only activation; 500 MB normalized playback | normal under published retention | choose paid cycle before exact trial end |
| Active | unlimited core use; 2 GB or 5/20/100/500 GB total add-on capacity | normal | manage plan/method/storage |
| Cancel scheduled | unlimited through exact paid+bonus cutoff | normal | resume or prepare for Free capacity |

| Storage full/over-capacity | explicit `Обработать без сохранения аудио` uses bounded transient media; archival upload denied | read/export/delete; no new audio playback artifact | process without archive, delete or buy/restore capacity |
| Fair-use review | only named server capability may be temporarily restricted; no balance/overage | local Record/Stop, history, export/delete unchanged | see reason/review-by, contact support, appeal |
| Usage stale | fail safely per action; never fabricate remaining | unchanged | show freshness/retry/support |
| Provider outage | no new uncertain charge; product uses last confirmed entitlement | unchanged | retry later/status page |

Free metered usage reserves declared whole seconds and commits only unique accepted source ranges in the authoritative Moscow-month window; failed/canceled/rejected/unaccepted ranges release. Trial/paid unlimited dimensions record actual accepted use without commercial deduction. Storage reservation uses exact normalized `meeting-review.m4a` bytes under lock and converges on active validated `TrackArtifact.byte_length`; logical delete releases quota immediately while physical purge/backups remain lifecycle truth. Current and legacy transcription sources are excluded from customer quota but retain lifecycle/verification/purge evidence. Transient processing is explicit on every plan, excluded from archive quota, has no playback artifact and purges on success/failure/timeout. Rebuildable storage projections reconcile against artifact truth; mismatch becomes stale/gap. Jobs accepted before paid cutoff finish; unaccepted queues remain local under the existing seven-day buffer policy.
