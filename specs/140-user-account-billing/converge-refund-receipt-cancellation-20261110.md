# T075/T077 — подтверждённая отмена чека возврата

В рабочем GET чека возврата результат с совпавшим ID связывается с ранее
наблюдённым успешным возвратом и исходным счётом. При несовпадении
сохранённого магазина или среды со средой запроса обработчик оставляет
событие на повторную сверку, не меняя счёт. Старый счёт без полной привязки
сохраняет прежнюю проекцию; основание для реакции из неё не выводится.

Если отмена подтверждена для связанной операции, в метаданных именно этого
чека сохраняется основание с временем PostgreSQL после проверки ответа и
сроком, равным этому времени. Входящий timestamp вебхука не используется
для основания. Повтор не меняет его; запись входит в ту же транзакцию, что
и обновление состояния. Откат до commit не оставляет основания. Клиентская
очередь писем не пополняется.

Проверены три варианта привязки, откат после flush, повторная обработка
через новую сессию и отсутствие клиентского письма. Остаток R1–R6:
сквозная проверка уникальности привязки между счетами, единый переход для
GET платежа и его чека, часы ожидания, ограниченный опрос, передача в O16,
проверка фактической доставки и тестовый магазин. T074/T075/T077 не закрыты.
