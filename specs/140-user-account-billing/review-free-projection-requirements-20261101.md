- `billing/renewal_charge.py`769–908: оба единственных найденных writer action

  reason_code допускает NULL, created_at в миграции не имеет nullable=False;
  server_default=now(). ORM type не принят за доказательство NOT NULL.
- `cli/billing_monitoring.py`66 фиксирует as_of до создания connection;
  READ ONLY REPEATABLE READ задаётся до hooks. Поэтому строка ≥as_of
  может законно попасть в видимый снимок. `billing/database.py` проверяет
  реальные session_user/current_user, row_security и запреты superuser/BYPASSRLS.
- `billing/monitoring.py`147–186 сохраняет guard и общий as_of;
  free_projection пока заглушка. `_source`75 — current_state, поэтому
  реализация обязана явно построить новый event_window по P1, сохранив
  остальные семейства. План это предусматривает.
- `billing/usage.py`24–31 строит месяц; план явно запрещает использовать
  этот helper для дня. Две локальные полуночи нужны и для исторической зоны.
