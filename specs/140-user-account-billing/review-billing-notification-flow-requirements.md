| Пункт | Вывод по исходным требованиям |
| --- | --- |
| CHK001 | План T068 называет пять событий и сохраняет остальные случаи в открытой T068; #7524 отдельно отвечает за реальную почту. Исходный перечень T068, FR-070 и §5 quickstart не сужаются. |
| CHK002 | Уточнения F140 §«неизвестный результат при окончании периода» и §«подтверждённый отказ → Free» разделяют неопределённость, итоговый отказ и сообщение о попытке. Номер платежа может отсутствовать у неизвестного исхода, но нужен для связанного подтверждённого отказа. F278 FR-014 запрещает новую попытку при неопределённости; F278 FR-041 сохраняет оплаченный срок при подтверждённых деньгах после отзыва. Старое правило `Charged after refusal → Free` не применяется: это закреплено в F140 §Scope Summary и `analysis.md` (M2). |
| CHK003 | F140 §Actors and Authority, US9, FR-070/072, план T068 и матрица `notifications-support.md` определяют плательщика, обязательную доставку при выключенной необязательной почте и уникальность по событию/получателю/каналу/версии шаблона. |
| CHK004 | После уточнения план T068 требует `pending / 0` до опроса; отдельная сессия при вызове транспорта видит сохраняемый захват `failed / 1 / postal_outcome_unknown`. После ответа сохраняется `delivered / 1` без ошибки с `delivered_at`. Идентичность и данные события неизменны, повторный запуск не вызывает транспорт снова. Все признаки наблюдаемы; `delivered` здесь означает результат подставного транспорта, а не получение реального письма. |
| CHK005 | План T068 сохраняет настоящие очередь, RLS и рабочий обработчик, заменяет только внешний почтовый транспорт, ограничивает опрос и исключает реальные данные, письма, деньги и изменения продуктового поведения. Это согласуется с F140 FR-075/077/078, quickstart §Safety and prerequisites и конституцией §§III/VI. |
| CHK006 | План T068 и `tasks.md` оставляют T068 открытой, связывают PR через `Refs #4922` и проводят независимое ревью до анализа, сверку задачи до реализации, профильный прогон до проверки полноты, обязательные проверки GitHub на точной версии исходников и базе.
