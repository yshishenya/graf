# UX Requirements Checklist

- [x] First-time verified target shows a separate visible prompt window.
- [x] Prompt states that recording will start automatically and exposes remaining
  time as text and accessibility content.
- [x] Prompt retains immediate start, Skip and target-scoped opt-in controls.
- [x] Start/stop and blocked states remain recoverable and truthful.
- [x] WebKit email verification remains in the same embedded session and returns
  to the meetings view.
