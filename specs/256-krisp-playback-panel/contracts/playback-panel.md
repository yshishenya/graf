# Контракт проигрывателя и спикеров F256

Источники: [spec.md](../spec.md), [handoff.md](../handoff.md),
[reference-contract.json](../reference-contract.json). Исполняемые действия
проигрывателя: C01, C02, C05–C17. Ножницы и их переходы отложены владельцем.

## Источник состояния

Один существующий HTML audio и серверная модель доступного медиа остаются
источником времени, скорости, паузы и ошибок. Канонические реплики содержат
speaker_key, start/end и source_segment_ids; клиент не создаёт новую диаризацию.
При обновлении основного содержимого встречи навигация читает живые элементы
расшифровки; сохранённый audio не заменяется ради смены имени или итогов.
Нет новых внешних сервисов, HTTP-маршрутов, базы настроек или зависимостей плеера.

## Переходы

| Команда | Результат |
|---|---|
| Play / Space | Запустить audio; значок Playing только после play event |
| Pause / Space | Пауза без потери позиции |
| −15 / +15, ← / → | Один сдвиг на15 s, ограниченный [0,duration] |
| Next / Shift+→ | Первая каноническая реплика строго позже позиции |
| Shift+← | Последняя каноническая реплика строго раньше позиции |
| Скорость | Меню0.75/1/1.25/1.5/2; выбранное значение, время сохраняется |
| Цветной сегмент | Начало связанной канонической реплики, прокрутка, подсветка2 s |
| Пустая часть дорожки | Время по X; клавиатура меняет позицию явно, без прыжка в середину |
| Аватар | Сброс Listen на всех, следующая реплика этого человека, play |
| Нет следующей реплики | Позиция сохраняется; без циклического перехода |
| Конец аудио | Пауза, позиция0, единое обновление значка и шкалы |
| Escape | Закрыть открытое меню и вернуть фокус его кнопке |

Сочетания не обрабатываются в input/textarea/select/contenteditable, модальном
окне и меню. Native range сам владеет своими стрелками. Клавиша не вызывает
одновременно native действие и общий обработчик. При отказе play показывается
существующая ошибка; состояние не выдаётся за Playing.

## Listen

Пустой Set означает всех. Выбор одного или нескольких начинает прослушивание,
снятие последнего возвращает всех. Счётчик и выбранные checkbox отражают Set;
остальные дорожки имеют opacity0.4 и доступное текстовое состояние.
Интервалы выбранных людей сортируются и объединяются при перекрытии/соприкосновении.
Во время воспроизведения паузы до следующего разрешённого интервала пропускаются.
После последнего разрешённого интервала воспроизведение останавливается без
повторения звука и зацикливания; включение всех возвращает обычное поведение.
Объединение пересчитывается при смене выбора, не на каждом timeupdate.

## Геометрия и доступность

Панель сохраняет строку CSS Grid из F205. Кнопки32×32, SVG20×20, шкалы5 px,
строки33 px, минимальная видимая полоса1 px при реальном проценте длительности.
Палитра вычисляется до сортировки дорожек по доле речи. Карусель спикеров
доступна от788 px; узкая компоновка сохраняет все основные действия без
горизонтального переполнения. Порог992 px проверяется отдельно.
Имена, названия кнопок и ошибки локализованы на русский; собственные SVG и
существующие шрифты GRAF, без извлечённых ресурсов Krisp.

Кнопка сворачивает только дорожки, сохраняя общую шкалу и управление.
Ручка на верхней границе изменяет высоту; минимум — доступная строка,
максимум ограничен viewport с сохранением содержимого встречи. ↑/↓ изменяют
высоту, Home/End выбирают границы. Последняя развёрнутая высота хранится только
в живом экземпляре панели. Collapse≤500 ms, opacity≤100 ms;
prefers-reduced-motion отключает анимацию. При одном спикере доступны
воспроизведение, навигация и управление дорожкой; лишний выбор людей скрыт.
При отсутствии речи не отображаются вымышленные дорожки.

## Проверка

Все команды проверяются на синтетическом audio с известными репликами,
перекрытием, паузами и концом записи. Требуются проверка отказа play,
однократного шага стрелками, актуальной расшифровки после замены main,
сохранения audio при переименовании, неизменности цвета после сортировки,
ширин390/768/787/788/991/992/1440, тёмной/светлой темы и масштаба200%.
Геометрия допускает2 px отклонения; seek —100 ms. GRAF Dev проверяется отдельно
через штатный harness после разрешённого коммита. Имитация embedded в браузере
не выдаётся за проверку установленного приложения.
