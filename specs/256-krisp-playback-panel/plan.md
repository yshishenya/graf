# План F256: основная панель без ножниц

**Ветка:** `codex/256-krisp-playback-panel` · **Дата:** 2026-09-08
**Спецификация:** [spec.md](spec.md) · **Режим:** `high-risk-product`
**Статус:** первый этап реализован после checklist, tasks, analyze и issue sync;
независимое ревью пройдено, завершаются проверки итогового PR. Ножницы отложены.

## Summary

Переиспользовать один HTML audio, общий renderer и канонические реплики GRAF.
Первый этап содержит US1–US3: проигрывание, меню скорости, навигацию, выбор
спикеров, дорожки, изменение высоты и комментарии. US4, ножницы, Share highlight,
серверное удаление диапазона и FR-019 перенесены на следующий этап пользователем.
Исследование полного образца сохранено; отсутствие ножниц — объявленное изменение
объёма. Новые изменения захвата и распознавания не нужны.

## Technical Context

- Языки: Python>=3.13, существующий JavaScript и CSS; без нового frontend framework.
- Зависимости: текущие FastAPI/SQLAlchemy/PostgreSQL, Jinja и HTML audio.
- Хранение: проигрыватель — состояние живой панели; комментарии — Postgres/RLS.
- Платформы: web и один GRAF Dev через существующий встроенный кабинет.
- Проверки: pytest, существующий Node/Playwright harness, PostgreSQL RLS,
  Chromium/WebKit, отдельная проверка GRAF Dev после разрешённого коммита.
- Производительность: объединять интервалы при смене выбора; не пересчитывать
  объединение и не заменять audio на каждом событии. До10 тыс. интервалов в
  синтетической проверке без зацикливания; комментарии выдаются страницами≤100.
- Геометрия: допуск2 px, seek100 ms; ширины390/768/787/788/991/992/1440,
  масштаб100/200%, обе темы, reduced motion.
- Release gate: focused проверки для diff, затем exact-SHA governance-fast для PR.
  Full CI — перед выпуском; production и публикация не входят в эту реализацию.
  Коммит требует отдельного согласия пользователя после проверок.

## Архитектура и порядок

1. Разметка/стили панели: сохранить F205 grid, общий audio, статус доступности,
   реальную длину полос, палитру до сортировки. Собственные SVG через `_ui_icon`.
2. Состояние проигрывателя: скорость через меню, next/previous по каноническим
   репликам, Set выбранных людей и объединённые интервалы. Клавиатура не мешает
   полям и native range. Текущие error/permission/replacement fences сохраняются.
3. Комментарии: защищённые маршруты и три таблицы (комментарий, упоминание,
   реакция), существующие grants получают явные can_comment/can_edit с
   default=false. Старые разрешения не расширяются. Нет отдельного realtime
   сервиса, очереди или таблицы обсуждений.
4. Форма комментария и боковая панель: plain text, якорь времени/реплики,
   ответ, изменение, реакция, resolve/reopen, фильтры, ссылка без выдачи доступа.
   Упоминание создаёт только внутреннюю нейтральную карточку уже допущенному
   человеку. Полное удаление/слияние аккаунтов учитывают новые сущности.
5. Независимая проверка, исправления, focused regressions, визуальная матрица,
   converge и owned changelog fragment. Коммит/Dev promotion — после согласия.

## Ограничения исследования

Серверный механизм ножниц, точные границы слов и работа с неполными метками
сохранены в [trim-reverse-engineering.md](trim-reverse-engineering.md) как
исследование следующего этапа. Они не влияют на выпуск проигрывателя.
Неизвестные детали эталона (fallback последнего аватара, persistence resize)
получили явный контракт GRAF: без циклического перехода, состояние только
живой панели. Недоказанный backend Krisp не используется как источник ACL.
