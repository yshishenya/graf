# Серверные связи панели F256

2026-09-08. Исследование существующего кода, без изменения реализации.
Предложения ниже требуют проверки требований; это не готовые функции GRAF.

## Повторное использование

- Общий HTML renderer и `initPlayback` обслуживают web и macOS. Сохраняются
  существующие `_ui_icon`, палитра, канонические проценты и переименование без
  пересоздания audio. Новая клиентская платформа не нужна.
- `cabinet/access.py:decide_meeting_access` определяет владельца, workspace,
  действующие grants, сроки и полный/ограниченный доступ. `can_comment` сейчас нет.
- `api/cabinet.py:_authorized_shared_meeting` проверяет внешнего получателя в
  контексте workspace владельца. Все операции содержимого обязаны следовать ему.
- `processing/fences.py:lock_meeting_fence` задаёт порядок блокировок и защиту
  от удаления. `cabinet/meeting_titles.py` уже использует optimistic version / 409.
- `MediaRevision` неизменяема после принятия. `ProcessingResult` связан с реальным
  workflow и source fingerprint. Нельзя вручную изготовить фиктивный ready result.
- `normalization/media.py` содержит ограниченный запуск FFmpeg, probe/decode/hash;
  `normalization/service.py` — проверку скачанного и загруженного объекта.
- Temporal и существующий MediaScribe workflow обеспечивают длительную обработку.
  Новая очередь или realtime-сервис не нужны.

## Комментарии

Готовых comments/replies/mentions нет. Минимально нужны MeetingComment и связь
упоминаний; отдельная таблица тредов не нужна. Поля: meeting/workspace/author,
media revision, необязательные result/segment, start/end в миллисекундах,
корневой parent, текст, version, клиентский ключ повторной отправки.

Каждое изменение проверяет доступ заново, CSRF, текущую media revision, parent и
source принадлежность той же встрече. Автор изменяет свой комментарий; право
модерации чужих сообщений не выводится из can_share. RLS обязателен.
Emoji хранится как Unicode, HTML не принимается. Упоминание не выдаёт доступ.
Существующий search_share_recipients — кандидаты на предоставление доступа,
а не список разрешённых адресатов упоминания: нужен дополнительный access filter.

Полное удаление физически очищает текст и mentions в deletion/service.py.
Новые author FK нужно включить в auth/account_merge.py и account close.
Тексты комментариев не добавляются в AI/Temporal/Langfuse автоматически.
ServerNotification сейчас допускает только result/share; для уведомлений
комментариев нужен явный контракт, существующее share email не переиспользуется.

## Доступ к диапазону

MeetingShareGrant знает только summary_only/full_meeting. Public links разрешают
только summary_only. playback_artifact выдаёт полное аудио, включая HTTP Range.
Поэтому start/end в URL могут быть только навигацией при уже полном доступе.
Остановка HTML audio на end не ограничивает получателя выбранным фрагментом.

Если эталон обещает доступ только к highlight, нужен отдельный серверный clip с
границами, source revision, собственным артефактом, ACL и ограниченной проекцией
расшифровки. Срок, отзыв и удаление должны применяться и к clip. Передача
параметров полного медиа под видом защищённого clip недопустима.

## Частичное удаление

LOCAL_TRIM — лишь существующий source_kind, серверного удаления диапазона нет.
Сервис полного удаления нельзя вызвать для части: он очищает всю встречу,
включая grants, имена, итоги и все сегменты.

Минимальный корректный процесс:

1. Сохранить устойчивую операцию с исходной media/result revision, fingerprint,
   диапазоном `[start_ms,end_ms)`, idempotency key, deletion epoch и состоянием.
   Под блокировкой проверить owner, актуальность и отсутствие конкурирующей операции.
2. Подготовить новый файл, удалить выбранную часть и соединить остаток. Точная
   обрезка требует decode/re-encode; `-c copy` не гарантирует границы. Проверить
   длительность, полное декодирование и hash, учесть временные объекты для очистки.
3. До принятия новой media revision закрыть выдачу старого содержимого и показать
   обновление записи. Выбор latest accepted используется несколькими consumers,
   поэтому раннее accepted с прежним transcript недопустимо.
4. Построить производную расшифровку с сохранением оставшихся слов и спикеров.
   Прежнее предложение повторного распознавания отозвано после
   [исследования Krisp](trim-reverse-engineering.md). words_json уже сохраняется,
   но необязателен; соответствие каноническому тексту и границы пересечённого
   слова требуют проверки. Неполные метки нельзя компенсировать молчаливым
   изменением текста. Возможность выравнивания готового текста по аудио ещё
   не подтверждена. Производный результат должен иметь реальное происхождение.
5. Удалить контролируемые старые медиа/экспорты/итоги и выдать новый согласованный
   результат. Старые pinned outcomes также закрыть: смены current media недостаточно.
6. Разделять готовность новой записи и подтверждение физической очистки. Сбой
   purge не обозначать успехом; после точки необратимости retry продолжает операцию,
   а не обещает вернуть уже удалённый источник.

Старые source_result_id/segment UUID не заменяются новыми по близкому времени.
Времена до start сохраняются, после end сдвигаются на длину удаления, внутри
становятся недействительными. Текст комментария внутри диапазона может содержать
цитату удалённой речи; судьба корня и ответов требует явного требования.
Имена спикеров сохраняются через происхождение оставшихся интервалов. Новое
распознавание с переносом имён только по provider ID не соответствует FR-019.

Остаток может содержать тишину. Нынешний result_is_complete требует transcript и
diarization, поэтому нужны явные audio-ready/no-speech состояния. Точные границы
опираются на проверенную длительность аудио, не целочисленное duration_seconds.

Границы retained Generation Call ledger, Langfuse, Temporal, backups, внешних
копий и неподключённых клиентов сохраняются по product-gates.md. Их нельзя
объявлять удалёнными только потому, что Krisp показывает успешную обрезку.

## Необходимые проверки

- Роли, RLS, cross-workspace, summary-only, отзыв доступа до POST, CSRF.
- Подмена parent/media/result; duplicate create; stale version / 409.
- Гонки comment/trim/full deletion; старые source/export/HTTP Range/pinned outcome.
- Срез внутри слова, перекрытие, тишина, точная длительность, сбои до/после публикации,
  поздний processing result, остановка worker, возобновление purge.
- Соответствующие существующие наборы: test_meeting_share_links,
  test_rls_meeting_content_policies, test_media_revision_identity,
  test_processing_result_idempotency, test_playback_normalization_deletion,
  test_recording_workflow_deletion_races, test_transcript_export_egress,
  test_deletion_lifecycle_blocks_access и tests/browser/protocol-source.test.cjs.
