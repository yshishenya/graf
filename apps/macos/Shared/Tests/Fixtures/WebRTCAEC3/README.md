# WebRTC AEC3 Metadata Fixtures

These fixtures are metadata-only. They must not contain raw audio samples,
debug WAVs, transcript text, meeting content, participant names, signed URLs,
credentials, tokens, object keys, secret paths, or private local paths.

The lab corpus fixture models the minimum feature-039 promotion gate using
counts and safe scenario identifiers. Runtime/manual captures, if used during
development, must stay outside the repository.
