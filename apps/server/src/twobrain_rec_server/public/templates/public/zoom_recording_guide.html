Как расшифровать готовую запись Zoom в текст

Найдите запись, выберите файл с голосами участников и загрузите его в ГРАФ.

Если встреча уже записана в Zoom, для расшифровки понадобится сохранённый аудио- или видеофайл. Найдите запись, убедитесь, что в ней слышны нужные участники, и загрузите её в ГРАФ. После обработки можно прочитать текст по спикерам с таймкодами и проверить итоги разговора.

Это инструкция для готовой записи. Повторно проводить встречу или воспроизводить её через динамики для новой записи не нужно. Если звонок ещё впереди, начните с руководства по записи на Mac.

В этом руководстве

  1. Найдите файл встречи
  2. Выберите файл со всем разговором
  3. Проверьте возможность передачи
  4. Загрузите запись в ГРАФ
  5. Проверьте текст и итоги
  6. Если что-то пошло не так

1. Найдите файл встречи

Запись сохранена на компьютере

На Mac проверьте папку «Документы» → Zoom. Если файл лежит в другом месте, откройте настройки приложения Zoom: Settings → Recording → Local recording storage. Рядом с Storage location указан путь; Open открывает папку.

Дождитесь завершения преобразования записи в Zoom. Если у встречи отображается Convert, сначала выполните преобразование. Переименование служебного файла в MP4 не заменяет этот шаг. Подробнее: управление локальными записями в Zoom.

Запись сохранена в облаке Zoom

Откройте веб-кабинет Zoom, затем Recordings & Transcripts → Cloud recordings. Найдите встречу и скачайте запись через Download, если у вас есть такое право. Облачная запись должна завершить обработку.

Если организатор прислал только ссылку для просмотра, возможность скачивания зависит от настроек доступа. Попросите его предоставить разрешённый файл или включить скачивание для вас. Не обходите ограничение. См. инструкцию Zoom по скачиванию и доступу.

2. Выберите файл, в котором есть весь разговор

В папке одной встречи могут находиться разные материалы:

  • M4A содержит аудио.
  • MP4 может содержать видео и аудио; для расшифровки нужна аудиодорожка.
  • TXT может содержать чат встречи, а не устную речь.
  • VTT может содержать уже готовую расшифровку облачной записи.

Zoom также позволяет создавать отдельные аудиодорожки участников. Поэтому расширение M4A само по себе не означает, что внутри слышна вся встреча. Эти типы файлов описаны в документации Zoom.

Перед загрузкой откройте выбранный файл в проигрывателе. Послушайте начало, несколько мест со сменой говорящего и конец. Проверьте, что это нужная встреча и запись не оборвалась. Если в папке несколько частей, разберите их порядок и состав до обработки.

Для расшифровки речи удобно выбрать общую аудиодорожку M4A, если в ней есть все нужные реплики. Не нужно передавать видео с лицами и демонстрацией экрана, когда для вашей задачи достаточно звука. Если подходящего аудиофайла нет, можно использовать MP4 с аудиодорожкой.

ГРАФ принимает M4A и MP4 среди форматов загрузки. Повреждённый файл, отсутствующая аудиодорожка или неподдерживаемое содержимое контейнера могут помешать обработке. Одного расширения недостаточно, чтобы гарантировать результат. Если внутри файла несколько аудиодорожек, не рассчитывайте на автоматическое объединение голосов: выберите запись, в которой нужный разговор уже слышен целиком.

3. Проверьте, можно ли передать запись на обработку

Согласуйте использование записи и её обработку выбранным сервисом по правилам вашей команды. Возможность скачать файл не означает, что его разрешено передавать дальше.

Если в разговоре есть закрытые сведения, проверьте требования организации до загрузки. Ознакомьтесь с политикой обработки данных ГРАФ. Обработка загруженного файла не ограничивается вашим компьютером.

4. Загрузите запись в ГРАФ

  1. Войдите в ГРАФ и откройте «Мои встречи».
  2. Нажмите «Загрузить запись». Откроется окно «Загрузить файл».
  3. Перетащите один файл в окно или нажмите «Выбрать».
  4. Сверьте имя и показанную длительность. В поле «Название» укажите понятную тему и дату встречи.
  5. Проверьте переключатель «Сохранить аудио». Если вам нужно прослушивать запись в ГРАФ при проверке текста, оставьте его включённым. Сохраните исходный файл у себя до завершения проверки.
  6. Нажмите «Загрузить» и следите за состоянием встречи в списке.

Передача файла и подготовка расшифровки идут отдельными этапами. Не загружайте ту же запись повторно только потому, что файл уже передан, а текст ещё не появился. Сначала откройте встречу и проверьте её состояние.

Для загрузки и обработки нужен интернет. Доступное хранение и условия использования проверяйте в своём аккаунте; ограничения файла и сообщения об ошибках учитывайте отдельно. Здесь нет обещания определённого времени обработки или приёма файла любого размера.

5. Проверьте текст и итоги

Начните с реплик, от которых зависят дальнейшие действия: имён, сумм, сроков и формулировок согласия. Сверяйте их с исходным звуком и соседними фразами.

Отдельно проверьте авторство. Метка спикера помогает разделить голоса, но не гарантирует правильное имя человека. Если кто-то предложил дату или возможное действие, это ещё не подтверждает договорённость.

Подробный порядок сверки есть в руководстве по проверке качества расшифровки. Для оформления проверенных решений и задач используйте шаблон протокола встречи.

Если что-то пошло не так

Вместо файла у меня ссылка Zoom

Сначала получите файл разрешённым способом. Эта инструкция описывает загрузку файла с компьютера.

В тексте нет одного участника

Сначала послушайте исходный файл. Возможно, выбрана отдельная дорожка одного человека. Если голос есть в аудио, но потерян или неверно подписан в тексте, проверяйте расшифровку. Если голос отсутствует в самом файле, эта запись не даёт основания восстановить его слова.

Файл не выбирается или не загружается

Проверьте, что Zoom завершил преобразование, файл не пуст и воспроизводится. Затем прочитайте сообщение ГРАФ. Не меняйте расширение для обхода проверки. При обращении в поддержку начните с типа файла, его размера и текста ошибки без содержания разговора.

У Zoom уже есть расшифровка?

Для облачных записей Zoom предусмотрена собственная аудиотранскрибация при подходящем аккаунте и включённых настройках. В документации указан и русский язык. Если готового текста достаточно, сначала проверьте его. Условия и инструкция Zoom.

Начните с готовой записи

Загрузите разрешённый аудио- или видеофайл, дождитесь обработки и сравните важные реплики с оригиналом. После успешной обработки в ГРАФ можно проверить расшифровку по спикерам с таймкодами и итоги разговора.
