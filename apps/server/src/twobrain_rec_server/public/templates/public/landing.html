03 / Календарь

Данные Google — только для функций календаря

Как GRAF использует Google Calendar

После подключения GRAF читает список календарей и события только из выбранных пользователем календарей. Эти данные нужны, чтобы показать ближайшие встречи, напомнить о начале и предложить событие как контекст записи.

Только чтение
GRAF не создаёт, не изменяет и не удаляет события Google Calendar.
Без скрытого запуска
Подключение календаря само по себе не начинает запись и не подключает пользователя к звонку.
Под контролем пользователя
