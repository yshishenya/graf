Автозапись для выбранных приложений

Настройте один раз. Встречи запишутся сами

Отметьте нужные приложения один раз. Когда в одном из них начинается встреча, GRAF распознаёт её и запускает запись автоматически. Для остальных сначала показывает запрос.

Ручной старт и остановка всегда остаются доступны.
