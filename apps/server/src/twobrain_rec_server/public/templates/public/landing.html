Автозапись для выбранных приложений

Выберите приложения. GRAF подхватит встречу

Отметьте приложения, для которых нужна автозапись. Когда GRAF замечает встречу, он запускает запись по вашему правилу. Для других поддерживаемых приложений сначала показывает запрос.

Контроль во время встречи

Активная запись всегда видна. Остановить её можно одним действием; ручной запуск тоже доступен.

Контекст из календаря
