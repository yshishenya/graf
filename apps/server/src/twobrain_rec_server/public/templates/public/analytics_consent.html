Какие варианты есть

  • Разрешить все категории.
  • Оставить только необходимые cookies.
  • Настроить категории отдельно.
  • Изменить выбор позже на публичных страницах.

Категории

Необходимые cookies сохраняют выбор. Аналитика включает Яндекс Метрику для публичной воронки. Рекламная атрибуция использует безопасные campaign labels. Поведенческая запись разрешает replay только на / и /download, если включена в конфигурации и выбрана пользователем.

Границы

Публичная аналитика не включается на login, cabinet, meeting, upload, playback, deletion, admin, desktop embedded и других product/content-bearing surfaces. Google, GA4, Google Ads, GTM, PostHog и другие product analytics tools не входят в Phase 1.

Отзыв и изменение

Если выбрать only necessary или убрать analytics category, новые публичные взаимодействия не должны отправлять custom analytics events. Уже загруженный сторонний provider script не используется для новых custom events после изменения выбора.
