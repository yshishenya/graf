# ГРАФ: органическое продвижение на 90 дней

Версия 16.10.2026. Владелец подтвердил аудиторию: руководители и специалисты в России; рекламный бюджет 0. Исходные факты и ограничения: [audit-2026-10-16.md](audit-2026-10-16.md). День 0 — фактический выпуск первого проверенного набора исправлений, дата пока не назначена. План не выдаёт подготовку за публикацию.

## Результат и приоритеты

Нужны люди, которые получают пригодную расшифровку и возвращаются к продукту. Поисковые показы и загрузки установщика — промежуточные сигналы. На старте Google Web показывает 0 кликов / 1 показ за отображённые 28 дней; брать процентный рост с нуля нельзя.

Рабочая гипотеза к дню 90: не менее 30 дополнительных небрендовых переходов за сопоставимые 28 дней и не менее 3 подтверждённых полезных действий из органики, если источник можно законно и надёжно связать с результатом. Это ориентир проверки спроса, не обещание трафика. Если исходная сопоставимая величина окажется ненулевой, отдельно показывать абсолютный прирост и относительный ориентир +30%. По 1–3 случаям не выбирать «победившую» страницу. Цели пересмотреть после 28 дней с работающим измерением.

Порядок: измерение → доступность/индекс → полезность существующих страниц → проверенные новые материалы → внешние упоминания → повторение того, что приводит к результату. Не ставить UTM на внутренние ссылки: они могут переписать источник.

## Видимость в ответах ИИ (GEO)

Цель — чтобы ответы могли точно сослаться на полезную страницу. Базовые требования: доступный HTML, индексация, ясный короткий ответ на вопрос, проверяемый пример, факты об авторе/операторе, дата проверки и источники. Нет обязательной магической длины абзаца или специального «балла GEO». llms.txt не является первоочередным исправлением.

Для каждой инструкции: вопрос → прямой ответ → порядок действий → пример → ограничения → подходящее действие. В сравнении ссылаться на первоисточники конкурентов и датировать сведения. Скриншоты и примеры должны соответствовать продукту; учебный диалог подписывать учебным, реальный результат обработки проверять отдельно.

Ежемесячная ручная выборка: 12 фиксированных вопросов в доступных поисковых режимах ChatGPT, Perplexity и Google. Примеры: «как записать встречу на Mac без бота», «как перевести запись Zoom в русский текст», «как получить решения и задачи из встречи», «как проверить ошибки в расшифровке». Ещё вопросы — про Телемост/Meet только по проверенным сценариям, контроль спикеров, обе стороны звука, платформы, цены и честное сравнение. Записывать дату, страну/язык, продукт/режим, точный вопрос, упоминание ГРАФ, ссылку и точность описания. Эти 12 вопросов не представляют весь рынок и не доказывают причинность.

Отдельно вести: показы в текущем Google AI report (на старте 1), реальные переходы с доменов ИИ и проверенные публичные цитаты. Прямой трафик не переименовывать в «ИИ». Доступ робота по User-Agent не означает цитирование.

Правила действий: нет показов несколько недель → проверить индекс, намерение и внутренние ссылки; есть показы без кликов → посмотреть запрос/позицию/сниппет; есть клики без первого результата → исправить установку, загрузку и ожидания; есть результат без возврата → проверять ценность сценария. Новые статьи добавлять после этого разбора. При низком объёме агрегировать дольше, не объявлять статистическую уверенность без основания.

## Первые два редакционных задания

1. «Как записать и расшифровать встречу в Яндекс Телемосте на Mac». Перед текстом проверить версию приложения, запись обеих сторон, разрешения, вариант готового файла. 2. «Протокол клиентской встречи: как проверить решения, ответственных и сроки». Данные учебные, оригинальная методика явная. При совпадении намерения расширить существующую статью вместо создания ещё одной страницы.
