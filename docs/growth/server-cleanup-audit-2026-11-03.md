## Резервные копии: почему есть большой запас, но пока нет списка удаления

Присутствуют каталоги minio-objects. Их содержимое не читалось и не

У37 прежних комплектов нет нового профиля checksum/inventory. Это прежний
формат, а не доказательство испорченной или бесполезной копии.

Журнал рабочего v2026.11.01.3 связывает backup_result=pass с комплектом
20261101T173314Z. Его checksum-профиль сегодня подтверждён. Этот факт
не доказывает весь цикл восстановления всех классов данных F273.

**Вариант для отдельного решения:** сохранить7 последних каталогов с датами;

точный перечень, защита последней пригодной копии/отката и проверка
