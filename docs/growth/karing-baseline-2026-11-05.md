# Karing: работающий прямой узел — 5 ноября 2026

Проверка существующего клиента по прямому поручению владельца
«посмотри сам и подключи то, что нужно». Сохранение результата — полоса
docs-only / mechanical; это не изменение реализации и не приёмка T098.

## Наблюдения

1. Штатным CUA открыт существующий Karing `com.nebula.karing`. В списке
   Select Server выбран существующий `2brain-9433`, метка `vless`.
   Главный экран показал `Connected` и выбранный узел. Системный прокси
   остался `off`; переключатели сети/правил не менялись.
2. Через Net Check один раз запущен штатный тест с уже установленным
   `google.com`. Готовый результат:
   - `Ipv4 connection succeeded`;
   - `The network is connected to the Internet`;
   - `Rule Set: All downloaded successfully`;
   - Proxy Server: `[kvn.2brain.pro] DNS query succeeded`,
     `[2brain-9433] connection succeeded`;
   - DNS Server: `Proxy Traffic[Current Selected]:[1409 ms]`;
   - DNS: `[google.com] DNS query succeeded`, `DNS Rule:[Proxy Traffic]`.
3. В My Profiles развёрнут имеющийся список; долгое нажатие на узел
   открыло меню с `Disable[vless;kvn.2brain.pro;9433]`. Поэтому9433
   установлен по интерфейсу, а не выведен только из имени. View/Edit/Share/
   Remove не нажимались, профиль/ключи/UUID не открывались и не копировались.
   Меню закрыто; выполнен возврат на главный экран с выбранным узлом.
4. Обычный SSH без sudo подтвердил DNS `kvn.2brain.pro` к адресу общего
   входа сервера. `ss -H -ltn`: публичный443 принимает на этом адресе,
  9433 слушает на wildcard;10444 слушает на loopbackIPv4/IPv6,
  10445 на loopbackIPv4;10446/10447 не слушают. Loopback443 в этой
   описи отсутствует. Nginx/config не читались и не менялись.

## Значение для T098

Работающий настоящий VLESS-клиент и успешная штатная проверка выбранного
прямого узла подтверждены. Прежнее препятствие «не найден клиент/нет ни
одного успешного запроса через выбранный узел» больше не актуально.

Узел использует прямой9433. Эти результаты **не доказывают** VLESS/REALITY
через публичныйTCP443, сохранность старого special→loopback443, параметры
REALITY или полный переход/возврат T098. Диагностика Karing сама предупреждает
о зависимости от правил и сети; состояние TUN и маршрут всего трафика Mac
из этого теста не устанавливались. Нулевые счётчики главного экрана не
использованы как подтверждение продолжительной сессии.

Следующий адресный шаг — сопоставить принятые требования прежнего маршрута
с фактическими443/9433 и определить допустимую проверку перехода/возврата.
Менять порт существующего профиля, создавать новый или менять nginx в этом
проходе не стали. Почтовый baseline/T098, T113, аналитика/T0 и Product Radar
остаются открытыми. Собственный тест не считается внешним посещением ГРАФ.
