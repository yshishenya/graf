# TenChat: проверка после семи полных дней

Проверено 26.10.2026, после 07:27 UTC. Публикация от 19.10:
<https://tenchat.ru/media/6259494-neyroset-sostavila-protokol-chto-proverit-pered-otpravkoy-komande>.

В существующей авторизованной сессии Zen и отдельной гостевой вкладке
показано «Просмотрено 7»; комментариев — 0. Ранее наблюдалось то же число.
Площадка не отделяет в доступном представлении внешние просмотры от наших
проверок. Поэтому семь просмотров не считаются семью привлечёнными людьми;
внешний охват остаётся неизвестным.

В авторизованном тексте есть кликабельная ссылка ГРАФ с UTM; карточка
предпросмотра ведёт на URL без UTM. Гостевой текст показывает адрес, но
кликабельная ссылка ГРАФ не найдена. Проверка DOM гостевой страницы:

```javascript
await tenGuest.playwright.locator('a[href*="rec.2brain.pro"]')
  .evaluateAll(es => es.map(e => ({text: e.textContent, href: e.getAttribute('href')})))
// []
```

В информационном окне «Кто увидит эту запись?» указаны подписчики и темы
«Управление проектами», «Нейросети». Это описание потенциального показа,
не доказательство фактической рекомендации.

| Результат | Доказанное значение |
|---|---|
| Счётчик площадки | 7 просмотров, внешняя доля неизвестна |
| Комментарии | 0 |
| Клики в ГРАФ | Не подтверждены доступными данными |
| Регистрации и оплаты из материала | Не подтверждены |
| Гостевая кликабельная ссылка | Не найдена |

G050 выполнена как проверка завершённого периода. Подтверждённого
привлечения первая попытка не показала; повтор того же формата пока не
обоснован. Одна публикация не доказывает бесполезность TenChat вообще.
Следующий приоритет владельца: выпуск, минимальное достоверное измерение,
затем проверенный формат Product Radar. Новых публикаций, реакций, сообщений
и изменений этого поста в ходе проверки не делали.
