## G038: чтение и путь к входу без аккаунта

10 ноября в 13:48–13:50 UTC в отдельной сессии Chrome на рабочем сайте
проверены `/guides`, руководство по Zoom и руководство по протоколу.
При фактической ширине области просмотра **320 и 390 CSS px** ширина
документа и `body` совпала с областью просмотра на всех трёх страницах.
Это обычный масштаб браузера при заданной ширине, без отдельного смартфона.

| Путь с клавиатуры при ширине 320 px | Наблюдение |
| --- | --- |
| Список → «К содержанию» → карточка руководства | Tab находит ссылку пропуска и обе карточки; Enter переводит к содержанию и открывает выбранное руководство. У ссылки пропуска есть контур фокуса, у карточек применяется подчёркивание `:focus-visible` в `content.css`. |
| Zoom → пункт оглавления `#upload` | Enter открывает раздел «4. Загрузите запись в ГРАФ»; заголовок появился в области просмотра. |
| Протокол → пункт оглавления `#graf-result` | Enter открывает раздел «Проверка настоящего результата ГРАФ». При обычной настройке прокрутка продолжается после изменения адреса: на отметке около 0,8 с заголовок ещё ниже экрана, к отметке около 1,6 с виден. При настройке уменьшенного движения заголовок виден сразу после Enter. |
| Обе статьи → ссылка «Открыть ГРАФ» | `/meetings` вернул 303, `/login` — 200. Показана форма «Войти в кабинет» с полем электронной почты, сохранён путь возврата `/meetings`. Форма не заполнялась. |

Для оглавления протокола положение заголовка прочитано после полной загрузки
страницы и шрифтов. Поэтому мгновенную проверку сразу после изменения якоря
не следует трактовать как отказ перехода. Измерение показывает, что на узком
экране переход к далёкому разделу заметно задерживается в обычном режиме.

Сессия без аккаунта, сторонние запросы и изменения запрещены в браузере.
Запросы помечены как учебные; их серверная классификация не проверялась.
Подтверждена только эта часть G038: две статьи доступны по проверенному
пути до формы входа. Штатный масштаб 200%, другие браузеры, вход, загрузка
файла и остальная редакционная приёмка этим проходом не подтверждены.
