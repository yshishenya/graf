# Evidence: 034 MVP Loop Readiness

Feature: `034-mvp-loop-readiness`

This directory stores metadata-only readiness evidence for the complete MVP loop.
It must not contain raw audio, private transcript text, credentials, tokens,
signed URLs, private emails, live local paths, or private Krisp screenshots.

## Files

- `readiness-report.json`: structured readiness report generated by
  `apps/server/scripts/generate_mvp_loop_readiness.py`.
- `readiness-report.md`: reviewer-facing readiness summary.
- `launch-gap-register.md`: blocker register and next-action list.
- `validation-log.md`: command evidence collected during implementation.
- `screenshots/`: metadata-safe screenshots or blocker notes only.

## Evidence Boundary

The current generated report may prove partial readiness and
`infra_smoke_ready` only. It cannot claim pilot readiness or user rollout
readiness until live desktop/web evidence and remaining P0/P1 launch blockers
are resolved.
