# Clean-Room Reference Comparison

Feature: `034-mvp-loop-readiness`

## Allowed Lessons From Krisp Review IA

- Keep the meeting list as the first product surface after launch.
- Make transcript/playback/provenance discoverable in one review workspace.
- Reserve visible places for notes, assistant, templates, speaker assignment, sharing, export/download, and deletion truth.
- Keep local recording authority outside embedded web content in the desktop app.

## Intentional 2brain Differences

- Native Record/Stop remains a local trust control owned by the desktop shell.
- Web and embedded surfaces use 2brain Rec terminology, layout, and policy copy.
- Public link behavior stays disabled by default and login-controlled.
- Deletion copy describes only what 2brain Rec controls and does not promise external erasure.

## Forbidden Similarity Result

No private Krisp screenshots, assets, icons, brand colors, or long product copy are committed as evidence. The comparison is limited to IA categories and launch-readiness lessons.
