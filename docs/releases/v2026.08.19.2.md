# GRAF `v2026.08.19.2` — компактное меню снова компактное

Дата выпуска: 2026-08-19

Тег: `v2026.08.19.2`

Release SHA: `71ed831e9d6f2661a88e8708ec0d408ffbe8bd8f`

## Что стало удобнее

- Профиль снова виден в компактном левом меню даже на узком окне.
- Кнопки, разделы и профиль больше не съезжают относительно друг друга.
- Настройки используют одну понятную навигацию и одну колонку содержимого — без
  пустого второго меню.
- Меню профиля работает мышью и клавиатурой: Escape закрывает его и возвращает
  фокус на кнопку профиля.
- Страница проверки добросовестного использования снова открывается из
  настроек.
- Правая панель управления macOS стала проще внутри, а её переключатель остаётся
  в одном верхнем положении при раскрытии и сворачивании.

## Что нужно сделать после обновления

Обычно — ничего. Миграции данных и повторная настройка не нужны. Штатное
обновление Developer ID → Developer ID сохраняет уже выданные разрешения macOS.

## Как проверяли

- Полный exact-SHA gate: macOS — `696` тестов; сервер — `3049 passed / 1
  skipped`; strict RLS — `42 passed / 1 skipped`; lint, compile, Compose и
  evidence scan — успешно.
- Production deploy: backup, пробное восстановление, миграции, readiness, smoke
  и фоновые обработчики — успешно; откат не понадобился.
- macOS: Developer ID Application и Installer, universal `arm64 + x86_64`,
  Apple notarization, stapling, Gatekeeper и Sparkle Ed25519 — успешно.
- Установленный production GRAF штатно обновлён с `2026.08.19.1` до
  `2026.08.19.2` без нового запроса разрешений и показал готовность микрофона и
  системного звука.
- Установленный `GRAF Dev` проверен отдельно: production updater отсутствует,
  native-панель раскрывается и сворачивается одной верхней кнопкой без
  перекрытий, accessibility-подписи корректны.

## Совместимость и ограничения

- Миграции пользовательских данных и новые зависимости не нужны.
- Логика записи, транскрипции и генерации итогов не менялась; принятые итоги не
  заменяются автоматически.
- После одного из перезапусков production-приложение показало экран входа с
  `missing_auth_context`. Причина не подтверждена как регрессия обновления; при
  повторении достаточно войти заново, а случай будет отдельно диагностирован.
- Clean-Mac first-grant не повторялся: проверено сохранение уже выданных
  разрешений при штатном обновлении.
- Реальная запись не запускалась, чтобы не создавать пользовательское аудио в
  release evidence.
- Public-link readback остаётся выключен действующей политикой безопасности.
