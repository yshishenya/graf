# v2026.08.12.3 — универсальный macOS installer

## Что изменилось

- GRAF распространяется одним `graf.pkg` для Apple Silicon и Intel.
- В приложении один universal Mach-O с архитектурами `arm64` и `x86_64`.
- Публичная страница использует одну ссылку на этот пакет.
- Retired privileged audio component не входит в source, build, installer или
  validation path.

## Validation evidence

- `infra/scripts/ci-local.sh`: `ci_local_result=pass`; 657 Swift-тестов,
  2889 parallel server-тестов и 42 strict-теста прошли.
- Universal package: `lipo -archs` → `x86_64 arm64`; один desktop component.
- Apple notarization: submission `c8f9bc06-138a-4cad-bbb3-fd0f4c5d168e`,
  status `Accepted`; stapler validate и `spctl` прошли.
- Public asset SHA-256:
  `6c6cb57affebd65430c8b49a4636506638950e6ecb9fc4c88b638b6067342c5c`.

## Compatibility и migration impact

- macOS 14.5 и новее; Apple Silicon и Intel.
- Пользовательский путь один: скачать `graf.pkg`; выбор архитектуры не нужен.
- Установка не требует миграции данных и не устанавливает virtual audio driver.

## Known limitations

- Live public download receipt после deploy остаётся операционным gate и не
  фабрикуется локальной проверкой.
