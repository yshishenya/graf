# GRAF `v2026.08.15.4` — единая тёмная визуальная система

## Что изменилось

- Кабинет GRAF и нативный macOS shell получили согласованную тёмную визуальную
  систему: мягкие радиусы, спокойнее поверхности, единые акцентные цвета,
  расстояния и веса текста.
- Сохранены ручные действия записи, доступность элементов управления и
  системные шрифты без внешних загрузок.
- Контракт публичной авторизации синхронизирован с текущим customer-only
  workspace boundary: публичный список провайдеров больше не принимает
  внутренний `workspace_id`, а устаревший admin invitation completion route
  удалён из контракта.

## Совместимость и обновление

- Новых миграций базы данных, изменений формата записей или переноса данных нет.
- Сервер совместим с предыдущим desktop-клиентом; macOS UI-изменения вступят в
  силу только после отдельной подписанной и notarized публикации приложения.
- PR #4972 закрыт и не вливался целиком: его история содержала опасные удаления
  billing/auth/webhook-кода. В `master` перенесён только проверенный UI-срез:
  [clean branch](https://github.com/yshishenya/crisp/tree/codex/144-clean-ui-modernization).

## Проверка

- Полный локальный gate `infra/scripts/ci-local.sh --full` выполнен на точном
  релизном SHA; результат и число тестов зафиксированы в production receipt.
- В составе gate: macOS build, 671 Swift-тест, contract validation, полный
  PostgreSQL/server suite, lint, compile, deployment-readiness и secret scan.
- Дополнительно: OpenAPI runtime/committed contract equality, migration smoke и
  personal workspace admin boundary — PASS.

## Выкатка и ограничения

- Серверный runtime выкатывается на `master` через backup, restore rehearsal,
  миграции, health checks и production smoke.
- Публичная macOS раздача не выполняется этим серверным релизом: для неё нужен
  отдельный Developer ID build, Apple notarization, stapling, Gatekeeper и
  Sparkle feed validation. Неподписанный или локально подписанный артефакт не
  публикуется.
- GitHub Release должен содержать эти русские release notes и ссылки на
  production evidence; откат выполняется только на ранее проверенный SHA.
