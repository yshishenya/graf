# GRAF `v2026.08.19.1` — аккуратнее панели, таймлайны и настройки

Дата выпуска: 2026-08-19

Тег: `v2026.08.19.1`

Release SHA: `3ebb8d450feeb6dc49656e57534f02bf3f2e1ac8`

## Что стало удобнее

- Таймлайны встреч с одним–тремя спикерами занимают естественную высоту, а для
  больших встреч сохраняется безопасное расширение панели.
- Левое меню на широком окне открывается сразу, на узком остаётся компактным и
  больше не сбрасывает ручной выбор из-за клика по содержимому.
- Переключатель native-панели macOS закреплён сверху и остаётся в одной точке
  после раскрытия и сворачивания.
- Компактное меню, профиль и нижний плеер выровнены по общей сетке без пустых
  полос и перекрытий.
- В настройках убрана пустая колонка от старого второго меню.

## Что нужно сделать после обновления

Обычно — ничего. Штатное обновление Developer ID → Developer ID сохраняет уже
выданные разрешения macOS. При первой установке на новом Mac система может один
раз попросить доступ к микрофону и системному звуку.

## Как проверяли

- Полный exact-SHA gate: macOS — `695` тестов; сервер — `3049 passed / 1
  skipped`; strict RLS — `42 passed / 1 skipped`; lint, compile, Compose и
  evidence scan — успешно.
- Production deploy: backup, restore rehearsal, миграции, readiness, smoke и
  фоновые обработчики — успешно; откат не понадобился.
- macOS: Developer ID Application и Installer, universal `arm64 + x86_64`,
  Apple notarization, stapling, Gatekeeper, Sparkle Ed25519 и обновление с
  `2026.08.18.2` — успешно.
- Установленный production GRAF обновлён штатно до `2026.08.19.1`; приложение
  перезапустилось без нового permission prompt и показало готовность микрофона
  и системного звука.
- `GRAF Dev` пересобран и атомарно обновлён отдельно от production; bundle ID
  `pro.2brain.graf.dev`, origin `127.0.0.1:8081`, production updater отсутствует.
- Web проверен во встроенном браузере на обычной и узкой ширине `800×720`:
  горизонтального переполнения и ошибок консоли нет, download CTA доступен,
  отдельной кнопки «Зарегистрироваться» нет.

## Совместимость и ограничения

- Миграции пользовательских данных и новые зависимости не нужны.
- Генерация новых итогов не менялась в этом релизе; текущий принятый результат
  не заменяется автоматически.
- Clean-Mac first-grant не повторялся: финальная проверка подтверждает именно
  сохранение уже выданных разрешений после штатного обновления.
- Реальная запись не запускалась, чтобы не создавать пользовательское аудио в
  release evidence.
- Public-link readback остаётся выключен действующей политикой безопасности.
