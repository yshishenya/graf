# GRAF `v2026.07.26.9` — исправление browser-приглашений

Дата выпуска: 2026-07-26
Тег: `v2026.07.26.9`

Feature PR: [#4671](https://github.com/yshishenya/crisp/pull/4671)
GitHub Release: [v2026.07.26.9](https://github.com/yshishenya/crisp/releases/tag/v2026.07.26.9)

## Что изменилось

- Повторное, просроченное или недоступное приглашение в браузере теперь
  показывает понятную HTML-страницу GRAF вместо технического JSON-файла.
- Явные API-запросы с `Accept: application/json` сохраняют прежний Problem
  Details-ответ.
- Одноразовость ссылки, привязка к получателю, CSRF, сессия, grant и RLS не
  изменены; страница ошибки не раскрывает секреты или содержимое встречи.
- Опубликовано обновление macOS `2026.07.26.8 → 2026.07.26.9` через обычный
  Developer ID → Developer ID Sparkle-путь.

## Проверка

- Focused invitation matrix: `32 passed`.
- macOS: сборка, `640 passed` и `ContractValidation` — pass.
- Server full local stage: `2446 passed / 1 skipped`; отдельный существующий
  SC-017 performance threshold под полной параллельной нагрузкой дал
  `52.18 ms` при пороге `50 ms`, а изолированный тест прошёл.
- Ruff, Python compile, Compose config, deployment evidence scan, Apple
  notarization, stapling и Gatekeeper-проверки — pass.

## Совместимость и ограничения

- Новых миграций базы данных и изменения формата email нет.
- Клиентам до `.6` по-прежнему нужен одноразовый notarized `.pkg` bootstrap;
  после него обновления идут через обычный Developer ID → Developer ID Sparkle.
- Известное ограничение валидации: SC-017 — timing-sensitive benchmark,
  который может пересекать порог только под полной параллельной нагрузкой.
- Откат выполняется только на ранее проверенные подписанные артефакты через
  guarded deployment runbook; неподписанный downgrade запрещён.

Release evidence содержит только агрегированные технические результаты и не
записывает пользовательские данные.
