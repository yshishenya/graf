# v2026.08.23.10 — автозапись по умолчанию с подтверждением

## Что изменилось

- На чистой установке после первого валидного реестра GRAF включает режим
  определения встреч и выбирает все проверенные native-приложения, для которых
  доступен prompt.
- Первый prompt появляется автоматически. До явного подтверждения кнопка
  «Записать сейчас» запускает только текущую запись; timeout и сохранённый
  автоматический старт запись не запускают.
- «Всегда писать это приложение» сохраняет выбор приложения и актуальное
  подтверждение только после успешной atomic-записи настроек.
- Assisted auto-start поддерживает явный `all_workspaces` scope с отдельным
  approval-флагом. При global scope workspace ID запрещён, а policy/subject/device
  references остаются opaque и tenant-bound.

## Совместимость и миграция

- Существующий settings file и legacy JSON без marker не перезаписываются;
  пользовательские target selection и режим сохраняются.
- Server policy остаётся disabled по умолчанию; включение production policy и
  внешний participant notice rollout не входит в этот релиз.
- Bundle identity, Developer ID → Developer ID Sparkle trust chain и ручные
  Record/Stop сохраняются.

## Известные ограничения

- Без acknowledgement первая запись по timeout не стартует — требуется явное
  действие пользователя или последующее сохранение «Всегда писать это приложение».
- Synthetic/unit evidence не заменяет production smoke и health evidence; они
  будут добавлены в deployment receipt после выкладки.
