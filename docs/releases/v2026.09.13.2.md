# GRAF v2026.09.13.2 — системная тема

Статус: подготовка к выпуску. Версия ещё не опубликована.

## Что изменится

«Системная» тема страницы встречи и настроек будет использовать те же цвета,
что «Светлая» или «Тёмная», в зависимости от оформления операционной системы.
Изменение темы ОС автоматически обновит открытый кабинет без перезагрузки.
Выбранная вручную тема GRAF сохранит приоритет.

## Проверка

- 155 целевых тестов кабинета и настроек: PASS.
- 240 сравнений вычисленных палитр Chromium/WebKit: PASS; проверены обе темы
  ОС, обычная и встроенная разметка, узкое и широкое окно, включённый и
  выключенный JavaScript. Исходный CSS воспроизводит ошибку тем же сценарием.
- Сухой запуск CD: PASS как план действий; решение о выпуске ещё не передано.
- Проверка GitHub `governance-fast` относится к точному SHA PR; её актуальный
  результат и ссылка указываются в PR, а не подменяются локальными тестами.

## Совместимость

Изменений данных, миграций БД, сохранённых настроек, API и нативного моста
темы нет. Исправление находится в общих стилях серверного кабинета.

## Ограничения и выпуск

До публикации необходимо принять PR, зафиксировать итоговый SHA кандидата,
пройти `release-full`, получить решение `go` и проверить установленный GRAF Dev.
После этого выполняются разрешённый выпуск, проверки сервера и, для публичного
пакета macOS, Developer ID, notarization, stapling, Gatekeeper и Sparkle.
Ни публикация, ни production deploy этим документом не подтверждаются.

Откат серверного изменения — возврат к предыдущему проверенному образу;
новых миграций или преобразований пользовательских данных нет.
