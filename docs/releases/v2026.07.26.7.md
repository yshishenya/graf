## Что изменилось

- Исправлен HTTP 500 при первом входе нового получателя по invitation
  magic-link.
- Pending auth-аудит теперь явно записывается в personal workspace до смены
  RLS-контекста на workspace встречи. Для этого использован один flush в
  существующей `AsyncSession`; новые абстракции и миграции не добавлялись.
- Сохранены exact-recipient, CSRF, replay, expiry/revoke, grant и post-commit
  notification boundaries.

## Совместимость и ограничения

- Новых миграций базы данных и переноса пользовательских данных нет.
- Системный `/Applications/GRAF.app` не заменялся автоматически: для ручного
  bootstrap macOS потребовала локальную admin-аутентификацию.
- v6 bootstrap нотарифицирован Apple. Для v7 в текущем release-operator
  окружении нет Apple notarization credentials, поэтому v7 notarization staple
  и Gatekeeper public-trust не заявляются; проверена Developer ID signature и
  Sparkle continuity для уже доверенного v6 клиента.
- Post-deploy retry/backfill/range/normalization остаются отдельными
  `required_post_deploy` проверками CD и не входят в этот hotfix.
