# ГРАФ v2026.08.21.6

## Что изменилось

- Обновлён публичный лендинг ГРАФ и страница скачивания в едином дизайне.
- Опубликованы тарифы 1 000 ₽/месяц и 10 000 ₽/год с семидневным пробным периодом.
- Добавлены безопасные цели публичной воронки для Яндекс Метрики без передачи содержимого встреч и аккаунтов.
- Публичный тариф теперь показывается только при совпадении с утверждённой версией серверного каталога.

## Проверка

- Целевые unit/contract-тесты, Ruff, проверка синтаксиса JavaScript, Python compile и `git diff --check` проходят.
- Полный exact-SHA CI выполняется на изолированном временном worktree на `2brain.dev`; его результат должен быть зафиксирован в validation evidence до выкладки.
- Production database и работающие production-контейнеры не используются в тестах.

## Совместимость и ограничения

- Публичная загрузка остаётся только для macOS 14.5+; Windows и Linux не входят в этот релиз.
- Оплата остаётся fail-closed и открывается только после действующих billing launch gates.
- Полный релиз требует отдельного merge, production smoke, rollback evidence и проверки exact SHA.
