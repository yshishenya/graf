## Совместимость и ограничения

- Клиентам до `.6` нужен ручной notarized `.pkg` bootstrap; после него
  обновления идут только Developer ID → Developer ID через Sparkle.
- Новых миграций базы данных и переноса пользовательских данных нет.
- Rollback выполняется только на ранее проверенные подписанные артефакты и
  через guarded deployment runbook; unsigned downgrade через appcast запрещён.
- Обязательные post-deploy maintenance checks (`automatic_retry`, `backfill`,
  `range_playback`, `normalization_cleanup`) остаются отдельным follow-up и не
  меняют результат основного deploy gate.

Release evidence содержит только агрегированные технические результаты и не
записывает пользовательские данные.
