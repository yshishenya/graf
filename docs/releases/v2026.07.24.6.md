  расшифровки; удаление и гонки публикации закрываются серверными блокировками.

## Совместимость и миграции

- Добавлена merge-миграция `0040_merge_content_regeneration_and_share_heads`;
  она сводит Feature 125 auth/share и Feature 124 lifecycle-ветки. Проверено
  повышение существующей production-схемы с `0037_auth_rate_limit_buckets` до
  `0040_merge_content_regen_share`; Alembic применяет sibling-ветку `0032–0039`
  перед merge-head, публичный API захвата не меняется.
- Миграции `0035` и `0039` сохраняют разрешённую операцию
  `prompt_optimization`, поэтому изолированный worker не теряет доступ после
  обновления RLS helper.
- Если legacy lineage markers блокируют downgrade `0039`, rollback сохраняет
  безопасную схему `0040`, закрывает automatic dispatch и запускает
  compatibility runtime. Старый checkout не запускается против неизвестной
  merge-head схемы; при отсутствии legacy markers обычный rollback возвращает
  предыдущий checkout и схему.
- Старые записи сохраняются через legacy lineage/backfill; native macOS
  system-audio-first capture не изменён.
- История сравнения, отката и ручного выбора старых вариантов остаётся будущим
  отдельным срезом.
