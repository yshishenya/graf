Дата выпуска: 2026-07-27

Feature: [133 — полный egress внешнего приглашения](../../specs/133-share-egress-access/spec.md)

## Что изменилось

- Получатель с полным доступом может воспроизводить запись после открытия
  приглашения.
- Доступны скачивание аудио и расшифровки.
- Доступны существующие отчёты `summary`, `transcript` и `combined` в их
  текущих форматах.
- Подтверждение получателя сохраняется во всех повторных проверках egress.

## Проверка

- Focused full-invitation flow: `1 passed`.
- Полный local CI на merged feature SHA: macOS `642 passed`, server parallel
  `2456 passed / 1 skipped`, strict RLS `42 passed / 1 skipped`.
- Ruff, Python compile, ContractValidation, Compose config и deployment
  evidence scan прошли.
- Local RLS hardening boundary корректно не выполнял production probe без
  production database.

## Совместимость и ограничения

- Миграции базы данных, новые endpoints и новые storage URLs не требуются.
- `summary-only`, revoke, expiry, deletion, policy и storage/revision gates
  остаются ограниченными.
- Клиентам до `v2026.07.26.6` по-прежнему нужен одноразовый Developer ID
  notarized `.pkg` bootstrap; более новые клиенты используют обычный
  Developer ID → Developer ID Sparkle update.
- Откат выполняется только на ранее проверенные подписанные артефакты через
  guarded deployment runbook.

## Публикация и выкатка

- macOS public candidate обязан пройти Developer ID Application/Installer,
  notarization, stapling, Gatekeeper и Sparkle continuity checks.
- Production deploy выполняется на том же immutable SHA после
  `infra/scripts/cd-remote.sh --dry-run`.
- Фактические artifact checksums, smoke и remote deployment receipt
  фиксируются после успешной публикации.

Все committed evidence остаётся metadata-only и не содержит пользовательских
данных встречи.
