# GRAF `v2026.08.03.5` — надёжное сохранение аудиозаписи

Тег: `v2026.08.03.5`

## Что изменилось

- Устранена ложная ошибка выравнивания аудиопотоков при обычной задержке
  доставки системного звука.
- При реальном сбое финализации сохраняется уже принятый локальный звук и
  записывается безопасный диагностический код.
- Неполная запись не отправляется на сервер как готовая; пользовательская
  история старых записей не переписывается.

## Совместимость

- Миграции базы данных не требуются.
- Обновление устанавливается поверх `2026.08.03.4`.
- Исторические записи читаются без изменения их исходного статуса.

## Проверка

- Полный macOS build и `ContractValidation` пройдены.
- Полный набор из 645 macOS-тестов пройден без ошибок.
- Server full lane выполняется как exact-SHA release/deploy gate.

## Откат

До публикации сохраняются предыдущий пакет и предыдущий appcast. При
необходимости rollout останавливается восстановлением последнего проверенного
appcast; уже обновившимся клиентам нужен только новый более высокий CalVer.
