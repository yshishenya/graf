# v2026.08.23.11 — тихая подпись источника записи

## Что изменилось

- В верхней капсуле записи теперь тихо показывается, какое приложение
  записывается: `Источник · <приложение>`.
- Для ручной записи системного звука остаётся короткая подпись `Системный
  звук`, а при отсутствии подтверждённых данных — `Источник не определён`.
- Дублирующая строка источника в боковой панели убрана. Pause/Resume/Stop
  остались отдельными действиями, а длинные названия сокращаются без переноса.

## Проверка

- Focused macOS: `CaptureIndicatorTests` 13/13 и
  `AppControlAccessibilityTests` 22/22.
- Полный Swift suite macOS: 753/753; `ContractValidation: PASS`.
- Legacy-audio guard и локальная сборка приложения прошли.
- Локальная metadata-only проверка подтвердила active, paused, narrow и
  finalized состояния; после Stop подпись исчезает.
- Server CI пропущен по явному указанию владельца релиза: Feature 197 не
  меняет `apps/server`, `infra` или серверные контракты. Это не считается
  успешным полным CI.

## Совместимость и миграция

- Серверный API, схема данных и формат записи не меняются.
- Существующий bundle identity и ручные Record/Stop сохраняются.
- Новых зависимостей, сетевых вызовов и изменений разрешений нет.

## Известные ограничения

- Проверка использует безопасные synthetic metadata и локальный smoke; реальные
  встречи, аудио и расшифровки в evidence не записывались.
- Публичная macOS-публикация отдельно требует Developer ID, notarization,
  stapling, Gatekeeper и Sparkle-проверки.
