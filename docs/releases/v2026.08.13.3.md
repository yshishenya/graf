# v2026.08.13.3 — автоматическая запись встреч

## Что изменилось

- GRAF научился находить поддерживаемые встречи и заранее показывать, что
  запись начнётся автоматически.
- Добавлены локальный буфер и безопасное подтверждение области записи.
- Улучшены настройки автоматической записи и обратная связь во время захвата.
- Универсальный установщик поддерживает Apple Silicon и Intel.

## Совместимость

- macOS 14.5 и новее.
- Обновление выполняется через подписанный Sparkle-архив поверх предыдущей
  Developer ID-версии.
- Миграции пользовательских данных не требуются.

## Проверка

- Developer ID Application и Developer ID Installer.
- Apple notarization, stapling и Gatekeeper.
- Sparkle-архив и appcast будут опубликованы только после отдельной проверки
  подписи и публичных ссылок.
