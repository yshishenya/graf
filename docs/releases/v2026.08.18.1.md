## Что изменилось для пользователя

- Итоги и расшифровка остаются доступны при прокрутке длинной встречи.
- Дорожки спикеров можно расширять мышью и клавиатурой; постоянная подсказка
  объясняет переход к фрагменту записи.
- Основная и settings-навигация используют одну понятную боковую область.
- В macOS shell добавлена кнопка «Домой» при сохранённых Back, Forward и
  Reload.
- Установленный production GRAF обновляется через Developer ID → Developer ID;
  отдельный канал `GRAF Dev` использует стабильный bundle ID и loopback-only
  origin.

## Исправления

- После обычного обновления разрешения production GRAF сохранились: приложение
  после relaunch сообщило «Микрофон и системный звук готовы».
- Восстановление Screen & System Audio честно сообщает о необходимости
  перезапуска после ручного изменения разрешения в macOS.
- Переименование спикера не перезапускает аудио и не сбрасывает позицию.
- Поиск встреч и download CTA не перекрываются на узком экране; в embedded
  surface нет лишнего CTA скачивания.
