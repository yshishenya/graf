# GRAF `v2026.08.18.2` — спокойнее разбирать встречи и обновлять приложение

Дата выпуска: 2026-08-18  
Тег: `v2026.08.18.2`  
Release SHA: `e6e838b5870de2b882890d5b306c477493dd9f2e`

## Что стало удобнее

- Верхняя часть встречи с названием и вкладками остаётся на экране, пока вы
  прокручиваете длинную расшифровку или итоги.
- Боковая панель сразу выбирает понятное состояние для широкого и узкого окна;
  при наведении и фокусе кнопка объясняет, что именно произойдёт.
- Дорожки спикеров можно растягивать, когда участников много, а постоянная
  подсказка объясняет переход к нужному фрагменту записи.
- Переименование спикера больше не прерывает текущее воспроизведение.
- В web-сценарии ссылка на приложение заметнее, а во встроенном GRAF нет
  предложения скачать уже открытое приложение.
- Для локальной разработки остаётся отдельный канал `GRAF Dev`, который не
  смешивает данные, обновления и разрешения с production GRAF.

## Что нужно сделать после обновления

Обычно — ничего. Production GRAF обновляется штатно, а выданные macOS
разрешения сохраняются при обычном обновлении с Developer ID на Developer ID.
При первой установке нового канала macOS может один раз попросить доступ к
микрофону и системному звуку — это нормальное системное подтверждение.

## Как проверяли

- Полный exact-SHA gate: macOS `693` теста; сервер `3046 passed / 1 skipped`;
  strict RLS `42 passed / 1 skipped`; lint, compile, Compose и evidence scan —
  успешно.
- Production: backup, пробное восстановление, миграция, health/readiness,
  smoke-загрузка и запуск фоновых обработчиков — успешно.
- macOS: Developer ID, Apple notarization, Gatekeeper, подпись Sparkle и
  обновление с предыдущей версии — успешно.
- После публикации ZIP, PKG и appcast скачаны заново по HTTPS и совпали с
  проверенными файлами.

## Известные ограничения

- Генерация новых итогов не входила в этот релизный срез; текущий принятый
  результат не заменяется автоматически.
- Первый grant разрешений на новом Mac остаётся одноразовым действием
  пользователя; сброс TCC и обход системных диалогов не используются.
- Public-link readback остаётся выключен действующей политикой безопасности.
