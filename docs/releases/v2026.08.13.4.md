# v2026.08.13.4 — явное окружение YooKassa и локальный release-контур

## Что изменилось

- Окружение YooKassa (`test` или `production`) теперь задаётся отдельной
  server-owned настройкой и больше не определяется по адресу API.
- Checkout, renewal, webhook и reconciliation используют одну и ту же
  проверенную пару окружение + shop ID.
- Edge-маршрут webhook ограничен явными окружениями, а проверка test shop
  выполняется последовательно на той же установке без включения checkout.
- Локальный Sparkle release-контур работает через named macOS Keychain,
  проверяет provenance, предыдущую версию, безопасность ZIP и draft-only upload.

## Совместимость и миграция

- Сервер сохраняет production по умолчанию; `TWOBRAIN_BILLING_CHECKOUT_ENABLED`
  остаётся `false`.
- Пользовательские данные и формат macOS-приложения не меняются.
- macOS installer остаётся универсальным для macOS 14.5+, Apple Silicon и
  Intel; отдельная физическая Intel-проверка не входит в этот выпуск.
