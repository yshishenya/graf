# GRAF `v2026.08.16.1` — публичный лендинг и подписанное macOS-обновление

## Что изменилось

- Лендинг получил более прямой путь от первого экрана к продуктовым доказательствам.
- Добавлены читаемые desktop/mobile-снимки расшифровки, итогов и управления записью.
- В hero добавлена пауза показа, а CTA и публичная аналитика приведены к единому контракту.
- В настройки и нативный экран автозаписи вошли изменения из объединённого PR #5126.
- Для macOS подготовлены universal Developer ID Application/Installer-артефакты с Apple notarization и Sparkle-подписью.

## Совместимость и обновление

- Сервер совместим с предыдущими клиентами.
- macOS поддерживает Apple Silicon и Intel, macOS 14.5+.
- Обновление идёт по обычной цепочке Developer ID → Developer ID через Sparkle.
- Checkout YooKassa остаётся выключенным до отдельного canary и финансово-юридических подтверждений.

## Проверка

- `infra/scripts/ci-local.sh --fast`: 1088 тестов, lint и compile — PASS.
- macOS package: universal `arm64` + `x86_64`, Developer ID, Apple notarization, stapler и Gatekeeper — должны быть подтверждены в production receipt.
- Sparkle archive/appcast подписываются локальным Keychain signer и проверяются на предыдущем Developer ID-релизе.
- GitHub Actions не запускались.

## Ограничения и откат

- Публичный billing checkout не включается этим релизом.
- При проблеме обновления восстановить предыдущий подписанный appcast и сохранить предыдущий ZIP; неподписанный downgrade запрещён.
