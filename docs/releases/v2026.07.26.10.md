# GRAF `v2026.07.26.10` — скачивание аудио владельцем встречи

Дата выпуска: 2026-07-26
Тег: `v2026.07.26.10`

Feature PR: [#4673](https://github.com/yshishenya/crisp/pull/4673)
Feature: [131 — скачивание аудио владельцем по умолчанию](../../specs/131-owner-audio-download/spec.md)

## Что изменилось

- Владелец встречи может скачать готовое аудио без отдельного разрешения.
- Web cabinet и встроенный macOS cabinet используют тот же server-mediated
  маршрут и одинаковое состояние действия.
- Явный запрет для конкретной встречи и доступ не-владельца по-прежнему не
  дают скачать аудио.

## Проверка

- Feature 131 focused PostgreSQL suite: `57 passed`.
- macOS: `642` теста и `ContractValidation` прошли.
- Изолированная проверка известного SC-017 timing-sensitive benchmark: `1
  passed`; полный параллельный запуск сохранил независимый failure по порогу
  p95 (`136.764875 ms` при лимите `50 ms`).
- Ruff, `node --check`, Python compile, Compose config и deployment evidence
  scan прошли на соответствующих этапах.
- Перед публикацией обязательны Developer ID Application/Installer,
  notarization, stapling, Gatekeeper и Sparkle continuity `2026.07.26.9 →
  2026.07.26.10`.

## Совместимость и ограничения

- Миграции базы данных и перенос пользовательских данных не требуются.
- Существующие политики transcript, summary, package, playback и удаления не
  изменяются.
- Клиентам до `v2026.07.26.6` по-прежнему нужен одноразовый notarized `.pkg`
  bootstrap; клиенты после него обновляются обычным Developer ID → Developer
  ID Sparkle-путём.
- SC-017 остаётся отдельным load-sensitive ограничением полной локальной
  матрицы; его изолированная проверка проходит.
- Откат выполняется только на ранее проверенные подписанные артефакты через
  guarded deployment runbook; неподписанный downgrade запрещён.

## Выкатка

- Сначала публикуются и проверяются versioned ZIP/PKG и checksums.
- Затем заменяется appcast, после чего выполняется update smoke с `v9` на
  `v10` и production deploy на том же immutable SHA.
- Release evidence содержит только агрегированные технические результаты и не
  записывает пользовательские данные.
