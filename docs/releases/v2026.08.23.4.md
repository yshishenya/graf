# ГРАФ `v2026.08.23.4` — единый ввод email-кода

Дата выпуска: 2026-08-23

Тег: `v2026.08.23.4`

Release SHA: `9c67e1b89050f202582dcf602d8860e9b92d36ce`

## Что изменилось

- Во всех найденных email-code сценариях web и встроенного macOS-кабинета
  пользователь видит шесть отдельных квадратных ячеек, по одной цифре в каждой.
- Общий server-rendered компонент сохраняет вставку, автозаполнение,
  клавиатурную навигацию и прежний серверный параметр `code`.
- Проверены login, signup, invitation, browser account-link и desktop
  account-link. Отдельной нативной копии OTP-компонента в macOS нет.

## Совместимость

- Формат серверной проверки кода не менялся.
- Миграция пользовательских данных и новые зависимости не требуются.
- Действия пользователя после обновления не нужны.
- Нативный macOS-артефакт отдельно не выпускался: embedded cabinet использует
  тот же server-rendered экран, что и web.
