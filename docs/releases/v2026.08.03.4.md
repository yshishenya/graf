# GRAF `v2026.08.03.4` — стабильный вход в личный кабинет

Тег: `v2026.08.03.4`

## Что изменилось

- Исправлен повторный запуск входа через Yandex после перехода на страницу
  авторизации. Личный кабинет больше не перезагружает внешний экран входа при
  каждом обновлении интерфейса.
- После успешной авторизации пользователь возвращается в личный кабинет, а не
  остаётся на бесконечно обновляющемся экране загрузки.

## Совместимость

- Миграции базы данных не требуются.
- Обновление устанавливается поверх `2026.08.03.3`.

## Проверка

- 15 тестов маршрутизации кабинета.
- Полный набор из 643 macOS-тестов.
- Серверный fast lane и macOS fast build в CI.
